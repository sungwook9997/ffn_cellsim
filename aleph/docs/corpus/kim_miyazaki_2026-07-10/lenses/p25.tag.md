# TAG-validation lens — p25

**Paper:** Slater, Jung & Kim (2024), "Emergence of diverse patterns driven by molecular motors in the motility assay," *Cytoskeleton* 81(12):902–912. DOI 10.1002/cm.21808. Kim lab (Purdue Weldon BME).

## Paper kind

**simulation** (agent-based Brownian-dynamics model output — NOT experimental measurement, NOT analytic closed-form).

This is the Kim-lab agent-based actin/myosin framework (Langevin + Euler, parallel-cluster-model motors) run as an *in-silico mimic* of the myosin motility (gliding) assay. Every quantitative result is a model output, so under our philosophy it is **comparison-only, never a truth source and never a fit target**. It cannot become an acceptance oracle. Its value to us is (a) as the SAME engine lineage FF emulates (semiflexible filaments = connected cylindrical segments with extensional+bending+repulsive potentials, explicit surface-anchored motors with force-velocity walking + force-dependent unbinding), so it is a natural *cross-model reproduction* target for FF's collective-pattern regime, and (b) it supplies measurement-protocol definitions (velocity correlation, curl, homogeneity Q) we could adopt for FF collective runs. Note also: the KB already carries a Kim-lineage relationship (see the DCM⊗ECM-vs-Kim work), so this sits inside an already-recognized comparison family.

**Hard caveat on the numbers:** most magnitudes in the paper are read off heatmap color bars (velocity-corr ~0.5–0.95; curl ~0.018–0.033), and every load-bearing physical constant (κb*, κr*, motor stall force, PCM on/off rates, drag coefficients, r0,A, stretching stiffness) lives in Supporting Information Table S1, which is NOT in the available text. So even as a comparison target this paper is **regime/trend-level, not tight single-value**.

## Coverage vs existing gates

- **VG-U5-velocity-correlation** (`372120daec5d81568aeccf1833ae7dee`, observable C(r), ξ_v ~50–200 µm epithelial monolayer): **NOT the same observable.** This paper's velocity correlation (item 3) is the mean absolute cosine of *filament-endpoint* velocity alignment in a reconstituted 2-D motor assay, a molecular-scale active-matter metric — not a cell-centroid correlation length in an epithelial monolayer. Different engine (FF filaments vs collective CBM), different scale, different definition. It neither confirms, tightens, nor challenges VG-U5. At most it offers a *protocol* (Eq 1, <0.5 µm cutoff) reusable for FF collective runs. **No overlap → no tighten.**
- **VG-U3-cortex-multifilament** / **MC-U3-cell-integration**: our cortex is semiflexible connected filaments with Bell-Evans crosslink dynamics — mechanistically adjacent, but this paper is a free gliding assay (no cortex geometry, no crosslinkers, no turgor), so no gate overlap.
- **F_stall_motor** param (`PARAM-F_stall_motor`, default 2 pN): related in spirit (motor stall drives gliding speed), but this paper's stall force is inside PCM/SI Table S1 and not extractable here → cannot confirm/supersede.
- **PARAM-kappa_fiber / PARAM-ell_p** (κ_fiber = ℓ_p·k_BT): Eq 2 (item 11) is the same standard discrete-WLC persistence-length relation we already encode. It **confirms our existing convention** (nothing new); not a new oracle.
- No existing gate covers emergent motility-assay pattern regimes (network/flock/band/ring), curl, or the critical-concentration band-collapse. Those are genuinely uncovered — but see the philosophy caveat below before proposing them as contracts.

## New gate candidates

All flagged **candidate — PI-gate review, COMPARISON-ONLY** (source is a *simulation*, so any gate built on it is a cross-model reproduction check, explicitly NOT an acceptance oracle and NOT a fit target). Propose only if/when FF grows an explicit surface-anchored-motor gliding-assay mode; none is defensible as a tight single-value band today.

1. **proposed_vg_id CAND-FF-motility-regimes** — observable: emergent structure class of a periodic quasi-2D myosin gliding assay of semiflexible filaments; expected: the ordered sequence **network → flock → band → ring** as repulsion↑ / bending-stiffness↓, with the 4 classes all reproducible. Condition: 10×10 µm² PBC, ⟨L⟩≈2.5 µm, effective myosin ~96 µM, 100 s. Engine: **FF** (motor-assay mode). Source: Figs 1–6, p5–10. *Qualitative regime gate — no numeric band; comparison-only.*
2. **proposed_vg_id CAND-FF-motility-Ccrit** — observable: presence of thick coherent bands vs actin concentration; expected: **thick bands vanish for C < 60 µM** (collectivity threshold) in the reference κr/κb window. Engine: **FF**. Source: Fig 2, p7. *Threshold/trend gate; the 60 µM is a model output, so band-collapse is the assertion, not the exact value; comparison-only.*
3. **(weak) proposed_vg_id CAND-FF-motility-curvature-order** — observable: mean filament curvature ordered ring > band > flock > network. Engine: **FF**. Source: Fig S7f, p6. *Ordinal check only; list for completeness, low priority.*

## Param candidates

**None registrable as sourced physical constants.** The extractable numbers (CM = 12 µM, 8 heads/motor arm, effective myosin 96 µM, ⟨L⟩ref 2.5 µm, C 15–120 µM, Δt 1.15×10⁻⁵ s) are *modeling conventions / numerical choices of a simulation*, not measured in-vitro values — so they must not enter the Parameter table as sourced constants. The physically-anchored constants that WOULD be candidates (motor stall force, PCM on/off & walking rates, drag coefficients, κb*, κr*, r0,A) are all deferred to SI Table S1, which is unavailable here. **Flag:** if the SI is retrieved later, re-scan Table S1 for a PCM stall-force / off-rate that could cross-check `PARAM-F_stall_motor` (2 pN) and our Bell-Evans/Hill oracle configs — but treat as cross-model, not a fit source. n_params = 0.

## Oracle candidates

**None new.** Eq 2 (l_p = κb·r0/k_BT) is the standard discrete-segment WLC persistence-length identity we already encode via `PARAM-kappa_fiber = ℓ_p·k_BT` — it confirms our convention rather than adding an oracle. Eqs 1 (velocity correlation), 3 (tangent-vector correlation → l_p fit to exp(−Δs/l_p)), and 4 (morphology homogeneity Q) are *measurement-protocol definitions*, not closed-form ground-truth laws; they could be adopted as FF collective-run analysis protocols but are not acceptance oracles. The PCM (Erdmann–Schwarz) motor kinetics are an alternative to our Hill force-velocity oracle — noted as a mechanistic cross-reference, not adopted (our runtime uses Hill + Bell-Evans per the architectural principle).

## Duplicates / notes

- **Same engine lineage as FF and as prior KB work.** This is the Kim-lab Brownian-dynamics actin framework; the KB already recognizes the Kim relationship (DCM⊗ECM-vs-Taeyoon-Kim comparison). Not a duplicate claim, but firmly inside an existing comparison family — FF's fine-grained filament+motor physics is the "native" version of this coarse model.
- **DCM: not relevant** (no membrane/cortex-tension/turgor/junction content).
- **Reproducibility caveat:** 1 run per condition (cost of explicit motors); authors assert cross-run stochastic variation is non-significant but provide no ensemble — another reason to treat all magnitudes as trend-level.
- **Provenance gap:** load-bearing constants in SI Table S1 (not available). Any future param/oracle work must fetch the SI first.
- **Net:** high mechanistic *relevance* to FF, low *new-contract* yield — it adds qualitative/ordinal regime targets and reusable metrics, not tight bands or sourced constants.
