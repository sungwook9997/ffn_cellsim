# TAG-validation lens — p38

**Paper:** Yamazaki, Miyata, Morigaki, Miyazaki (2024) — *Controlling Physical and Biochemical Parameters of Actin Nucleation Using a Patterned Model Lipid Membrane.* Nano Lett. 24(5), 1825–1834. DOI 10.1021/acs.nanolett.3c02742.

## Paper kind

**experimental** — in-vitro reconstitution / biomimetic membrane micropatterning. Purified-protein and crude-extract actin self-organization on a photopolymerized-DiynePC / fluid-POPC micropatterned supported lipid bilayer. No mathematical model, no integrator/timestep, no closed-form governing physics. Optical readouts only (confocal 3D, TIRF, pyrene kinetics, FI quantification). The single quantitative relation (FI = 157.7·x − 2.32) is an **instrument-specific calibration fit**, not a physical law.

Consequence for use: all numbers are **overlay / on-demand cross-check** targets (reconstitution values, per the philosophy "lab reconstitution values are on-demand cross-checks, not truth"). Nothing here is an analytic oracle candidate. Nothing is fit-to.

## Coverage vs existing gates

- **No existing gate covers NPF/nucleator surface density.** The closest contracts are `VG-U3-lamellipodia-separation` (blocked, Phase-2 entry; wants per-instance {r_LE, p, w_L, n_barbed, v_p}, Bieling-2016 branching) and `VG-U3-cortex-multifilament` (blocked; N_filaments ≥ 50, KB-3.18/3.19/3.20). Neither carries a nucleation-site areal-density band. Items #1–#3 are **new, uncovered** — but they are seeding/initialization inputs, not emergent single-cell observables, so they belong as a **Parameter with a defensible range**, not a gate.
- **Architecture dichotomy (#10)** maps directly onto the FF unified-architecture module (CORTEX / LAMELLIPODIUM Arp2/3 70°±35° branched vs FILOPODIUM formin+fascin bundle — see MEMORY `project-ff-unified-arch-and-stiffness`). No gate currently asserts the *emergent* branched-⊥ vs bundled-∥ outcome as a contract. This is a candidate **qualitative sanity gate** for FF, but it is a morphology-class check, not a banded scalar — flag PI-gate review.
- **Barbed-end-at-membrane polarity (#11)** confirms (does not tighten) the FF protrusion mechanism already used in the crawl/protrusion work (barbed-end-out pushing; MEMORY `project-ff-active-movement-pieces`, `project-ff-crawl-mechanism`). No dedicated gate; treat as CONFIRMING physical-sense evidence.
- **Reconstitution concentrations (#13/#14)** are assay conditions, not single-cell-scale observables. No gate. Overlay/cross-check only if FF ever runs an in-vitro-matched nucleation assay.
- **Pillar length / density-dependence (#7–#9)** are geometry-specific (10 µm micropattern, unconfined bulk polymerization) — **not measurable at OUR single-cell scale** as written. Do not propose as gates.

None of these **challenge** an existing band. NPF density #1/#2 is broadly consistent with, and slightly above, the cited in-cell range #3 (self-consistent).

## Oracle candidates

**None.** The only closed-form is the calibration fit FI = 157.7·x − 2.32 (Fig 3b), which is fluorescence-intensity vs Ni-lipid mole-fraction — instrument- and assay-specific, R²=0.88, no physical-law content. It cannot serve as an analytic cross-check (fails the "analytic ground truth" bar; oracles are κL/2R², κq⁴, ΔP·R/2, Bell-Evans, Hill class). The qualitative barbed-end pushing force is invoked by analogy to Brownian-ratchet but given no functional form. No oracle to add.
