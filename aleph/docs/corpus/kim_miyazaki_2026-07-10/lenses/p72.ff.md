# FF lens — p72

**Paper**: Noji, Suzuki et al. (2025) "Protein design of two-component tubular assemblies similar to cytoskeletons", *Nat. Commun.* 16:6738, DOI 10.1038/s41467-025-62076-3.

**Verdict up front**: This is a **de novo protein-design + in-vitro reconstitution + cryo-EM + TIRFM** paper. It has **no motor, crosslinker, off-rate, clutch, branching, or turnover physics**. The engineered filament is an artificial two-component coiled-coil-linked PuuE tube, NOT actin, myosin, or any FF ingredient. **The single genuinely transferable item for FF is the semiflexible-filament persistence-length physics**: a cleanly re-measured actin Lp datum and the standard 2D worm-like-chain (WLC) relation that FF can use as a validation cross-check for its actin bending stiffness κ. Everything else is off-scale for our fine-grained single-cell simulator. FF impact is **low but nonzero (a sanity anchor, not a mechanism)**.

---

## 1. MECHANISMS to adopt

- **Filament module — NO new mechanism.** The paper introduces no cytoskeletal mechanism FF lacks. The designed PuuE tube is a semiflexible beam (like FF's actin bending beam) but built from a completely different chemistry (C4 PuuE allantoinase tetramer scaffold + M3L2/p66α heterolinker coiled-coil). FF should NOT try to represent the PuuE tube; it is not a biological cytoskeletal element and violates the "keep proposals at our single-cell fine-grained scale" rule if adopted as a species.
- **The ONLY adoptable content is a validation cross-check, not a mechanism**: use the paper's measured actin persistence length as an independent literature anchor for FF's actin bending-beam calibration (see §3, §5). It reinforces (does not supersede) the FF value ℓ_p ≈ 17 µm.
- Why it does not beat any current FF mechanism: FF already models bending via angular κ tied to ℓ_p·k_B·T. This paper adds a second, independent measurement of the SAME quantity — corroboration, not a new lever.

## 2. FORCE LAWS / KINETIC SCHEMES to port

- **Only equation in the paper — Eq. (1), the 2D thermal WLC (Kratky–Porod) mean-square end-to-end distance:**

  ⟨R²⟩ = 4·L_p²·[ 2·exp(−L / (2 L_p)) − 2 + L / L_p ]

  - `⟨R²⟩` — ensemble mean-square end-to-end distance of a filament confined to 2D (evanescent-field / methylcellulose-depleted plane).
  - `L` — filament contour length.
  - `L_p` — persistence length (fit parameter, extracted by nonlinear least squares, scipy `curve_fit`).
  - Note the factor **4** and the **2 L_p** inside the exponential: this is the **2D** form (in-plane bending only). The 3D WLC form uses 2·L_p²[…] with L/L_p in the exponential. FF filaments fluctuate in 3D, so if FF reproduces this assay it must either (a) project onto a plane and use Eq. (1) as-written, or (b) use the 3D WLC form for a free 3D filament. **Do not blindly apply the 2D formula to 3D FF trajectories** — dimensionality changes the prefactor.

- **Mapping to FF state**: FF stores per-filament bead positions; end-to-end vector R = r_last − r_first, contour L = Σ|r_{i+1}−r_i|. Bin filaments by L, compute ⟨R²⟩ per bin over an equilibrated ensemble, fit L_p. Relate to the FF bending stiffness via κ = L_p · k_B·T (standard, implied in-paper not written); at T=310 K, k_B·T = 4.28e-21 J, so L_p = 17 µm ⇒ κ ≈ 7.3e-26 J·m.

- **No off-rate, motor duty-cycle, force-velocity, branch-angle, or unbinding-spectrum law appears in this paper.** Nothing to port to myosin/crosslinker/formin/Arp2/3/clutch modules.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce

- **Nothing at network scale.** No reconstituted actomyosin network, no motility assay, no confinement geometry, no density/connectivity relevant to a cytoskeleton. The "network" here is a single hollow protein tube self-assembling from purified components.
- **One reusable single-filament protocol** (measurement, not architecture): the **2D-confined thermal-bending persistence-length assay** — constrain a filament to a plane (methylcellulose 0.2% w/v depletion + TIRF evanescent field), record thermal shape fluctuations (40 ms/frame, ~seconds), skeletonize (JFilament), fit Eq. (1) across a contour-length ensemble (they used 55 tubes / 37 actin filaments). FF can mimic this as a **single-filament equilibrium test scenario**: place one native-length-distribution actin filament (1–10 µm) in the FF integrator at physiological T and viscosity, let it thermally equilibrate under BAOAB, sample ⟨R²⟩(L), fit L_p, confirm 9–20 µm. This is a good stand-alone unit test for the bending-beam + thermostat coupling — cheap, single-filament, not a native-cortex run (so it is a dev-scale *unit test of the bending law*, explicitly labelled non-authoritative for cortex conclusions).

## 5. VALIDATION TARGETS for FF observables

- **Primary**: FF single actin filament persistence length **L_p ∈ [9, 20] µm**, with **12.5 µm (this paper's TIRFM)** and **17 µm (FF's current ℓ_p)** both inside band. Acceptance: fitted L_p from an equilibrated FF actin filament lands in 9–20 µm.
- **WLC curve shape**: FF's ⟨R²⟩ vs L should trace Eq. (1) (short-L rigid limit ⟨R²⟩→L²; long-L flexible limit ⟨R²⟩→2·L_p·L) — a functional-form check, not just a single number.
- **Not FF targets** (recorded for completeness, do not chase): PuuE tube L_p 19.7 µm; tube diameters C4 29.2 / C5 34.2 / C6 40.0 nm; symmetry-class distribution C4–C10; growth to ~5 µm at 48 h; salt/temperature reversibility. These are protein-design observables with no cytoskeletal-mechanism analog in FF.

## 6. RISKS / caveats

- **Regime mismatch (severe)**: purified de novo protein tube in a test tube vs living MCF7 cortex. The material, the assembly chemistry (coiled-coil + salt screening), and the length scale (28–40 nm hollow tube) share nothing mechanistic with F-actin. Only the *generic semiflexible-polymer bending physics* transfers, and only because it is universal (WLC), not because the systems are related.
- **Dimensionality trap**: Eq. (1) is the **2D** WLC (factor 4, 2L_p in exp). FF filaments live in 3D. Do not apply the 2D formula to raw 3D FF end-to-end data — use the correct-dimensionality form or project to a plane matching the assay. Getting this wrong biases the fitted L_p by ~2×.
- **Temperature**: paper's assay is 25 °C (k_B·T = 4.11e-21 J); FF's physiological baseline is 37 °C (4.28e-21 J). L_p is measured at the assay T; when converting to κ, use the assay temperature, and remember FF runs hotter (κ from L_p is weakly T-dependent through k_B·T, ~4% — negligible but be consistent).
- **Do NOT let this paper move FF's ℓ_p.** 12.5 µm is one measurement below FF's 17 µm; the no-fitting / no-magic-number rules mean we keep FF's sourced value and merely note this as a corroborating datum inside the band. Treating 12.5 µm as "the" value would be fitting to a single in-vitro number from a non-actin-focused paper.
- **Scale rule**: the persistence-length unit test is a single-filament dev-scale check of the bending law; any *conclusion about the cortex* must still be reconfirmed on the native 38000-filament full-compartment cell. This paper supplies a filament-level sanity anchor only.
- **KB action**: at most one SourceEvidence row — "actin filament L_p = 12.5 µm (measured, Noji 2025) / 9–20 µm (Isambert 1995)" + the WLC Eq. (1) — as a citable validation datum. Register NOTHING as a mechanism claim; the protein-design/cryo-EM/reversibility content is off-scope for the mechanistic simulator.
