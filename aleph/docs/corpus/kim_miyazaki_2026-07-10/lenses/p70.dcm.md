# DCM lens — p70

**Paper:** Sakamoto et al. 2020, *Tug-of-war between actomyosin-driven antagonistic forces determines the positioning symmetry in cell-sized confinement*, Nat Commun 11:3063, DOI 10.1038/s41467-020-16677-9.

**One-line honesty upfront:** this is an in-vitro reconstitution paper (Xenopus egg extract in water-in-oil droplets), not a triangulated-surface cell with turgor/K_A/κ_m. It gives DCM **no elastic modulus, no surface-tension value, no node-face contact datum.** Its real gift to DCM is *conceptual + scenario-level*: (a) a clean **cell-sized confinement + intracellular-body positioning** scenario, (b) an **emergent slow timescale from percolation/maturation** (τp = 2^N τ, exponential in size) that is the same shape as the DCM open problem "loose→compact aggregate compaction RATE is drag-limited, real 24–48 h needs escalating maturation," and (c) a **contractile-ring / centripetal-wave line-tension** picture usable for a cytokinesis / cortical-flow demo. Treat all numbers as *reconstitution reference values*, never as MCF7 constitutive parameters.

---

## 1. MECHANISMS to adopt

**M1 — Nucleus positioning as EMERGENT force balance (DCM `nucleus` inclusion + `cortex` γ).**
Today the DCM nucleus is a stiffer inclusion that sits wherever it is placed; there is no mechanism that *positions* it. This paper's core result is that an intracellular body's centered-vs-edge position **emerges** from a tug-of-war between a boundary-directed inward force (centripetal cortical/wave contraction) and an outward force (a percolated bulk-network "bridge" pulling the body to the wall). For DCM this is a ready **validation scenario**: place the nucleus inclusion off-center in a confined cell, turn on cortical contraction (γ) + a bulk cytoplasmic contractility, and check that the nucleus centers for large R and can be driven off-center when boundary–cytoskeleton coupling is raised. WHY it beats now: gives the nucleus compartment an actual mechanistic role (positioning readout) instead of a passive stiff ball, and it is a physiological check DCM currently has no test for.

**M2 — Percolation-gated force transmission as the slow-timescale generator (DCM aggregate-σ / cadherin-maturation RATE problem).**
The paper's outward force only turns on when the bulk network *percolates* — all N in-series crosslink sites are simultaneously bound — giving a **mean maturation time τp = 2^N τ that is EXPONENTIAL in system size R** (N ≃ R/L). This is exactly the functional form the DCM aggregate-compaction problem needs: our current aggregate-σ compaction is drag-limited (~100 s), but the physiological 24–48 h compaction is set by a *slow, escalating maturation* (cadherin cluster maturation / T1 rearrangement), not by pulling harder. p70 supplies a **derivable slow-timescale law** (contact-age → occupancy → percolation → force) that is grid-invariant and NOT a tuned constant: the slowness comes from the combinatorics 2^N, with N and τ each anchored to microscale rates. WHY it beats now: replaces "aggregate-σ pulls until drag stops it" (an end-state-only, rate-meaningless mechanism, per the DCM scope note) with a mechanistic *rate* whose exponential size dependence is the right shape for the real 24–48 h window. Adopt as the maturation kernel for the cadherin junction / T1-escalation module, not as a new lumped σ.

**M3 — Centripetal contractile wave / ring line-tension (DCM `cortex` γ + future cytokinetic ring).**
The waves are contracting actomyosin **rings** whose hoop tension is directly demonstrated (UV-cutting a ring re-opens it in seconds). Wave period T ≈ 46 s, weakly size-dependent; contraction velocity v ≈ 1–5 µm/s scaling ~linearly with droplet diameter. For DCM this is a template for a **cortical-flow / cytokinetic-ring** mechanism: a band of elevated surface tension γ_ring on the mesh that contracts along a meridian, with the ring-closure kinematics (period, front velocity vs size) as benchmarks. WHY it beats now: DCM lists cell division / cytokinetic ring as an *open* problem with no line-tension law; this gives the ring-tension existence proof + a velocity/period scaling to reproduce.

**M4 — Boundary–cytoskeleton coupling as an explicit, tunable surface property (DCM `contact` / membrane–cortex coupling).**
Surface passivation (PEG) → body centers; boundary Arp2/3 activation (VCA) → body edges (and even drives whole-droplet migration). This is a clean demonstration that **the sign of the emergent positioning is set by how strongly the internal network couples to the boundary.** For DCM, membrane–cortex coupling strength (the cortex↔membrane tether stiffness) is a real, currently-underexercised knob; p70 says this coupling is *the* control parameter for internal-body polarity and for translating internal contraction into net migration. WHY it beats now: motivates membrane–cortex coupling as a first-class control variable with a qualitative validation (raise coupling → symmetry break; lower → center).

## 2. EQUATIONS to port

**E1 — Crosslinker turnover time (feeds M2 maturation kernel).**
τ = 1 / (k_off + C0 · k_on)
Map: k_off, k_on = crosslinker off/on rates; C0 = crosslinker concentration. In DCM this becomes the *per-site turnover time* of the cadherin catch-bond cluster's constituent bonds — the elementary clock of contact-age maturation. Do NOT tune τ; derive it from the junction's own k_off (Bell/Rakshit KU-4.2 off-rate) and cluster density.

**E2 — Site count along a load path.**
N ≃ R / L   (paper: N ≃ D/(2L))
Map: R = characteristic length of the force path (for DCM aggregate: cell–cell junction interface span or cluster→contact distance; L = elementary crosslink/bond spacing). N is grid-invariant if L is a physical bond spacing, not a mesh edge.

**E3 — Maturation / percolation time (the slow-timescale law — core port for M2).**
τp = 2^N τ ,  with N ≃ R/L
Meaning: expected time for *all* N series sites to be simultaneously occupied → force-percolating connection. Map to DCM: mean time for a cadherin junction cluster of N sub-bonds to reach the fully-load-bearing (matured) state that transmits contractile σ across the interface. Exponential-in-size → naturally produces hours-scale maturation from sub-second bond turnover without a magic number.

**E4 — Occupancy/percolation probability over an observation window (for stochastic maturation updater).**
p(N) = 1 − [ 1 − (1/2)^N ]^{T/τ}   (Eq. 1)
p(D) = 1 − [ 1 − (1/2)^{D/(2L)} ]^{T(D)/τ}   (Eq. 2)
Map: probability that a load-percolating bridge/junction has formed at least once in window T. In DCM, this is the per-timestep probability that a junction cluster transitions to the matured/force-bearing state — a mechanistic replacement for any binary latch (the CLAUDE.md-forbidden `cad_mult` switch). The 1/2 is the equilibrium single-site occupancy for k_on·C0 = k_off; replace it with the junction's actual occupancy p_site = C0·k_on/(k_off + C0·k_on) for a physiological (non-symmetric) baseline.

**E5 — Timescale-crossing / transition condition (the "which force wins" criterion).**
τp = T  ⇒  Rc / L = log₂( T / τ )   (Eq. 3)
Map: the body/junction goes to the "matured/edge/compacted" branch when the maturation time τp drops below the competing contractile-wave period T. For DCM this is the analytic knob that says whether the *maturation-limited* outward/compaction force or the *contraction-limited* centering force dominates at a given cell/aggregate size — a size-dependent regime boundary to test, not a fit.

**E6 — Positioning readout (DCM observable definition).**
DC-ratio = d / R_cell , with d = |center_of_confinement − centroid(nucleus)|
Edge if DC-ratio > 0.5, center if < 0.2. Directly usable as the DCM nucleus-positioning observable.

*(No mechanical constitutive equation — bending, area, Bell force — is given; those stay from DCM's existing laws.)*

## 4. GEOMETRY / PROTOCOL to reproduce

**P1 — Cell-sized confinement scenario.** A closed boundary of controllable size (D = 16–330 µm here; for DCM use single-cell R≈7.5 µm and small aggregates) with an intracellular stiff body (nucleus). Quasi-2D option: confine between two plates at aspect ratio h/D ∈ [0.3, 0.6]. DCM already enforces enclosed volume; add a *rigid external confinement wall* (node-face penalty against a fixed spherical/cylindrical boundary) — this is the missing "confinement response" scenario in the DCM open list.

**P2 — Nucleus-positioning tug-of-war run.** Start nucleus off-center inside a confined cell at physiological baseline (turgor Π₀, cortex γ ON). Add (i) a centripetal cortical contraction and (ii) a bulk cytoplasmic contractility with boundary coupling. Measure DC-ratio(t). Sweep cell size to look for a centered↔edge transition (E5). Perturb boundary–cortex coupling to flip the outcome (mimics PEG vs VCA).

**P3 — Contractile-ring / centripetal-wave.** Impose a band of elevated γ (ring) on the mesh; let it contract along a meridian. Measure ring-front velocity and period; compare scaling shape to v(D), T(D). This doubles as the seed for the cytokinetic-ring division mechanism.

**P4 — Laser-ablation analog.** Instantaneously remove the matured outward junction/bridge in a running sim and confirm the body relaxes back toward center, then re-matures over τp (bridge reassembly ~4 min in paper). A clean causal test that maturation, not a static field, holds the off-center state.

**P5 — Boundary-migration analog.** Strong asymmetric boundary–cortex coupling should convert internal contraction into net cell translocation — a mechanistic durotaxis/migration seed (paper shows Arp2/3-boundary activation drives whole-droplet migration).

## 5. VALIDATION TARGETS (DCM observables)

These are **qualitative/scaling** targets (egg-extract regime, so match the *form and sign*, not the absolute number, unless running an extract-matched scenario):

1. **Two-state size dependence:** large confinement → nucleus centers; small → nucleus edges; sharp transition. DCM confined-nucleus sweep should show a size-dependent centered↔edge switch.
2. **Transition-size scaling:** longer filaments / more crosslinkers → larger transition size (Dc: 60 → 85 → 115 → 138 µm for gelsolin/control/α-actinin/mDia2). In DCM terms: stronger/longer-range junction maturation → wider "edge/compacted" regime. Reproduce the *monotonic direction*.
3. **Wave/ring kinematics:** period T ≈ 40–50 s, weakly size-dependent (T = 0.025·D + 39); contraction velocity v ≈ 1–5 µm/s, ~linear in size (v = 0.016·D − 1.3). Targets for a DCM cortical-flow/ring demo.
4. **Cluster size law:** intracellular body ≈ 0.25 × confinement size (R²=0.86). A geometric consistency check for emergent condensation, if DCM ever models cytoplasmic condensation.
5. **Ablation recovery time:** matured outward connection reassembles in ~4 min after cutting → the DCM maturation kernel τp should regenerate a matured junction on a comparable (mechanism-set, not tuned) timescale.
6. **Analytic crossing:** Rc/L = log₂(T/τ) reproduces Dc ≈ 73 µm from T=46 s, L=5.7 µm, τ=0.54 s (vs measured 85 µm) — a self-consistency target if DCM ports E1–E5 exactly.

## 6. RISKS / caveats

- **Regime mismatch (biggest).** In-vitro **Xenopus egg-extract**, cytoplasm-only, **microtubules removed (nocodazole)**, **no lipid-bilayer tension / no turgor / no membrane K_A** — the boundary is a passive phospholipid *monolayer*, not a pressurized MCF7 cortex+membrane. So there is **no cortical-tension γ value, no elastic modulus, no contact stiffness** to import. Do not register any of its numbers as MCF7 constitutive parameters. Adapt by using p70 only for *mechanism form* (E1–E5) and *scenario design* (P1–P5), keeping every DCM constitutive value at its existing MCF7 physiological baseline.
- **2D vs 3D.** Experiments are quasi-2D (h/D 0.3–0.6). The percolation N≃R/L and wave hoop-tension are 2D-flavored. Porting E3/E5 to the 3D DCM surface mesh needs care: N should count sub-bonds along the *3D* junction load path, and the "ring" is a meridional band on a closed surface, not a planar loop. Verify grid-invariance of N (L must be a physical bond spacing, not a mesh edge length) before use — else it becomes a hidden magic number.
- **Cell type.** Egg extract ≠ epithelial MCF7; the α-actinin k_off here (0.66 s⁻¹) conflicts 10× with the KB's Ferrer-2008-anchored 0.066 s⁻¹. Keep Ferrer for the KB; treat p70's rates as its own model inputs only.
- **Positioning body ≠ our nucleus mechanically.** The "cluster" is a self-assembled organelle condensate, not a lamin-shelled nucleus with E_nuc ~1–10 kPa. Use the *positioning logic* (M1), not the body's material identity.
- **Physiological-baseline rule.** The 1/2 single-site occupancy in E4 is the symmetric k_on·C0 = k_off case — an unphysical convenience for our junction. Replace with the actual p_site from the junction's real on/off rates so the maturation kernel starts at the physiological operating point, not a symmetric null.
- **Don't over-claim the compaction-rate fix.** M2/E3 supply the *right functional shape* (exponential-in-size maturation) for the loose→compact RATE problem, but this is a hypothesis to test against DCM T1-rearrangement escalation — not a validated 24–48 h reproduction. Port it as a candidate maturation kernel and gate it, don't declare the open problem closed.
