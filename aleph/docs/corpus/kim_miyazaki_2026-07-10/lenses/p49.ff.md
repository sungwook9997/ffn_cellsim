# FF lens — p49

**Paper:** Yamaguchi, Nakagawa, Tran, Shimizu, Miyazaki (2025) *Kinetic Scheme of Myosin Phosphorylation by ZIP Kinase.* Biochemistry 64, 4805–4817. DOI 10.1021/acs.biochem.5c00495.

**One-line verdict for FF.** This is an in-vitro enzyme-kinetics paper, not a filament-mechanics or motor-mechanics paper. It contains **no force law, no off-rate, no bending/stretch constant, no force–velocity relation**. Its sole FF-relevant contribution is the *upstream activation switch* of myosin II: the sequential Ser19→Thr18 MRLC-phosphorylation scheme and its measured rate constants (kcat 0.40–0.95 s⁻¹, Km 2.5–4.2 µM). This is a candidate for a **myosin activation-state gating layer** that would let FF cortical-tension γ emerge from a physiological *active-myosin fraction* instead of an all-heads-on assumption — directly relevant to the open γ-floor problem, but as a modulator, not a mechanism replacement. **Do not** treat any number here as a force-generation datum; it sets *timescales of activation*, nothing mechanical.

---

## 1. MECHANISMS to adopt

### 1a. Myosin module — add an explicit MRLC phospho activation state (0P / 1P / 2P) that gates head engagement
- **Current FF state:** myosin II is a Stam–Hocky bipolar minifilament of Hill (1938) force–velocity heads; heads are (as built) constitutively active force generators — the *activation fraction is implicitly 1.0*. There is no representation of the regulatory-light-chain phospho switch that biology uses to turn myosin on.
- **Change:** give each minifilament (or each head) a discrete activation variable `mrlc_state ∈ {0P, 1P, 2P}`. **0P = inactive** (folded 10S-like, cannot assemble/engage), **1P (Ser19) = active** (sufficient for filament assembly, actin-activated ATPase, and force generation — paper Intro refs 5–7), **2P (Ser19+Thr18) = active, enhanced assembly** but *no faster gliding velocity than 1P* (paper Intro, ref 9 — important: 2P does **not** raise v_unloaded, only assembly propensity). Head engagement / duty ratio in the Hill kernel is gated by `mrlc_state != 0P`.
- **Why it beats current FF:** it converts "how much myosin is on" from an implicit constant into a mechanistically-modelled, physiologically-anchored fraction with real seconds-scale kinetics. Under the project's no-magic-number + physiological-baseline rules, the resting active fraction becomes a *derived* quantity (steady state of the phosphorylation/dephosphorylation balance) rather than a tuned density. This is the single most useful hook for the cortical-tension γ open problem: γ ∝ (active-head density), and this paper tells you the timescale (≈1/kcat ≈ 1–2.5 s per phosphorylation event at saturating kinase) over which that fraction relaxes toward its setpoint.
- **Caveat that must be honoured:** this is *smooth-muscle* myosin (SMM, chicken gizzard) + human MRLC isoform-2. FF's cortex is nonmuscle myosin IIA/B. The MRLC sites (Thr18/Ser19) and the sequential Ser19-first logic are conserved across NMM/SMM (both activated by MRLC di-/mono-phosphorylation; paper Intro §), so the *scheme* ports; the *absolute rate constants* are ZIPK-on-SMM specific and should be flagged as provisional for NMII (see §6).

### 1b. Do NOT adopt the kinase/heavy-chain competition (Model 2) into FF
- The KI = 0.30 µM ZIPK–MHC competitive-sequestration mechanism (Model 2, eqs 4–5) is an *in-vitro artifact of purified kinase + purified myosin in bulk solution*. It explains why SMM phosphorylates slower than isolated MRLC in a test tube. In the living cortex the kinase is not the rate-limiter we model, and MHC/MRLC competition is not a cortical-mechanics lever. **Skip it.** (Recorded here only so a later reader doesn't mistake it for a cortex mechanism.)

## 2. FORCE LAWS / KINETIC SCHEMES to port

There are **no force laws**. The portable object is the **two-step sequential Michaelis–Menten activation scheme** (Model 1). Port it as a per-minifilament activation kinetics kernel, decoupled from the Hill force kernel.

**Reaction scheme (Model 1):**
```
ZIPK + 0P-MRLC ⇌(Km^S19)  ZIPK·0P  →(kcat^S19)  ZIPK + 1P-MRLC   (Ser19)
ZIPK + 1P-MRLC ⇌(Km^T18)  ZIPK·1P  →(kcat^T18)  ZIPK + 2P-MRLC   (Thr18)
```

**Eq 1 (0P→1P, Ser19):**
  V^{0P→1P} = kcat^{S19} · [ZIPK_tot] · [0P] / (Km^{S19} + [0P])

**Eq 2 (1P→2P, Thr18):**
  V^{1P→2P} = kcat^{T18} · [ZIPK_tot] · [1P] / (Km^{T18} + [1P])

**Symbol → FF state map (for a single-cell fine-grained port):**
- `[0P]`, `[1P]`, `[2P]` → fractions of the minifilament population in each activation state (dimensionless populations, sum = 1), OR per-minifilament categorical state advanced stochastically.
- `[ZIPK_tot]` → a lumped "activating-kinase activity" scalar A (the net MLCK/ROCK/ZIPK drive). In FF this is a **single physiological control parameter** representing contractile activation, NOT three separate kinases. Set A to its resting operating point (see §6); perturb it to model contraction onset.
- `kcat^{S19}, kcat^{T18}, Km^{S19}, Km^{T18}` → per §3.
- Add a **dephosphorylation (deactivation) channel** the paper does *not* measure but the physiological baseline demands (MYPT1/PP1 phosphatase): reverse rates `k_dephos^{S19}, k_dephos^{T18}` so the system has a genuine steady-state active fraction rather than running monotonically to 2P. The paper gives you the *on* limb only; the *off* limb (phosphatase) must be sourced separately (surface to PI / KB) — flag it, do not invent a magic value.

**Implementation form in FF (per timestep dt, GPU-resident):** because kcat ≪ 1/dt for FF's fine-grained dt, treat activation as a slow stochastic Poisson process per minifilament:
  P(0P→1P in dt) = kcat^{S19}·A/(Km^{S19}+[0P-like]) · dt   (deterministic-rate → per-object Bernoulli draw)
Keep it in the myosin updater alongside the existing binding kinetics; it is O(N_minifil), negligible cost.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce

Nothing here is a cytoskeletal network or motility-assay geometry — it is bulk well-mixed enzyme kinetics (no filaments, no confinement, no mesh). The only reproducible protocol is a **0-D activation-kinetics unit test**, not an FF-scale scenario:

- **Time-course unit test:** integrate eqs 1–2 for [0P],[1P],[2P] with the Table-1 constants; reproduce the 2 µM MRLC + 5 nM ZIPK-FL curve (at 10 min: 1P ≈ 34%, 2P ≈ 4%, Total-P = 1P + 2·2P ≈ 40%). Use this as an *acceptance oracle* for FF's activation-kernel implementation (analogous to how the project uses closed-form oracles): FF's stochastic per-minifilament kernel, in the well-mixed limit and stripped of dephosphorylation, must reproduce this deterministic ODE curve. **Total-P metric:** Total P(%) = 1P(%) + 2·2P(%), max 200%.
- **Ordering check:** monophospho population must be ≈35:1 Ser19:Thr18 (sequential), i.e. 1P is essentially all Ser19-phospho — a structural assertion the FF scheme must satisfy (0P→1P is Ser19, not a 50/50 random draw).

This is a validation harness, not a production FF geometry. There is no reconstitution network, confinement, or density to import.

## 6. RISKS / caveats

1. **Isoform mismatch (biggest risk).** Measured on smooth-muscle myosin II (chicken gizzard) via ZIPK/DAPK3. FF's cortex is nonmuscle myosin IIA/IIB, and the dominant physiological cortical activators are MLCK (Ca²⁺/CaM-dependent) and ROCK, not ZIPK. The **scheme** (sequential Ser19→Thr18, di-phospho enhances assembly not gliding velocity) is conserved and portable; the **absolute kcat/Km** are ZIPK-SMM-specific. Use the numbers as *order-of-magnitude activation timescales* (seconds), flag them provisional, and prefer an NMII-specific source for a production γ study. Do not KB-register these as NMII activation constants without that caveat.

2. **Purified bulk vs living cortex.** Well-mixed enzyme kinetics with no crowding, no cortex geometry, no mechanochemical feedback (no tension-dependent MRLC turnover). The Model-2 KI competition is a purified-protein artifact — explicitly excluded from FF (§1b).

3. **25 °C vs 37 °C.** Physiological-baseline rule requires 37 °C; Arrhenius/Q10-correct kcat (~2× up) before any native-scale run. Verbatim 25 °C use = starting off the physiological operating point.

4. **On-limb only — no phosphatase.** The paper measures phosphorylation forward rates but no dephosphorylation. Porting only the on-limb makes myosin monotonically saturate to 2P (all-on) — which reproduces the current implicit "activation = 1" and gains nothing. The *value* of this lens is realised only if paired with a phosphatase (PP1/MYPT1) off-rate so a genuine steady-state active fraction emerges. That off-rate is NOT in this paper — surface to PI / KB, do not invent it (no-magic-number).

5. **Not a force/off-rate source.** Guard against over-reading: nothing here changes Bell-Evans crosslinker off-rates, Hill force–velocity, stall force, step size, ℓ_p, link stiffness, or branching angle. Any FF change beyond the activation-fraction gate is out of scope for this paper.

6. **Native-scale discipline.** The kernel is O(N_minifil) and adds negligible cost, so it can and must be exercised on the native 38000-filament cortex (Nc≈266k) with full compartments before any conclusion about its effect on γ. A 0-D kinetics unit test (§4) validates the kernel arithmetic only; it is explicitly non-authoritative for cortex behaviour.
