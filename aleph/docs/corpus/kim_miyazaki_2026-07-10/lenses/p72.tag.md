## Oracle candidates

- **2D worm-like-chain ⟨R²⟩ relation (Eq.1):** ⟨R²⟩ = 4·Lp²·[2·exp(−L/2Lp) − 2 + L/Lp]. This is a standard closed-form Kratky–Porod result for a thermally-fluctuating 2D-confined semiflexible filament. It is a **legitimate analytic-oracle candidate** for FF: cross-check that a simulated free filament's ensemble ⟨R²⟩ vs contour length L round-trips to the input κ (Lp = κ/kB·T). Complements the existing Helfrich κq⁴ / κL/2R² oracles (those are curvature-spectrum; this is real-space end-to-end).
  - **Note:** this is textbook physics, not novel to this paper — the paper is a convenient citable instance, not the origin. If added to `validation/oracles/`, cite the primary WLC literature, not p72, as the derivation source. **Flag: candidate oracle, PI review; low priority (FF bending is already oracle-covered).**
