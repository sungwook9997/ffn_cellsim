# FF lens — p64

**Paper:** Bidone, **Kim (Taeyoon)**, Deriu, Morbiducci, Kamm (2015) "Multiscale impact of nucleotides and cations on the conformational equilibrium, elasticity and rheology of actin filaments and crosslinked networks." *Biomech Model Mechanobiol* 14:1143–1155. DOI 10.1007/s10237-015-0660-6.

**Why this paper matters to FF (one line):** its network layer *is* the Taeyoon-Kim agent-based Brownian-dynamics crosslinked-actin engine — the direct conceptual ancestor of our FF (Cytosim-style) filament model. It gives us a fully-specified, literature-anchored **crosslinked-network rheology scenario** (cylindrical segments + two-arm ACPs + Langevin + shear) with concrete segment/ACP stiffnesses and a **nonlinear strain-stiffening validation target** (critical strain ≈0.5; stress 200–2500 Pa at 60% strain; crosslinker-stiffness-dependent divergence). It is a rheology-oracle paper, not a new-mechanism paper — treat it as (a) a scenario+validation gate and (b) a parameter cross-check, NOT as a source of a new active mechanism.

---

## 1. MECHANISMS to adopt

The paper's runtime engine is a coarser-grained sibling of FF, so most "mechanisms" are already in FF. The genuinely adoptable items:

1. **Crosslinker (α-actinin / filamin) as a two-segment elastic ACP with an explicit arm-alignment bending penalty — FF module: crosslinker.**
   - Current FF: crosslinkers are explicit bonds with Bell-Evans off-rate + Ferrer link stiffness. The paper models each ACP as **two serial cylindrical arms** (23.5 nm each, 10 nm dia) with (i) an extensional spring `k_s,ACP` per arm and (ii) **two distinct bending springs**: `k_f,ACP1` keeping the two arms co-linear (parallel), and `k_f,ACP2` keeping the arm–F-actin angle near 90°.
   - **Why it can beat / augment current FF:** FF's crosslinker is (from the memory notes) essentially a stretch bond; it has no *geometric* bending resistance encoding the crosslinker's own bending stiffness or its preferred attachment angle. Adding an explicit arm-alignment `k_f,ACP1` and a filament-attachment-angle `k_f,ACP2` makes the crosslinker mechanistically fine-grained (matches the "explicit bond + geometry" hard rule) and is exactly what sets the *soft-vs-rigid* network regime this paper's headline result turns on. **Caveat/hard-rule check:** the ACP here is a *permanent* crosslink (no unbinding). Do NOT replace FF's Bell-Evans catch/slip off-rate with a permanent bond — keep FF's kinetics and only borrow the *geometry+stiffness* of the two-arm element. This is additive, not a substitution.

2. **Filament rigidity is set by monomer nucleotide/cation state — FF module: filament (bending κ, stretch k_s).** The paper's whole thesis is that ℓ_p (hence κ) is a *tunable* function of ATP/ADP/ADP-Pi + Mg²⁺/Ca²⁺ occupancy, spanning **ℓ_p ≈ 3.5–4 µm** for the sites they modeled and up to **12.7 µm** at the discrete "stiffness" site (Kang 2012). FF currently hard-codes ℓ_p≈17 µm (canonical actin). **Actionable:** expose ℓ_p (→ κ) and extensional k_s as a per-filament state variable, defaulting to the *physiological* Mg²⁺-ADP cortex value, so that FF can (a) run the rheology validation across the p64 ℓ_p sweep and (b) later couple to nucleotide-turnover if we ever add ATP-hydrolysis aging of filaments. This is a *hook*, not a magic number — the default stays at the physiological operating point.

3. **The "soft-element dominates" network principle — engine-level insight, no code change.** Key finding: when actin segments are much stiffer than the crosslinkers (`k_s,filament ≫ k_s,ACP`), the network shear response is **dominated by the compliant crosslinkers**, so filament-rigidity changes are invisible (p=0.88). Only when ACP and filament stiffness are *comparable* (scruin-like, `k_s,ACP=0.2 N/m`) does filament rigidity matter (p=0.03). **Why FF should internalize this:** it tells us *which* stiffness FF's cortical-tension / stress-relaxation behavior is actually sensitive to. For a physiological MCF7 cortex crosslinked by compliant α-actinin/filamin, network mechanics are **crosslinker-limited**, not filament-rigidity-limited — a directly relevant prior for the open γ-generation / stress-relaxation problems (don't chase filament κ to move network stress if the crosslinkers are soft).

**Not adoptable (out of scope):** the atomistic MD + ENM/RTB normal-mode pipeline (angstrom/ns scale, GROMACS). FF operates at µm/s; the molecular layer only *feeds a number* (κ, k_s) we can take as a parameter. Do not build MD into FF.

## 2. FORCE LAWS / KINETIC SCHEMES to port

All potentials below are the **network-layer** (Kim-lab BD) forms — the same family FF already uses; transcribe to confirm parity and to set the ACP geometry.

**(a) Overdamped Langevin EOM (per segment) — maps to FF integrator.**
```
0 = F_stochastic + F_drag + F_det ,   F_det = F_bending + F_extensional + F_repulsion(excluded-vol)
F_drag = −ζ·v   (Stokes drag on cylindrical segment)
```
FF map: F_stochastic ↔ BAOAB thermal kick; F_drag ↔ per-segment drag ζ; F_bending ↔ angular κ; F_extensional ↔ stretch modulus; F_repulsion ↔ LJ excluded-volume. Confirms FF's force inventory is complete for this scenario.

**(b) Extensional (stretch) potential — actin segment & ACP arm.**
```
V_s = ½ k_s (ℓ − ℓ₀)²
```
- actin segment: ℓ₀ = 140 nm; `k_s,actin` from RTB ≈ **0.055–0.075 N/m** (per 140-nm segment).
- ACP arm: ℓ₀ = 23.5 nm; `k_s,ACP ∈ {0.002 (compliant), 0.2 (rigid)} N/m`.
FF map: `k_s` → filament segment stretch modulus / crosslinker link stiffness (`link_k`). Note FF currently uses Ferrer link_k ≈ 4.6e5/8.2e5 (per memory) — that is a *molecular* stiffness in different units; reconcile units before porting (see §6).

**(c) Bending (angular harmonic) potential — filament hinge & ACP.**
```
V_b = ½ k_f (θ − θ₀)²
```
- actin hinge: θ₀ = 180° (keep adjacent segments parallel); `k_f,actin` from RTB, tied to ℓ_p via `κ = k_B T · ℓ_p`.
- ACP arm–arm alignment: `k_f,ACP1 = 1.45×10⁻²⁵ N·m²`.
- ACP arm–filament right-angle: `k_f,ACP2 = 5.8×10⁻²⁵ N·m²`, θ₀ ≈ 90°.
FF map: `k_f` → FF angular bending κ (filament) and two new crosslinker-geometry springs.

**(d) Persistence-length ↔ bending-rigidity conversion (how to set κ from a measured ℓ_p).**
```
ℓ_p = κ / (k_B T),   κ = EI (flexural rigidity)
```
Ideal-chain / elastic-rod theory; this is exactly how p64 turned Kang-2012's measured ℓ_p (2.1–12.7 µm) into network k_s, k_f inputs. FF should use the *same* conversion so a validation run is apples-to-apples. (k_B T = 4.114 pN·nm at 300 K ⇒ κ = ℓ_p·k_B T; e.g. ℓ_p=17 µm ⇒ κ ≈ 70 pN·µm².)

**(e) Macroscopic shear stress observable.**
```
σ = (Σ F_clamped) / A_z ,   imposed strain rate  dγ/dt = 0.1 s⁻¹
```
Boundary protocol: filaments crossing the ±z faces are severed & clamped, PBC off in z, top face translated at constant rate, bottom fixed; σ = total clamp-force / z-face area. **This is a ready-made FF measurement protocol** for network shear rheology.

No motor / off-rate / branching kinetics are given in this paper (purely elastic crosslinked network, permanent ACPs). So there is nothing here to port for myosin / formin / Arp2/3 / clutch off-rate.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario name (proposed):** `ff_crosslinked_shear_rheology` — a purified reconstituted crosslinked-actin network shear test, usable as an FF validation gate.

- **Domain:** cubic box, width **3 µm**, PBC in all directions during self-assembly.
- **Composition:** actin **20 µM**; ACPs at **R_ACP = 0.01**; self-assemble until mean filament length ≈ **1.2 µm**.
- **Filament model:** cylindrical segments 140 nm × 7 nm, harmonic stretch (k_s from ℓ_p) + hinge bending (θ₀=180°), LJ excluded volume between segments.
- **Crosslinker model:** two 23.5 nm × 10 nm arms; stretch k_s,ACP; bending k_f,ACP1 (parallel) + k_f,ACP2 (⟂ to filament); binds every 7 nm along a segment; permanent for this test.
- **Shear protocol:** sever + clamp filaments crossing the ±z faces, deactivate z-PBC, translate top face at **dγ/dt = 0.1 s⁻¹**, hold bottom fixed. Record σ = Σ(clamp force)/A_z vs strain γ up to ≥0.6.
- **Sweeps:** (i) crosslinker regime {compliant 0.002, rigid 0.2 N/m}; (ii) filament ℓ_p {≈3.5, 4, and 2.1→12.7 µm stiffness-site endpoints}.

**Scale caveat vs our native rule:** this is a *purified in-vitro reconstituted network at our fine-grained scale* (µm box, explicit segments) — it does **not** violate the native-scale rule the way a coarse *cell* would, because there is no cell cortex to structurally collapse; it is a periodic bulk network. It is a legitimate **standalone rheology validation** of FF's filament+crosslinker sub-engine. Keep it labelled as a **sub-engine validation scenario**, not as a cell-level conclusion — cortical/γ conclusions still require the native 38000-filament full-compartment cell.

## 5. VALIDATION TARGETS for FF observables

Reproduce these (crosslinked-network shear rheology of the FF filament+crosslinker sub-engine):

1. **Critical strain (linear→nonlinear onset):** γ_c ≈ **0.5** in all sampled cases — stress rises ~linearly below γ_c, then diverges super-linearly (strain-stiffening). Primary qualitative gate.
2. **Network stress at 60% strain, compliant ACP (k_s,ACP=0.002):** plateau/curve reaching ≈ **200–230 Pa**.
3. **Network stress at 60% strain, rigid ACP (k_s,ACP=0.2):** ≈ **800–1000 Pa** (this-study ℓ_p sites); up to ≈ **2000–2500 Pa** with the Kang stiffness-site ℓ_p (12.7 µm).
4. **Crosslinker-regime sensitivity:** with compliant ACP, filament-rigidity variation across the 11 nucleotide/cation states is **statistically insignificant (p≈0.88)**; with rigid ACP it becomes **significant (p≈0.03)**. FF must reproduce this *qualitative* regime dependence (soft ACP → filament-κ-insensitive network; stiff ACP → sensitive).
5. **Stiffness-site ℓ_p spread:** with ℓ_p 2.1→12.7 µm, even soft ACP shows a significant difference (p<0.01), curve spread ≈ **25%** at high strain; with rigid ACP the highest-ℓ_p stress is ≈ **3×** the lowest-ℓ_p stress. Monotone rising σ(60%) vs ℓ_p.
6. **Filament-rigidity cross-checks (single-filament FF unit test):** ℓ_p ≈ **3.5–4 µm** for their cation/nucleotide sites (low end of the Kang 3–12 µm experimental range); extensional k_s ≈ **0.055–0.075 N/m** per 140-nm segment; ATP-F-actin up to **~12%** stiffer in bending than ADP-F-actin (lit comparators: 24% Isambert 1995; 16–45% Chu & Voth 2006b).
7. **Mechanistic-regime literature note (for interpreting FF results):** bending dominates at low strain, extension dominates at high strain (Head 2003; Onck 2005; Broedersz & MacKintosh 2014) — a check on FF's strain-partitioning if we instrument bending vs stretch energy separately.

## 6. RISKS / caveats

1. **Purified in-vitro network, not a living cortex.** No membrane, no turgor, no myosin, no ATP-hydrolysis turnover, permanent (non-kinetic) crosslinks. This is a **passive elastic rheology** benchmark. Use it to validate FF's filament+crosslinker *elasticity*, then keep the native-scale full-compartment cell as the ONLY basis for any *cortical-tension / cell-level* conclusion (per the HARD rule). Do not let a 3-µm periodic-box rheology number stand in for a cortex γ.

2. **Permanent ACPs vs FF Bell-Evans kinetics.** The paper's ACPs never unbind, and it even notes real ACPs form reversible crosslinks whose stress *collapses* during strain-stiffening before high strain (Wagner 2006; Gardel 2006c; Kim 2011). If FF runs this scenario with its physiological Bell-Evans off-rate ON, FF's high-strain stress will be *lower / will roll over* relative to p64's permanent-crosslink curves — that is **correct physics, not a bug**. Adopt the geometry (two-arm ACP, k_f,ACP1/2) but keep FF's off-rate; expect and document the divergence at high strain.

3. **ℓ_p ≈ 3.5–4 µm is an ENM/RTB estimate of short (150 nm) filaments at the low end of experiment — do NOT adopt as FF's default cortex ℓ_p.** The authors themselves flag it as low (canonical/Kang range 3–12 µm; standard cytoskeleton value ~17 µm). Keep FF's physiological ℓ_p default; use 3.5–17 µm only as a *sweep* to reproduce the rheology sensitivity. No fitting, no gate-loosening — this is a sensitivity study, not a re-anchoring of the actin persistence length.

4. **Unit reconciliation before porting stiffnesses.** k_s here is **N/m per 140-nm segment** and k_f is **N·m²**; FF's crosslinker link_k (Ferrer ~4.6e5/8.2e5) and its bending κ are in FF's own conventions/length-units. Given the project's two prior 10⁶× unit slips (DCM=meters, FF=µm; K_A), run an adversarial unit audit (per-segment length, N/m vs N/m per unit length, N·m² vs pN·µm²) before any of these numbers enter FF config. Convert k_f,ACP2=5.8×10⁻²⁵ N·m² and k_f,ACP1=1.45×10⁻²⁵ N·m² carefully.

5. **Cation/nucleotide state is an isoform/condition axis FF does not currently model.** The physiological cortex is Mg²⁺-ADP F-actin (paper explicitly: ADP-6Mg²⁺ = contractile-muscle physiological condition). If FF ever sets ℓ_p from nucleotide state, default to **Mg²⁺-ADP** to stay at the physiological operating point — not Ca²⁺ or ATP convenience states.

6. **Species/assay generality.** The strain-stiffening magnitudes (200–2500 Pa) are for 20 µM / 1.2 µm-filament / R_ACP=0.01 reconstituted networks — the paper explicitly warns rheology can differ strongly at other actin concentrations / filament lengths (e.g. Mg²⁺-ATP polymerizes ~2× faster than Ca²⁺-ATP → longer filaments → different network stress even with soft ACPs). Treat the numeric targets as regime-specific; match the scenario's (C, L, R_ACP) exactly when validating, or expect different magnitudes.
