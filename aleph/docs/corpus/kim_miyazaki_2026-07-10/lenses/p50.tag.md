# TAG-validation lens — p50

Mair, Elmasli, J.H. Kim, … **Taeyoon Kim**, D.-H. Kim, R. Li — "The Arp2/3 complex enhances cell migration on elastic substrates," *Mol. Biol. Cell* 34:ar67 (2023), DOI 10.1091/mbc.E22-06-0243.

## Paper kind

**Mixed experimental + simulation — classified `experimental`** for schema purposes (it contains genuine in-vitro measurements), but the *load-bearing* validation content is split:

- **Experimental (H4 human glioblastoma on PAA gels):** migration speed / directionality / Cohen's d, TFM traction maps, SIM-TIRF focal-adhesion (FA) counts and areas. → usable only as **OVERLAY / on-demand cross-check**, never a fit target, and note the cell line is **H4 glioma, not MCF7** (our single-cell reference), so overlays are cross-type-qualitative.
- **Simulation (two Kim-lab models):** (1) agent-based Brownian-dynamics cross-linked actomyosin network + triangulated elastic substrate coupled by molecular clutches; (2) the **Parallel Focal Adhesion (PFA)** model = Chan–Odde (2008) motor-clutch extended to N parallel adhesions. → **comparison-only, never a truth source** (project philosophy). These are exactly the FF engine's own physics class, so they are *reproduction targets*, not oracles.

Net: this paper supplies **emergent-behavior cross-checks for the FF adhesion-clutch layer**, not new numeric contract bands. Nearly every quantitative model constant (k_clutch, k_off,0, F_b, k_sub, v_unloaded, F_stall, densities, dt) lives in **Suppl. Tables S1–S3, which are NOT in the PDF** → flag `NO_SI` for all param registration.

## Coverage vs existing gates

## New gate candidates (all **candidate — PI-gate review**; FF engine)

> These are staged, not authored. All are qualitative/shape cross-checks or overlays — no convenient numeric band is invented.

1. **`VG-FF-lamellipodium-FA-count` (overlay)** — number of nascent FAs per lamellipodium. **Value: mean ~37, range 6–89** (item 1). Condition: single spread cell, mature lamellipodium. Engine: FF. Source: Fig 6B, p6/p8. *Caveat:* H4 glioma, OVERLAY-ONLY, not an MCF7 fit target; use as an order-of-magnitude reproduction check for FF lamellipodium adhesion density (tens, not units, of small nascent adhesions).

2. **`VG-FF-adhesion-width-stress-law` (emergent, monotone)** — as the adhesive footprint (lamellipodium width / A_FA) widens at *fixed total clutch budget*, **mean total force rises monotonically while substrate stress (force/area) falls monotonically** (items 2,3). Engine: FF, as a qualitative sign/monotonicity cross-check (no numeric band — simulation-derived). Source: Fig 3C/D. This is the paper's central mechanistic claim and is directly reproducible in FF.

3. **`VG-FF-PFAC-cluster-lifetime` (emergent)** — a **single** filopodial adhesion undergoes catastrophic load-and-fail (sawtooth substrate deformation), whereas **≥ ~10 parallel adhesions sharing the same clutch pool prolong interaction time, with no failure at ~30** (Parallel Focal Adhesion Compensation) (items 4,5,7). Engine: FF. Source: Fig 4H, Fig 5. Qualitative emergent-behavior gate: cluster lifetime increases with parallel-adhesion count via load redistribution. **Cross-link:** this is the *substrate-adhesion analogue of the DCM cadherin load-sharing cluster* in `project-dcm-cadherin-cluster-redesign` (a bundle whose members fail one-at-a-time, not all-at-once) — same physics, different bond. Worth flagging to PI as shared-mechanism corroboration.

## Oracle candidates

**None new.** The paper's closed forms are all mechanisms we *already* hold as oracles or contracts:
- Clutch = Hookean spring `f = k·x` (already the clutch model in MC-U2).
- Slip-bond off-rate `k_off = k_off,0·exp(F/F_b)` = **Bell-Evans**, already an oracle.
- Motor force-velocity `v = v_0·(1 − F/F_stall)` = linear **Chan–Odde / Hill-class**, already in MC-U2 and the Hill oracle family.

The PFAC / load-and-fail behavior is a **stochastic emergent** result with **no closed form** — it cannot become an analytic oracle; it can only be a reproduction cross-check (see gate candidate 3). The substrate stress definition σ = Σf_clutch / A_FA is a bookkeeping identity, not a predictive law.
