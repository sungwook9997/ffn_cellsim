# TAG-validation lens — p19

**Paper**: Rabbi, Yim, Boyd, Nam, Chaudhuri, Kim (2026) — *Mechanical Checkpoint for Cell Division in Three-Dimensional Microenvironments*. bioRxiv 10.64898/2026.06.16.732593 (NOT peer-reviewed; CC-BY). Taeyoon Kim lab (Purdue) + Chaudhuri lab (Stanford) imaging.

---

## Paper kind

**simulation** (primary), with a thin **experimental overlay** anchor.

The paper's quantitative core is the OUTPUT of a discrete agent-based Brownian-dynamics fiber-network + deformable-membrane model (aspect ratios, T_pole/T_mat decomposition, shell-area %, force sweeps). Per the philosophy these are **comparison-only, never a truth source**. The only genuinely *experimental* numbers are the MDA-MB-231/collagen PIV deformation field (Fig. 1, qualitative ± scale) and two **borrowed** constitutive constants used to parameterize the FE control (cell E=324 Pa, Eldridge 2019; collagen E_mat=832 Pa / ν=0.313, Lane 2018) — those two are external refs, not measured here. The one **analytic** ingredient worth harvesting is the fiber Euler-buckling critical load (~30 pN) and the standard over-damped Langevin/FDT/cylinder-drag/Bell force laws (Eqs. 1–9), several of which the KB already carries as oracles.

Net: treat every *observable* in the results table as a sim cross-check (low as a contract target); harvest the **force laws** (analytic) and **flag one parameter conflict** (ℓ_p).

## Coverage vs existing gates

- **Fiber buckling ~30 pN cap (#1)** — NO existing gate for a fiber compressive-buckling threshold. FF explicitly targets semiflexible-fiber buckling ("Fiber buckling (~30 pN critical load) … matching FF's design intent", per KB memory). This is the strongest NEW cross-check: an analytic Euler load FF can be validated against directly. → **new candidate (oracle-backed)**.
- **Bell cross-linker unbinding (#11)** — **DUPLICATE / CONFIRM.** KB already carries a Bell-Evans off-rate oracle and `MC-U2-fa-motor-clutch` uses Bell-Evans (not Metropolis) per the architectural rule; FF cross-linker YAMLs use force-dependent unbinding. This paper's Eq. 7 is the same law (slip-only branch, tensile). No new band; confirms the mechanism and supplies a sweep sensitivity (×100 → anchorage → 0). No gate change.
- **Strain-stiffening / σ(r) force propagation** — the paper's collagen network *exhibits* strain-stiffening + non-affine 1/r-like load paths (equatorial anchors = few straightened high-tension fibers), consistent with **VG-U1-strain-stiffening** (PASS, magnitude 1.5–2.5) and **VG-U1-force-propagation** (PASS, ~1/r). It gives no new exponent → **CONFIRMS qualitatively, no tighten**.
- **Mikado topology / mesh size** (VG-U1-mikado-topology, ξ~1–5 µm, z~3–3.5) — paper's self-assembled network (r₀,f=1 µm, avg L_f~10 µm) is compatible; no numeric z reported. No change.
- **Volume conservation (#13)** — matches DCM's turgor/enclosed-volume penalty; no dedicated gate exists but this is a mechanism match, not a band. The **mitotic-elongation load protocol** (0.5 µm equatorial CRC band, 5 µm axial ISE band, stop at 58.74%) is a ready-made DCM cytokinesis BC → basis for a DCM division cross-check gate.
- **Catch-slip bond (VG-U2-catch-slip-bond, peak ~30 pN)** — NOT the same: that gate is integrin-FN *catch* lifetime; this paper's cross-linker is *slip-only*. No overlap despite the coincidental ~30 pN.
- **Aspect ratio / shell area (#2–5)** — no existing division/mitosis gate. These are sim outputs (comparison-only); could seed a DCM division cross-check but are low-grade as contracts.

## New gate candidates (all **candidate — PI-gate review**)

1. **VG-FF-fiber-buckling-cap** *(candidate)*
   - Observable: max compressive force a semiflexible ECM fiber sustains before buckling (per-fiber, under axial compression).
   - Band/value: critical load ~**30 pN** at ℓ_p~100 µm reference; more defensibly, matches analytic Euler F_c = π²κ_b/L² (scales ∝ κ_b,f, ∝ 1/L²). Band anchored to the analytic oracle, not the sim number.
   - Condition: FF collagen fiber, compression along axis; cross-check that measured compressive force saturates at F_c.
   - Engine: **FF** (oracle cross-check).
   - Source: "polar force capped < ~30 pN (≈ critical buckling load)", p15, Fig. 4E/4I.
   - Note: register as an **analytic oracle** first (Euler buckling), then the gate cross-checks FF against it — the 30 pN is derived, not a fit target.

2. **VG-DCM-mitotic-elongation** *(candidate, low priority — sim cross-check)*
   - Observable: cell aspect ratio + pericellular-shell area change under a CRC(inward-equatorial)+ISE(outward-polar) division load in a fibrous ECM.
   - Value: AR → **1.41 (2D) / ~2 (3D)**; shell area **+10% (2D) / +20% (3D)**; elongation stop 58.74%.
   - Condition: DCM cell, 2-fold G1 pre-growth then mitotic load; MDA-MB-231/collagen regime.
   - Engine: **DCM** (division protocol + volume-conservation penalty already native).
   - Source: Fig. 2G/2H, Fig. 5B/5C.
   - Note: sim-derived (not experimental) → comparison-only; mark explicitly non-fit. The anchoring ratio **T_mat/T_pole~0.37** (checkpoint engaged) vs **<0.5** (released) is a useful qualitative DCM-emergence check but too model-specific to be a hard band.

## Param candidates

1. **ℓ_p (collagen FIBER persistence length) ~100 µm — CONFLICT FLAG.** Existing `PARAM-ell_p` = **17 µm** (range 9–22, KU-1.1, "type I collagen"). This paper uses **~100 µm** as the reference fiber semiflexibility. This is NOT a clean supersede — it is a **scale/definition difference**: ~14–17 µm is the single collagen *molecule/fibril*, whereas ~100 µm applies to thicker reconstituted *fibers/bundles* (κ_b ∝ thickness⁴). **Surface to PI**: confirm whether FF fibers represent fibrils (keep 17 µm) or bundled fibers (Kim uses ~100 µm). Do not overwrite; register as a context-tagged alternate.
2. **Cell modulus E = 324 Pa** (incompressible, MDA-MB-231; Eldridge 2019 QPI/AFM). Overlay/cross-check only; borrowed ref, not measured here. Relevant to H.9/H.10 whole-cell modulus context (distinct from MCF7). Low priority.
3. **Collagen matrix E_mat = 832 Pa, ν = 0.313 (K = 741 Pa)** (Lane 2018, type-I collagen, compressible Neo-Hookean). Overlay/cross-check for the continuum ECM control only; the fine-grained line does not use a bulk modulus (per MC-U1-ecm-network philosophy). Borrowed ref. Low priority — do NOT feed into the fibrous ECM contract.

Discretization constants (r₀,f=1 µm, r₀,xl=200 nm, 100 nm site spacing, r₀,m=400 nm, Δt=3.97e-4 s) are **model numerics, not physical** → not registrable.

## Oracle candidates

1. **Fiber Euler buckling critical load** — F_c ∝ κ_b,f / L² (≈30 pN at reference). Best new analytic cross-check; directly serves FF semiflexible-fiber compression. **Recommend implementing.**
2. **Cylinder drag coefficient** — ζ = 3πµ r_c (3 + 2r₀/r_c)/5 (Clift/Grace/Weber, ref 27). Analytic per-element drag; candidate cross-check for FF fiber/rod drag assignment. Note FF/DCM may already use a Cytosim/Stokes drag form — reconcile before adding.
3. **Bell force-dependent unbinding** (Eq. 7) — **already an oracle** (Bell-Evans). Confirms, no new oracle needed.
4. **Over-damped Langevin + FDT** (Eqs. 1–3) and **harmonic stretch/bend** (Eqs. 4–5) — the standard integrator/potential basis; already the FF/DCM/BAOAB foundation. No new oracle.
5. **Enclosed-volume harmonic penalty** (Eq. 9) — matches DCM turgor/volume conservation; a mechanism match, not an independent analytic oracle.
