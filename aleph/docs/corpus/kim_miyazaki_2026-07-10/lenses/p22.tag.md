## Paper kind

**Mixed experimental + simulation.**
- **Experimental track (Chaudhuri):** live-cell confocal + PIV matrix-displacement + AR-G2 rheology on MDA-MB-231 / MCF10A single cells in reconstituted type-I collagen (1/3/5 mg mL⁻¹). → these numbers are **overlay / cross-check targets**, never fit.
- **Simulation track (Kim):** agent-based overdamped-Langevin crosslinked-fiber network + coarse-grained volume-conserving membrane. → its outputs (elongation curves, deformation maps) are **comparison-only, never a truth source**; its *applied* forces (F_Cyto/F_Is = 100 pN) are **fitted model inputs**, not measurements.
- Governing equations (Eqs 3, 4, 9, 10, 11) are standard closed forms → **candidate analytic oracles / conversion cross-checks**.

Use rule: experimental G′ / deformation / elongation = overlay; simulation forces & elongation = comparison; Eqs 4/9/10/11 = oracle cross-checks. **Do NOT KB-register the raw simulation constants** (κ_s, κ_b, k_{0,u}, λ_u, Δt, μ) — they live only in Supporting-Information **Table S1**, which is NOT in this PDF. Flag: Table S1 required before any full sim-block registration.

## Coverage vs existing gates

**VG-U1-G0-linear (`372120daec5d8131b2b4c8518da5f412`)** — ECM linear shear modulus G0, band "~30–100 Pa reference collagen; applied [15,200] Pa". **CONFIRMS + could TIGHTEN into a concentration-resolved band.** The paper's *measured* G′ = ≈10 / ≈100 / ≈400 Pa at 1 / 3 / 5 mg mL⁻¹ (items 1–3). Our current band covers the 3 mg mL⁻¹ point (≈100 Pa) squarely and the applied [15,200] covers 1 mg mL⁻¹ (≈10 Pa is just below the applied floor — worth noting). The 5 mg mL⁻¹ point (≈400 Pa) sits *above* our band — so this is not a challenge to the mid-density contract but an **extension**: a real, defensible G′(concentration) curve we don't currently gate. Recommend a concentration-resolved companion gate (candidate G-1 below) rather than loosening the existing single-value band.

**VG-U1-force-propagation / VG-U1-strain-stiffening / VG-U1-mikado-topology** — the paper's fiber network (serial cylindrical beams + explicit two-arm crosslinkers, Bell's-law off-rate, sites every 100 nm, ℓ_p≈100 µm) is the same class of object; its **strain-enhanced stress-relaxation** result (item 22) is adjacent to strain-stiffening but is a *different* observable (relaxation, not stiffening exponent) → not covered, candidate G-5. Topology params (item 20, r_{c,f}=6.5 nm; mesh via Eq 11) are inputs, not a new gate.

**VG-U2-catch-slip-bond / MC-U2 Bell-Evans oracle** — the paper's crosslinker unbinding (Eq 9, `k_u = k_{0,u} exp(λ_u|F|/k_BT)`, tension-gated) is **Bell's slip law**, which we already implement as the Bell-Evans off-rate oracle. **DUPLICATE mechanism** — confirms our oracle form; adds no new band (the k_{0,u}, λ_u values are in Table S1, unavailable). No new gate.

**No existing gate covers cell division / mitotic mechanics.** There is no DCM gate for mitotic elongation, cytokinetic-ring force, spindle force, or volume conservation during division. Items 4, 9, 14–17 are **entirely uncovered** — this is the paper's biggest gap-fill for the DCM engine (which already has a membrane + volume constraint + node-face contact, i.e. exactly the machinery this protocol drives). See candidates G-2/G-3/G-4.

**PARAM conflicts** (detailed in Param candidates): item 18 (E≈30 MPa) vs our `PARAM-E_fibril` default 1.1 MPa; item 19 (ℓ_p≈100 µm) vs our `PARAM-ell_p` 17 µm (range 9–22). Both are fibril-vs-fiber / measurement-vs-model-input distinctions, not clean supersessions — flag for PI, do not overwrite.

## New gate candidates (all **candidate, PI-gate review** — staged, not authored)

**G-1 — `VG-ECM-Gprime-vs-collagen-conc` (FF / oracle; overlay-cross-check)**
- observable: reconstituted type-I collagen storage modulus G′ vs mass concentration.
- band/value: G′ ≈ 10 / 100 / 400 Pa at 1 / 3 / 5 mg mL⁻¹ (order-of-magnitude, ±factor ~2 given read-from-figure); monotonic increasing, super-linear in concentration.
- condition: strain 0.01, 1 rad s⁻¹, 37 °C, pH 8.5 gelation.
- engine: FF fiber network (concentration mapped via Eq 11).
- rationale: extends VG-U1-G0-linear from a single mid-density value to a concentration-resolved curve — the strongest *measured* target here. Overlay-only; the tolerance is deliberately loose (figure-read, no error bars in dossier) so it stays a defensible contract, not a fit.
- source: Fig 1B / p2.

**G-2 — `VG-DCM-mitotic-elongation` (DCM; overlay)**
- observable: fractional axial elongation of a dividing cell confined in collagen, ring-only vs ring+spindle.
- band/value: ring-only plateau ~20% (norm 1.1–1.25); ring+spindle ~40% (norm ~1.4) at low density (~1 mg mL⁻¹); elongation **decreases with increasing fiber density**.
- condition: single cell R≈10 µm in collagen, constant-volume constraint, T~2000 s.
- engine: DCM (membrane + volume constraint + node-face contact already exist).
- rationale: the ~40% figure is *experimentally* measured (Fig 1E) and independently reproduced in sim; the ring-only/+spindle decomposition is a clean additive-mechanism test. Overlay target for a future DCM division module. Note the two force magnitudes (G-3) are sim-fitted, so this gate is on the *emergent elongation*, not the input forces.
- source: Fig 1E, Fig 5D/E/I/J, p2,9.

**G-3 — `VG-DCM-mitotic-force-scale` (DCM; comparison-only, NOT a fit target)**
- observable: order of magnitude of the two active mitotic forces used to reproduce experimental elongation.
- value: F_Cyto (ring) ≈ 100 pN/side and F_Is (spindle) ≈ 100 pN/side (equal order).
- condition: applied over ±0.5 µm equatorial band (ring, off within 1 µm of axis) and ≤5 µm polar band (spindle).
- engine: DCM.
- rationale: **these are simulation inputs fitted to match deformation, not measurements** — register as a *comparison ceiling* ("our emergent mitotic push should land in the ~10²-pN/side range"), explicitly flagged never-fit. Include only as a sanity envelope for a DCM division force, with the caveat text baked in.
- source: p12 (Experimental/model).

**G-4 — `VG-DCM-mitotic-volume-conservation` (DCM; sanity check)**
- observable: cell volume across mitotic stages (Meta / Ana / T-C).
- band/value: conserved, n.s. (< ~few % drift) through division.
- engine: DCM (direct test of the constant-volume constraint the engine already enforces).
- rationale: a clean, cheap invariant gate — the DCM volume constraint must hold while the cell elongates 40%. Good conservation-invariant sanity gate (matches our Sanity-Gate protocol's conservation-invariant requirement).
- source: Fig 4B / p7.

**G-5 — `VG-ECM-strain-enhanced-stress-relaxation` (FF; comparison)**
- observable: shear stress relaxation of the crosslinked fiber network is *enhanced* at higher applied strain (crosslinker unbinding under tension).
- band/value: qualitative — larger strain ⇒ faster/greater stress decay (monotonic); quantitative curve needs Table S1 constants.
- condition: matrix-only, 50×50×1 µm periodic, strain-rate 0.1 s⁻¹, hold.
- engine: FF.
- rationale: distinct observable from strain-stiffening; directly exercises FF's Bell's-law crosslinker turnover. **Blocked on Table S1** for a numeric band — stage as qualitative-only until SI obtained.
- source: Fig S12 / p12.

*(Deliberately NOT proposed: fiber-buckling incidence 32% (item 7) — too stochastic/small-N to be a defensible contract band; matrix-deformation magnitudes (items 5,8,12,13) — real but PIV-protocol- and ROI-dependent, better as overlay figures than gated bands unless a DCM cell-in-ECM deformation readout is built.)*

## Oracle candidates

**O-1 — cylindrical-element drag (Eq 4, Clift ref[45]):** `ζ = 3πμ r_c (3 + 2 r_0/r_c) / 5` for a cylinder length r_0, diameter r_c in viscosity μ. Clean closed form → **candidate analytic cross-check for FF fiber-segment drag** (verify FF's per-segment ζ against this). Standard, defensible.

**O-2 — fiber-concentration conversion (Eq 11):** `C = π r_{c,f}² L_{f,tot} / (V ν)`. Maps total fiber length in a domain to mg mL⁻¹. → **conversion oracle** to translate FF/DCM ECM builds into the experimental concentration axis (needed to use G-1). Pairs with Eq 10 `k_{s,f} = πE r_{c,f}²/r_{0,f}` (stiffness↔modulus). Both are algebraic, not fits — good utility oracles.

**O-3 — Bell's-law crosslinker off-rate (Eq 9):** `k_u = k_{0,u} exp(λ_u|F|/k_BT)` (tension-gated). **DUPLICATE** of our existing Bell-Evans off-rate oracle — confirms the functional form; no new oracle needed, and the constants are in Table S1.

*(Not oracles: Eqs 2–3 fluctuation-dissipation and Eq 5 Euler are the generic overdamped-Langevin BD our BAOAB integrator already subsumes; Eq 1 "degree of plasticity" ε_remaining/ε_max is a rheology metric, not a mechanistic law.)*
