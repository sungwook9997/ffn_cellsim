## Paper kind

**Primary: experimental** (bottom-up in-vitro reconstitution: purified F-actin + smooth-muscle myosin II + α-actinin encapsulated in ~20 µm liposomes) — **with two additional, separable components** that must be treated differently for validation:

- **Analytic theory (Supplementary Note 1)** → *candidate oracle* material. Closed-form cortex-**detachment** threshold from a Bell-kinetics ODE + Young-Laplace (Eqs 2–8).
- **Agent-based simulation (Supplementary Note 2, Taeyoon Kim's engine)** → *comparison-only, never a truth source*. This is exactly the FF/DCM paradigm (overdamped Langevin + FDT + cylindrical drag + severing + parallel-cluster myosin + triangulated volume/area-conserving membrane), so its numbers (network tension ~200 pN/µm, bleb onset ~150 s, membrane tension) are model outputs to compare against, not lab data.

**Usage rule that follows:** experimental numbers = overlay / **on-demand cross-check** (this is a *reconstituted minimal system with a His-tag/Ni-NTA engineered actin–membrane linkage*, **not** an MCF-7 cell — so per the "oracle is cross-check, not truth" hard rule these are cross-checks for FF filament/motor physics, never MCF-7 gate targets or fit targets). Analytic laws = candidate oracle. Simulation = comparison scenario for a future coupled FF⊗DCM run.

## Coverage vs existing gates

- **Young-Laplace (ΔP·R/2 oracle — already in our oracle set; `young_dupre.py`, DCM ΔP=γ·2/R).** Item 1 **CONFIRMS** it and **extends** it: Eq 2 adds an explicit membrane-tension term ΔP = 2(γ_m+γ_c)/R − 2γ_m0/R₀, and the paper confirms *in silico* that near the bleb threshold γ_c≫γ_m so ΔP≃2γ_c/R (our form). → tighten/extend existing oracle, no new gate.
- **Bell-Evans off-rate oracle (already in our set).** Items 2–3, 10–11 **CONFIRM** it: the detachment ODE (Eqs 4–5) is Bell kinetics k_off=k_off⁰·exp(r₀f/k_BT) with f=ΔP/ρ_H^b. No band change; this is corroborating literature. Note α-actinin rupture force here (1.4–80 pN, Ferrer/Miyata) is consistent with our KB's Ferrer-2008 re-anchoring of the α-actinin k_off⁰ (0.066 s⁻¹).
- **Hill force-velocity oracle (already in our set).** The paper does **not** use Hill; it uses the **parallel-cluster model (Erdmann-Schwarz)** catch-bond motor. Items 13–14 (stall 5.7 pN/arm, v₀ 140 nm/s) are a *different mechanistic motor model* — a comparison/cross-check for FF's motor, not a Hill-gate change.
- **VG-H8-membrane-tension** (band f_t 5–40 pN; T 3e-5–3e-4 N/m; κ_m 0.4–1.2e-19 J). Item 5 (membrane tension ~0–8 pN/µm ≈ 0–8e-6 N/m) sits *below* our T band but this is a floppy reconstituted vesicle pre-bleb, not a tethered MCF-7 membrane → comparison only. Item's model κ_b,MB=2.4e-19 N·m is **above** our κ_m band 0.4–1.2e-19 J, but it is a coarse 50-nm-thick mesh bending constant (model), **not** a lipid-bilayer measurement → do **not** supersede the H.8 band; flag as a modeling-convention mismatch.
- **VG-H3-KU35 / KU-3.5 cortex tension (band 0.35–0.65 mN/m).** Item 4 (reconstituted cortex network tension ~0.2 mN/m) is *near but below* our band. It **does not challenge** the MCF-7 contract — it is a minimal reconstituted actomyosin cortex (simulation output), and it actually **corroborates the recurring interphase cortical-tension figure ~0.15 mN/m** noted in project memory. Comparison/cross-check only; not a gate change.
- **VG-H10-cytoplasm (η 10–70 Pa·s).** Item 15 (μ=8.6 Pa·s) is a *model choice* in the sim (real buffer 0.92 mPa·s), so it is **not** a viscosity datum — do not register against our cytoplasm band.
- **FF filament/motor/crosslinker physics (MC-U3-cell-integration cortex; U3 multifilament gate VG-U3-cortex-multifilament; motor/clutch params).** Items 6–14 are the **fully-specified native-scale parameter set** for exactly the FF paradigm — largely *new coverage* (see param candidates). No FF **gate** currently pins actin persistence length, severing force, or minifilament length.

## Oracle candidates

**ORACLE-cand-detachment-threshold (analytic, FF⊗DCM cross-check).** A closed-form combining Bell-kinetics + Young-Laplace for cortex-from-membrane detachment:

- ΔP* ≃ 0.7·(k_BT·ρ_H / r₀)·ln(ρ_A / K_m^2D)  (Eq 6)
- γ_C^D* ≃ 0.35·(k_BT·ρ_H·R / r₀)·ln(ρ_A / K_m^2D), with **γ_C^D* ∝ R_C** (Eqs 7–8)
- K_m^2D = k_off⁰/k_on; rupture counterpart γ_C^R* = increasing in R_X, R_C-independent (stated, not derived).

This is a genuine analytic ground-truth for a coupled FF⊗DCM run in which a contractile cortex peels off a volume-conserved membrane under internal pressure — i.e. it predicts the critical cortical tension/pressure at which a bleb nucleates by detachment, as a function of the adhesion (coupling) density. It composes two oracles we already trust (Bell-Evans + Young-Laplace), so it is low-risk to implement as a derived cross-check. **Candidate — PI review**; useful once FF cortex ⊗ DCM membrane coupling with breakable clutches exists. n_tighten (Young-Laplace membrane+cortex extension / confirm) = **1**.
