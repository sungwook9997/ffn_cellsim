# FF lens — p15

**Paper:** Ding, Matsui, Kaunas, **Kim**, Deguchi (2025) — *Dissecting Molecular Origins of the Mechano-Adaptive Behaviors of Actomyosin Bundles*. bioRxiv 10.1101/2025.07.09.663940.

**Why this paper is special for FF:** it is the **canonical Taeyoon Kim agent-based actomyosin model** (refs [43]–[48], the same lineage FF already cites for the DCM⊗ECM 1/r work) run as a *single contractile unit* — i.e. it is FF's own physics class (explicit actin bending beams + Bell-model ACPs + multi-arm parallel-cluster-model myosin minifilaments + overdamped Langevin) at the sub-bundle scale, with a **complete, provenance-tagged parameter table (Table S1)** and clean **stress-fiber buckling/recovery validation targets**. This is a near-drop-in reference parameter set and a validation scenario for FF's crosslinker + myosin + filament modules. Two co-authors (Kim, Kaunas) overlap our existing KB. Caveat: it is smooth-muscle stress-fiber (A7r5), purified/permeabilized, *turnover-OFF* — that is a feature for parameter-porting (isolates intrinsic mechanics) but a regime flag for cortex work.

## 1. MECHANISMS to adopt

### 1a. Myosin — replace/validate the walk-off scheme with the **Parallel-Cluster-Model (PCM) catch-bond** force-velocity + force-dependent unbinding (STRONG, primary lever)
FF's `myosin` module currently uses Hill (1938) force-velocity + a duty ratio. This paper uses **PCM** (Erdmann–Schwarz parallel-cluster-model, 3 myosin head states, 5 transition rates) on a Stam–Hocky-style multi-arm bipolar minifilament — the *same architecture class* FF already targets, but with the walking rate `k_w,M(F)` and the unbinding rate `k_u,M(F)` BOTH decreasing with longitudinal-spring force (catch-bond), plus a **hard 30 pN slip cutoff** (catch→slip approximation, ref [62] Guo & Guilford). Why it beats current FF: Hill is a phenomenological *deterministic* force-velocity closure; PCM is a *stochastic per-head kinetic scheme* whose macroscopic force-velocity and stall EMERGE (v₀≈56 nm/s, F_s≈24 pN emerge from k₂₀=8 s⁻¹ and N_h=4). This is exactly FF's "mechanistic over lumped" rule — a per-head Markov cluster is finer-grained than a Hill curve. **Recommendation:** offer PCM as a mechanistic alternative walking kernel alongside Hill; keep Hill as the acceptance oracle (its stall/v₀ should reproduce the PCM output).

### 1b. Myosin — **load-free walking drives shape recovery / bundle shortening** (mechano-adaptation without turnover)
Key conceptual mechanism for FF's *network contraction & stress-relaxation* open problem: after the load is removed, the motors **keep walking toward barbed ends at their unloaded speed**, progressively shortening the bundle and straightening buckles — a purely mechanical, **turnover-independent** relaxation that no spring-dashpot (Kelvin–Voigt/Maxwell/SLS) captures. Recovery *rate* is set by motor walking speed (k₂₀), **not** motor density (R_M). This is a directly testable prediction FF can reproduce and a mechanism FF should expose: FF's stress-relaxation should show a motor-walking-driven mode distinct from crosslinker-unbinding-driven relaxation.

### 1c. Crosslinker (ACP / α-actinin) — **Bell slip-bond force-dependent unbinding is confirmed and parameterized** (validate FF's existing Bell-Evans)
FF already uses Bell-Evans k_off = k_off0·exp(F/F_b). This paper gives a clean, self-consistent ACP slip-bond datum: **k⁰_u,ACP = 0.05 s⁻¹**, bond length **x_u,ACP = 0.9 nm**, with the exact functional form (Eq. S8). This is a cross-check / candidate parameter for FF's generic ACP; note the mechanism that stretch-induced ACP unbinding under tension → **permanent bundle lengthening** (force relaxation) — the crosslinker-unbinding relaxation channel FF should reproduce alongside 1b.

### 1d. Filament bending — **bundle bending stiffness sets buckling shape, not recovery time** (decouples two FF observables)
Parametric result: filament/bundle κ_b sets the buckling curvature K_r but barely changes recovery time t_r (Fig. 3). For FF this is a validation invariant: if FF's cortex/SF buckling recovery time depends strongly on ℓ_p, something is wrong. Also a *modeling-cost lesson* directly relevant to FF's native-scale mandate — they varied bundle stiffness via κ_b (10× the experimental value) instead of adding filaments, explicitly to save cost. FF must NOT copy this shortcut (it violates our native-scale rule); flag κ_b,A/κ*_b,A=10 as a non-physical modeling choice whenever citing their reference runs.

### 1e. Buckling criterion — **buckle iff compression rate > unloaded motor walking speed** (emergent symmetry-breaking rule)
Clean mechanistic criterion for FF's buckling/condensation open problem: a bundle buckles only when the imposed shortening rate outpaces the rate at which motors can walk-in the slack. Slow compression → motors keep the bundle taut → no buckling. This gives FF a *predictive* buckling threshold to validate against, tying motor kinetics to a mechanical instability.

## 2. FORCE LAWS / KINETIC SCHEMES to port

Map to FF state: `seg` = filament segment (bead-rod), `θ` = hinge angle between consecutive segments, `r` = segment length, `F` = tensile force on a bond/spring.

**(S5) Bending harmonic** (→ FF filament angular bending κ):
```
U_b = ½ κ_b (θ − θ₀)²            θ₀ = 0
```
κ_b,A = 2.64×10⁻¹⁹ N·m ↔ persistence length ℓ_p = 9 µm (their actin datum, ref [4]/Isambert [54]). **NOTE:** FF currently uses ℓ_p ≈ 17 µm for actin; this paper uses 9 µm (isolated/older datum) and *then inflates it 10×* for the reference run. Keep FF's 17 µm as physiological; treat 9 µm as a lower-bound cross-check, and DO NOT adopt the ×10.

**(S6) Extensional harmonic** (→ FF stretch modulus):
```
U_s = ½ κ_s (r − r₀)²
```
κ_s,A = 1.69×10⁻² N/m, r₀,A = 140 nm (segment length).

**(S7) Volume-exclusion repulsion** (→ FF LJ/excluded-volume; here harmonic one-sided):
```
U_r = ½ κ_r (r₁₂ − r_c,A)²   if r₁₂ < r_c,A ;  else 0
```
κ_r = 1.69×10⁻³ N/m, r_c,A = 7 nm (actin diameter). FF uses LJ-repulsive; this is a one-sided harmonic alternative — same physics, cheaper; keep LJ but note equivalence.

**(S8) Bell force-dependent ACP unbinding** (→ FF crosslinker Bell-Evans):
```
k_u,ACP = k⁰_u,ACP · exp( x_u,ACP · |F_s,ACP| / k_B T )   if r ≥ r₀,ACP
        = k⁰_u,ACP                                        otherwise
```
k⁰_u,ACP = 0.05 s⁻¹, x_u,ACP = 0.9 nm, k_BT = 4.142×10⁻²¹ J. Maps 1:1 onto FF's k_off = k_off0·exp(F/F_b) with F_b = k_BT/x_u = 4.142×10⁻²¹/0.9×10⁻⁹ ≈ **4.6 pN**. This F_b≈4.6 pN is a concrete Bell characteristic force for a generic ACP.

**ACP binding:** k₊,ACP = 100 (µM·s)⁻¹; binding sites every **7 nm** along the filament (binding pitch).

**Motor binding (per arm):** k₊,M = 40·N_h s⁻¹ = 160 s⁻¹ (N_h=4).

**PCM catch-bond walking / unbinding** (→ FF myosin kernel, mechanistic alt to Hill): 3 head states, 5 rates; the ATP-dependent post-power-stroke→unbound rate **k₂₀ tunes walking speed** (k₂₀ = 4/8/16 s⁻¹ → zero-force walk rate k_w,M(0) = 4/8/16 s⁻¹). Both k_w,M(F) and k_u,M(F) decrease with longitudinal-spring force (catch-bond). **Hard slip cutoff: arm unbinds instantly if F > 30 pN** (ref [62]). Emergent macroscopics: **unloaded velocity v₀ ≈ 56 nm/s** (k₂₀=8), **stall force F_s ≈ 6·N_h pN = 24 pN** (F where k_w,M→0, common to all k₂₀). k_u,M(0) up to ~1.0 s⁻¹ at k₂₀=16.

**Motor arm geometry (Stam–Hocky-style minifilament):** backbone = 7 segments (center = bare zone), N_a = 8 arms, N_h = 4 heads/arm → **32 heads/motor**. Arm = two-spring model: transverse spring κ_s,M2 = 1.0×10⁻³ N/m (r₀=13.5 nm) + longitudinal spring κ_s,M3 = 1.0×10⁻³ N/m (r₀=0, enforces right-angle arm↔actin). Backbone stiff (κ_b,M = 5.07×10⁻¹⁸ N·m ≫ κ_b,A) so it stays straight.

**(S3) Cylinder drag** (→ FF per-segment drag ζ):
```
ζ_i = 3π µ r_c,i · (3 + 2 r₀,i / r_c,i) / 5
```
µ = 8.6×10⁻² Pa·s (≈86 cP, their in-vitro buffer). NOTE for FF: our *cytoplasm* is 65 Pa·s (MCF7, Dessard) — ~750× higher; this µ is buffer, do NOT adopt for intracellular FF (physiological-baseline rule). Their drag *functional form* is portable; the value is not.

**(S1/S2/S4) Overdamped Langevin + FDT + Euler** — FF uses constrained BAOAB (finer integrator), so their Euler is a *coarser* integrator; keep BAOAB. Their FDT variance ⟨F_iᵀ F_jᵀ⟩ = (2 k_BT ζ_i δ_ij/Δt)δ is the standard thermal-noise form FF already satisfies.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario: "single contractile unit / mini stress fiber")

**Geometry (anti-parallel sarcomere-analog):**
- N_F = 50 actin filaments, L_f = 4.9 µm each, initial 5 µm span, all oriented along z.
- Barbed ends of half → spring-tethered (κ_s,bnd = 1.0×10⁻² N/m) to −z boundary; other half → +z boundary. → one anti-parallel contractile unit.
- x,y placed on a **27 nm** circle (bundle cross-section); filaments intentionally overlap to guarantee uniform cross-linking (they note only ~12 of 7-nm filaments physically fit; real SF = 10–30/cross-section, so 50 is ≥ physiological).
- Cross-linked by explicit ACPs (R_ACP=0.1) + explicit multi-arm myosin (R_M=0.01).
- Domain 20×20×5 µm.
- **Assembly phase:** filaments held fixed while ACPs+motors bind, then released; thermal + repulsion thickens bundle. (FF equivalent: relax-to-resting before load — matches our `--from-resting` discipline.)

**Loading protocol (portable as an FF mechanical-test scenario):**
1. Stretch +z boundary at ε̇_s = 0.1 s⁻¹ to ε = 0.5 over 5 s.
2. Hold ε = 0.5 for 1 s (force relaxation).
3. Compress back to ε = 0 at ε̇_c = −0.25 s⁻¹ over 2 s (sweep 0.01–0.5).
4. Hold ε = 0; measure recovery. Complete when L_B − L_ee < 0.01 µm.

**Observables to implement in FF (measurement protocols):**
- Tensile force **F_B**: average over 20 equispaced z cross-sections of summed z-component of extensional forces on ALL segments crossing each section (actin + motor arms + motor backbone + ACP), every 1 s.
- **Curvature** κ = |r′×r″|/|r′|³ (Eq. 1) per filament endpoint → bundle curvature K.
- **L_ee** = z-distance between extreme actin endpoints; **L_B** = contour length (sum of two half-domain averaged filament lengths, excluding fragments split off the bundle).

This is a clean, cheap (N_F=50, one unit) FF regression scenario for the myosin + crosslinker + filament-bending modules — small enough for dev smoke tests but mechanistically native (no lumping). It complements FF's cortex work: it isolates *contractile-unit* mechanics that the full cortex is built from.

1. Recovery rate ∝ **motor walking speed (k₂₀)**, independent of motor density (R_M). (t_r, |dL_B/dt| move with k₂₀; flat with R_M.)

## 6. RISKS / caveats

- **Regime = purified permeabilized smooth-muscle SF, turnover OFF.** Actin/ACP/myosin turnover was deliberately removed (de-roofed, buffer-activated) so mechano-adaptation is *intrinsic mechanics only*. This is a FEATURE for parameter-porting (isolates the mechanics) but means these numbers do NOT include cortex turnover/fragmentation. For FF cortex work (γ-floor, turnover) this is a **contractile-unit sub-model**, not a cortex constitutive law — use it to validate the myosin/ACP kernels, then re-run at native cortex scale with turnover ON.
- **Drag µ = 86 cP is buffer, not cytoplasm.** FF's physiological-baseline rule requires 65 Pa·s intracellular viscosity. Port the drag *form* (Eq S3), never the value. Recovery times t_r would rescale with the true viscosity — do NOT expect the raw 12 s to survive at cytoplasmic drag.
- **κ_b,A deliberately inflated ×10 for the reference runs** (κ_b,A/κ*_b,A=10) "to get a clear buckling pattern," and ℓ_p=9 µm is already below FF's 17 µm. Their *reference* buckling shapes are therefore at a NON-physical bending stiffness. Cite Fig 3 as a *scaling* result (K_r∝stiffness⁻¹, t_r flat), not as absolute buckling curvatures. FF must keep physiological ℓ_p and never copy the ×10 shortcut (violates native-scale + no-magic-number rules).
- **Bundle stiffness varied via κ_b instead of filament count** to save cost — the exact shortcut FF's HARD native-scale rule forbids. Reproduce their *finding* (stiffness sets shape) by adding filaments at native density, not by scaling κ_b.
- **N_F=50, single anti-parallel unit** is far below cortex Nc≈266k. Use as a dev-scale FF regression/unit-test (labelled non-authoritative per the coarse-scale rule); any conclusion for the cortex must be reconfirmed on the native full cell. It is legitimate as an *isolated SF/contractile-unit* scenario in its own right (SFs really are ~10–30 filaments/cross-section) — but not as a cortex claim.
- **PCM vs Hill:** adopting PCM as a mechanistic myosin kernel is a genuine engine change — gate it kernel-by-kernel against the Hill oracle (v₀, F_s must match) before it supersedes anything. Don't silently swap.
- **Euler integrator (Δt=1.15 µs) is coarser than FF's BAOAB** — keep BAOAB; their timestep is only informative for CFL sanity of the stiff motor arm springs (κ_s up to 1.69×10⁻² N/m).
- **Not peer-reviewed (bioRxiv 2025).** Treat as candidate/corroborating for KB; the ACP k⁰=0.05 s⁻¹ is model-tuned, and v₀=56/F_s=24 are model outputs, not independent measurements — register as sim-derived, not as new SourceEvidence, unless tracing to the underlying Kim [43]–[48] or Guo/Guilford [62] primary sources.
