# TAG-validation lens — p16

**Paper:** Yim, Patterson, Suter, Miller, Kim (2025) — *Computational Modeling of Motor-Driven Extension of Microtubule Bundles in Axons.* bioRxiv 10.1101/2025.09.25.678704 (preprint, NOT peer-reviewed). Taeyoon Kim lab, agent-based cylindrical-element Brownian dynamics.

## Paper kind

**simulation** (agent-based / particle-based Brownian dynamics; model output). Its own extension/buckling/energy curves are *comparison-only*, never a truth source. HOWEVER two ingredients are borrowed from external sources and carry independent validation weight:
- **analytic** — Euler critical buckling load `F_cr ∝ κ_b/L_uns²` (Eq. 10) and persistence-length relation `l_p = κ_b/(k_BT)` (Eq. 11): closed-form → candidate oracles.
- **experimental (literature-anchored)** — dynein force–velocity + unbinding curves (Monzon 2018, ref 48), MT diameter 25 nm (ref 6), MT persistence length l_p≈1 mm (Isambert, ref 45), curvature/buckling threshold 0.2 rad/µm (Memet 2018, ref 49), Bell slip-bond form (Bell 1978, ref 47). These may be used as overlay/cross-check.

Net: the paper is **not** a source of new experimental cell-scale bands; it is a **methods/oracle sibling** to the FF engine (same cylindrical-element lineage, ref 46 Jung–Murrell–Kim). Its value is as an FF cross-check for filament buckling + motor+crosslinker mechanics, and as a source of the analytic Euler-buckling oracle.

## Coverage vs existing gates

- **No existing gate covers microtubules, dynein motors, motor-driven filament transport, or filament buckling.** All current gates are actin-cortex (VG-H3/H7/H8/H9/H10, VG-U3-*), ECM Mikado (VG-U1-*), FA integrin clutch (VG-U2-*), cadherin junction (VG-U4-*), or spheroid/necrosis (VG-U5-*). This paper's observable class (MT bundle + dynein + buckling) is **entirely new** to the KB.
- **VG-U2-catch-slip-bond** (Bell/catch-slip lifetime vs force, integrin-FN, peak ~30 pN) is the *nearest* relative to item 6, but that gate is a **catch-bond** for integrin; the paper's crosslinker is a **monotonic slip-bond** (Tau-like, ref 47) — a different bond and different protein. **Neither confirms nor challenges** VG-U2. The paper does reinforce that FF's crosslinker off-rate must be Bell force-dependent (matches the architectural principle / MC-U2 caveat) — consistency note, not a band change.
- **VG-U3-cortex-multifilament** requires "Bell-Evans crosslink dynamics active" as a Phase-2 entry gate — the paper is a good *methods sibling* for that mechanism (transient two-element crosslinker with Bell off-rate) but on MTs, not actin; no band overlap.
- **l_p = κ_b/k_BT** (item 2) is already the relation behind PARAM-kappa_fiber / PARAM-ell_p (derived at runtime from ℓ_p·k_BT). Paper **confirms** the convention; no change. Note values differ by filament (collagen ℓ_p=17 µm vs MT ℓ_p=1 mm) — do not cross-anchor.
- Result: **CONFIRMS** the Bell-off-rate and l_p conventions; **covers a new class** for everything else. 0 bands tightened, 0 challenged.

## New gate candidates

All flagged **candidate — PI-gate review**. These are only warranted if/when FF grows an MT-bundle or generic motor-compression module; today FF is actin-cortex + filopodium. Stage, do not author.

1. **[candidate] VG-FF-euler-buckling** — *observable:* onset of filament buckling (fraction of nodes with curvature > 0.2 rad/µm rising above ~0) vs applied axial compressive load, for a single crosslinked filament segment. *band/value:* buckling onset scales as `F_cr ∝ κ_b/L_uns²` (Euler); measured critical load within a factor ~2 of πκ_b/L_uns² for the clamped/pinned case. *engine:* FF (or oracle cross-check). *source:* Eq. 10, p.14. — This is the strongest addition: an **analytic** anti-buckling law FF can be validated against directly.
2. **[candidate] VG-FF-dynein-fv** — *observable:* single dynein walking speed vs load. *value:* unloaded ~1.1 µm/s, → ~0 near stall; k_u,M rising to ~1 s⁻¹ under load. *engine:* FF motor module (oracle-style, analogous to the existing Hill myosin oracle). *source:* Monzon 2018 via Fig. 1F, p.8. — Only if FF adds dynein; band is literature (Monzon), overlay/cross-check not fit.
3. **[candidate] VG-FF-buckling-curvature-metric** — *measurement-protocol constant, not a physics gate:* adopt discrete per-node curvature (Eq. 9) with the 0.2 rad/µm "curved" threshold as FF's buckling readout, so buckling gates are apples-to-apples with this literature. *source:* Eq. 9 + Memet 2018, p.9.

Explicitly **NOT** proposed as gates: ε_max magnitudes, time-to-peak, biphasic R_X optimum, energy ratios — these are the paper's own simulation outputs (comparison-only), and several core parameters (κ_s, κ_b magnitudes, k⁰_u,X, x_u,X, F_R, μ) are **unspecified in the text**, so no defensible band can be anchored to them.

## Oracle candidates

1. **Euler critical buckling load (STRONG).** `F_cr = C · κ_b / L_uns²` (Eq. 10; C = boundary-condition constant, π² for pinned-pinned). Closed-form ground truth for FF filament buckling under motor/axial compression — a genuine analytic cross-check FF currently lacks (FF has Helfrich bending & Young-Laplace, but no compression/buckling oracle). Recommend implementing as an FF oracle: apply known axial load to a crosslinked segment of known κ_b and L_uns, confirm buckling onset matches F_cr. Fits the "validate against analytic ground truth as primary" rule perfectly.
2. **Persistence length ↔ bending stiffness** `l_p = κ_b/(k_BT)` (Eq. 11) — already the FF convention (PARAM-kappa_fiber derived from ℓ_p·k_BT); paper confirms, no new oracle needed.
3. **Bell slip-bond off-rate** `k_u = k⁰ exp(F·x/k_BT)` (Eq. 8) — the KB already has Bell-Evans as an oracle; this is a duplicate form (slip branch), useful only as a consistency check on the FF crosslinker off-rate.

## Duplicates / notes

- **Bell-Evans off-rate** and **Hill/force-velocity motor** are already sanctioned FF oracles/mechanisms (CLAUDE.md architectural table). The paper's crosslinker Bell slip-bond and dynein force-velocity are **the same mechanistic class** — reinforces the existing architecture, adds no new claim, except that the motor is **dynein** (Monzon curves) rather than myosin (Hill) — a new motor species FF does not yet model.
- Same **Taeyoon Kim cylindrical-element lineage** (ref 46, Jung–Murrell–Kim 2015) that FF/Cytosim parallels — this is a *methods sibling*, valuable as an independent implementation to cross-check FF filament+motor+crosslinker dynamics, NOT a new physics contract.
- **DCM relevance: none** — no cell surface/membrane/cortex-shell/turgor/junction; purely a filament-bundle model.
- **No KB duplicate found** — no existing KU/KB claim covers MT-bundle dynein-driven extension or Euler buckling of crosslinked filaments; this is net-new territory, but net-new territory FF does not currently occupy (actin cortex + filopodium, not axonal MT bundles).
- Bottom line: **highest-value single item = the Euler buckling oracle (candidate VG-FF-euler-buckling)**; everything else is overlay/comparison-only or preprint-flagged params gated on a future FF MT module.
