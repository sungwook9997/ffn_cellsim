# FF lens — p08

**Paper:** Sasmal, Miyazaki, Carlier-Grynkorn, Tran (2026) *Chimeras of kinesin-6 and kinesin-14 reveal head-neck-tail domain functions and dysfunctions that lead to aneuploidy in fission yeast.* Curr Biol 36, 415–425. DOI 10.1016/j.cub.2025.11.073.

**Bottom line for FF:** LOW direct relevance. This is a purely in-vivo *S. pombe* mitotic-spindle molecular-genetics paper (domain-swap chimeras of the plus-end kinesin-6 Klp9 and minus-end kinesin-14 Pkl1). It contains **no force law, no force-velocity relation, no stall force, no run length, no bond off-rate, no duty cycle, no mesh size, no rheology** — the authors state "No in-house code was used" and there is no model of any kind. FF is an **actomyosin/actin-filament** engine (Cytosim physics, but our modules are actin cortex + α-actinin/filamin crosslinkers + Stam–Hocky myosin-II minifilaments + Arp2/3 + formin + integrin clutches); it does not currently model microtubules or processive plus/minus-end kinesins. The only genuinely transferable content is **conceptual motor-design logic** (which structural domain sets directionality vs. speed vs. localization) plus a handful of **coarse in-vivo sliding velocities** that could seed an *optional future* MT/kinesin module — not the actin cortex we run today. Nothing here supersedes any current FF parameter.

---

## 1. MECHANISMS to adopt

Ranked by (low) applicability. None replaces a current actin-engine mechanism; all are conditional on FF someday growing a microtubule + directional-motor module (which Cytosim's core physics supports — Nédélec & Foethke 2007 was built for exactly MT/kinesin spindles).

1. **Motor module — separate "directionality/localization" from "speed" as independent, structurally-assigned properties (the head-neck-tail decomposition).** The paper's central, robust finding: the **tail** dictates where the motor localizes and can even *reverse the effective walking direction of a foreign head* (P1 minus-end head on K9 neck-tail walks plus-end toward the midzone); the **neck modulates head speed** (K9 neck speeds up, P1 neck slows down) but does NOT set direction/localization; the **head produces the binding/sliding force** and carries an intrinsic speed. For FF this is a clean *software-architecture* lesson even for the existing Stam–Hocky myosin module: keep (a) the walking-direction/track-affinity rule, (b) a scalar speed modulator, and (c) the force-generating stepping kinetics as **three orthogonal knobs**, so an isoform or a targeting change can be expressed by swapping one knob without re-deriving the force law. Why it beats the current lumped treatment: FF myosin currently bakes direction (toward barbed end) and speed into one Hill relation; this paper shows biologically these are dissociable, so a factorized motor state is the more mechanistic representation for future non-myosin motors.
   - **Caveat:** this is an *organizational* adoption, not a physics change. Do NOT re-parameterize FF myosin from a kinesin paper.

2. **(Future MT module only) Antiparallel-MT sliding by a bipolar/tetrameric plus-end motor at an overlap zone.** Klp9 is a homotetramer that crosslinks antiparallel midzone MTs and slides them apart — the exact analog FF already implements for actin via the Stam–Hocky bipolar minifilament sliding antiparallel actin. If FF adds MTs, reuse the existing bipolar-crosslinking-motor code path with a kinesin force law rather than writing a new mechanism. Not adoptable today (no MT filament type in FF).

3. **(Future) Emergent "too-fast motor buckles/breaks its own filament network" as a mechanistic failure mode.** P1h:K9nt slides ~1.5× faster than WT → over-elongates the spindle into an S-shape → buckling → breakage. This is a genuinely mechanistic emergent instability (motor drive exceeding the load-bearing/relaxation capacity of the filament bundle under a resisting boundary). It maps conceptually onto FF's OWN open problem list: **buckling/condensation symmetry-breaking** and **motor-driven contraction outrunning stress relaxation**. Worth remembering as a qualitative validation of "excess motor drive → buckling" but the paper gives **no threshold force, no critical velocity, no bending modulus**, so it cannot parameterize an FF buckling gate.

## 2. FORCE LAWS / KINETIC SCHEMES to port

**None.** The paper contains zero governing equations, zero force laws, zero bond-kinetics schemes, zero force-velocity relations. The only "law" invoked (from its ref 16, verbally) is the qualitative scaling *anaphase spindle-elongation velocity increases with the number of Klp9 midzone motors* — not written as an equation and not usable as a force law. There is nothing to transcribe or map to FF state.

## 3. PARAMETERS / RATE CONSTANTS to set

**None to set in any current FF actin module.** No k_off0, F_b, stall force, step size, duty ratio, ℓ_p, link stiffness, or nucleation rate appears anywhere in the paper. The measured quantities are in-vivo sliding *velocities* and aneuploidy frequencies, not mechanistic constants. For completeness, the only numbers that could ever seed a *future* MT/kinesin module (as coarse emergent-velocity targets, NOT force parameters):

| observable | value | units | note |
|---|---|---|---|
| WT Klp9 anaphase-B sliding velocity | 0.68 ± 0.07 | µm/min (≈11 nm/s) | plus-end tetrameric kinesin-6, in vivo |
| Klp9 deletion (K9Δ) residual velocity | 0.35 ± 0.08 | µm/min | other midzone motors |
| P1h:K9nt (fast chimera) velocity | 1.19–1.51 | µm/min (≈20–25 nm/s) | P1 head intrinsically faster |
| FRAP midzone motor recovery speed, WT | 1.62 ± 0.48 | µm/min | plus-end-directed signal front |
| FRAP recovery speed, P1h:K9nt | 2.39 ± 0.92 | µm/min | ~1.5× faster refill |
| FRAP midzone recovery time, WT / chimera | 47 ± 18 / 29 ± 6 | s | turnover timescale of motor on overlap |

These are **whole-spindle emergent rates** (10s of nm/s), not single-motor force-velocity data; they cannot be plugged into a Hill/Bell-Evans law. They do **not** supersede any current FF value (FF myosin uses actin-myosin kinetics; this is kinesin-MT). Registering them would require a new "MT/kinesin motor" KnowledgeClaim the project does not currently have.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce

**Not reproducible as an FF scenario today.** The system is a closed-mitosis yeast spindle (~25 MTs per pole, antiparallel midzone overlap, poles focusing minus ends) — an MT architecture FF does not build. No reconstitution geometry, no in-vitro gliding/motility assay, no defined crosslink density, no confinement dimensions, no purified-protein concentrations are given (it's all in-vivo genetics with native-promoter expression). The one architectural datum — **~25 MTs per spindle pole** and a "critical motor number to focus minus ends" — is a spindle-assembly fact, not an actin-cortex protocol. Nothing here defines an FF cortex/lamellipodium/filopodium scenario.

If FF ever adds a spindle module, the reproducible qualitative protocol would be: two half-spindles of ~25 MTs each, antiparallel overlap at the midzone, a tetrameric plus-end motor crosslinking the overlap and sliding it (elongation), plus a minus-end motor clustering at poles (focusing), under a **resisting closed-nuclear-envelope boundary** (tensile force opposing elongation). That is a Cytosim-class setup but outside our current actin scope.

## 5. VALIDATION TARGETS for FF observables

**None for the current FF actin cortex / adhesion / ECM gates.** The paper's numbers are yeast-spindle sliding velocities (0.35–2.39 µm/min) and aneuploidy frequencies (2–11% mini-chromosome loss) — not G'(ω)/G''(ω), stress-relaxation times, cortical tension γ, contraction rate, buckling threshold, mesh size, or motor velocity-vs-load, which are the FF validation observables. No rheology, no tension, no exponent, no load-dependence is measured.

The single conceptual "target" one could carry forward (again, only for a hypothetical MT module) is the **motor-drive → buckling → breakage** cascade: an overly fast slider over-extends and buckles its bundle against a resisting boundary. FF could *qualitatively* reproduce that with actin bundles + excess myosin, but the paper provides no quantitative band to gate against.

## 6. RISKS / caveats

- **Wrong filament class.** This is microtubule + kinesin; FF is actin + myosin/α-actinin/Arp2/3/formin. Bending modulus, persistence length (MT ℓ_p ~1–5 mm vs actin ~17 µm), motor mechanochemistry, and polarity conventions are all different. Do **not** import any kinesin number into an actin module. This would violate the "no fitting / physiologically-correct-from-t=0" rules (using a kinesin velocity to tune actomyosin is category-error tuning).
- **In-vivo, not reconstituted.** Every velocity is a whole-spindle emergent rate inside a living yeast nucleus with unknown load, MAP crosslinking (Ase1, Msd1/Wdr8), and a resisting nuclear envelope — not a single-motor force-velocity measurement. It cannot calibrate a mechanistic per-motor law; treating it as one would inject a lumped proxy, which the FF architecture principle forbids.
- **Species/isoform gap.** Fission-yeast mitotic kinesins; the cancer touchpoint is only that kinesin-14/HSET is a therapeutic target — irrelevant to MCF7 actin cortex mechanics.
- **How to adopt without breaking rules:** (i) take ONLY the *architectural lesson* (factor motor direction/localization from speed from force-generation into orthogonal state) — a code-organization improvement that changes no physics or parameter; (ii) shelve the sliding velocities as **SourceEvidence for a would-be future MT/kinesin KnowledgeClaim**, clearly labeled as coarse in-vivo emergent rates, never as force parameters, and never registered against the current actomyosin gates; (iii) note the "excess motor drive → buckling → breakage" motif as qualitative corroboration for FF's existing buckling/contraction-instability agenda, with no numeric gate. Provenance is clean (peer-reviewed Curr Biol, verified DOI), so citation-safe if ever used.
