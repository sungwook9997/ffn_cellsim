# FF lens — p22

**Paper:** Nam, Lin, Kim, Chaudhuri (2021) *Cellular Pushing Forces during Mitosis Drive Mitotic Elongation in Collagen Gels*, Adv. Sci. 8, 2000403. DOI 10.1002/advs.202000403.
**Computational contributor:** Taeyoon Kim lab (Purdue) — agent-based Brownian-dynamics crosslinked-fiber network. This is a Cytosim-adjacent, FF-native model: fibers = serial cylindrical beam elements (stretch + bend), explicit two-arm crosslinkers with Bell's-law force-dependent off-rate, overdamped Langevin with fluctuation–dissipation. **The ECM/matrix side of this paper is essentially an FF sub-engine.**

> Scope caveat up front: this is a **collagen ECM fiber network** (E≈30 MPa fibrils, ℓ_p≈100 µm — semiflexible-to-rigid) driven by an **applied** mitotic force protocol, NOT an actin cortex. The direct FF transfer is (a) the crosslinked-fiber-network machinery + calibration + stress-relaxation validation protocol, which maps 1:1 onto FF's existing ECM/collagen-Mikado layer (the same one used in the FF crawl-on-collagen scenarios), and (b) a validated division-force scenario for the FF cell embedded in that ECM. The mitotic forces themselves (F_Cyto, F_Is) are lumped applied loads — do NOT adopt them as FF mechanisms; they are DCM-side / scenario inputs. Actin-cortex parameters (ℓ_p, off-rates) are NOT transferable across the collagen/actin boundary.

## 1. MECHANISMS to adopt

### 1a. Crosslinker unbinding = Bell's law, tension-gated (adopt as cross-check / confirm FF form)
FF already uses Bell-Evans force-dependent off-rate `k_off = k_off0·exp(F/F_b)` on α-actinin/filamin. This paper's Eq 9 is the **same law with an explicit tension-only gate**:
- unbinding is force-accelerated **only when the crosslinker arm is in tension** (`r ≥ r_{0,X1}`); under compression the off-rate stays at the zero-force baseline `k_{0,u}`.
- **Why it beats current FF:** if FF's crosslinker off-rate currently applies `exp(F/F_b)` to the force *magnitude* (both tension and compression), that is unphysical — a compressed α-actinin bond does not unbind faster. Adopt the **one-sided (tensile-only) gate** so compressed crosslinkers keep baseline `k_{0,u}`. This is a mechanistic correctness fix, not a tuning change. (Applies to collagen crosslinkers here; the same gate is the correct form for FF actin crosslinkers.)

### 1b. Per-element cylindrical drag (adopt for FF ECM fibers + audit actin drag)
The paper uses a **length-and-radius-dependent drag** per cylindrical element (Eq 4, from Clift/Broersma), not a lumped per-node γ:
`ζ_i = 3πμ r_{0,i} · (3 + 2 r_{c,i}/r_{0,i}) / 5` (see §2 for exact symbol mapping).
- **Why it beats current FF:** FF's known **grid-drag / crawl-speed problem** (Σγ ∝ Nc, native crawl 500× slow) comes from drag scaling with particle *count* rather than with *physical geometry*. A geometry-derived cylindrical drag ties the dissipation to fiber length × radius × cytoplasm viscosity — the physically correct scaling — and is a candidate reframing of the bulk-drag term that currently destabilizes the solver. At minimum, adopt Eq 4 as the drag law for the FF **ECM collagen fibers** (where it is exactly right) and audit whether the actin-filament drag uses the same geometric form.

### 1c. Explicit fluctuation–dissipation thermal force tied to the same ζ (adopt for consistency)
Eq 3 sets the stochastic force variance from the **same per-element ζ**: `⟨F^T_i F^T_j⟩ = (2 k_B T ζ_i / Δt) δ_ij`. FF's BAOAB integrator already enforces FDT, but this is the explicit check that the ECM-fiber noise amplitude must be rebuilt from the **geometry-derived ζ_i (Eq 4)** if 1b is adopted — otherwise the network temperature drifts. No new mechanism, but a mandatory consistency constraint on 1b.

### 1d. Crosslinker as an explicit two-arm, two-angle element (confirm FF filamin/α-actinin geometry)
The crosslinker is not a single spring: it is **two cylindrical arms** with (i) an inter-arm bending stiffness κ_{b,xl,1} (rest angle 0) and (ii) an arm-to-bound-fiber bending stiffness κ_{b,xl,2} (rest angle π/2, i.e. binds perpendicular). Binding sites are discretized every 100 nm along the fiber.
- **Why relevant:** confirms the FF fine-grained crosslinker should carry **angular** (orientational) stiffness at the fiber-binding interface, not just an axial spring. If FF's α-actinin/filamin bonds are axial-only, this is the mechanistic upgrade path (an α-actinin actually enforces a preferred crosslink geometry). Note the *values* here are for collagen crosslinkers — the FF actin crosslinker angles come from the α-actinin/filamin literature, not this paper.

### 1e. NOT to adopt as mechanisms (lumped — scenario inputs only)
F_Cyto (cytokinetic-ring inward force) and F_Is (spindle-elongation outward force) are **constant applied loads on membrane nodes**, plus a **geometric constant-volume constraint** (surface-of-revolution volume recomputed each step, transverse corrective forces restore V₀). These are DCM-side membrane/turgor mechanisms + a division scenario, NOT fine-grained FF mechanisms. Keep them as an **FF scenario** (a cell dividing inside the FF collagen network) but do not lump them into FF filament physics.

## 2. FORCE LAWS / KINETIC SCHEMES to port (with FF symbol mapping)

**Overdamped Langevin force balance (Eq 2):**
`F_i − ζ_i (dr_i/dt) + F^T_i = 0` → FF: deterministic bonded+EV force `F_i`, per-particle drag `ζ_i`, thermal force `F^T_i`. (FF already integrates this via BAOAB; this is the reference form.)

**Fluctuation–dissipation (Eq 3):**
`⟨F^T_i(t) F^T_j(t)⟩ = (2 k_B T ζ_i / Δt) δ_ij δ`
→ FF: noise amplitude per particle `= sqrt(2 k_B T ζ_i / Δt)`. Must use the *same* ζ_i as the drag (see Eq 4).

**Cylindrical-element drag (Eq 4):**
`ζ_i = 3π μ r_{c,i} (3 + 2 r_{0,i}/r_{c,i}) / 5`
Symbol map: `μ` = medium (cytoplasm/buffer) viscosity; `r_{0,i}` = element length; `r_{c,i}` = element diameter/radius; `ζ_i` = translational drag of that fiber/crosslinker segment.
→ FF: replace/augment the per-node lumped γ for ECM fibers with this geometry-derived drag. For the FF cortex, `μ` = physiological cytoplasm ~65 Pa·s (NOT water); `r_{0,i}` = FF segment rest length; `r_{c,i}` = actin filament radius ~3.5 nm (actin), collagen fibril `r_{c,f}` = 6.5 nm (§3).

**Extensional (stretch) potential (Eq 6):** `U_s = ½ κ_s (r − r_0)²` → force `−κ_s (r − r_0)`.
→ FF: this is FF's existing bead-spring stretch modulus. For ECM fibers, `κ_{s,f}` is set from Young's modulus via Eq 10 (below).

**Bending potential (Eq 7):** `U_b = ½ κ_b (θ − θ_0)²` → torque `−κ_b (θ − θ_0)`.
→ FF: FF's angular bending term. `κ_b` is fixed by persistence length: `κ_b = k_B T · ℓ_p / r_0` (per hinge; ℓ_p = 100 µm for collagen fiber here, 17 µm for actin in FF — DO NOT cross-use). θ_0 = 0 (straight) for fibers; π/2 for the crosslinker arm–fiber angle.

**Excluded-volume repulsion (Eq 8):** `U_r = ½ k_r (r_12 − r_c)²` if `r_12 < r_c` else 0.
→ FF: one-sided harmonic repulsion between membrane element and any fiber/crosslinker segment when min-distance `r_12` drops below cutoff `r_c`. FF already uses LJ-repulsive EV; this is the softer harmonic alternative used specifically for **membrane↔fiber contact** (the FF cell↔collagen contact term in crawl-on-substrate). Note it is **segment-to-segment** min-distance, not particle-particle — matters for the ECM contact.

**Bell's-law crosslinker off-rate (Eq 9):**
`k_u = k_{0,u} · exp( λ_u |F_{s,X1}| / k_B T )` if arm in tension (`r ≥ r_{0,X1}`), else `k_u = k_{0,u}`.
Symbol map: `k_{0,u}` = zero-force off-rate; `λ_u` = force sensitivity (units of length, i.e. the bond's characteristic length x_β = k_B T / F_b in Bell-Evans terms, so `F_b = k_B T / λ_u`); `F_{s,X1}` = current spring force in the crosslinker arm.
→ FF: this is FF's `k_off = k_off0 · exp(F/F_b)` with `F_b = k_B T / λ_u`. **Port the tension-only gate** (§1a): apply the exponential only when the bond is stretched (`r ≥ r_0`), clamp to baseline under compression.

**Fiber stiffness ↔ Young's modulus (Eq 10):**
`k_{s,f} = E·A / r_{0,f} = π E r_{c,f}² / r_{0,f}`
→ FF ECM calibration: given collagen fibril `E`, radius `r_{c,f}`, and element length `r_{0,f}`, this fixes the FF fiber stretch spring constant. Directly usable to calibrate FF's collagen-Mikado stretch stiffness from a material modulus.

**Fiber concentration ↔ mass density (Eq 11):**
`C = π r_{c,f}² L_{f,tot} / (V·ν)`
Symbol map: `L_{f,tot}` = total fiber length in domain, `V` = domain volume, `ν` = collagen specific volume 0.73 mL/g.
→ FF: converts an FF collagen network's total filament length into an **experimentally comparable mg/mL concentration** — lets FF report its ECM density in the same units as the wet-lab gels (1/3/5 mg/mL). Essential for validating FF collagen scenarios against this and other Chaudhuri/Kim datasets.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (as FF scenarios)

**Scenario A — Stress-relaxation / shear rheology calibration (matrix-only, high priority).**
- Domain 50×50×1 µm, periodic in x,y. Fibers grown from 1 µm seeds to mean length 9.3–11.6 µm. Crosslinkers bind sites every 100 nm.
- Protocol: translate top boundary in +x at strain rate 0.1 s⁻¹ to a goal shear strain, then **hold**; stress = Σ(forces on clamped top-boundary nodes)/area.
- Reproduces: shear modulus, **nonlinear (strain-stiffening) elasticity**, and **strain-enhanced stress relaxation** (Fig S12).
- **FF use:** this is a ready-made validation harness for the FF crosslinked-fiber ECM — it exercises exactly FF's stretch + bend + Bell's-law-off-rate machinery and produces a G'(strain) curve and a stress-relaxation time-series that FF can be scored against. It is the FF analogue of a Cytosim rheology cross-check and needs no living cell.

**Scenario B — Cell dividing inside collagen (FF cell embedded in FF ECM).**
- Cylindrical domain R=50 µm, height 1 µm (quasi-2D slab). Cell = circular membrane R=10 µm, 158 elements, element rest length 400 nm, embedded in the assembled collagen network.
- Applied loads (scenario inputs, not FF mechanisms): F_Cyto inward on nodes within 0.5 µm of equator, 100 pN/side, **cut off** when a node comes within 1 µm of the axis; F_Is outward on nodes within 5 µm of the axis, 100 pN/side. Constant-volume constraint via surface-of-revolution recompute.
- Run to T = 2000 s. Fiber concentration set to 0.94 / 1.0 / 2.8 mg/mL via Eq 11.
- **FF use:** the ECM half is pure FF; drop in the FF cell + a DCM-style division force and you have a validated **cell-pushes-collagen** scenario, a close cousin of the existing FF crawl-on-collagen scenes. The **fiber-buckling** observable (compressive fibers along the push axis) is a fine-grained emergent test FF can directly render and measure.

## 5. VALIDATION TARGETS for FF observables

**ECM-network (Scenario A) — the strongest FF targets:**
- Collagen shear storage modulus G' = **≈10 Pa (1 mg/mL), ≈100 Pa (3 mg/mL), ≈400 Pa (5 mg/mL)** — FF collagen network must reproduce this G'(density) trend after Eq-11 density mapping.
- **Nonlinear strain-stiffening** and **strain-enhanced stress relaxation** curves (Fig S12) — qualitative + quantitative modes/times (exact curves in SI).
- Mechanical **plasticity** = ε_remaining/ε_max after 300 s creep + 1 h recovery, ~similar across 1/3/5 mg/mL at ~30% strain (Eq 1).
- Pore size ≈ **1.5 µm** for the 3 mg/mL gel (microbead fiducial size ≈ pore size) — FF network mesh-size check.

**Cell-in-ECM (Scenario B) — emergent targets:**
- Simulated cell elongation: **ring-only ≈20% (max, low density)**, decreasing with fiber density; **ring+spindle ≈40% at 0.94 mg/mL** (matches experimental ~40% at 1 mg/mL). Normalized length ≈1.1–1.25 (ring) → ≈1.4 (ring+spindle).
- Matrix deformation field: **outward along the mitotic axis, inward along the perpendicular axis** (colorbar 0→0.8 µm); the perpendicular inward flow **increases** as axial elongation increases — a long-range network-connectivity signature FF must reproduce.
- **Fiber buckling** along the push axis (compressive) — occurred in 32% (10/31) of real cells; a discrete emergent event FF can detect.
- Experimental matrix-deformation magnitudes for scoring: max ~0.4–0.8 µm (MDA-MB-231), MCF10A ~0.25→~0.6 µm across stages.

**Force scale:** each active mechanism ~**100 pN per side** produces the observed µm-scale collagen deformation at 1–3 mg/mL — a sanity anchor for the FF ECM stiffness calibration (a 100 pN push should deform an FF collagen network by ~sub-µm, not 10× more or less).

## 6. RISKS / caveats

1. **Collagen ≠ actin cortex.** ℓ_p = 100 µm, E = 30 MPa, r_c = 6.5 nm describe a stiff collagen fibril. **Do NOT port these into the FF actin cortex** (actin ℓ_p ≈ 17 µm, radius ≈3.5 nm). Everything transferable here lives in the FF **ECM/collagen** layer, not the cortex. The one genuinely cross-cutting item is the *form* of the laws (Eq 4 drag, Eq 9 tension-gated Bell), not the collagen numbers.
2. **Crosslinker kinetics values are in SI Table S1, absent from the fetched PDF.** `k_{0,u}`, `λ_u`, `κ_s`, `κ_b`, `k_r`, `μ`, `Δt` are not in main text. Retrieve Table S1 before KB-registering any collagen-crosslinker rate; and remember it is a collagen crosslinker, distinct from FF's α-actinin datum.
3. **Mitotic forces are lumped applied loads, not fine-grained mechanisms.** F_Cyto/F_Is/constant-volume are exactly the abstracted-vs-mechanistic trap the project's HARD rule warns against. Use them ONLY as a scenario (external boundary condition on an FF cell); if a *mechanistic* cytokinetic ring is ever wanted, it must be built from explicit actomyosin (Stam–Hocky minifilaments + Hill FV) contracting an equatorial actin band — this paper does not provide that.
4. **Quasi-2D slab (1 µm height, 2D membrane with only x,y).** The published sim is effectively 2D. FF is 3D and native-scale; use the 2D result only for *trend/qualitative* validation (elongation-vs-density, inward-perpendicular-flow), not for exact 3D magnitudes. Reproduce at NATIVE 3D scale before drawing any conclusion (HARD rule).
5. **Euler integrator + strain rate 0.1 s⁻¹.** The paper uses explicit Euler; FF uses constrained BAOAB. The 0.1 s⁻¹ shear-rate protocol is a fast (non-quasistatic) ramp — when reproducing the rheology, hold FF at the same rate for comparability but check CFL/stability with FF's stiffer actin timestep; do not import Euler Δt.
6. **Physiological baseline.** If Eq 4 drag is adopted for FF, set `μ` to the physiological cytoplasm viscosity (~65 Pa·s MCF7) from t=0, not the dilute-medium value implicit in an in-vitro collagen gel. Set the FF collagen network to a real physiological density (mg/mL via Eq 11) as the baseline, not an unphysical sparse default.
7. **No fitting / no gate-loosening.** The G'(density) and elongation numbers are *acceptance targets* — reproduce them by building the network at literature density + literature E, never by tuning κ_s/k_{0,u} to hit the curve.
