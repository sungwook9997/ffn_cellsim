# FF lens — p65

**Paper:** Kim, Hwang & Kamm (2009) *Computational Analysis of a Cross-linked Actin-like Network*, Exp. Mech. 49:91–104. DOI 10.1007/s11340-007-9091-3.
**One line:** This is the **ancestral blueprint of FF itself** — a 3D Brownian-dynamics bead-spring actin network with harmonic stretch/bend/torsion, truncated-LJ excluded volume, two explicit ACP cross-linker archetypes, Bell's-law force-dependent unbinding, and on-the-fly nucleation/elongation. Taeyoon Kim's PhD-era foundation paper. Almost every FF crosslinker/filament design decision has a direct precedent here. This lens mines it for (a) the **torsional binding-site-registry mechanism** FF is currently missing, (b) the **two-ACP-archetype geometry gates** (bundler vs orthogonal), and (c) a pile of **calibration/validation targets** (L_p↔k_b, cross-angle, L_c bimodality, pore-size scaling, effective off-rates).

> **Regime caveat up front (governs every number below):** this is a *purified, accelerated, small-box* reconstitution model (560 nm cube, 1–10 ms accessible time, rate constants deliberately accelerated, k_s deliberately softened, no myosin, no membrane, no turgor). It is a **mechanism + geometry + calibration source**, NOT a physiological-state source. Its rate constants (k_A,n, k_A,e, k⁰_off=0.4967 s⁻¹) are simulation-tuning artifacts, not in-vivo kinetics — do NOT KB-register them as physiological. What ports cleanly is (i) the *functional forms*, (ii) the *geometry/angle equilibria*, and (iii) the *emergent morphology metrics* as FF acceptance targets.

## 1. MECHANISMS to adopt

### M1 — Torsional binding-site registry on filaments (κ_t) → correct emergent cross-link angle. **[highest-value new mechanism]**
FF today has stretch + bending κ on filaments and explicit crosslinker bonds, but (per our notes) treats crosslink attachment largely by distance/angle without a **helical binding-site register**. Kim gives each 7-nm bead **two binding sites on opposing sides, rotating π/5 (36°) per bead → one full helical turn per 10 beads (~74 nm)** (Fig. 1b), maintained by a **harmonic torsion/dihedral potential Ũ_t = ½κ̃_t(φ−φ₀)²** (Eq. 9). This is what makes the cross-link *angle* an **emergent, thermally-fluctuating** quantity instead of a geometric imposition — exactly the fine-grained-over-lumped principle FF is built on.
- **Why it beats current FF:** without helical registry, a crosslinker can bind any azimuth freely, so bundle vs orthogonal-network selection cannot *emerge* from the filament's own structure — you'd have to impose it. With κ_t + rotating sites, α-actinin-type bundlers spontaneously give near-0° parallel cross-links (−2.39±3.98°) and filamin-type give ~90° (87.5±10.5°) from the **same filament model** — the crosslinker's own equilibrium geometry (θ₁,θ₂,φ₁) does the selecting. This is the mechanistic route to bundle/cortex architecture divergence FF wants for filopodium (bundled) vs cortex (isotropic mesh).
- **FF module:** `ff` filament (add torsion potential + per-bead binding-site azimuth state) + crosslinker binding gate.

### M2 — Two-gate (attach → cross-link) binding kinetics with angular acceptance windows. 
Kim's crosslinking is **two-step** (Eqs. 14–15): (1) ACP binds ONE monomer if distance gate AND two angle gates satisfied; (2) the singly-bound ACP binds a monomer on a *different* filament only if the distance + both angle gates + a **dihedral φ₁ gate** are satisfied → *active* cross-link. Both steps use an acceptance window of **±0.1745 rad (±10°)** on each angle.
- **Why it beats current FF:** FF's crosslinker binding is (per our config) largely a distance + off-rate model. Kim's angular acceptance gate is the mechanistic origin of *why* a bundler makes tight parallel links and a cross-linker makes wide-angle ones — the gate rejects mis-registered geometries. Adopting the two-step gate makes crosslink formation *selective on local filament geometry*, which is fine-grained-correct and reproduces the emergent angle distributions.
- **FF module:** crosslinker (α-actinin, filamin) binding kernel.

### M3 — Distinct ACP archetypes as *geometry parameter sets*, not distinct code paths.
One crosslinker mechanism, two parameter blocks: **ACP^B (bundler: fimbrin/fascin/α-actinin)** short (σ_ACP=1.5σ_A), θ₁,eq=π, θ₂,eq=π/2, φ₁,eq=0, **stiff** torsion κ_t=500 → narrow-angle parallel bundles; **ACP^C (cross-linker: filamin)** long (σ_ACP=3σ_A), θ₁,eq=1.158 rad, θ₂,eq=π/2, φ₁,eq=π/2, **soft** bending κ_b,1=50 and torsion κ_t,1=50 → wide-angle orthogonal mesh. This is exactly FF's "one unified crosslinker mechanism, parameterized per protein" principle — Kim supplies the numeric geometry that distinguishes α-actinin from filamin.
- **FF module:** crosslinker config YAML — add `ACP^B`/`ACP^C` archetype rows with these equilibrium angles + arm stiffnesses.

### M4 — Emergent late-time cross-link remodeling (t^{−0.05} weak power law) as a stress-relaxation / fluidization mechanism.
After polymerization completes, the number of active cross-links keeps **slowly evolving** ("4000−N_ACP" ~ t^{−0.05}, Fig. 11) driven by **Bell-law force-dependent unbinding + rebinding** — a *non-first-order* rebinding process. Kim connects this speculatively to **cytoskeletal fluidization / self-healing / power-law rheology** (Trepat universal stretch response). This is directly relevant to FF's OPEN problem "**network contraction & stress relaxation**": the mechanism for slow stress relaxation is emergent crosslinker turnover under load, not an imposed Maxwell element.
- **Why it beats current FF:** gives a *mechanistic* origin for power-law rheology / slow stress relaxation from Bell-law crosslinker turnover, rather than a lumped viscoelastic damper. FF already has Bell-Evans off-rate on crosslinkers — this says: run long enough and watch N_active(t) to reproduce weak power-law relaxation.
- **FF module:** crosslinker turnover (already present) — use as observable/acceptance, not new code.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### FL1 — Harmonic torsion / dihedral (NEW to FF filament):
```
Ũ_t = ½ κ̃_t (φ − φ₀)²        (Eq. 9)
```
- φ = dihedral angle about the filament backbone bond; φ₀ = equilibrium (helical registry). κ_t,f = **4.142×10⁻¹⁸ N·m** (dimensionless 1000).
- **Map to FF state:** add per-bead azimuth φ_i defined by consecutive backbone tangent + binding-site vector; apply torsion spring between consecutive beads with φ₀ advancing by **π/5 per bead** (36°/bead, 10 beads/turn). This is the missing helical-registry potential.

### FL2 — Persistence-length ↔ bending-stiffness calibration (VERIFY current FF κ):
```
⟨C(s)⟩ = ⟨cos[θ(s)−θ(0)]⟩ = e^{−|s|/L_p}   (Eq. 7)
L_p = k_b,f · σ_A / (k_B T)                  (Eq. 8)
```
- With σ_A = 7 nm and target **L_p ≈ 17–20 µm** (actin), Eq. 8 → k_b,f. Kim uses **k_b,f = 1.243×10⁻¹⁷ N·m** (dimensionless 3000) giving L_p ≈ 20 µm on a 0.9-µm test filament.
- **Map to FF:** this is a **cross-check** for FF's bending κ. FF uses ℓ_p ≈ 17 µm — confirm FF's discretized κ reproduces e^{−s/ℓ_p} tangent-correlation on a single filament (a clean unit test). NOTE Eq. 8's form is for a bead-*angle* harmonic at spacing σ_A; FF's segment length differs, so recompute κ for FF's bead spacing rather than copying 3000.

### FL3 — Bell's-law force-dependent crosslinker unbinding (CONFIRM FF form + adopt slip form):
```
k_ACP,− = k⁰_ACP,− · exp( γ F_b / k_B T )   (Eq. 16)
```
- k⁰ = zero-force off-rate (Kim: 0.4967 s⁻¹, a simulation value — do NOT adopt as physiological); γ = reactive compliance length; F_b = instantaneous bond force.
- **Map to FF:** FF already uses Bell-Evans k_off = k_off0·exp(F/F_b) on crosslinkers — **same functional form**, so this *corroborates* FF's slip-bond crosslinker law. Keep FF's physiologically-sourced k_off0 (Ferrer 2008 α-actinin 0.066 s⁻¹, per our KB) and F_b — do NOT overwrite with Kim's accelerated 0.4967 s⁻¹.
- **Useful derived observable:** Kim reports **effective (thermal+Bell) off-rates ~100 s⁻¹ (ACP^B) and ~30 s⁻¹ (ACP^C)** vs athermal k⁰=0.4967 s⁻¹, and estimates **equilibration times ~5 ms (ACP^B) / ~10 ms (ACP^C)**. These are *ratios/timescale relationships* FF can sanity-check, not absolute targets.

### FL4 — Truncated (WCA) excluded volume (CONFIRM FF LJ):
```
Ũ_LJ = 4ε̃[(σ̃₁₂/r̃₁₂)¹² − (σ̃₁₂/r̃₁₂)⁶], r̃₁₂ ≤ 2^{1/6}σ̃₁₂; else 0   (Eq. 4)
```
- σ₁₂ = ½(σ₁+σ₂); ε = k_BT = 4.142×10⁻²¹ J. Purely repulsive.
- **Map to FF:** FF has "LJ repulsive on from Phase 1" — this confirms the WCA cutoff (2^{1/6}σ) and ε=k_BT choice. Corroboration, not new.

### FL5 — Nucleation / elongation kinetic scheme (reaction- vs diffusion-limited):
- **Nucleation:** two free monomers within r̃=1.1·σ̃₁₂ form a dimer with per-encounter probability P_n → reaction-limited; k_A,n = **2.51×10¹³ · P_n** M⁻¹s⁻¹ (Eq. 12).
- **Elongation:** free monomer within 1.1·σ̃₁₂ of a barbed end is incorporated **immediately** and aligned to axis → diffusion-limited; k_A,e = **1.41×10⁹** M⁻¹s⁻¹ (Eq. 13).
- **Map to FF:** FF has barbed-end growth (ratchet) + formin. Kim's scheme is a *diffusion-limited* incorporation model; FF's ratchet is a mechanistic elongation. Kim is useful here mainly as the **Damköhler framing** (below) — whether your network's morphology is nucleation- or elongation-controlled. FF should NOT adopt these accelerated rate constants; keep formin/barbed-end kinetics at physiological rates.

### FL6 — Damköhler control parameter (design/analysis tool, not a force law):
```
Da_n = t_nucleation / t_diffusion = (1/(k_A,n C_A)) / (ζ_A r₀² / 6 k_B T),  r₀=(500·N_AVO·C_A)^{−1/3}   (Eq. 17)
Φ = 54.06 · C_A[M]   (solid fraction, Eq. 19)
```
- **Scaling laws (the master results):**
  - Polymerization time: **t̃_p ~ Φ^{−5/6} Da_n^{1/2} ~ 1/(k_A,n^{1/2} C_A)** (Eq. 20)
  - Mean filament length: **⟨L_f/σ_A⟩ ~ (Da_n Φ^{1/3})^{1/2} ~ k_A,n^{−1/2}** (Eq. 21)
- **Map to FF:** these tell FF that at fixed monomer pool, **raising nucleation rate shortens filaments (∝k_n^{−1/2})** and **increasing concentration Φ shrinks pores (∝Φ^{−1/3})**. Use as a *predictive check* when FF builds a cortex from a monomer pool: filament-length distribution should follow these scalings if FF's polymerization is mechanistically correct.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario "kim2009_reconstitution" — in-silico reconstituted crosslinked network.**
- Geometry: periodic cubic box, width 40σ_A (280 nm) at C_A=1.21 mM → 80σ_A (560 nm) at 151 µM; **8000 actin monomers** (converged from a 512→27,000 study, Fig. 3).
- Init: free monomers uniform, ACPs random, **no pre-existing filaments** (FF would instead seed from a monomer pool + nucleation).
- Sweep: {C_A × Da_n(via P_n) × R × ACP-type}, 51 runs.
- Termination: 99% monomer incorporation (a cost cutoff — flagged as NOT a true crosslinking steady state; ACP binding still evolving, Fig. 11).
- **Usable as an FF unit-scenario** to validate FF's crosslinker geometry + polymerization kernel *against emergent morphology metrics* (§5) in a controlled small box before running the native 38000-filament cortex. This is a legitimate **dev-only smoke scenario** — per our HARD rule it must be labelled non-authoritative, and any mechanism conclusion (e.g. "bundler gives 0° cross-links") must be reconfirmed at native scale + full compartments.
- **The extension roadmap the paper itself names (p13):** viscoelastic modulus over 0.1–10⁴ Hz, myosin motors, membrane, focal adhesion, cell-cell junction mechanotransduction — i.e. Kim's own stated next steps ARE the FF program. FF is the realization of "extend this BD base with motors + membrane + FA."

## 6. RISKS / caveats

1. **Accelerated kinetics (do NOT KB-register as physiological).** k_A,n, k_A,e, k⁰_off=0.4967 s⁻¹ are simulation-tuned to reach 99% polymerization in ms wall-time, NOT in-vivo rates. Adopting them would violate the physiological-baseline HARD rule. Keep FF's sourced kinetics (Ferrer 2008 α-actinin k_off0=0.066 s⁻¹). Kim's rates are usable ONLY if you explicitly reproduce Kim's accelerated assay for cross-checking morphology.

2. **Deliberately soft backbone (k_s gives 0.05 strain @60 pN vs real 0.002 — 25× too compliant).** The authors chose this for timestep affordability and *showed it doesn't affect the analyzed morphology*, but it WOULD affect FF's force-transmission / cortical-tension γ (a stiffness-limited observable). FF must use the physiological stretch modulus, not 0.1691 N/m.

3. **Purified in-vitro reconstitution, no active elements.** No myosin, no membrane, no turgor, no ATP-driven treadmilling under load. So it informs **passive network architecture + crosslinker geometry + passive stress relaxation** only. It says nothing about myosin-driven contraction, motor-clutch crawl, or turgor-borne γ — FF's active machinery stays sourced from its own oracles (Stam-Hocky, Hill, Bell-Evans catch bonds).

4. **Tiny box + ultra-short time (560 nm, 1–10 ms), pre-steady-state.** Bundles have only "a few filaments" and the run stops before true crosslink equilibrium (Fig. 11 still evolving). So bundle *diameter* (1.5–2.3σ_A) and *count* are lower bounds, not cortex-scale predictions. The 38000-filament native cortex (Nc≈266k, R=7.5 µm) is ~10⁶× the volume — Kim's scenario is a **mechanism/geometry unit test**, and per our HARD rule any conclusion must be reconfirmed at native scale + full compartments before it is reported. Adapt by using Kim only to *validate the crosslinker kernel* in isolation, then run the native cortex.

5. **Single-stranded bead-spring, not double helix; friction is Stokes-per-bead (no hydrodynamic coupling, no length/orientation-dependent drag).** The authors flag this (p13). FF's grid-drag / bulk-drag treatment differs; don't import Kim's ζ=3πησ_A per-bead friction as FF's drag model (FF already has its own drag work — the crawl-speed grid-drag open problem). Kim's friction is fine for the small-box passive assay but not for FF's motility.

6. **Excluded electrostatics / salt effects.** Kim drops charge for cost; α-actinin/filamin binding IS ionic-strength dependent in reality. FF's geometry-gate adoption inherits this simplification — acceptable at our current fidelity target, flag for later.

**Net:** port the **torsion+helical-registry mechanism**, the **two-gate binding kernel**, and the **two ACP archetype geometries**; use the **morphology metrics as acceptance targets**; **reject** the soft stretch constant and all accelerated rate constants; keep everything downstream of it on FF's own physiological/native-scale rails.
