## 1. Mechanisms to adopt  (HIGH — this is FF gold; the 3D sim IS the FF physics family)
- **Catch-bond crosslinker kinetics.** FF already uses Bell-Evans slip off-rates for α-actinin (k_off0 re-anchored to Ferrer 2008 per CLAUDE.md). This paper shows α-actinin-4 WT is a genuine *catch* bond (single-molecule lifetime peaks ~4 pN) and that catch kinetics qualitatively change network mechanics: catch crosslinkers form up to +80% more links between high-tension filament pairs, homogenize per-bond force, and postpone rupture. FF should upgrade the crosslinker off-rate from slip-only to the **two-pathway catch/slip form** (Eq.1), unlocking the strength+deformability behaviour.
- **"Dissociation on demand" + crosslinker mobility.** After unbinding, a crosslinker reappears within 5 µm of its old site (diffusive remodelling). FF's crosslinker turnover should include this mobility (rebind at a nearby new location), which is *required* for the catch advantage (immobile crosslinkers abolish it).
- **The 3D agent-based network model is a near-clone of FF.** Cylindrical F-actin segments + two-arm hinged crosslinkers with κ_b/κ_s + volume exclusion + Langevin BD + force-dependent unbinding + 30×30×1 µm periodic box + shear at 0.001 s⁻¹. Code path (Kim lab) is a direct FF cross-check/parity reference. Public 1D model: github.com/YuvalMulla/Minimal_1D_Crosslinker_Model.

## 2. Force laws / kinetic schemes to port
- **Bell–Evans double-exponential** (Eq.1): `k_off(f) = k_catch0·exp(−f/f_catch,1/e) + k_slip0·exp(+f/f_slip,1/e)`; slip-only ⇒ k_catch0=0. Direct FF crosslinker off-rate upgrade. (Exact k_catch0, k_slip0, f_catch, f_slip are in Suppl. Table 1 — flag SI fetch before KB-registering constants.)
- **Load sharing** (Eq.2) `f_i = (l_i/Σl_i)·σ·N` — per-bond force ∝ inter-bond gap → crack seeds at large gaps.
- **Semiflexible-network G′/G″ moduli** (Eqs.3–8): drag term χ(ω/ω_fluid) + crosslinker term α(ω/ω_off) with ω_fluid≈100 Hz — a fit-form FF can use to compare simulated G′(ω)/G″(ω) to.
- **Stress-stiffening K′ ∝ (1+σ)^{3/2}** (Eq.9).

## 5. Validation targets for FF observables
- Rupture stress: WT catch 24.5±2.7 Pa vs K255E slip 6.5±0.5 (25°C) / 8.1±1.1 (10°C) Pa.
- Rupture strain: WT catch 221±16% vs slip 63±4% / 129±10%.
- Catch links between high-tension filament pairs: +80% vs slip.
- Crosslinkers/filament: catch ~19 vs slip ~23 (fewer bonds, stronger network).
- Mean normalized per-bond force: catch 0.241 vs slip 0.223, catch distribution far narrower (slip has >100× more f>1 bonds).
- Single-molecule α-actinin-4 lifetime-vs-force: catch peak ~4 pN (WT), monotone decay (K255E).
