# FF lens — p07

**Paper:** Wisdom, Indana, Chou, Desai, **Taeyoon Kim**, Chaudhuri (2020) — *Covalent cross-linking of basement membrane-like matrices physically restricts invasive protrusions in breast cancer cells.* Matrix Biology 85–86, 94–111. DOI 10.1016/j.matbio.2019.05.006.

**One-line relevance:** This is a **Taeyoon-Kim agent-based Brownian-dynamics cross-linked-fiber model** — the *same physics family* as FF's crosslinker/off-rate + Mikado-ECM machinery. It hands FF (a) a clean **Bell slip-bond off-rate with reference constants**, (b) a **matrix-plasticity emergence protocol** (creep→recovery, permanent strain) that is a ready-made validation scenario, and (c) a **protrusion-into-ECM invasion assay** that maps almost 1:1 onto the FF crawl-on-substrate / filopodium-into-collagen line. It is an **ECM-side / boundary** contribution — it does NOT touch actin cortex myosin internals, so treat it as an environment + crosslinker-kinetics paper, not a cortex-mechanism paper.

---

## 1. MECHANISMS to adopt

### 1.1 Crosslinker off-rate — confirm/anchor the FF Bell slip-bond (crosslinker module)
FF already uses Bell-Evans force-dependent off-rate `k_off = k_off0·exp(F/F_b)` for α-actinin/filamin. This paper is an **independent same-family use of exactly that law** for ECM crosslinks, with two things FF should adopt:
- **Tension-only gating (slip bond, one-sided):** the off-rate is elevated **only under tensile spring force**; under compression `k_u = k0,u` (base rate). FF's crosslinker unbinding should apply the exponential factor **only when the bond is stretched beyond its rest length** (`r ≥ r0`), not when compressed. This is a mechanistic fidelity fix — a symmetric `exp(|F|/F_b)` over-unbinds compressed crosslinks. *Why it beats current:* matches the physical slip-bond picture (protein–protein interactions unbind under pull, not push) and is what Kim's canonical model does.
- **Plasticity = unbind/rebind rearrangement, not bond breakage alone:** permanent (plastic) matrix strain **emerges** from crosslinkers unbinding under load and **rebinding in the deformed configuration**. FF's crosslinker turnover (bind to discrete sites, unbind by Bell) already contains this; the paper shows it is *sufficient* to reproduce viscoplastic creep+permanent-set with NO extra viscoplastic term. FF should therefore **not** add any lumped viscoplastic/Maxwell element to its ECM — the plasticity must be left emergent from crosslinker kinetics + discrete rebinding sites.

### 1.2 Discrete crosslinker binding sites along fibers (crosslinker + ECM module)
Crosslinkers bind at **fixed discrete sites spaced every 140 nm** along each fiber (not a continuum). This discretization is what makes rebinding-in-deformed-state produce *permanent* offset. FF's ECM/collagen-Mikado and cortex crosslinker binding should use a **discrete binding-site lattice per filament** (site spacing a config parameter) rather than continuous nearest-approach binding, so plastic set can accumulate at native scale.

### 1.3 Short-fiber ECM network builder (ECM scenario module)
The ECM here is a **short-fiber Mikado** built by nucleation + capped elongation, giving mean fiber length ~4 µm from 1.4 µm segments (max 2 added). This is a concrete, reproducible recipe for FF's ECM environment around a crawling/protruding cell that differs from long-collagen Mikado — useful as a **basement-membrane (nanoporous, short-fiber, high-crosslink) environment preset** distinct from stromal collagen.

### 1.4 Covalent-vs-transient crosslink as a *parameter regime*, not a new bond type (crosslinker module)
The paper emulates covalent (permanent) crosslinking purely by **(a) lowering k0,u** and **(b) lowering λu (force sensitivity)** of the *same* Bell bond. FF gets a "covalent crosslink" for free by pushing an existing crosslinker toward `k_off0 → 0` and `F_b → ∞` (λ→0). *Why it beats current:* no new mechanism/module needed to represent stable cross-links (e.g. LOX/tTg-type or tightly bound filamin) — it is a limit of the existing Bell law. Keeps the fine-grained-over-lumped rule.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### 2.1 Bell slip-bond crosslinker off-rate (Eq. 1) — **the transcribe target**
```
        ⎧ k0,u · exp( λu · F_s / (kB·T) )   if r ≥ r0   (tensile: elevated)
  k_u = ⎨
        ⎩ k0,u                              if r <  r0   (compressive: base)
```
Symbol → FF state map:
| paper | meaning | FF state |
|---|---|---|
| `k0,u` | zero-force unbinding rate | crosslinker `k_off0` (per-bond attribute) |
| `λu` | force sensitivity (a **length**) | FF force scale via `F_b = kB·T / λu`; i.e. `exp(F/F_b)` with `F_b = kBT/λu` |
| `F_s` | tensile spring force on the crosslinker element | FF crosslinker bond stretch force `k_link·(r − r0)` |
| `r0` | crosslinker equilibrium length | FF crosslinker rest length |
| `kB·T` | thermal energy | 4.114e-21 J at 310 K |

Note the **equivalence to FF's form**: Kim writes `exp(λu·F/kBT)`; FF writes `exp(F/F_b)`. They are identical with **`F_b = kB·T / λu`**. With `λu = 100 pm = 1.0e-10 m` and `kBT = 4.114e-21 J` → **`F_b = 41.1 pN`**. That is a concrete Bell force scale for a transient (protein–protein) crosslink under load — directly comparable to FF's Ferrer/α-actinin `F_b`.

### 2.2 Matrix strain observable (Eq. 2) — port as an FF cell-shape/ECM readout
```
  ε = (d − r0,m) / (2·r0,m)
```
`d` = distance from membrane/cell center to the **farthest** of 120 nearest fiber nodes sampled at 3° angular resolution; `r0,m` = initial cell radius (10 µm). Use this as the FF **matrix-deformation-around-cell** metric for protrusion runs (max-strain during load, permanent-strain after unload).

### 2.3 Modulus conversion (experimental, for validation only)
```
  G* = (G'² + G''²)^½ ;  E = 2(1+ν)G* = 3G*  (ν = 0.5)
```
Use when comparing FF-measured shear modulus to the paper's Young's-modulus targets.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenarios)

### 4.1 Creep–recovery matrix-plasticity assay (no cell) — **FF ECM validation scenario**
- Domain **40 × 40 × 1 µm**, PBC in x,y (quasi-2D slab; FF can run true-3D).
- Build short-fiber crosslinked Mikado (§1.3) to steady state via dynamic bind/unbind.
- Sever + clamp chains crossing y-boundaries; **shear** by displacing top boundary in +x, bottom fixed.
- Feedback the top-boundary position to hold **goal shear stress = 100 Pa for 1 h** (creep), then **0 Pa for ~2 h** (recovery).
- Measure **initial modulus** (short-time) and **permanent (plastic) strain** (residual after recovery).
- **Sweep `k0,u` and `λu`** and confirm plasticity rises with both while initial modulus stays ~flat.

### 4.2 Protrusion-into-matrix invasion assay — **FF crawl/filopodium scenario**
- Domain **100 × 60 × 1 µm**. Cell = closed loop of serial elements, initial radius **10 µm**, **158 elements**, element length 400 nm (window 4–800 nm), with bending + extensional forces + **volume-exclusion repulsion against the matrix** (no interpenetration).
- Apply **25 pN radially outward to 40 nodes on one side for 1 h** (≈1 nN total, one invadopodium), then release for 0.3 h.
- Measure ε(t) (Eq. 2), max strain, permanent strain; observe protrusion morphology (long-thin in HP vs blunt-round in LP).
- **FF mapping:** replace the abstract "membrane wall" with FF's real membrane-containment + a filopodial bundle exerting the ~1 nN protrusive load into an FF ECM built with §1.3/§3 constants. This is essentially the existing FF filopodium-into-collagen-Mikado run with a **BM-plasticity-tuned crosslinker set**.

## 6. RISKS / caveats

- **ECM, not cortex.** Every mechanism here is on the *extracellular* side. Do NOT let these constants leak into cortical actin crosslinker configs (the α-actinin `k_off0=0.066 s⁻¹`, Ferrer, stays). Tag the 3e-6 s⁻¹ / 100 pm set explicitly as *ECM/BM crosslink*.
- **Coarse membrane is a proxy — replace it.** The paper's "cell" is a lumped serially-connected wall with a prescribed 1 nN force — exactly the kind of abstracted boundary FF's mechanistic rule forbids as a *mechanism*. Use it only as a **scenario/validation target**, and drive the FF version with a real filopodial bundle + membrane containment generating the load emergently. Reproduce the ~40%/~30% strain numbers, don't import the wall.
- **Quasi-2D (1 µm z slab, PBC).** Their domain is a thin slab; FF must confirm targets at true 3D native scale before drawing conclusions (native-scale rule). The strain magnitudes may shift in 3D — treat the 2D numbers as order-of-magnitude.
- **Purified in-vitro rBM/alginate ≠ living cortex ECM contact.** Alginate/click chemistry has no biological analog; only the **plasticity phenomenology and the Bell-law crosslinker kinetics** transfer. Stiffness values (100 Pa rBM, 2 kPa IPN) are the assay's, not necessarily the in-vivo BM a MCF7 cell meets.
- **`λu` / `F_b` provenance.** 100 pm and 3e-6 s⁻¹ are Kim's *model reference values* (his canonical framework), not a fresh single-molecule measurement in this paper — so they are a **cross-check/anchor, not ground truth**. Before KB-registering, note they are model reference constants (Kim-lab convention) and compare against FF's independently sourced crosslinker Bell parameters; do not fit FF to them.
- **No magic-number / no gate-loosening:** the sweeps (k*/3, 3k*, 10k*) are *illustrative*, not tuned to hit a number — keep FF's physiological `k_off0` derived and use these only to set the covalent→transient *regime*, not to backfit a target.
