# FF lens — p50

**Paper**: Mair, Elmasli, J.H. Kim, Barreto, Ding, Gu, Weinberg, **Taeyoon Kim**, D.-H. Kim, R. Li — "The Arp2/3 complex enhances cell migration on elastic substrates." *Mol. Biol. Cell* 34:ar67, 1–10 (2023). DOI 10.1091/mbc.E22-06-0243.

**One-line for FF**: A Taeyoon-Kim-lab fine-grained agent-based actomyosin network (explicit F-actin segments, Arp2/3 ~70° branches, ACP cross-linkers, myosin motors) coupled to a triangulated elastic substrate through *explicit molecular clutches* with Bell slip off-rates + Chan–Odde force-velocity. It is essentially a sibling engine to FF's adhesion-clutch / lamellipodium stack, and it hands FF (a) a concrete clutch-attachment protocol, (b) an emergent multi-adhesion load-sharing phenomenon (PFAC) FF can reproduce and validate, and (c) a set of graph-readable validation numbers. **Big caveat: all numeric constants live in Suppl. Tables S1–S4, which are NOT in the PDF** — so parameter *values* here are mostly flagged NO_SI, and the concrete wins are mechanism + protocol + validation-shape, not new rate constants.

## 1. MECHANISMS to adopt

### 1.1 Clutch attachment geometry: barbed-end-proximal, multi-node, radius-gated (adopt into FF clutch module)
The paper's agent-based model forms a clutch whenever a substrate mesh node lies **within 300 nm of an F-actin barbed end**; each such link is an independent linear spring, and a single barbed end can bind **multiple** nodes. This is a cleaner, more mechanistic attachment rule than a lumped "FA site engages" latch:
- **FF change**: in the motor-clutch / integrin module, gate clutch nucleation on *barbed-end proximity* (distance ≤ r_bind ≈ 300 nm to a substrate/ECM node), allow one filament tip to seed several parallel clutches, and let each be its own Bell-Evans slip bond. FF already has explicit barbed ends (formin/Arp2/3 tips) and explicit ECM nodes (collagen-Mikado), so this is a natural upgrade of the current clutch-seeding rule.
- **Why it beats current FF**: FF's crawl work (`project-ff-crawl-mechanism`) already gets traction-driven crawl from protrusion + clutch turnover, but clutch *placement* is not tied to the growing barbed end. Tip-gated seeding makes traction spatially co-localize with protrusion (matches the paper's "force localized to FLP tips vs distributed across lamellipodium") — directly relevant to the open grid-drag/crawl-speed problem, because it changes *where* load enters the network.

### 1.2 Parallel-Focal-Adhesion Compensation (PFAC) — an emergent, not lumped, load-sharing mechanism to reproduce
Central finding: when N parallel adhesions share one substrate/load, a surviving adhesion **ramps its force to hold the substrate when 2 neighbors stochastically fail**, preventing the single-filopodium "load-and-fail" catastrophe (Chan–Odde). Consequences: mean-time-to-failure **decreases** at 3–6 FAs but **increases** at ≥10 FAs, and **never fails at 30 FAs**.
- **FF change**: nothing to *add* — PFAC should EMERGE for free once FF has (a) tip-gated parallel clutches (1.1), (b) Bell slip off-rate (2.1), and (c) a shared elastic load (substrate spring or the cortex tension itself). The action item is to **run the N_FA sweep and confirm the emergent crossover**, then register it as a validation gate (§5). This is a fine-grained-over-lumped win: FF gets adhesion-lifetime prolongation from *collective clutch statistics*, not from a hand-tuned maturation/lifetime parameter.
- **Why it matters**: it mechanistically explains adhesion-lifetime as emergent from clutch count — exactly the kind of thing FF should show rather than parameterize. It also connects to `project-dcm-cadherin-cluster-redesign`'s load-sharing cluster idea (m→0 survival), but here at the cell–substrate integrin interface.

### 1.3 Buckling-induced F-actin fragmentation as a contraction facilitator (from cited Li, Biel, Lomada, Yu, **Kim** 2017, Soft Matter 13:3213 — the model's own lineage)
The paper explicitly names its lineage (Kim 2009; Jung 2015; Mak 2016; **Li 2017**) and lists **F-actin dynamics / fragmentation** as the one missing ingredient (it is why their network contraction decays and forces them to a 20 s window). Li 2017 (same Kim framework) shows **buckling-induced F-actin fragmentation modulates active-network contraction** — motors buckle antiparallel filaments, buckled segments sever, and severing *facilitates* net contraction by relieving extensile/jammed elements.
- **FF change**: add a **curvature/buckling-triggered fragmentation channel** to the filament module — when a segment's local bending exceeds a buckling-strain threshold (Euler load for the bead-rod κ), give it a severing probability per unit time. This is the mechanistically-correct version of "network contraction slows because there is no turnover."
- **Why it beats current FF**: FF's contraction / γ-floor work stalls partly because a cross-linked network jams and cannot compact (motors stall against a percolating passive scaffold). Buckling-severing is the *native* release valve real cortex uses; it is fine-grained (per-segment curvature, no lumped turnover rate), directly addresses the open **network contraction & stress relaxation** and **cortical-tension γ generation** problems, and is by the same lab whose framework FF's physics tracks. **This is the single highest-value adjacent mechanism the paper points to.**

### 1.4 F-actin turnover at the leading edge (the paper's self-declared weakness → FF's opportunity)
Discussion states plainly: their model has **no F-actin polymerization/depolymerization**, so contraction decays and they can only trust the first 20 s. FF already has barbed-end growth (`project-ff-filament-length-growth`, KB-3.6 ratchet) and distributed lengths — i.e. FF is *ahead* here. Adopt the *lesson*, not code: when FF reproduces this scenario, keep polymerization ON (physiological baseline rule) so FF is not measurement-window-limited the way the paper is, and can run the lamellipodium to steady state rather than a 20 s transient.

## 2. FORCE LAWS / KINETIC SCHEMES to port

The main text prints these relations (constants deferred to SI). Map to FF state:

**(2.1) Clutch = linear (Hookean) spring**
`f_c = k_clutch · x_c`, x_c = clutch extension.
→ FF: existing clutch/integrin bond spring; keep linear, set k_clutch from FF's Ferrer-anchored link stiffness (SI value NO_SI here).

**(2.2) Substrate/load spring (PFA lumped form)**
`F_sub = k_sub · x_sub`, x_sub in nm (Figs 3–4 report x_sub ~ up to −150 nm).
→ FF: for a *substrate-coupled* scenario this is the ECM compliance; for a *cortex* scenario the analogue is the cortical tension the clutch bundle loads. Use FF's real substrate/ECM stiffness (PA-gel 500 Pa / 4 kPa / 90 kPa if reproducing the assay), not the lumped spring.

**(2.3) Force-dependent slip-bond off-rate (Bell/Evans)** — the load-and-fail driver
`k_off = k_off,0 · exp(F_clutch / F_b)`  (stated as "off rate increases with tension; break at a rate proportional to applied force").
→ FF: this is **already** FF's Bell-Evans clutch off-rate `k_off = k_off0·exp(F/F_b)`. No new law — confirms FF's choice. F_b, k_off0 values are NO_SI (Suppl. Table S3); do NOT invent them — use FF's existing sourced integrin catch/slip parameters.

**(2.4) Catch-slip variant (Suppl. Fig S3, ref Bangasser 2013)**
Bond strengthens with force to a threshold, then slips. Paper reports: with catch-slip, the *smallest-FA-area* case shows higher mean force/lifetime/stress, **but conclusions are unchanged**.
→ FF: FF's integrin **catch bond** is the physiological choice (mechanistic-over-slip rule). Port note: run FF's PFAC/A_FA sweep with the full catch-slip integrin, expect the same qualitative crossover — this is a robustness cross-check, not a re-parameterization.

**(2.5) Motor force–velocity (Chan–Odde 2008 linear)**
`v_actin = v_unloaded · (1 − F_motor / F_stall)`  (retrograde flow slows with load).
→ FF: FF uses **Hill (1938)** force-velocity for myosin (mechanistic-over-linear rule). The Chan–Odde linear form is the *acceptance oracle / cross-check*, not the runtime law. Keep Hill in FF; use this only to compare retrograde-flow-vs-load against the paper.

**(2.6) Arp2/3 branch angle**
Daughter nucleated at **~70°** off the mother side (Mullins 1998).
→ FF: matches FF's Arp2/3 angle-harmonic **70° ± 35°** exactly. Confirms current FF value; no change.

**(2.7) Substrate stress observable**
`σ = (Σ f_clutch in FA region) / (A_FA region area)`.
→ FF: define this as an FF *diagnostic* (sum of engaged-clutch forces ÷ adhesion footprint) so FF can reproduce the "force ↑ but stress ↓ as adhesion widens" result.

**(2.8) FA-area / clutch-budget controls**
`A_FA = W_FA / W`; constraint `A_FA · N_C^max = const`.
→ FF: scenario knobs — adhesion-footprint fraction and a matched max-clutch budget so total clutch count is held while footprint varies.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario spec)

A directly-runnable FF scenario ("lamellipodium-on-substrate"):
- **Domain**: thin slab **5 × 5 × 0.1 µm** (lamellipodium geometry). Substrate = 2-D triangulated Hookean mesh at z = 0, chain eq length 50 nm.
- **Boundaries**: PBC on ±x; **repulsive** at +y (leading edge); **sticky** at −y (y=0, rear/nucleation).
- **Assembly**: seed F-actins nucleate/grow from y=0; Arp2/3 side-binds and nucleates daughters at ~70° → network grows toward +y. ACP cross-linkers uniform. Myosin **rear-biased** (0 ≤ y ≤ 1.25 µm), actin & ACP uniform.
- **Adhesion**: clutches link mesh nodes within 300 nm of barbed ends inside an FA region of fractional width A_FA; each clutch = Bell slip (FF: catch) spring.
- **Drive**: myosin contracts network in −y; clutches load/deform substrate.
- **Two sweeps**: (a) agent-based A_FA ∈ {0.05…1} with matched N_C^max (fine-grained); (b) PFA lumped N_FA ∈ {1,3,6,10,15,20,30} with total clutches held constant and split equally, 10 replicates each.
- **Conditions**: control (Arp2/3 ON, wide lamellipodium) vs "CK-869" (Arp2/3 OFF → single narrow FLP, A_FA=0.05). 
- **Measurement**: retrograde flow from the y=4.5–5.0 band; stress = Σf_clutch/area; if turnover OFF, restrict to first 20 s (FF should instead keep polymerization ON and run to steady state).

**Native-scale adaptation (HARD-rule compliant)**: do NOT ship the 5×5×0.1 µm coarse slab as a *conclusion* basis. Use it as a dev-only smoke test, then reproduce the PFAC crossover and force/stress-vs-footprint trends on the **native 38000-filament cortex + full compartments** with FF's real Arp2/3 lamellipodium graft, before reporting.

## 6. RISKS / caveats

- **NO_SI**: the mechanical constants (k_clutch, k_off0, F_b, k_sub, v_unl, F_stall, densities, κ, dt) are in Suppl. Tables S1–S3, absent from the PDF. Flag every such value NO_SI; **do not fabricate or back-fit** to the pN/nm figure readouts. FF keeps its own sourced Bell/Ferrer/Hill values. If these constants are wanted, pull Suppl. Tables from the publisher / Kim-lab, or from the lineage papers (Kim 2009, Mak 2016, Li 2017).
- **Slip vs catch, linear vs Hill**: the paper uses *slip* bonds and the *linear* Chan–Odde force-velocity — both are the abstracted options FF's hard rule rejects. FF must keep **integrin catch bond** and **Hill** as runtime; treat the paper's slip/linear forms as cross-check oracles only. The paper itself shows catch-slip does not change conclusions (Suppl. Fig S3), so this is safe.
- **In-vitro-analogue / 2D assay vs living cortex**: this is a thin (0.1 µm) 2D lamellipodium-on-gel migration assay, not a 3D pressurized cortex. The clutch/PFAC physics ports cleanly, but the *scenario* is a substrate-coupled protrusion — reproduce it as FF's lamellipodium graft on ECM, and separately keep the native cortex scenario for γ/contraction work. Don't conflate substrate stress (this paper) with cortical tension.
- **No F-actin turnover in their model** → their results are a 20 s transient. FF's polymerization/growth is ON, so FF should run to steady state and NOT inherit the 20 s window; expect quantitative (not qualitative) divergence in late-time force decay because FF replenishes the network.
- **Coarse-slab / stripped scenario**: the 5×5×0.1 µm box with rear-only motors is a stripped reduced geometry. Per the HARD native-scale rule, any conclusion (PFAC crossover, stress-vs-footprint) MUST be reconfirmed on the native 38000-filament cortex + full compartments before it is reported — use the slab only as a labelled dev smoke test.
- **Species/context**: H4 human glioblastoma on laminin; migration-speed / Cohen's d numbers are cell-line-specific and are **experimental overlay targets**, not FF fitting data (literature-first, PI-data-overlay-only rule). Use them to sanity-check trends (soft-substrate deficit larger), not to tune FF.
- **Highest-value follow-up is a *cited* paper, not this one**: Li et al. 2017 (Soft Matter 13:3213), **buckling-induced F-actin fragmentation** (same Kim framework), is the mechanism most likely to unblock FF's contraction/γ work. Pull and mine it next.
