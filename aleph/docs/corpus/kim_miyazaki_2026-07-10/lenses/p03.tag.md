# TAG-validation lens — p03

**Paper:** Kim, Gardel & Munro (2014) "Determinants of Fluidlike Behavior and Effective Viscosity in Cross-Linked Actin Networks," *Biophys J* 106(3):526–534. DOI 10.1016/j.bpj.2013.12.031.

---

## Paper kind

**simulation** (dominant) + **analytic** (secondary, a closed-form toy model).

The paper's headline numbers (η_eff⁰≈35 Pa·s, σ_th≈1 Pa, ε̇∝n, biphasic σ scaling, 5%/99% load-bearing fraction, 50 pN tension normalizer) are all **agent-based Brownian-dynamics simulation OUTPUTS** — model results, not lab measurements. Under our philosophy these are **comparison targets, never a truth source**: they cannot become a fit target or an experimental overlay. Their real value is that this is the **canonical Taeyoon-Kim agent model** — precisely the physics family FF (Cytosim-style semiflexible filaments + explicit ACP cross-linkers + Bell off-rate + treadmilling + overdamped Langevin) implements. So FF reproducing the *emergent constitutive law* is a legitimate **model-vs-model cross-check**.

A minority of the content IS validation-grade in our sense:
- The **toy-model closed forms** (Eqs. 6, 8, and the creep predictions) are analytic → candidate **oracle** cross-checks.
- Several **input parameters** are experiment-anchored (Fujiwara-2007 treadmilling rates; Ferrer-2008 Bell params; Isambert-1995 persistence length) → parameter/provenance rows, some already in KB.

Net: treat every *result* row as "simulation cross-check, FF-only"; treat the *toy-model laws* as candidate oracles; treat the experiment-anchored *inputs* as parameter provenance.

## Coverage vs existing gates

**No existing gate covers cross-linked-network creep / effective viscosity / yield-stress rheology.** Closest neighbors, and why none cover it:

- **VG-H10-cytoplasm** (`372120daec5d81588b09c9f5a8c99ec1`) — band η 10–70 Pa·s, G 30–80 Pa. This is the **cytoplasm** (poroelastic cytosol+organelles), a *different material* from the actin cortex network. η_eff⁰≈35 Pa·s is numerically in the same decade but physically distinct (cortex creep vs cytoplasm bulk viscosity) — do **not** conflate. No overlap.
- **VG-U3-cortex-multifilament** (`372120daec5d81f388e5d43867b7539f`, Phase-2 entry, blocked) — asserts N≥50 filaments + Bell-Evans crosslink dynamics + measurable Q_ij, i.e. the *structural reconstruction* the FF cortex needs. It is the natural **host contract** for a creep gate but currently defines no rheological observable (no η_eff, no yield stress). This paper supplies the missing emergent observable.
- **VG-H7-gate-a / gate-b / VG-H3-KU35** — active cortical *tension* (myosin-generated γ, band 0.35–0.65 mN/m). Orthogonal: those measure static contractile tension, this measures passive creep viscosity under applied stress. No overlap.
- **VG-U2-catch-slip-bond** (`372120daec5d814ab61fecca9f92d356`) — integrin-FN catch bond lifetime. The Ferrer-2008 Bell datum here is an α-actinin/filamin *cross-linker slip bond*, a different bond. No overlap.

Verdict: this paper **CONFIRMS nothing existing and CHALLENGES nothing** — it opens a genuinely uncovered observable class (cortex network fluidization / effective viscosity). All findings are **NEW candidates**, none tighten an existing band.

## New gate candidates

All flagged **candidate — PI-gate review**. All are FF-engine, model-vs-model **cross-checks** (this is simulation, not experiment), and should be phrased as "FF's fine-grained cross-linked cortex reproduces the Kim-2014 emergent law," never as an experimental truth band.

1. **`VG-FF-cortex-creep-biphasic` (candidate)** — *Observable:* effective viscosity η_eff = σ/ε̇ vs applied tensile stress σ on an FF cross-linked cortex slab under constant-stress creep. *Expected form:* biphasic — η_eff constant (Newtonian, ε̇∝σ) for σ<σ_th, then η_eff∝σ (yield-like plateau, ε̇→σ⁰) for σ>σ_th, over ~2 decades. *Engine:* FF. *Why defensible:* it is a *qualitative law* (shape of the curve), not a fitted magnitude — robust across the paper's entire parameter sweep, so a contract on the *form* is legitimate. *Source:* Fig 1D, Eq. 6, p.3–4.

2. **`VG-FF-cortex-turnover-scaling` (candidate)** — *Observable:* creep rate ε̇ (or η_eff) vs filament turnover rate. *Expected:* ε̇ ∝ turnover rate, η_eff ∝ turnover⁻¹, in the elastic-dominated regime; ε̇→0 (no long-term creep) at zero turnover. *Engine:* FF. *Why defensible:* a scaling exponent (−1) + a hard zero-turnover control, both parameter-robust. *Source:* Fig 2C, Fig 1C, p.3–4.

3. **`VG-FF-load-bearing-percolation` (candidate)** — *Observable:* fraction of cortex filaments carrying the bulk of network tension at any instant. *Expected:* heavy-tailed tension distribution, ~5% of filaments carry ~99% of load (nonaffine, percolating pathways). *Engine:* FF. *Why defensible:* directly measurable natively in FF (per-filament tension is a primitive); a distributional/qualitative contract, not a tuned band. *Source:* Fig 4B, p.5.

*Not proposed as gates* (magnitudes are pure simulation outputs of a specific coarse-graining, so a numeric band would be inventing convenience): η_eff⁰=35 Pa·s and σ_th=1 Pa. Register these as **reference values** (Param rows / SourceEvidence), usable as order-of-magnitude sanity anchors for candidate #1's σ_th, but the *contract* should be on the biphasic FORM, not on "σ_th=1 Pa ± x."

## Oracle candidates

1. **Master-curve collapse (Eq. 6)** — `η_eff·n = η_eff⁰·max(σ,σ_th)/σ_th`. A single closed form unifying the ε̇∝n and biphasic-σ behavior. Implementable as an analytic cross-check curve that an FF cortex-creep sweep should collapse onto (2 constants η_eff⁰, σ_th fit from the FF run itself, then check the *functional form*). **Candidate cross-check oracle** — but note it is a *fit-summary of simulation output*, so weaker epistemic status than the mechanistic oracles (Helfrich, Young-Laplace) we already trust; use as a form-checker, not ground truth.

2. **Toy-model creep predictions** — linear regime `ε̇ ~ k⁻·σ/E₀` (E₀=n_L·K) and plateau regime `ε̇ = k⁻·Δε_avg` (σ-independent), transition at `σ_th ~ E₀·Δε_avg`. A genuinely **analytic, mechanistic** parallel-spring-array derivation (Eq. 8, stiffening element). This is the strongest oracle candidate in the paper: it predicts *why* a turnover-driven cross-linked network yields (nonlinear force-extension of serially-connected filament+ACP subsegments as L_r=L_ee/L_c → 1). Good sanity-gate for an FF pathway-decomposition module. **Candidate oracle — analytic.**

3. **Stokes cylinder drag (Eq. 4)** — `ζ = 3πη_m r_c(3+2r₀/r_c)/5`. Standard analytic per-segment drag (Clift-Grace-Weber). FF/Cytosim likely already uses an equivalent; worth registering as the reference drag oracle so FF's segment drag can be cross-checked. **Candidate oracle — analytic (probably already implicit in FF).**

## Duplicates / notes

- **Ferrer-2008 Bell params (k⁰_ub, λ_ub)** already exist in the KB (α-actinin re-anchor, 2026-06-02 audit). The values here (0.115 s⁻¹, filamin-A) differ by protein — keep both, labeled. Not a new source, not a supersession.
- **Taeyoon-Kim agent model** is already a recognized reference family in this project — see memory `project-dcm-ecm-kim-1r-gap` (single-cell fiber-ECM matched Taeyoon-Kim). This paper is the *rheology* sibling of that force-propagation work; same lab/model lineage. FF's ECM/cortex validation already treats Kim as a cross-check partner, consistent with proposing FF-cross-check (not experimental) gates here.
- **Actin persistence length 9 µm (Isambert 1995)** almost certainly duplicates an existing KB actin L_p claim; do not re-ingest, just cross-reference.
- **Scale caveat:** the paper's slab is 5×5×1 µm with ~1200 filaments — sub-native by FF standards. Per the NATIVE+FULL hard rule, any FF creep gate must ultimately run on the native cortex; the Kim numbers set the *expected law/exponents*, not a small-scale acceptance value.
- **Philosophy compliance:** every proposed gate is on a *form/exponent/distribution* (biphasic shape, ε̇∝turnover, ~5%/99% tail), never on an invented numeric band — respecting "no magic numbers / bands are contracts." Magnitudes (35 Pa·s, 1 Pa) are staged as reference values only.
