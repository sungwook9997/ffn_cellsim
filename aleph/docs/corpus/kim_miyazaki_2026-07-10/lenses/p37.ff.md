# FF lens — p37

**Paper:** Cifuentes, Athamneh, Efremov, Raman, **Kim (Taeyoon)**, Suter — *A modified motor-clutch model reveals that neuronal growth cones respond faster to soft substrates.* Mol Biol Cell 35:ar47 (2024). DOI 10.1091/mbc.E23-09-0364.

**One-line verdict for FF:** This is a *lumped* 1-D Chan–Odde/Bangasser motor-clutch model (Gillespie-SSA, one filopodium + one elastic substrate spring), not a fine-grained filament engine. Its mechanisms (Bell slip-bond off-rate, linear motor force-velocity, equal force-sharing) are things FF **already does more mechanistically** (Bell-Evans per-bond, Hill per-head, explicit springs). So the paper's runtime *scheme* is **not** something to port — it is an **acceptance-oracle / cross-check** for the FF crawl-on-substrate module. Its real value to FF is: (a) a small set of clean single-molecule **parameter anchors** (F_s, F_b, K_clutch, v_u), (b) a **force-threshold adhesion-reinforcement** idea that FF should implement mechanistically (talin-unfold/integrin recruitment, catch-bond), and (c) a **durotaxis validation scenario** with numeric targets for `ff_crawl_on_substrate`.

---

## 1. MECHANISMS to adopt

### 1a. Force-threshold adhesion reinforcement (clutch recruitment) — adopt the PHENOMENON, mechanistically
- **Paper mechanism (lumped):** new clutches are *added* at rate `k_add = k_add0·(#engaged clutches with F≥F_t)·f_available`, gated at **F_t = 10 pN** per bound clutch (Eq 6). This positive feedback is what converts the classic model's unstable oscillating steady state into a **stable** steady state (constant substrate deformation) matching experiment (Fig 6).
- **Why it matters for FF:** FF's motor-clutch / integrin catch-bond currently has binding + Bell-Evans unbinding but (per memory `project-ff-crawl-mechanism`) crawl emerges from protrusion + clutch turnover with **no force-dependent recruitment** of *new* adhesions. Force-triggered adhesion *growth* is a real missing lever — it is exactly the mechanism that stabilizes traction and sets a strong-coupling latency.
- **FF-mechanistic implementation (NOT the lumped k_add):** the hard rule forbids a lumped recruitment rate. The fine-grained substrate for the same physics is already named in the paper's own Discussion:
  - **talin unfolding at 5–10 pN** exposing cryptic vinculin sites (Yao 2016) → force-gated addition of a reinforcing crosslink/clutch bond. Implement as a per-clutch stretch-triggered state change that recruits an additional bond, threshold in the **5–10 pN** window (consistent with F_t=10 pN).
  - integrin recruitment proportional to local force (Choquet 1997, Roca-Cusachs 2009).
- **Module:** `ff/` adhesion clutch / integrin catch-bond + motor-clutch on substrate (`ff_crawl_on_substrate.py`).

### 1b. Equal force-sharing → emergent bond-lifetime lengthening (already correct in FF, verify)
- **Paper:** total load `n_m·F_s` is shared equally over all bound clutches; adding clutches lowers per-clutch F, which (via Bell, Eq 5) **lengthens** bond lifetime. This is the emergent stabilizer.
- **FF:** in FF this is **automatic and fine-grained** — load is distributed by the actual spring network, not an equal-sharing assumption. Nothing to port; use as a **sanity check**: an FF clutch cluster under load must show longer mean bond lifetime as cluster size grows (matches memory `project-dcm-cadherin-cluster-redesign` load-sharing cluster physics on the DCM side).

### 1c. Motor recruitment scaling with substrate stiffness — note, do NOT hard-code
- **Paper:** number of NMII motors `n_m` had to increase ~linearly with K_sub (≈4000→13000 across 2.5→106 pN/nm) to reproduce substrate deformation. This is a **fit knob**, not a mechanism — flagged here only so FF does **not** adopt it as a rule (would violate no-fitting / no-magic-number). In FF, any stiffness-dependence of engaged motor number must **emerge** from load-dependent myosin duty ratio (see §2c), not be imposed.

## 2. FORCE LAWS / KINETIC SCHEMES (transcribed, mapped to FF state)

### 2a. Bell slip-bond clutch off-rate (Eq 5) — FF already has this; use for F_b anchor
```
k_off,i(t) = k_off0 · exp( F_clutch,i / F_b )
F_clutch,i = K_clutch · (x_actin,i − x_sub)      (Eq 4, Hookean clutch spring)
```
- **Map to FF:** `F_clutch,i` → tension on FF integrin/clutch bond; `F_b` → Bell-Evans rupture-force scale in the clutch off-rate; `k_off0` → unloaded off-rate prefactor; `K_clutch` → clutch bond stiffness.
- **Note:** purely slip (no catch term). Paper explicitly states *no evidence for catch bonds in apCAM–ConA–F-actin*. FF's integrin adhesion should keep its **catch-bond** (Rakshit KU-4.2) for integrin–collagen; this paper's slip-only law applies only to the apCAM system and is a **cross-check regime**, not a replacement.

### 2b. Linear motor force-velocity (Eq 7) — DO NOT port; FF's Hill is more mechanistic
```
v_f(t) = v_u · ( 1 − K_sub·x_sub / (n_m·F_s) )
```
- **Map:** retrograde flow `v_f`; unloaded flow `v_u`; total stall `n_m·F_s`; elastic load `K_sub·x_sub`.
- **Verdict:** this is a lumped linear Hill approximation over the *whole* filopodium. FF resolves force-velocity **per myosin head** via Hill (1938) on a Stam–Hocky bipolar minifilament. **Keep FF's Hill.** Use Eq 7 only as an aggregate acceptance oracle: FF's native retrograde-flow vs. total-load curve should reduce to this linear form in the many-head limit.

### 2c. Load-dependent myosin kinetics (Discussion — the mechanistic upgrade the paper wishes it had)
The paper's Discussion (p9) is essentially a to-do list that FF **already satisfies or should**:
- **Load-dependent ADP release / duty ratio** (Kovács 2007): duty ratio rises with load → longer F-actin attachment. FF's Hill + duty-ratio head model should reproduce this; verify duty ratio increases under load.
- **Stam 2015 two-state cross-bridge, NMIIA "adaptable motor":** force output depends on (1) force build-up time and (2) attachment time; NMIIA shows a sharp stiffness transition. FF uses the **Stam–Hocky** minifilament — this is the same lineage; the paper endorses it as the correct fine-grained direction over the lumped linear law.
- **Weirich 2021 / Muresan 2022:** myosin force output depends on **crosslinker stiffness, interfilament spacing, network compliance** — more heads needed at larger spacing; force rises with crosslinker stiffness. **Directly relevant to FF's open γ-generation / contraction problem:** FF's cortical tension and contraction should be sensitive to crosslinker stiffness (already anchored Ferrer, memory `project-ff-unified-arch-and-stiffness`) and mesh spacing. This is a *design confirmation*, not a new equation.

### 2d. Gillespie SSA (Eqs 1–3) — not for FF
FF's runtime is the constrained Leimkuhler–Matthews BAOAB integrator with force-dependent binding updaters, not event-driven SSA. No port. (SSA relevant only if a stand-alone single-clutch oracle is written.)

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario: "durotaxis / substrate-stiffness latency" for `ff_crawl_on_substrate`.**
- **Geometry:** a single actin **bundle/filopodium** (FF already builds bundled filopodium, memory `project-ff-unified-arch-and-stiffness`) coupled to an **elastic substrate** of tunable stiffness K_sub, via integrin/clutch bonds. Myosin minifilaments drive retrograde flow.
- **Initial condition:** unloaded retrograde flow at physiological rate, no bound clutches → clutches engage under load. (Respect the physiological-baseline rule: start the filopodium at its resting operating point, not a floppy null.)
- **Sweep:** substrate stiffness across the 2.5–106 pN/nm range (≈0.6–26 kPa effective, Chan–Odde regime switch ~1 kPa).
- **Protocol:** run until retrograde flow attenuates to 20% of unloaded (the strong-coupling onset), record **latency time** and **substrate deformation** at that instant.
- **Ensembles:** paper used n=40 per stiffness — FF should ensemble ≥ that for the biphasic curve (seed-robustness per memory `project-ff-active-movement-pieces`).
- **Caveat on scale rule:** this filopodial scenario is a *sub-cell* module test, not the native 38000-filament cortex. Any *conclusion* (e.g. "FF reproduces the soft-substrate optimum") must be reconfirmed with the filopodium built at native filament density within the full-compartment cell, per the NATIVE+FULL hard rule — do not conclude from a stripped single-bundle toy.

## 6. RISKS / caveats

1. **This is a lumped paper-model, not a fine-grained engine.** Per CLAUDE.md's mechanistic-over-lumped hard rule and the dossier's own flag, treat the whole scheme as an **acceptance oracle / cross-check**, never as an FF runtime mechanism. Port anchors and the validation scenario, not Eqs 6–9.
2. **Species / ligand mismatch.** Aplysia bag-cell growth cone, apCAM–ConA adhesion, PLL substrate, 14 °C sea water. FF's target is MCF7 (R=7.5 µm) with integrin–collagen. v_u=100 nm/s and the 4-pN/nm optimum are **Aplysia** numbers — do not import as MCF7 setpoints; use them only to validate the *filopodial motor-clutch sub-module* in the Aplysia regime, or as order-of-magnitude sanity.
3. **Slip-only vs catch-bond.** Paper deliberately omits catch bonds (no evidence for apCAM). FF's integrin adhesion **should keep** the catch-bond (Rakshit KU-4.2). Don't let this paper's slip-only Bell law downgrade FF's integrin to slip-only.
4. **Fit knobs (k_add0, n_m(K_sub)) are not physics.** k_add0's bimodal stiffness dependence and the linear n_m ramp are optimized to match one experiment — importing them would violate the no-fitting / no-magic-number rules. FF must let stiffness-dependence **emerge** from load-dependent duty ratio + reinforcement, then *compare* to the biphasic curve.
5. **1-D single filopodium vs 3-D full cell.** The scenario is a sub-cell bundle on an elastic spring. Any FF conclusion must be reconfirmed at native filament density in the full-compartment cell (NATIVE+FULL hard rule); the single-bundle run is a dev-only smoke test.
6. **F_t=10 pN "reinforcement" is phenomenological.** Implement it as talin-unfolding (5–10 pN, Yao 2016) / integrin recruitment, not as a bare k_add rate, or it becomes exactly the lumped proxy the architecture forbids.

---

### Bottom line for FF
Modest but real: **no new runtime mechanism** (FF's Bell-Evans + Hill + explicit springs already dominate the paper's lumped laws), but it delivers (i) clean single-molecule **anchors** — F_s=6 pN, F_b≈4 pN, K_clutch≈0.3 pN/nm, v_u≈100 nm/s; (ii) a well-motivated **force-triggered adhesion-reinforcement** lever to add *mechanistically* (talin/integrin, 5–10 pN) that stabilizes traction; and (iii) a fully-specified **durotaxis validation scenario** with numeric targets (biphasic latency 14→2→8 min, substrate deformation 1.6→0.8 µm, optimum 4 pN/nm) for the FF crawl-on-substrate module.
