## 1. MECHANISMS to adopt

### 1.1 Myosin binding: add **mechanosensitive (lattice-spacing-dependent) attach/detach rates** — Sato/Ishiwata SPOC assumption
- **FF module:** `ff/` myosin — Stam–Hocky bipolar minifilament head binding/unbinding kinetics.
- **Current FF:** head off-rate is force-dependent (Bell–Evans `k_off = k_off0·exp(F/F_b)`); attachment is a fixed-rate / duty-ratio process. Force is the ONLY state variable feeding kinetics.
- **Paper's mechanism (the group's "original assumption", p7, refs [2,3]):** both attach AND detach rates depend on the **inter-filament lattice spacing** `d` (perpendicular distance between the myosin thick filament and the actin it reaches for), not on longitudinal force alone: `k_attach = k_attach(d)`, `k_detach = k_detach(d)`. Because the actin lattice is roughly constant-volume, `d` grows as the network shortens — so contraction feeds back on binding. This lattice-spacing feedback + a threshold coexistence of force-generating and non-force-generating cross-bridges is what produces the auto-oscillatory SPOC "third state" between full contraction and relaxation.
- **Why it beats current FF:** FF myosin heads reach toward neighboring actin across a *transverse gap*; the probability a head can even bind depends on that gap, which in a contracting/condensing cortex changes as the mesh densifies. Encoding attach-rate as a function of local transverse actin availability (head-to-nearest-actin distance) is strictly more mechanistic than a spacing-blind fixed attach rate, and it is a candidate microscopic origin for **stress-relaxation and slow oscillatory / pulsatile flows** in the cortex (one of our open problems). This is a geometric gate, not a lumped proxy — it stays inside the fine-grained rule.
- **Adopt as:** an optional `attach_rate_fn(d_head_to_actin)` gate in the head-search kernel, physiological-on. Do NOT import the mean-field `P(ξ,t)` population variable — that is a lumped continuum quantity and would violate the mechanistic rule. Port only the *geometric dependence*, realized per-head.

### 1.2 Confinement-driven ring self-organization as an FF **scenario / emergent test** — Miyazaki 2015 [5]
- **FF module:** cortex + filament + crosslinker + myosin, run inside a spherical membrane-containment boundary.
- **Mechanism:** purified actin + a bundler, encapsulated in a cell-sized droplet, spontaneously forms a **single equatorial ring** with NO spatial patterning signal — purely from (i) rigid-rod bending-energy minimization when droplet radius ≲ L_p and (ii) depletion bundling. HMM myosin then remodels branched bundles into one ring and constricts it. This is *emergent* structure from filament mechanics + boundary alone.
- **Why FF should reproduce it:** it is the cleanest possible fine-grained validation that FF's bending beam + crosslinker + containment produce correct *emergent* organization, and it directly exercises our open "confinement-driven self-organization / buckling / symmetry-breaking" item. It is single-cell scale, purified components (no living-cell confounds), and has a sharp pass/fail (ring vs 3D bundle mesh at the 20 µm threshold).

### 1.3 Crosslinker: **depletion (Asakura–Oosawa) bundling** as an explicit bundling channel — ref [63]
- **FF module:** crosslinker / bundling.
- **Current FF:** bundling is via explicit α-actinin/filamin bonds (Bell–Evans, Ferrer stiffness).
- **Paper:** the ring assay bundles actin with **methylcellulose/PEG depletion** (Asakura–Oosawa entropic attraction) rather than a molecular crosslinker; they confirm **α-actinin gives essentially the same result**. So the FF explicit-crosslinker path is validated as interchangeable with the depletion path — no code change needed, but it tells us the ring-formation result is *crosslinker-mechanism-agnostic*, i.e. a robust geometric/entropic effect. Keep FF's explicit-bond bundling (more mechanistic); use this only to justify that the emergent ring is not a crosslinker-specific artifact.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### 2.1 Confinement → ring criterion (rigid-rod bending-energy argument) — p20, Fig. 3-3d
Transcribe as an FF-checkable predicate:
```
ring self-organizes  ⇔  R_droplet ≲ L_p        (actin persistence length)
```
Mechanism = worm-like-chain bending energy `E_bend = (κ/2) ∫ (∂θ/∂s)² ds`, with `κ = k_B T · L_p`. When the confinement radius is below L_p the filament behaves as a rigid rod and localizes to the droplet **equator** (great circle) to minimize bending strain; above L_p it acts as a flexible polymer and forms a 3D bulk mesh.
- **Map to FF state:** `L_p` ↔ FF filament bending stiffness κ_bend (per-segment angular harmonic); `R_droplet` ↔ membrane-containment radius. FF already has both — this is a zero-new-parameter test: sweep containment R across ~L_p and confirm the equatorial-ring vs bulk-mesh transition emerges.

### 2.2 Lattice-spacing-dependent cross-bridge kinetics (mechanism only; no closed form given) — p7
```
k_attach = k_attach(d),   k_detach = k_detach(d)
d ↑  as network shortens   (constant-volume lattice)
active force  F_active ∝ N_engaged = P(ξ,t)·N_total     ← population form; DO NOT port as a lumped variable
longitudinal ledger:  F_load = F_crossbridge(active) − F_friction(cross-bridge viscous drag)
transverse ledger:    0 = F_elastic(cross-bridge) + F_elastic(lattice) + F_elastic(Z-disc)
```
- **Portable piece:** the functional dependence `k_attach(d)` / `k_detach(d)` on transverse head-to-actin distance (§1.1). The review gives no numeric `k(d)` form — the closed forms are in Sato 2011 *Prog. Biophys. Mol. Biol.* 105:199 [2] and Sato 2013 *PRL* 111:108104 [3]; fetch those before implementing.
- **NOT portable:** `P(ξ,t)` mean-field population ODE, longitudinal/transverse continuum force balance — these are the lumped sarcomere model; FF's per-head/per-bond dynamics already resolve them microscopically.

### 2.3 Constriction-rate scaling — p21, ref [5]
```
ring constriction rate  ∝  initial ring diameter
```
An emergent observable for FF, not a force law to impose. Purely diagnostic.

**No Bell–Evans, catch-bond, Hill f–v, branching-angle, or LJ law appears in this review** — it is review-level. FF's existing Bell–Evans / Hill / Arp2/3-angle machinery is unaffected.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario spec)

**"Confined actomyosin ring" reconstitution (Miyazaki 2015 [5]) — an FF emergent-organization scenario:**
1. Geometry: spherical membrane containment, diameter swept 5–40 µm (straddle the 20 µm ≈ L_p threshold).
2. Filaments: actin bending beams at L_p (whatever FF production value), distributed lengths, explicit bundling bonds (α-actinin path — the paper confirms it reproduces the depletion result).
3. Stage A (no motor): confirm **emergent single equatorial ring** for Ø < 20 µm and **3D bulk bundle mesh** for Ø > 20 µm. Pass = ring localizes to a great circle; the transition is the bending-energy prediction §2.1.
4. Stage B (add myosin): HMM-analog minifilament heads → confirm branched-bundle→single-ring remodeling, then **constriction with rate ∝ initial ring diameter**.
5. Physiological-baseline caveat: run from a relaxed-but-pressurized shell at real cytoplasm η (65 Pa·s), not water — the ring assay is buffer-viscosity in-vitro, so FF's living-cortex run will differ in timescale; compare *scaling/topology*, not absolute constriction seconds.

This is single-cell, fine-grained, purified — fully inside our scale and rules.

## 6. RISKS / caveats

- **Domain mismatch (the big one).** ~85% of this paper is striated-muscle sarcomere (smectic myofilament lattice, SPOC, cardiac SL-nanometry) and mitotic-spindle (microtubule, DCM lane) — NOT the actin cortex FF models. Only the Miyazaki artificial-cell ring + the L_p anchor + the lattice-kinetics *idea* transfer. Do not over-weight this source for FF.
- **Review, not primary.** Every number is re-cited. KB-register against primaries: ring assay → Miyazaki 2015 *Nat. Cell Biol.* 17:480 [5]; lattice-kinetics forms → Sato 2011 PBMB 105:199 [2] + Sato 2013 *PRL* 111:108104 [3]; L_p → Gittes/Ott [64–66]. Fetch [2],[3] before coding §1.1 — the review gives no equation.
- **In-vitro purified vs living cortex.** The ring assay is 2-component (actin + bundler + HMM) in buffer viscosity; FF production is a full-compartment pressurized MCF7 cortex at η=65 Pa·s. Reproduce **topology/scaling** (ring-vs-bulk threshold, rate∝diameter), never absolute in-vitro seconds. Run the scenario at physiological baseline; label the purified-buffer variant a dev cross-check.
- **HMM ≠ full myosin minifilament.** The assay uses truncated 2-head HMM that cannot self-assemble into filaments; FF's Stam–Hocky bipolar minifilament is the more mechanistic object. The paper confirms full-length myosin gives the same qualitative ring result, so use FF's minifilament (do not downgrade to a 2-head proxy to match the assay).
- **L_p discrepancy is a real flag, not a free knob.** 5–15 µm (this paper) vs FF's 17 µm — surface to PI rather than tuning; the 20 µm confinement threshold is only interpretable relative to whichever L_p FF runs, so the ring test is self-consistent either way but the *quantitative* threshold moves with L_p.
- **Native-scale rule.** Any conclusion (ring emerges / doesn't) must be confirmed on a native-density confined cortex, not a coarse ~250–1000-filament shell — a coarse ring could "form" or "fail" for stability-artifact reasons, per the 2026-07-09 HARD rule.
- **Do not port `P(ξ,t)`.** It is a lumped mean-field population variable; importing it would violate the fine-grained-over-lumped rule. Realize the mechanism per-head only.
