# DCM lens — p34

**Paper:** Mak, Kim, Zaman, Kamm — "Multiscale mechanobiology: computational models for integrating molecules to multicellular systems," *Integr. Biol.* 2015, 7, 1093–1108 (DOI 10.1039/c5ib00043b).

**Verdict up front:** This is a **narrative REVIEW**, not primary research. It contains **no original governing equations, no parameter tables, and no simulated/measured observables of its own**. Every number in it is a second-hand citation to a primary paper. Its value to DCM is as a **roadmap/citation graph** — it points at the right primary sources for mechanisms DCM already has or wants — not as a source of any equation, parameter, or validation datum you can port. Nothing below should be KB-registered from this paper; trace to the cited primary source first.

---

## 1. MECHANISMS to adopt

There is **nothing to adopt directly** (no mechanistic law is written out). What the review does is *frame* mechanisms DCM already implements and *flag two frontiers* worth pursuing via the primary literature it cites. Concretely:

- **Aggregate compaction driver (relevant to DCM's OPEN loose→compact RATE problem).** The review flags ref 128 (Mgharbi/embryonic micro-oil-droplet force quantification) and the general finding that **actomyosin contraction drives 3D aggregate compaction** — i.e. compaction is a contractility-driven, cadherin-mediated *active* process, not a passive surface-tension relaxation. This *corroborates* the memory-note conclusion that aggregate-σ pull is the wrong RATE driver and that the real driver is active junction remodeling (T1 rearrangement escalation). It does not supply the law — chase **ref 128** and the CPM cancer-compaction refs (Boghaert DCIS, ref 12) for the actual mechanism. WHY it beats DCM-now: only conceptually — it confirms the direction, gives no equation.

- **Cell–cell junction is one mechanosensitive interface (already DCM's design).** The review's Fig. 2 / Fig. 4b framing — integrin AND cadherin as a single "transmembrane adhesion complex" that transmits force inside-out and outside-in, with catch/slip force-dependent kinetics — is exactly DCM's "cell–cell contact = ONE cadherin catch-bond junction" principle. Confirmatory, not additive.

- **Cortex as a transiently-crosslinked, tension-tunable network (γ-generation frontier).** The actin-cytoskeleton section frames cortical mechanics as **strain-stiffening via bending→stretching transition** + **transient-crosslink-governed softening/creep/stress-relaxation** + **myosin-driven active stiffening** with a **motor:crosslinker percolation phase transition** (Fig. 3: unstressed→stiffening→softening). This is the correct conceptual picture for DCM's cortical-tension γ generation — but it is an **FF-scale (fine-grained filament)** story, and this review supplies no coarse-grained surface law for it. For DCM, the takeaway is only that γ should have a stress-dependent (stiffening-then-softening) character; the actual constitutive form must come from the cited primary papers (Kim/Hwang/Lee/Kamm ref 4/47; Storm ref 29; MacKintosh/Broedersz active-gel line).

- **Nucleus mechanotransduction frontier.** Flags LINC-coupled nuclear stiffening and nN-scale chromatin decondensation (ref 135 Iyer, ref 136). Relevant to DCM's nucleus compartment (E_nuc), but as a future direction with no law/parameter here.

## 2. EQUATIONS to port

**None portable.** The only force expressions in the entire paper are the schematic annotations of the *Kim et al.* single-cell migration model in Fig. 1c (adapted from primary ref 110), which is an FA/stress-fiber **node** model, not a surface-mesh continuum. For completeness:

- **Eq. (Fig.1c-1), linear viscous drag on adhesion node i:**
  F_D,i = −C_c · v_i
  Map to DCM: this is just Stokes per-node drag F = −ζ v, which DCM *already* has (per-node drag derived from η=65 Pa·s). No new content.

- **Eq. (Fig.1c-2), quasi-static nodal force balance:**
  F_SF,i + F_E,i + F_FA,i + F_L,i + F_D,i = 0
  Map to DCM: nodal equilibrium of stress-fiber + elastic + focal-adhesion + ligand + drag forces. DCM's Warp force-balance per surface node is the same *pattern* (Σ F_node = 0 → integrate), but the functional forms of F_SF/F_E/F_FA/F_L are defined in ref 110, **not here**. Nothing to transcribe.

There are no bending/stretching potentials, no Bell/catch-bond rate laws, no Hill relations, no continuum stress PDEs written out anywhere in the paper.

## 3. PARAMETERS to set

**None.** The paper has no parameter table. Every numeric value is a cited illustration and is either (a) molecular-scale (talin SMD 300 pN, 3.2 nm equilibrium domain, filamin-A domain-20 unfold >4 pN, talin in-vivo stretch "hundreds of nm") — well below DCM's surface-mesh scale — or (b) an order-of-magnitude frontier fact (~10 s motor-fluctuation processivity, ref 132; nN chromatin-decondensation force, ref 135). **None feeds a DCM config field.** The Fig. 1b "~10–40 Pa network stress at 1–6 ms" is read off a borrowed plot (Kim ref 4) and is an actin-network-rheology datum for FF, not a DCM surface tension.

Do **not** supersede any DCM default from this paper.

## 4. GEOMETRY / PROTOCOL to reproduce

No quantitative protocol is specified, but the review enumerates scenario *types* DCM could stage (all to be sourced from the primary refs, not this paper):

- **Actomyosin-driven 3D aggregate compaction** (ref 128 micro-droplet force sensor; Boghaert DCIS CPM ref 12) — the natural DCM N≈400 aggregate compaction scenario; the review only confirms it is contractility+junction driven.
- **Confined-channel single-cell migration** (ref 114) — a confinement BC (cell squeezed through a channel narrower than R) usable as a DCM confinement-response scenario; no dimensions given here.
- **Durotaxis on a deformable substrate / endothelial network formation** (hybrid CPM+FE, Fig. 1d, ref 13) — a substrate-stiffness-gradient scenario; DCM would need the substrate as an elastic BC. Timescale note only: sim t=1800–2400 vs experiment 0–6 h.
- **Cell-pair force transmission through fibrous ECM** (Fig. 4a/b) — two DCM cells contracting a shared fibrous matrix, force channeled by tension-driven fiber alignment (Wang ref 79, Ma ref 81, Abhilash ref 80). This is really an FF/ECM scenario.

All are qualitative; none carries reproducible geometry or numbers in *this* document.

## 5. VALIDATION TARGETS

**None usable for DCM.** The paper reports no DCM-scale observable (no cortical tension in mN/m, no shape index, no division force, no ring-closure time, no compaction fraction, no contact angle, no cortical flow speed). The numbers it does state are molecular SMD trajectories (talin ΔL 0.4→6.2 nm at 300 pN; rupture at 7.3 ns) and network-rheology stresses (~10–40 Pa, 1–6 ms) — the former is atomistic, the latter belongs to FF actin-network validation, and both are second-hand citations. No DCM run should be gated on any figure from this paper.

## 6. RISKS / caveats

- **It is a review — regime mismatch is total for quantitative use.** No value here was measured or simulated by the authors; all are re-citations. Using any of them as a DCM datum would violate "no fitting / literature-first with traceable provenance" because the provenance is one hop removed. **Always trace to the primary ref before any use.**
- **Scale mismatch.** The concrete content is molecular (single-protein SMD) or fine-grained network (Brownian-dynamics actin+ACP) — i.e. **FF-scale, not DCM surface-mesh scale**. Porting Fig. 1c's node model to DCM would be adopting an FA-point migration model, not a deformable-surface model — wrong altitude for DCM.
- **In-vitro / mixed cell types.** The cited experiments span reconstituted purified actin, endothelial cells, embryonic aggregates, DCIS lines — not living MCF7. Nothing is MCF7-anchored, so it cannot set a physiological baseline for our cell.
- **Correct use without rule violation:** treat p34 purely as a **citation-graph pointer**. If a DCM mechanism needs a law (cortex stiffening constitutive form, compaction driver, confinement BC), follow p34's reference numbers to the primary source, validate *that* source's regime against MCF7/our scale, and register from there — never from p34 itself.

---

**Bottom line for DCM:** relevance is low and conceptual-only. p34 confirms two things DCM already believes (junction = one mechanosensitive catch-bond interface; aggregate compaction is active-contractility driven, not passive-σ driven — supporting the OPEN T1-rearrangement direction) and points at the right primary papers for the cortex-γ and nucleus frontiers, but it supplies zero equations, parameters, or validation targets to port.
