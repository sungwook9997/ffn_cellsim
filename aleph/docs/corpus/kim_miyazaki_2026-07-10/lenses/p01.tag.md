# TAG-validation lens — p01

**Paper:** Miyazaki & Harada (2011), *Bayesian estimation of the internal structure of proteins from single-molecule measurements*, J. Chem. Phys. **134**, 085108. DOI 10.1063/1.3516587.

## Paper kind

**method / analytic-theory** (statistical inference + Brownian-dynamics numerical experiments). NOT experimental — there are no in-vitro biophysical measurements (no tensions, moduli, motor speeds). All quantities are **nondimensional** (units fixed k\* = γ\* = k_BT = 1). The "data" are (a) closed-form results of a Bayesian/Onsager–Machlup/WKB derivation, and (b) Metropolis-optimizer outputs on a synthetic 2-bead Langevin toy. Under our philosophy: simulation/analytic numbers → comparison/cross-check only, **never a truth source and never a fit target**; and because they are dimensionless toy-model results, they are not even a defensible overlay target at our single-cell scale.

## Param candidates

**None.** Every parameter in the paper is either a unit-fixing convention (k\*=γ\*=k_BT=1), a swept independent variable (h\*, Γ\*, Δt, τ, σ_noise ∈ 10⁻²–10²), or a numerical setting (10⁵ Metropolis iterations, step SD 0.01, discard threshold 3, replicas/samples). All dimensionless; none is a sourced physical constant for MCF7 / actin / ECM / motors. Nothing to register; nothing supersedes an existing Parameter row.

## Oracle candidates

**One narrow, method-scoped candidate (flag: PI-gate review, low priority).**
- **Analytic MAP hidden-trajectory error, Eq. (20):** ⟨(x̂−x)²⟩ = (1/βh)[2/κ − 1/√(κ²+g)], with κ = 1 + k/h, g = γ/Γ. This is an exact closed form for a linear 2-bead overdamped Langevin system — implementable as an analytic cross-check IF and only if FF adopts a linear trajectory-inference tool. It is **not** a cell-mechanics oracle (unlike Helfrich / Young-Laplace / Bell-Evans / Hill / Kelvin-Voigt, which validate our physics), so it does not belong in the current oracle set. Recommend: hold as a documented method reference, not an implemented oracle, until/unless an inference tool exists.
- The τ⁻¹ error law (Eq. A11) and the φ²=(k+h)²/γ², χ²=h²/(γΓ) Hamiltonian (Eq. 17) are correct closed forms but are estimator-convergence results, not physical ground truth — no oracle value.
