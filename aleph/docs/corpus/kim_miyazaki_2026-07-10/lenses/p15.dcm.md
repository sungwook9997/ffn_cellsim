# DCM lens — p15

**Paper:** Ding, Matsui, Kaunas, Kim, Deguchi (2025), *Dissecting Molecular Origins of the Mechano-Adaptive Behaviors of Actomyosin Bundles* — bioRxiv 10.1101/2025.07.09.663940.

**One-line honest framing for DCM:** This is a *sub-cellular* paper — a single contractile actomyosin bundle (stress fiber) modeled as explicit actin beams + ACP crosslinkers + multi-arm myosin via Kim agent-based Brownian dynamics. It is squarely FF-engine physics, NOT a DCM constitutive input. But it contains one genuinely DCM-portable idea: a **mechanistic, rate-dependent active-tension law** in which the *steady-state* tension is set by motor density while the *relaxation/recovery rate* is set by motor walking speed — and this is exactly the decomposition DCM's cortical-tension γ source currently lacks (γ is presently a static scalar). Everything else is either scale-mismatched or better routed to FF.

DCM impact is **modest (2.5/5)**: it does not hand DCM a surface-mesh equation, but it hands DCM a *principled functional form* for a rate-dependent cortex γ(t) that supersedes the current static-γ / lumped-viscoelastic treatment, plus a physically-grounded buckling criterion for the confinement/bleb regime.

---

## 1. Mechanisms to adopt

### M1 — Cortex active tension as a rate-dependent, motor-driven source (NOT static γ, NOT lumped viscoelastic). **[highest DCM value]**
DCM module: **actomyosin cortex surface tension γ**.
Change: replace the static interphase/mitotic γ scalar with a two-timescale active law whose *plateau* is set by myosin surface density and whose *relaxation under stretch / recovery after slack* is set by the motor walking speed. The paper's central result (Figs. 2C, 5) is that these two knobs are **decoupled**:
- Stretch a contractile unit → tension rises, then **relaxes** (drops below half the peak, Fig. 2C) because force-dependent myosin/ACP unbinding lets the bundle permanently lengthen. This is a *mechano-adaptive* relaxation, and the paper explicitly shows no Kelvin-Voigt / Maxwell / SLS spring-dashpot reproduces it (p12).
- After slack/compression → tension **recovers** as unloaded motors walk the bundle back to taut; the recovery *rate* ∝ motor walking speed (k₂₀ sweep, Fig. 5B/C), *independent of motor density* (Fig. 5D/E).
- Steady-state tension after recovery ∝ motor density R_M (Fig. 5F).

Why it beats current DCM: DCM's γ is a fixed number (0.15 mN/m interphase, 1.5 mN/m mitotic) with no dynamics. Real cortex under fast deformation (confinement, aspiration, division-furrow) shows exactly this rate-dependent adapt/relax behavior. This gives DCM a **physiologically-grounded γ(t)** whose two parameters (plateau magnitude, relaxation timescale) each map to a measurable molecular quantity — directly attacking the open "cortical-tension γ generation" problem without introducing a magic number.

### M2 — Buckling / wrinkling criterion: deformation rate vs. motor walking speed.
DCM modules: **confinement response, bleb, membrane–cortex coupling**.
The paper establishes a clean physical criterion (Discussion p18): a contractile bundle **buckles only when the compression rate exceeds the unloaded motor walking speed** — slow compression lets motors take up the slack and the bundle stays straight; fast compression outruns the motors and it buckles, then straightens over t_r. Mapped to a cell surface, this is the condition under which the cortex **cannot keep its tension taut and wrinkles/blebs** vs. smoothly adapts. It gives DCM a mechanistic, non-fitted threshold for cortex wrinkling under fast confinement instead of an ad-hoc buckling instability.

### M3 — Force-relaxation source term = force-dependent unbinding, not dashpot.
DCM module: **cortex γ + membrane surface viscosity η_s**.
The relaxation in M1 arises because tension raises the Bell off-rate of ACPs (Eq. S8) and the PCM catch-bond unbinding of motors, so the network sheds stress by *losing connections*, then re-forms them relaxed. For DCM this argues that any cortex stress-relaxation term should be sourced from a load-dependent bond turnover rate (which DCM already has in the *cadherin junction*), not from a phenomenological surface-viscosity dashpot. It is the same modeling philosophy DCM already applies at the cell–cell junction, extended to the intra-cortex active tension.

*(Not adopted: explicit filament/ACP/motor beams — that is FF's job, not DCM's surface-mesh scale. DCM should consume the *emergent* γ(t) law, not the agents.)*

## 2. Equations to port (to the surface-mesh / continuum level)

DCM should port the paper's **emergent scalings**, not its per-segment ODEs. Concretely:

### E1 — Rate-dependent active cortex tension (constructed from the paper's decomposition)
Motivated by Figs. 2C + 5, an active-tension update on each face `f`:

    γ_active,f(t) = γ_plateau · s_f(t),      ds_f/dt = −(v_walk / ℓ_ref)·(s_f − 1)·H(taut) + (relax under stretch)

- **γ_plateau** ← plateau tension, ∝ myosin surface density (paper: F_B,ss ∝ R_M, Fig. 5F). Maps to DCM cortex γ scalar (per-face).
- **s_f** ← dimensionless "tautness" state (1 = fully recovered/taut), a per-face scalar carried alongside γ.
- **v_walk** ← motor unloaded walking speed (paper: ≈56 nm/s at k₂₀=8; in-cell ~200 nm/s cited). Sets the *recovery timescale* τ_rec = ℓ_ref/v_walk. This is the **new** DCM parameter that the paper uniquely justifies.
- **ℓ_ref** ← local cortex reference length (edge length between adjacent nodes on the mesh), so the term is grid-invariant (rate = strain-rate, not absolute-length, dependent).
- Relaxation branch: when the face is stretched at rate ε̇ above threshold, γ sheds toward a lower value on the bond-turnover timescale — the mechano-adaptive drop of Fig. 2C.

Symbol map to DCM state: γ↔per-face cortex tension; nodes↔bundle endpoints; ℓ_ref↔mesh edge; ε̇↔face in-plane strain rate; the "motor" is not meshed — only its two emergent rates (v_walk, γ_plateau) enter.

### E2 — Buckling criterion (dimensionless, grid-invariant)
From M2, a DCM cortex wrinkles locally when the compressive surface strain rate exceeds the motor take-up rate:

    |ε̇_compress| > v_walk / ℓ_ref     ⇒  cortex cannot stay taut → wrinkle/bleb-prone

This is a pure rate comparison (units s⁻¹ vs s⁻¹), no fitted constant — it reuses v_walk from E1.

### E3 — (Reference only, DO NOT port to DCM) the agent-level laws
Bell ACP off-rate `k_u = k⁰_u·exp(x_u|F|/k_BT)` (Eq. S8), overdamped Langevin (Eq. S1), cylinder drag (Eq. S3), harmonic bend/stretch (Eqs. S5/S6), curvature `κ=|r′×r″|/|r′|³` (Eq. 1). These belong to **FF**. DCM's only contact with them is that E1's v_walk and γ_plateau are the *coarse-grained outputs* of these laws — if DCM ever wants to *derive* (not assume) v_walk and γ_plateau, run the FF port of this paper and read them off.

## 4. Geometry / protocol to reproduce as a DCM scenario

The paper's isolated-SF micromanipulation is a **1D contractile-unit** protocol; the DCM analog is a **whole-cell fast-vs-slow deformation** test of the cortex γ(t) law:

- **P1 — Rate-dependent aspiration/compression of a single cell.** Take the native full-compartment MCF7 cell (`--from-resting`), impose a compressive surface strain to a fixed final shape at two rates (slow ε̇ ≪ v_walk/ℓ_ref, fast ε̇ ≫ threshold). Prediction from M1/M2: slow → cortex stays smooth, γ tracks quasi-statically; fast → transient cortex wrinkling then straightening over τ_rec = ℓ_ref/v_walk. This is the DCM reproduction of Fig. 1C/D + Fig. 4.
- **P2 — Stretch-hold-release tension relaxation.** Stretch the cell (or a cortex patch), hold, and measure cortical tension γ(t): expect a peak then relaxation to < half (Fig. 2C), then recovery on release — the DCM signature that the active-tension law is mechano-adaptive, not a spring-dashpot.
- **P3 — Confinement/bleb regime.** Apply cell-sized confinement at varying approach rate; use E2 to predict the confinement rate above which the cortex blebs. Ties into DCM's open confinement + bleb problems.
- **Protocol constants worth mirroring:** compression to a fixed final strain (paper compresses ε=0.5→0 in 2 s at ε̇_c=−0.25 s⁻¹); recovery-complete criterion L_B−L_ee<0.01 µm → DCM analog: cortex tautness s_f→1 within tolerance.

*(The paper's box is 20×20×5 µm with anti-parallel filaments — not a DCM geometry. Do not copy the box; copy the loading protocol.)*

## 5. Validation targets for DCM observables

These are the numbers a DCM run *of the ported γ(t) law* should reproduce qualitatively (the paper is a different cell type, so match trends/scalings, not absolute nN — see Risks):

| DCM observable | target behavior | source |
|---|---|---|
| Cortex tension after fast stretch | relaxes to **< half** of peak before deformation ends | Fig. 2C |
| Tension recovery rate vs motor speed | recovery time t_r drops **~32→12→4.5 s** as v_walk (k₂₀) 4→8→16; shortening rate |dL/dt| **0.07→0.17→0.53 µm/s** | Fig. 5B/C |
| Tension recovery rate vs motor **density** | t_r ≈ **constant (~12 s)** across 5× density change | Fig. 5D/E — *density must NOT set recovery rate* |
| Steady-state γ vs density | γ_plateau **∝ density** (F_B,ss 0.3→1.62 nN linear) | Fig. 5F |
| Buckling onset | **no wrinkling** at ε̇=0.01 s⁻¹; wrinkling grows with rate 0.05→0.5 | Fig. 4B/C, S5 |
| Buckling severity vs cortex bending stiffness | stiffer cortex → **gentler** wrinkles (curvature 0.26→0.063 µm⁻¹ over 1→100× κ_b) but recovery time **~unchanged** (14→11 s) | Fig. 3B/D — *stiffness sets shape, not recovery time* |
| Recovery independent of bending stiffness | ΔL recovered ≈ constant (1.85–1.95 µm) across 100× κ_b | Fig. 3C |

The two "*must NOT*" targets (recovery-rate independent of density; recovery-time independent of bending stiffness) are the sharp falsification tests for the ported law — if a DCM γ(t) makes recovery depend on density, the port is wrong.

## 6. Risks / caveats

- **Cell-type & preparation mismatch (major).** The experiment is an *isolated, de-roofed* ventral stress fiber from **A7r5 bovine aortic smooth muscle** — membrane, cytosol, nucleus, and all turnover removed. DCM targets a *living MCF7 epithelial cell* with intact compartments and turnover. Absolute forces (nN-scale SF tension) and the 56 nm/s isolated-SF motor speed are **not** transferable as DCM numbers. Adapt by taking only the *functional form* and the *in-cell* motor speed (~200 nm/s, ref [58]) as the physiological baseline — never the isolated-SF value, and never fit DCM γ to the paper's nN forces.
- **Single stress fiber ≠ whole cortex.** The paper models ONE contractile bundle; the DCM cortex is a 2D isotropic actomyosin *shell*. The decoupling (density↔plateau, speed↔rate) is expected to survive coarse-graining but is unproven at shell scale — treat E1 as a **hypothesis to validate on the native full cell (P2)**, not an established constitutive law. Flag it non-authoritative until reproduced on `--cortex-fil 38000 --from-resting --microtubules`.
- **Deliberate 10× stiffness inflation.** The paper's *reference* sims use κ_b,A = 10× the experimental actin value ("to get a clear buckling pattern," p14). If DCM ever consumes a bending number from this paper, use κ*_b,A = 2.64×10⁻¹⁹ N·m (L_p=9 µm), NOT the 10× reference. (This is an FF concern; noted so it is not accidentally KB-registered as physiological.)
- **Preprint, not peer-reviewed** (bioRxiv, posted 2025-07). Motor v_walk and F_s carry provenance to Kim's prior network papers ([43]–[48]) and Milo/Phillips ([58]); the *isolated-SF* observables are new and unreviewed. Cite v_walk in-cell ~200 nm/s to ref [58] (Milo/Phillips BioNumbers), not to this preprint's 56 nm/s model output.
- **No magic-number leak.** E1/E2 introduce v_walk and γ_plateau, both derivable from measurable molecular quantities (in-cell myosin speed; myosin surface density × per-motor stall). ℓ_ref is the mesh edge (grid-defined), so the rate law is grid-invariant. No constant is tuned to pass a gate — keep it that way when implementing.
- **Routing:** the bulk of this paper (explicit filaments, ACP Bell kinetics, PCM catch-bond motors, cylinder drag, buckling curvature) is **FF's** parameter set + validation battery, not DCM's. DCM should take only the coarse-grained active-tension decomposition (M1–M3, E1–E2) and let FF own the agent-level port.
