# FF lens — p20

**Paper:** Miyazaki, Yamazaki, Hasegawa, "Analysis of Brownian Motion by Elementary School Students," *Phys. Teach.* 60, 478–483 (2022). DOI 10.1119/5.0059810.

**Verdict up front:** This is a K‑12 physics‑education / outreach article (a 3‑hour Zoom workshop teaching grades 4–6 to track 1‑µm beads in water and play a dice random‑walk game). It contains **no actin‑network model, no crosslinker kinetics, no myosin force–velocity law, no reconstitution assay, and no cytoskeletal parameter**. There is nothing mechanistic to port into FF. Relevance to the Filament‑FEM engine is effectively **zero**; the sections below record the single canonical textbook relation it states and why it is not usable as an FF advance, so the negative result is documented rather than re‑litigated.

---

## 1. MECHANISMS to adopt
**None.** The paper adds no cytoskeletal mechanism. Molecular motors (kinesin, myosin V) appear only as qualitative lecture cartoons ("protein robots that rectify thermal collisions using ATP") — no duty ratio, no step size, no stall force, no force–velocity curve. There is no filament, crosslinker, formin, Arp2/3, or clutch content. Nothing beats or replaces any current FF mechanism.

## 2. FORCE LAWS / KINETIC SCHEMES to port
**None portable.** The only equations in the paper are the canonical isotropic 2D Einstein diffusion relations (p.480):

- Eq. 1:  ⟨[x(t)−x(0)]² + [y(t)−y(0)]²⟩ = 4·D·t
- Eq. 2:  √⟨…⟩ ∝ t^(1/2)

These are the textbook Brownian baseline, not a new force law or bond‑kinetic scheme. FF's constrained Leimkuhler–Matthews BAOAB thermostat already must satisfy MSD = 2·n·D·t (n = spatial dims) by construction — this is a *pre‑existing invariant the integrator obeys*, not a mechanism to add. No Bell/Evans off‑rate, no Hill force–velocity, no branching‑angle distribution, no unbinding spectrum is given. Symbol map is trivial and adds nothing: x,y → FF bead positions; D → free‑particle diffusion set by drag γ and kT (D = kT/γ), which FF already fixes from the physiological cytoplasm viscosity η ≈ 65 Pa·s.

## 3. PARAMETERS / RATE CONSTANTS to set
**None.** D is *never numerically evaluated* in the paper (kept qualitative for children). Every number in the paper is either an apparatus/protocol setting (1 µm bead, 100× objective, 25 fps, Δt = 0.20 s, 20 s window, 6‑sided die, A4 sheet) or a survey/pedagogy outcome (interest 4.69/5, difficulty 3.27/5, n=26). None supersedes any FF config value (k_off0, F_b, stall force, step size, duty ratio, ℓ_p, link stiffness, nucleation rate). There is no MCF7/cytoskeletal datum.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce
**None applicable.** The "assays" are (a) hand‑clicking free 1‑µm plastic spheres diffusing in bulk water, and (b) a paper‑and‑dice hexagonal random walk. Neither is a cytoskeletal reconstitution, motility assay, confinement, or connectivity geometry. Not usable as an FF scenario. (At most, the free‑bead‑in‑water assay is the same idea as a thermostat unit test — see §5 — but the paper supplies no quantitative target for it.)

## 5. VALIDATION TARGETS for FF observables
**None quantitative.** The paper reports only hand‑read, low‑precision figure values (√MSD ≈ 6–7 µm at 20 s for a 1‑µm bead in water; dice √MSD ≈ 4.5 cm at N=50) with no stated D, no error model, and manual‑clicking noise. These are not FF observables (no G'(ω)/G''(ω), no stress‑relaxation time, no contraction rate, no network tension, no motor velocity‑vs‑load, no buckling threshold, no mesh size, no exponent beyond the trivial ½ diffusive slope).

The one *conceptual* checkpoint worth noting for FF hygiene (not sourced numerically from this paper): a free FF bead with drag γ at temperature T must reproduce MSD = 2·n·(kT/γ)·t. FF already enforces this via BAOAB; if a dedicated regression test does not exist, adding a free‑particle MSD‑slope check against kT/γ is cheap and standard — but the reference for that is Berg *Random Walks in Biology* (ref 1 here) or the BAOAB integrator literature, **not** this outreach article, which would not be KB‑registered as a mechanistic source.

## 6. RISKS / caveats
- **Category mismatch (fatal):** purified free beads in bulk water vs. a living, crosslinked, active MCF7 cortex — no shared regime. Diffusion here is passive/free; FF's open problems (γ generation, network contraction, turnover, crawl drag) are active/constrained. The paper's √t law says nothing about any of them.
- **Do NOT KB‑register.** Per the citation‑integrity rule, this paper carries no mechanistic parameter and no cell‑mechanobiology datum; registering it would be over‑declaration. If FF ever needs an Einstein‑diffusion citation for a thermostat test, cite Berg 1983 (this paper's ref 1) or the primary Langevin/BAOAB sources instead.
- **No physiological‑baseline or native‑scale conflict** arises because there is simply nothing to adopt.
