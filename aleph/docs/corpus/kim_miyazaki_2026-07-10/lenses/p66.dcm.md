# DCM lens — p66

**Paper:** Hassan, Biel, Umulis, Kim (2019) "Interplay Between the Persistent Random Walk and the Contact Inhibition of Locomotion Leads to Collective Cell Behaviors." *Bull. Math. Biol.* 81:3301–3321. DOI 10.1007/s11538-019-00585-1.

**One-line verdict for DCM:** This is a 2-point agent "machine" on a *rigid 2D substrate* — NOT a deformable surface-mesh cell. It imports **zero** surface-mesh/continuum physics into DCM. Its value is (a) one conceptual reframe that lines up with our existing "cell–cell contact = ONE junction ≈ effective viscous friction" note, and (b) a set of **behavioral validation targets** for any future DCM aggregate/monolayer migration scenario. There are **no equations to port to the mesh level** and **no transferable parameters** (the numeric table, Online Table 1, is in the ESM and not in this PDF). Score kept low deliberately; recorded so we don't re-mine it.

---

## 1. MECHANISMS to adopt

Honest triage — most of the paper's machinery is a lumped 2-point construct that *violates* our fine-grained rule (constant-torque propulsion, instantaneous FA, no cortex/membrane/nucleus). Only two items survive as usable, and both are conceptual, not code-drops.

- **(WEAK, conceptual) Cell–cell contact as effective viscous friction, not repulsion/adhesion.**
  DCM module: `dcm/` cell–cell junction interface. The paper's *only* cell–cell coupling is a pairwise viscous-drag term `−Σ_J β(v_I − v_J)` within a cutoff `r_crit` (Eq. 2, term 3) — no repulsion, no elastic collision, no momentum transfer. In the Discussion (p.19) the authors explicitly speculate that **cadherin adhesion in a confluent layer acts mainly as an effective inter-cell friction**, matching our project note `feedback-cell-cell-contact-junction-mediated` (contact/adhesion/interfacial-tension = ONE junction). **WHY it beats nothing / where it helps:** it is external corroboration that a *velocity-difference drag* on the cadherin junction is physically defensible as the low-frequency limit of many transient bonds. It is NOT a replacement for our Rakshit catch-bond cluster — our mechanistic junction is strictly higher fidelity and the hard rule says keep the fine-grained option. Use only to justify the emergent friction the cadherin cluster already produces, never to swap it for a lumped `β`.

- **(WEAK, conceptual) CIL as competition/partitioning of shared adhesion sites, not as collision.**
  DCM relevance: aggregate compaction / monolayer ordering scenarios. CIL here emerges purely because each substrate point is assigned to a *single nearest* cell-point, so two approaching cells starve each other of traction and stall (p.10, p.17). **WHY / where it helps:** offers a substrate-mediated route to contact-driven redirection *without* an explicit repulsion force — conceptually adjacent to DCM's node-face penalty + cadherin junction handling contact. But our DCM cells sit on a deformable ECM/each other in 3D with real excluded volume (node-face Ericson + IPC), so we already have the stronger mechanism. Take-away: do **not** add a phenomenological CIL rule to DCM; if CIL-like behavior is wanted it should emerge from the existing contact + junction physics.

- **(REJECT for DCM) Constant-torque, non-centripetal traction propulsion (Eqs. 1, 4).** This is a lumped Lagrange-multiplier propulsion with a *fixed generated torque M* and *instantaneous FA maturation* — exactly the abstracted style the hard rule forbids. DCM traction, if/when added, must come from the FF-style mechanistic clutch/myosin, not this.

- **(REJECT) Instantaneous FA + FA-only-under-lamellipodium.** Paper itself lists force-dependent FA maturation as a *limitation* (p.18). We already model FA maturation mechanistically. Nothing to import.

## 2. EQUATIONS to port to the surface-mesh / continuum level

**None are portable to the DCM surface mesh.** The governing equations are point-particle force/torque balances on a rigid substrate, not surface-continuum PDEs. For completeness, the only term with any conceptual mapping:

- **Eq. 2, term 3 — inter-cell viscous drag:** `F_drag,IJ = −Σ_J β (v_I − v_J)` for cell-points J within `r_crit`.
  - Symbol map to DCM: `v_I, v_J` → velocities of nodes on two *different* cells that are within contact range across a cadherin junction; `β` → an effective inter-cell friction coefficient [force·time/length]; `r_crit` → junction interaction cutoff.
  - **Do not implement as a new lumped force.** In DCM this drag is *emergent* from the load-sharing cadherin catch-bond cluster (bonds form/break with relative sliding). The equation is only a sanity check: in the many-bond fast-turnover limit, the cluster's net tangential resistance should reduce to ≈ `β·Δv`. If we ever want to *report* an effective `β` for the junction, compute it from the cluster, don't set it.
- Eqs. 1 (torque balance), 3 (front–rear Hookean spring), 4 (kinematic constraint), 5 (`Ku=f`) — all specific to the 2-point machine; no DCM analogue.
- Eqs. 6–9 (MSD, log-slope `s = d ln MSD / d ln τ`, nematic Q-tensor, Saupe order parameter `h`) — these are **analysis observables, not physics**, and *are* directly reusable as DCM post-processing on cell centroid tracks (see §5).

## 4. GEOMETRY / PROTOCOL to reproduce

The migration assay is 2D-on-rigid-substrate and does not map to our 3D deformable-cell scenarios (aspiration, AFM, confinement, division). One protocol is *conceptually* reusable if DCM ever runs a monolayer:

- **Density-sweep monolayer / jamming assay.** Seed N deformable cells at a controlled areal density on a flat substrate, sweep density from dilute to confluent, and measure the PRW→jammed transition. In our units MCF7 R≈7.5 µm ⇒ single-cell footprint ~1.8×10⁴ µm² ⇒ the paper's ~2300 cells/mm² critical density corresponds to ~40 cells packed per mm² of nucleus-equivalent... i.e. near-confluent monolayer. This is a *future* DCM scenario, not a current one, and would need real cell–substrate FA physics we don't yet run at monolayer scale.
- **Not usable:** the 2-point machine geometry, the triangle-lattice rigid substrate, the partial-donut adhesion regions — all are artifacts of the abstraction.

## 6. RISKS / caveats

- **Wrong model class.** 2-point rigid-substrate machine, not a deformable closed-surface mesh. No membrane K_A, no cortex γ, no cytoplasm η/Π₀, no nucleus, no volume constraint appear anywhere. Any attempt to "port physics" would import an abstraction that violates the fine-grained hard rule.
- **Wrong cell type.** Fibroblast-like *mesenchymal, cadherin-free* migration (stated p.16, p.19). Our target is MCF7 (epithelial, cadherin-cohesive). The paper's whole CIL story is *substrate competition with no cadherin*; our aggregate compaction is *cadherin-junction mediated*. So its "CIL without adhesion" is the opposite regime from ours — useful as contrast, dangerous as a template.
- **2D, not 3D.** All densities, jamming, and nematic results are 2D monolayer. Our aggregate is a 3D N≈400 spheroid. The ~2300 cells/mm² transition does not translate to a 3D volumetric compaction threshold.
- **Lumped propulsion + instantaneous FA** violate the physiological-baseline & fine-grained rules; must never be adopted as DCM mechanism. FA maturation and force-dependent adhesion (which we model) are explicitly *absent* here (authors flag as limitations).
- **No parameters in-file.** Online Table 1 (ESM) missing ⇒ nothing KB-registerable except the behavioral targets in §5 and the clean author/DOI for citation integrity. Do not KB-register any physical constant from this paper.
- **How to use without violating baseline:** treat §5 numbers as *overlay comparison targets* for emergent DCM/FF migration behavior only; keep the mechanistic cadherin catch-bond cluster as-is and merely *note* that its low-frequency limit is consistent with the paper's effective-friction view. Do not add any phenomenological CIL/repulsion/torque term.
