# TAG-validation lens — p43

**Paper:** Kim, Hwang, Lee, Kamm (2009) "Computational Analysis of Viscoelastic Properties of Crosslinked Actin Networks," *PLoS Comput Biol* 5(7):e1000439. DOI 10.1371/journal.pcbi.1000439.

## Paper kind

**simulation** (primary) — a 3-D Brownian-dynamics / overdamped-Langevin agent-based model of a crosslinked semiflexible actin network (explicit filament segments + explicit two-armed crosslinkers + steric repulsion), with **one supporting in-vitro bulk-rheometer experiment** (filamin-A + gelsolin, AR-G2, 0.1–10 Hz). Most numbers are **model output → comparison-only, never a truth source**. The exceptions worth separating:
- The **in-vitro G′,G″(f) curve** (Fig 2, 1–10 Hz) is the only *experimental* datum → OVERLAY / cross-check target, never fit.
- The **crosslink-free high-frequency exponent G′∝f^0.75** is not just a sim output — it is the well-known **analytic** semiflexible-polymer signature (Gittes/MacKintosh transverse-undulation high-ω modulus ∝ ω^{3/4}). The paper *recovers* it; the exponent itself is an **analytic oracle candidate**.
- Prestress-stiffening exponent (G′∝τ₀^0.85), the "supportive framework" 25%→70% result, the three-regime decomposition, and all magnitude numbers are **simulation-grade, comparison-only** (and several rest on a deliberately unphysical ÷40 stiffness — see caveats).

This is the archetypal **FF-engine** physics (Kim-lab BD, the methodological ancestor of Cytosim-style actomyosin BD). It maps to FF, not DCM. DCM relevance is indirect (a material-law sanity target only).

## Coverage vs existing gates

- **No existing gate covers actin/crosslinked-network shear rheology (G′,G″ vs frequency, prestress stiffening, or the ω^{3/4} exponent).** The closest gates are ECM-network mechanics, not intracellular actin-cortex rheology:
  - `VG-U1-G0-linear` (G0 ~30–100 Pa, collagen ECM slab) — different material (collagen Mikado, not F-actin/ACP), a static shear modulus not a frequency-resolved G′(f). **Not covered / not a duplicate.**
  - `VG-U1-strain-stiffening` (exponent magnitude 1.5–2.5, collagen) — this is *strain*-stiffening of the ECM network vs applied shear strain; the paper's item 7 is *prestress*-stiffening of the *actin* network (G′∝τ₀^0.85). Related in spirit, **different observable + different material** → not the same gate.
  - `VG-U3-cortex-multifilament` (Phase-2 entry gate: N≥50 filaments, Bell-Evans crosslink dynamics, Q_ij measurable) — this is the FF cortex reconstruction the paper's physics belongs under, but it gates *topology/构造*, not a rheology band. The p43 rheology targets would be **new downstream gates on that contract**.
  - `VG-H3-*` / `VG-H10-cytoplasm` (whole-cell γ_total 0.35–0.65 mN/m; cytoplasm G 30–80 Pa) — whole-cell / cytoplasm scales, not a reconstituted crosslinked-actin network. `VG-H10` cytoplasm G 30–80 Pa is in the same ballpark as item 4 magnitudes but is a *different system* (crowded cytoplasm poroelasticity, not a pure F-actin+ACP gel) → overlay context only, **not a match**.
- **Verdict:** the paper opens a genuinely uncovered validation surface for the **FF engine's actin-network rheology**, but every band except item 1 (analytic) and item 4 (in-vitro) is simulation-grade and cannot become a contract band on its own.

## New gate candidates *(all "candidate, PI-gate review" — new gates are PI-authored)*

1. **`VG-FF-semiflex-omega34` (analytic oracle cross-check)** — engine **FF (oracle)**.
   - Observable: high-frequency shear-modulus power-law exponent of a **crosslink-free** semiflexible F-actin network.
   - Band/value: **exponent = 0.75 ± ~0.1** (G′,|G*| ∝ f^{3/4}), in the transverse-undulation regime, at physiological l_p (~10–20 µm) and no ACP.
   - Rationale: this is the analytic Gittes–MacKintosh ω^{3/4} law (ground truth), not a fit — the strongest, most defensible candidate. FF should reproduce it as an acceptance oracle. Source: Fig 3A/4A; "no-ACP slope 0.75" (dossier Quantitative Results, p3).
   - Caveat to flag: exponent softens toward 1.0 if steric repulsion is disabled (item 2) — so the gate must run with EV **on** (consistent with the ffn LJ-repulsive hard rule).

2. **`VG-FF-actin-network-modulus` (experimental overlay)** — engine **FF**.
   - Observable: G′,G″ vs frequency of a reconstituted crosslinked F-actin gel.
   - Band/value: **G′,G″ ≈ 0.1–10 Pa across 1–10 Hz**, at ⟨L_f⟩≈1.5 µm, C_A=12.1 µM, R≈0.01 (filamin-A/gelsolin).
   - Rationale: the paper's single *experimental* curve (Fig 2). **OVERLAY-ONLY, never fit** — matches the philosophy for in-vitro reconstitution values. Cross-check target if FF ever runs bulk oscillatory shear on a reconstituted network.
   - Caveat: narrow 1–10 Hz overlap window; permanent-crosslink model over-predicts above ~1–30 Pa (item 11).

3. **`VG-FF-prestress-stiffening` (simulation comparison — LOW priority, flag)** — engine **FF**.
   - Observable: differential G′ vs prestress τ₀; onset threshold + power-law exponent.
   - Value: threshold **τ₀ ≈ 0.1 Pa**, then **G′∝τ₀^0.85** (item 6/7).
   - Rationale/caveat: **simulation-derived, comparison-only.** The exponent depends on the (÷40, unphysical) k_s,A and drops to ~0.7 when k_s,A is softened — so 0.85 is NOT a defensible contract band. The *in-vitro* Gardel-2006 reference exponent is **~1.0**, which would be the real overlay target if a gate is authored. Stage only as a qualitative "prestress makes the network stiffen with exponent ~0.7–1, onset ~O(0.1 Pa)" cross-check. **PI must decide the band from the experimental reference, not from this sim.**

*(Not proposed as gates: the "supportive framework" 25%→70% result and the three-regime decomposition are mechanistically important but are structural/interpretive findings, not measurable single-cell observables with a defensible band — keep as design guidance for FF, not contracts.)*

## Param candidates

Flag hard: the paper **deliberately scales actin & ACP stretch stiffness to 1/40 of the real value for compute efficiency** — do NOT register the *used* values as physiological.

1. **Actin filament extensional stiffness `k_s,A`** — used value 1.69×10⁻² N/m is **1/40 of experimental**; the implied physiological value is **≈0.68 N/m** per 70 nm segment. Register only *with* the ÷40 caveat and the segment length; do not enter 1.69e-2 as the actin stretch modulus. Provenance: dossier Parameter Table / Force Laws.
2. **Actin bending stiffness `k_b,A` = 1.056×10⁻¹⁸ N·m → l_p ≈ 10–20 µm** (T=300 K). This is a physiological, non-scaled value and a clean **actin persistence-length** anchor. Note: existing `PARAM-ell_p` (17 µm, default) is the **collagen** persistence length (KU-1.1) — a *different molecule* that happens to sit at a similar number; do NOT conflate. Candidate new param `PARAM-ellp_actin` / `PARAM-kb_actin` for the FF cortex, condition = F-actin, 300 K.
3. **Crosslink spacing `l_c` = 0.393 µm at R=C_ACP/C_A=0.021** — a derived network-geometry datum useful as an FF cortex crosslinker-density sanity check (compare to KB-3.19 crosslinker spacing). Candidate, low weight.

*Not registering:* ACP stiffnesses (k_s,ACP=k_s,A/40; k_b,ACP,1/2) — explicitly *estimated* and efficiency-scaled, not measured (the real ffn crosslinker stiffness is sourced from Ferrer 2008 per project memory, which supersedes these). Coarse-graining N_C=10, box 2.8 µm, Δt=6.17e-9 s are numerical, not biological.

## Oracle candidates

1. **Semiflexible high-frequency modulus law `G*(ω) ∝ ω^{3/4}`** (Gittes–MacKintosh) — genuine closed-form analytic ground truth the crosslink-free FF network must reproduce. Directly implementable as an FF oracle cross-check (this is item 1 / candidate gate 1). **Strongest oracle contribution of the paper.**
2. **Modified Mason microrheology GSER (Eq 11):** |G*(ω)| ≈ k_BT / [π r_b ⟨Δr²(1/ω)⟩ Γ(1+χ(ω))], with χ(ω)=d ln⟨Δr²⟩/d ln t and r_b the effective cylinder radius (ζ_⊥=6πη r_b). This is a **measurement-protocol converter** (segment-MSD → G*), not a truth oracle — but worth implementing as the FF "segment-tracking rheology" readout so an FF network can be probed the way Fig 2/3 are. Method candidate.
3. **Young-Laplace / Helfrich / Bell-Evans / Hill / Kelvin-Voigt** already in the oracle set — none are added or challenged by this paper (it is a passive network, no motors, no membrane).
