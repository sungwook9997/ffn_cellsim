# DCM lens — p49

**Paper:** Yamaguchi et al. 2025, *Kinetic Scheme of Myosin Phosphorylation by ZIP Kinase*, Biochemistry 64:4805–4817, DOI 10.1021/acs.biochem.5c00495.

**One-line verdict for DCM:** This is an in-vitro enzyme-kinetics paper with **no mechanics, no geometry, no force law, no continuum/surface content**. It supplies the *upstream activation switch* for myosin II (mono-/di-phosphorylation of the regulatory light chain, MRLC/LC20), which is the biochemical layer that sets *how much* active motor exists to generate cortical tension γ. For DCM — whose γ is a lumped surface tension (pressure-borne γ=ΔP·R/2) — the only genuinely applicable use is as a **physiological time-constant + activation-fraction source for a myosin-activation modulator that scales γ**, not as a physics module. Relevance is therefore **low (1/5)**: nothing here changes the surface-mesh continuum, but it does give clean, DOI-verified numbers for the *rate* at which active myosin (and hence γ) can turn on, which bears on the γ-generation open problem and on any DCM scenario where γ is ramped (mitotic entry, cortex activation).

---

## 1. MECHANISMS to adopt

Honest scope: there is **no fine-grained mechanical mechanism** here to port — no motor stall, no catch-bond, no crosslink, no bending, no advection. What the paper offers DCM is a single, optional refinement:

**M1 — Cortex tension γ: replace an instantaneous γ set-point with a first-order myosin-activation ramp (activation-fraction gate on γ).**
- DCM now: γ is imposed as a static value (interphase ≈0.15 mN/m, mitotic ≈1.5 mN/m) or derived pressure-borne γ=ΔP·R/2. Transitions between states (e.g. interphase→mitotic cortex stiffening, or "add myosin as a modulator" per the physiological-baseline rule) are effectively step changes.
- Refinement: gate γ by an **active-myosin fraction** φ_act ∈ [0,1] that itself relaxes toward its set-point on the *biochemically correct timescale* set by this paper's kcat. i.e. γ(t) = γ_passive + (γ_max − γ_passive)·φ_act(t), with φ_act evolving by the di-phosphorylation kinetics below (Eqs 1–2). At steady state φ_act→1 and γ recovers the current value, so this is **back-compatible and does not touch the equilibrium γ** — it only supplies the *transient*.
- Why it beats DCM-now: DCM currently has **no principled rate** for cortical-tension onset; a myosin ramp is either instantaneous (unphysical) or hand-tuned (magic number). This paper hands us a derived, literature-anchored relaxation time (τ ≈ 1/kcat ≈ 1.7–2.5 s at saturating substrate) so the γ-ramp constant stops being a free knob. This directly serves the *γ-generation* open problem framing: it separates "how much tension" (magnitude, unresolved elsewhere) from "how fast it can appear" (this paper).
- **This is optional and does NOT resolve the γ magnitude floor** — see §6. It should be treated as an activation-kinetics decoration on γ, not a fix for the γ-floor deficit.

**M2 — (weaker) Two-site sequential activation, if DCM ever tracks a graded activation state.**
Myosin is activated sequentially: Ser19 first (0P→1P), then Thr18 (1P→2P). Mono-phospho (1P) already partly activates; di-phospho (2P) is fully active and promotes filament assembly. If DCM's φ_act is ever made two-level (partial vs full activation → two γ contributions), the sequential scheme and its 35:1 Ser19-first bias give the correct ordering. For a single lumped σ this is over-modeling; flag as future only.

No other DCM module (membrane K_A, bending κ_m, cytoplasm η, turgor Π, nucleus, node-face contact, cadherin junction, T1/compaction) is touched by this paper.

## 2. EQUATIONS to port

Only the activation kinetics are portable, and only into a scalar activation-fraction ODE that multiplies γ. Nothing ports to the mesh geometry.

**Sequential Michaelis–Menten (paper Eqs 1–2), reduced to a DCM activation-fraction ODE.**
Paper form (bulk, well-mixed initial rates):

- Eq 1:  V^{0P→1P} = kcat^{S19} · [ZIPK_tot]·[0P] / (Km^{S19} + [0P])
- Eq 2:  V^{1P→2P} = kcat^{T18} · [ZIPK_tot]·[1P] / (Km^{T18} + [1P])

Symbol map to DCM state:
- [0P], [1P], [2P] → fractions f0, f1, f2 of cortical myosin light chains in each phospho-state, with f0+f1+f2=1 (a **per-cell scalar**, or optionally a per-node field co-located with the cortex on each mesh node/face). These are *not* new particles — the DCM cortex is a continuum, so this is a scalar auxiliary field, not a fine-grained species.
- kcat^{S19}, kcat^{T18} → catalytic rate constants (s⁻¹), values in §3.
- Km → substrate half-saturation (µM); in a living cortex the light-chain concentration is high relative to Km (see §6), so the MM terms **saturate** and each step collapses to a pseudo-first-order rate k_eff ≈ kcat^{S19}·(kinase fraction). This is the regime DCM should use: **activation is zeroth/first-order with rate ~kcat, not concentration-limited.**

DCM ODE (dimensionless, drives φ_act):
```
df1/dt =  k_S19·f0  −  k_T18·f1
df2/dt =  k_T18·f1
φ_act  =  w1·f1 + f2        # w1∈[0,1]: partial activation weight of mono-phospho; use w1≈0.5 or 0 (fully-di-phospho-gated) — flag as PI choice, not tuned
γ(t)   =  γ_passive + (γ_max − γ_passive)·φ_act(t)
```
with k_S19 = kcat^{S19}, k_T18 = kcat^{T18} = k_S19/1.5. This is a linear 2-state relaxation; its slow eigenvalue sets the γ-ramp time. **De-activation** (phosphatase MYPT1/PP1c) is not measured here — for a reversible ramp DCM must supply an off-rate from another source (paper only cites Km(ZIPK–MYPT1)≈2 µM as context); until then treat γ ramp-down as an unmeasured input, do not invent a rate (§6).

**Competitive-sequestration term (paper Eqs 4–5): DO NOT port.** The (Km/KI)[MHC] denominator term describes ZIPK being sequestered by the myosin heavy chain in vitro (KI=0.30 µM). It reproduces why *purified smooth-muscle myosin* phosphorylates slowly. It is an in-vitro artifact of free-kinase partitioning and has no counterpart in the DCM continuum cortex; porting it would be adding a lumped biochemical proxy with no mesh meaning — violates the fine-grained-mechanistic principle for no benefit.

**Eq 3 (cosedimentation binding isotherm):** binding-assay data reduction only; not portable.

## 4. GEOMETRY / PROTOCOL to reproduce

**None.** The paper is bulk well-mixed solution biochemistry — no cell, no confinement, no aspiration, no AFM, no division, no aggregate, no substrate, no geometry of any kind. There is nothing here to set up as a DCM scenario.

The only "protocol" is a time-course fit (fraction 0P/1P/2P vs t under fixed kinase), which is reproduced by integrating the §2 ODE — a unit test of the activation-fraction field, not a mechanical DCM scenario. If DCM adds M1, a sensible *DCM-side* scenario is: a resting native full-compartment cell (R=7.5 µm, `--from-resting`), at t=0 switch cortex from passive to active and drive γ up via the φ_act(t) ramp with τ≈2.5 s; observe cortical-tension onset and shape response over ~5–10 s. That scenario is DCM's own; this paper only supplies the ramp constant.

## 5. VALIDATION TARGETS for DCM observables

This paper provides **no mechanical DCM observable** (no tension in N/m, no shape index, no division force, no ring-closure time, no compaction, no contact angle, no flow speed). Its measured numbers validate the *activation-kinetics auxiliary field only*, not any surface-mesh mechanics:

| observable | value | what a DCM run/unit-test should reproduce |
|---|---|---|
| kcat^{S19} / kcat^{T18} | 0.60 / 0.40 s⁻¹ | φ_act ODE eigen-timescale ≈ 1.7 / 2.5 s |
| Ser19:Thr18 mono-phospho order | ~35:1 (sequential) | f1 populated via Ser19 first (ordering, if two-site) |
| 1P fraction @10 min (2 µM MRLC, 5 nM ZIPK) | 34.3 ± 9.3 % | ODE integration of Eqs 1–2 with Table-1 constants |
| 2P fraction @10 min | 3.7 ± 3.2 % | same |
| linear initial-rate regime | R²>0.99 over 0–15 min | justifies pseudo-first-order approximation |
| activation timescale | seconds (order 1–3 s) | γ-ramp reaches steady state in ~5–10 s, NOT instantly and NOT minutes |

**The single DCM-relevant assertion:** cortical myosin activation is a **seconds-scale** process. Any DCM γ-ramp faster than ~1 s or slower than ~10 s (at saturating substrate) would be inconsistent with these kinetics. That is the one falsifiable check this paper buys us. It does **not** validate γ magnitude, cortex mechanics, or any shape observable.

## 6. RISKS / caveats

- **Different system entirely — in-vitro purified enzyme vs living MCF7 cortex.** All constants are from purified human ZIPK/DAPK3 on purified human MRLC (and chicken gizzard smooth-muscle myosin) in A50 buffer at 25 °C. MCF7 cortex is activated predominantly by **MLCK and ROCK**, with ZIPK one of several kinases; the in-vivo activation rate is a convolution of kinase abundances, localization, and phosphatase (MYPT1/PP1) activity, none measured here. So k=0.60/0.40 s⁻¹ is an **order-of-magnitude timescale (seconds), not a quantitative MCF7 rate.** Adapt by using it only to set the *order* of τ_activate and running a sensitivity sweep across the FL↔ΔC range (0.40–0.95 s⁻¹); do not register a single MCF7 γ-ramp rate as if measured in our cell.
- **Temperature.** 25 °C. MCF7 physiology is 37 °C; kcat roughly doubles per +10 °C (Q10≈2–3), so in-vivo τ_activate is plausibly ~2–4× faster (~sub-second to ~1 s). Physiological-baseline rule says init at the in-vivo operating point — so if M1 is adopted, **flag that 25 °C rates are a lower bound on rate / upper bound on τ** and either apply a documented Q10 correction or surface to PI, rather than silently using the 25 °C number as physiological.
- **Smooth-muscle myosin, not non-muscle myosin IIA/B.** The slow-SMM result and the KI=0.30 µM competitive term are specific to the 10S-folded smooth/non-muscle regulation and purified-protein partitioning. In the DCM continuum cortex there is no free-kinase pool to sequester; **the Model-2 competitive machinery must not be imported** — it would be a lumped in-vitro proxy with no mesh counterpart (fine-grained-mechanistic violation for zero gain).
- **No magnitude, no mechanics.** This paper cannot help the γ-magnitude floor, the loose→compact aggregate-compaction RATE problem (that needs cadherin T1 rearrangement, unrelated), division, confinement, durotaxis, or blebbing. It is strictly an *activation-onset-timescale* input. Do not overstate.
- **No reverse rate.** Phosphatase de-activation is unmeasured (only Km(ZIPK–MYPT1)≈2 µM cited as context). A DCM reversible γ-ramp needs an off-rate from elsewhere; do not invent one from this paper (would be a magic number).
- **Adoption gate:** M1 is a *decoration*, not a required fix. It should be added only when a DCM scenario actually ramps γ (mitotic entry, cortex-activation transient) and only as a back-compatible transient that preserves the existing equilibrium γ. Absent such a scenario, the correct action is to log this paper as a KB SourceEvidence row (myosin-activation kinetics: kcat, Km, sequential Ser19-first) and take no code change.
