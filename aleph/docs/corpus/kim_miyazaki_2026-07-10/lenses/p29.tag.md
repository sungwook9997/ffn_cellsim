# TAG-validation lens — p29

**Paper:** Weady, Palmer, Lamson, Kim, Farhadifar, Shelley — *Mechanics and Morphology of Proliferating Cell Collectives with Self-Inhibiting Growth*, PRL 133, 158402 (2024). DOI 10.1103/PhysRevLett.133.158402.

## Paper kind

**analytic** (primary) + **simulation** (secondary). The paper's deliverable is a *multiscale continuum theory* with **closed-form analytical solutions** (Eq. 5 radial pressure/velocity, Eq. 8 radius scaling, wavelength ∝ λ^−1/2), validated against its own large-scale discrete agent-based simulation (O(10⁵) growing spherocylinders). There is **no in-vitro/in-vivo measurement** in this paper — the only "experimental" numbers are a *back-of-envelope E. coli parameter estimate* pulled from a cited dataset (Hallatschek ref [58]), not measured here.

Consequence for use (per philosophy):
- The **closed-form laws are candidate analytic oracles** — but only for a *growth-driven proliferating-collective* engine, which DCM does not currently have (DCM = single-cell surface mesh; no division/growth).
- The **discrete-sim numbers are comparison-only, never a truth source.**
- All quantities are **dimensionless model outputs at bacteria/yeast scale (ℓ₀≈1 µm, τ≈54 min)** — NOT MCF7 cytoskeletal parameters. Provenance must be flagged on anything registered.

Relevance: **FF — none** (no filaments/motors/clutches). **DCM — indirect/conceptual** (proliferation-mechanics + a constraint-based contact solver relevant to the IPC large-dt line). **TAG — low-priority, conditional** (validation targets only materialize if the project builds growing-collective/division-in-aggregate physics).

BUT the **mechanism and system differ**: our gate is diffusion/spreading-limited **MCF7 spheroid** expansion (α~0.5 early); this paper is **proliferation-driven, stress-inhibited bacterial/yeast colony** growth (exponential early, not α~0.5). Do **not** treat this as a confirmation of the MCF7 band — it is a *different physical regime* (growth-dominated vs spreading-dominated), overlay/context only. Worth flagging on the gate note as a distinct proliferation-limited comparison curve if DCM ever adds division.

- **Young-Laplace / ΔP·R/2 oracle** — different geometry (this is a 2D Darcy tissue-flow pressure field p(r)=(R²−r²)/4, not a membrane Laplace tension). No conflict, no overlap.

**Net: no existing gate is confirmed, tightened, or challenged.** One gate (VG-U5-radial-expansion) is *contextually informed* by a distinct-mechanism comparison curve.

Band/value: **early R∝e^{t/2}; late-time asymptote R → (2/λ)^{1/2} t (linear)**, crossover onset near t≈5τ. Engine: DCM (growth-enabled aggregate) vs **analytic oracle Eq. 8**. 2. **`VG-cand-darcy-growth-pressure-profile`** — observable: radially-averaged pressure field of a growing 2D colony at λ=0. Value: **p(r) = (R²−r²)/4** (parabolic), peak at center → 0 at edge; velocity **u(r)=r/2**. Engine: DCM continuum / **analytic oracle Eq. 5**. Source: Eq. 5, p.4. *Clean closed-form; best oracle candidate here.*
3. **`VG-cand-ring-wavelength-scaling`** — observable: concentric size-ring wavelength. Value: **Λ ∝ λ^{−1/2}**, decreasing with radial distance, oscillation period ≈ ln2. Engine: DCM growth-collective vs **analytic**. Source: Fig. 4(c), p.5. *Emergent pattern; harder to pin a tolerance band — flag as sanity/scaling check, not a hard contract.*
4. **`VG-cand-stress-inhibited-growth-law`** — observable: per-cell growth-rate suppression vs local pressure. Value: **ℓ̇/ℓ = (1/τ) e^{−λσ}** (exponential inhibition). Engine: DCM (mechanistic constitutive check). Source: Eq. 7, p.2. *This is a constitutive-law verification, not an outcome band — belongs as a mechanism sanity gate if the law is adopted.*

## Oracle candidates

Strong analytic content, but **conditional** on a growth-driven Darcy-tissue continuum that DCM does **not** currently implement. Describe-and-shelve:

- **Radially-symmetric Darcy-growth solution (Eq. 5)** — closed forms for p(r), u(r), and the constant c(R,λ). λ=0 limit is the clean parabolic **p(r)=(R²−r²)/4, u(r)=r/2**. Implementable as an analytic oracle (a few lines) to cross-check any growing-aggregate pressure/velocity field. **Best candidate.**
- **Colony-radius scaling (Eq. 8)** — R(t)=R₀e^{t/2} (λ=0) → (2/λ)^{1/2} t (λ≠0 asymptote). Analytic oracle for the exponential→linear crossover.
- **Mean-length flow-map solution (Eq. 4)** — ℓ̄=2^{frac[∫g/ln2]} along Lagrangian characteristics. Oracle for the size-inheritance/patterning check.
- **Wavelength scaling Λ∝λ^{−1/2}** — analytic asymptote, usable as a scaling-law sanity oracle.

These belong in a *new* oracle family (e.g. `oracles/growth_collective/`) **only if the project commits to proliferating-collective physics**. Until then: documented, not built. Consistent with "oracles are cross-checks, not truth" — these would cross-check a DCM growth-collective run against the paper's own analytic theory.
