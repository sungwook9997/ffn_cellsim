# FF lens — p19

**Paper:** Rabbi, Yim, Boyd, Nam, Chaudhuri, Kim (2026) — *Mechanical Checkpoint for Cell Division in Three-Dimensional Microenvironments*, bioRxiv 10.64898/2026.06.16.732593 (Taeyoon Kim lab, Purdue). Non-peer-reviewed preprint (flag provenance).

**One-line for FF:** This is a Cytosim-class discrete fiber-network + Bell's-law dynamic cross-linker model of the **collagen ECM** with an enclosed-volume membrane growing/dividing inside it. It is essentially the same class of substrate FF already builds (collagen-Mikado / traction-ECM), authored by the same lab whose actomyosin-bundle force-distribution scheme FF cites. The gold here is (a) a *complete, self-consistent ECM-fiber + force-dependent cross-linker force-law set* with the exact symbol-to-node mapping FF needs, (b) the **growth-prestress → densified pericellular shell → three discrete resistance modes** emergent phenomenology to reproduce, and (c) a clean, quantitative validation battery for FF's ECM half (buckling cap ~30 pN, T_mat/T_pole=0.37, fiber curvature ↑buckle/↓straighten, aspect ratio 1.41).

## 1. MECHANISMS to adopt

FF modules touched: **ECM fiber (semiflexible beam)**, **cross-linker (Bell-Evans off-rate)**, **fiber self-assembly/nucleation**, **excluded-volume repulsion (soft-core)**, **membrane enclosed-volume + division loads**, **buckling/straightening emergent observables**.

1. **Cross-linker unbinding: adopt the TENSION-GATED (one-sided) Bell law.** FF currently uses a symmetric force-dependent off-rate `k_off = k_off0·exp(F/F_b)`. This paper's Eq. 7 gates the acceleration to **tensile load only** — under compression (`r < r0,xl`) the cross-linker unbinds at the bare rate `k_off0`, and only when `r ≥ r0,xl` (tensile spring force) does the exponential kick in. This is more mechanistic for a crosslinked fiber network: a compressed crosslink should not be force-ripened off. **Why it beats current FF:** matches the physical picture that Bell/Evans catch-slip bond-lifetime shortening is a *tensile* (bond-stretch) phenomenon; a compressive spring force on the two-arm crosslinker does not load the actual bond. Cheap to add: one `if` on the spring extension sign. Directly relevant to FF's α-actinin/filamin crosslinkers *and* collagen crosslinks in the ECM substrate.

2. **Cross-linker as a TWO-ARM element with two bending stiffnesses + proximity-weighted force distribution.** FF's crosslinker is an explicit bond. This paper models each crosslinker as *two cylindrical arms joined at a center* with (i) an arm–arm bending stiffness κ_b,xl,1 (θ0=0) and (ii) an arm–bound-fiber-axis bending stiffness κ_b,xl,2 (θ0=π/2), and distributes the arm force to the *two nodes of the bound fiber element weighted by the binding point's proximity* (ref. 26 = Kim's own actomyosin-bundle scheme). **Why:** binding sites are quantized (every 100 nm) but land *between* fiber nodes; naive nearest-node force injection creates artificial torque/segment-length artifacts. The proximity-weighted distribution is the correct way to couple a crosslinker or motor head that binds mid-segment — this same scheme should be used for FF **myosin heads and adhesion clutches** binding mid-filament, not just crosslinkers.

3. **Persistent (non-disassembling) semiflexible fiber with emergent buckling.** ECM fibers = serially connected cylindrical rod elements with harmonic stretch (Eq. 4) + harmonic bend (Eq. 5), κ_b tuned to ℓ_p≈100 µm (collagen), and a **critical buckling load emergent at ~30 pN**. FF already has this architecture for actin (ℓ_p≈17 µm); the paper confirms that with proper κ_b, buckling and strain-stiffening emerge for free with no special buckling model — validating FF's mechanistic choice and giving the collagen parameter set (ℓ_p=100 µm, r0,f=1 µm, buckle≈30 pN) FF's ECM substrate should use.

4. **Fiber SELF-ASSEMBLY from a monomer pool (nucleation + bidirectional elongation), non-disassembling.** ECM matrix is *grown in situ* via nucleation rate kn,f and elongation rate k+,f (bidirectional) over a 100 s assembly phase, then frozen. FF's collagen-Mikado is currently placed geometrically; a nucleation+elongation assembly phase gives a physically self-consistent, connectivity-percolated network instead of a hand-seeded one — and it is the correct baseline for the "short-fiber → checkpoint evasion" sweep.

5. **Growth-prestress protocol: ramp the enclosed-volume target to build a densified pericellular shell.** The central mechanism: linearly ramping V0 ×2 over 4000 s (G1 growth) *compacts and prestresses* the proximal ECM into a densified shell that then bears load in three modes. **Why FF cares:** FF's crawl/traction runs currently drop the cell into a relaxed ECM; this shows the *physiological baseline* is a prestressed pericellular cage, and gives FF a mechanistic route (volume ramp) to generate it — consistent with the physiological-baseline HARD rule (start from the prestressed state, not a floppy one).

## 2. FORCE LAWS / KINETIC SCHEMES to port

All map onto FF's Warp node state `r_i` (position), per-element rest length `r0`, rest angle `θ0`, spring const `κ`.

**(A) Tension-gated Bell unbinding — Eq. 7 (port into FF crosslinker/clutch off-rate):**
```
k_off,xl = k_off0 · exp( λ_off · |F_s,xl| / (k_B T) )      if  r ≥ r0,xl   (tensile)
k_off,xl = k_off0                                          if  r < r0,xl   (compressive)
```
Symbol map: `k_off0` → FF `crosslinker.k_off0` (zero-force rate); `λ_off` → force-sensitivity *length* (note: this is `x_β`, a distance, so `λ·F/kT` is dimensionless — equivalent to FF's `F/F_b` with `F_b = k_B T / λ_off`); `F_s,xl` → magnitude of the crosslinker spring force `κ_s,xl·(r−r0,xl)`; `r0,xl = 200 nm`. **The only change vs current FF is the compressive branch clamp to `k_off0`.** After unbinding the crosslinker stays attached to ONE fiber and awaits rebinding (transient network → viscoelasticity/plasticity) — FF should preserve one-arm attachment rather than fully deleting the crosslinker.

**(B) Over-damped Langevin + FDT — Eqs. 1–3 (already FF's BAOAB limit; use as parity oracle):**
```
F_i − ζ_i (dr_i/dt) + F_i^T = 0
⟨F_i^T(t) F_j^T(t)⟩ = (2 k_B T ζ_i / Δt) δ_ij δ
r_i(t+Δt) = r_i(t) + (1/ζ_i)(F_i + F_i^T) Δt        (forward Euler, Δt = 3.97e-4 s)
```
FF's constrained Leimkuhler–Matthews BAOAB is *higher-order* than this forward-Euler — so this is a **cross-check oracle**, not a replacement. Their Δt=3.97e-4 s at ℓ_p=100 µm collagen is a useful CFL anchor for FF's ECM substrate stability.

**(C) Cylinder per-element drag — Eq. 6 (port for anisotropic fiber drag):**
```
ζ_i = (3π µ r_c,i / 5) · (3 + 2 r0,i / r_c,i)
```
`µ` = medium viscosity, `r_c,i` = element diameter, `r0,i` = element length. **Why FF cares:** FF's grid-drag / crawl-speed open problem (Σγ ∝ Nc kills native crawl speed) is a per-element drag question. This is a physically-derived cylinder drag (Clift/Grace/Weber, ref. 27) that scales drag with element length/diameter — a principled alternative to FF's current bulk-drag heuristic. Worth testing whether adopting the cylinder formula (drag ∝ length, weak log-free approx) changes the grid-drag scaling that destabilizes native crawl.

**(D) Soft-core excluded-volume repulsion — Eq. 8 (port for node-vs-filament contact):**
```
U_r = κ_r (r12 − r0,r)^2 · [ 1/2 + (1/3)(1 − r12/r0,r)^4 ]     if  r12 < r0,r
U_r = 0                                                        if  r12 ≥ r0,r
```
`r12` = min distance between two cylindrical segments (or membrane element vs fiber); `r0,r` = sum/avg of the two element radii (contact cutoff); `κ_r` = repulsion strength. This is a smooth, bounded soft-core (steepens as r12→r0,r) — an alternative to FF's LJ-repulsive for **fiber–fiber and membrane–fiber excluded volume** that avoids the LJ singularity and is cheaper to integrate at large Δt.

**(E) Enclosed-volume conservation — Eq. 9 (membrane compartment; shared with DCM):**
```
U_v = (1/2) κ_v (1 − V/V0)^2
```
V0 ramped ×2 for growth. For FF this is the membrane-containment compartment; the growth ramp is the shell-prestress driver (§1.5).

**(F) Division load fields (imposed forces, boundary condition — reproduce as an FF scenario):**
- CRC (cytokinetic ring): constant **inward** force F_CRC on membrane nodes within **0.5 µm of equator**, applied until node >1 µm from mitotic axis.
- ISE (spindle elongation): constant **outward** force F_ISE on membrane nodes within **5 µm of the mitotic axis**.
- Both stop when cell elongation reaches **58.74%** (prevents over-elongation past two spheres).

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario "pericellular-shell-checkpoint" (FF ECM + membrane):**
1. **Assembly (100 s):** self-assemble collagen fibers (nucleation kn,f + bidirectional elongation k+,f, avg L_f≈10 µm, ℓ_p=100 µm, r0,f=1 µm) with dynamic Bell crosslinkers (200 nm arms, sites every 100 nm) filling the annulus between a 10 µm membrane and the domain boundary. 2D: thin cylinder R=50 µm, height 1 µm, fibers oriented ⊥z. 3D: sphere R=30 µm (verification, ~6× cost).
2. **Growth / G1 (4000 s):** ramp membrane V0 linearly ×2 → membrane R grows to ~1.26×, compacting a **densified pericellular shell** with roughly isotropic hoop tension.
3. **Mitotic elongation (to 20,000 s):** apply CRC (inward, equator ≤0.5 µm) + ISE (outward, axis ≤5 µm) until 58.74% elongation. Measure the three resistance modes.
4. **Controls (their supplements, worth replicating):** (a) *no-growth* control — skip step 2, verifies the shell/checkpoint is history-dependent (T_pole & T_mat markedly reduced); (b) *shell-severing* — cut a 3 µm annulus, tension becomes uniform, T_mat→negligible, elongation increases → proves anchoring mode.

**Sweep design (which FF ECM knob tunes which mode):**
- Fiber density C_f ↓ → elongation ↑, all three forces ↓ proportionally, ratio T_mat/T_pole ~unchanged.
- Fiber length L_f ↑ → locks elongation; **L_f ÷2 → catastrophic anchoring failure (T_mat/T_pole < 0.5)** (percolation-like connectivity threshold).
- Crosslink density R_xl ½ → elongation ~×2 (C_pole most sensitive — sets buckling length).
- **k_off0 ×100 → matrix fluidization, T_mat/T_pole → 0** (anchor loss, transient-network unjamming).
- κ_b,f ×10 → elongation ↓ via ↑ polar compression only (T's insensitive; C_pole ∝ κ_b,f).
- κ_s,f ÷25 → elongation ↑, all forces ↓.

This is a ready-made **FF ECM-substrate stress-generation validation harness** even without the division biology: it exercises Bell-crosslinker turnover, fiber buckling, strain-stiffening, and connectivity percolation against measured targets.

## 6. RISKS / caveats

- **This is the ECM half, not actomyosin.** The paper's fibers are **collagen** (ℓ_p≈100 µm, non-disassembling, no motors), not cortical actin. Do NOT overwrite FF's actin ℓ_p (17 µm) or actin turnover with these values — they belong to a *separate collagen-ECM fiber species* in FF's config. The Bell-crosslinker scheme and force-distribution (§1.2) DO transfer to actin crosslinkers; the fiber parameters do not.
- **Purified/passive matrix vs living cortex.** No myosin, no active contraction, no ATP turnover on the ECM side — matrix stress is *externally imposed* by the cell's growth+division loads. FF's γ-generation / active-contraction open problems get *nothing* from the force-generation side here; the value is on the **passive network mechanics + crosslinker kinetics + buckling** side.
- **2D approximation dominates the reference results.** Most quantities (aspect ratio 1.41, T's, +10% shell) are from the thin-cylinder 2D setup; only ONE 3D run verifies. 3D is less confined and gives different magnitudes (~60% extension, +20%, T_pole~10 nN). Reproduce at FF native 3D scale; treat 2D numbers as order-of-magnitude, not exact parity.
- **Reference κ values are not numeric.** Only sweep *ratios* are published (κ_s,f÷25, κ_b,f×0.1–10, k_off0×10/100, C_f×0.25/0.5, L_f×0.5/1.5). Anchor absolute stiffnesses from FF's existing DOI-verified sources (Ferrer link_k, KB collagen), then use these ratios for sweep design. Do NOT invent the missing κ_v, κ_r, µ, or k_B T — surface if a physiological value is needed and unknown.
- **Non-peer-reviewed bioRxiv preprint.** Flag provenance in any KB registration; the force laws (Eqs. 1–9) are standard and safe to port, but the quantitative targets (T_mat/T_pole=0.37 etc.) should be tagged as preprint-provenance until published.
- **Forward-Euler Δt is theirs, not a ceiling for FF.** Their Δt=3.97e-4 s is set by explicit Euler; FF's BAOAB limit can exceed it. Use it only as a lower-bound CFL sanity check for the collagen substrate, per FF's rule that CFL must include the stiffest spring (here κ_s,f and κ_v).
- **Native-scale mandate:** their 2D "cell" is R=10 µm with 157 membrane elements (coarse); FF must reproduce at native MCF7 scale (R=7.5 µm, full membrane+cortex+nucleus) before any conclusion. Their setup is a *scenario blueprint*, not a native-validated result to cite directly.
