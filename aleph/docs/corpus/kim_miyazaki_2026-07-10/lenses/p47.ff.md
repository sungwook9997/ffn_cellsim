# FF lens — p47

**Paper:** Yu, Kim, Rajagopal (2022) "Role of actin filaments and cis binding in cadherin clustering and patterning," PLOS Comput Biol 18(7):e1010257, DOI 10.1371/journal.pcbi.1010257.

**One-line verdict for FF:** This is fundamentally a *DCM* (adherens-junction / cadherin) paper, and its actin is a **rigid, immobile, projected 2D line network** — the antithesis of FF's dynamic fine-grained filaments. So it contributes **no new force law or motor mechanism** to FF. What it *does* give FF is (a) a clean set of cortical **actin length/concentration/turnover biological ranges** for the sub-membrane region, (b) an **F-actin excluded-volume radius (3.5 nm)** anchor, and (c) a **corralling → sub-diffusion of membrane proteins** phenomenon that FF should reproduce *emergently* (not import as a rule) once membrane-bound diffusers ride on the native cortex. Impact is **low-moderate**: parameter/validation reference, not a method import.

---

## 1. MECHANISMS to adopt (FF module → specific change)

Honest triage — most of this paper is out-of-scope for FF because its actin has no mechanics. Two items are genuinely useful, one is a "reproduce emergently" target, and the rest are explicitly rejected.

- **[ADOPT — turnover module] Cortical F-actin turnover lifetime spectrum at the sub-membrane region.**
  The paper brackets F-actin lifetime at adherens junctions as **10 s – several minutes** (FRAP), decomposed into a **fast bundle-tip pool ~20 s** and a **slow bundle-stalk pool half-life ~2 min** (cited Indra et al. [7]; Fritzsche cortex-turnover [38]). FF's turnover/fragmentation channel currently lacks a physiologically-anchored *cortex* lifetime distribution — this supplies a **bimodal** target (a fast tip pool + a slow stalk pool) rather than a single exponential. Why it beats current FF: our turnover is presently a single rate; a two-pool tip/stalk turnover matches the measured cortex FRAP structure and is directly testable against FF's own filament-age histogram.

- **[ADOPT — filament / excluded-volume] F-actin excluded-volume radius = 3.5 nm (= ½ filament diameter ≈ 7 nm).**
  Used here as the cad–actin capture cutoff `d_c^{cad/actin} = 3.5 nm = ½ F-actin diameter` (Egelman [25]; Cooper textbook [41]). This is the correct hard-core radius for FF's LJ excluded-volume σ on cortical actin segments and for any membrane-protein–filament contact test. Cross-check FF's current LJ σ against 7 nm filament diameter.

- **[REPRODUCE EMERGENTLY, do NOT import] Actin corralling → sub-diffusion of membrane proteins.**
  The paper *imposes* corralling as an infinite hard wall (a diffusive step that would cross a filament segment is rejected), producing measured **sub-diffusion** (MSD slope < 1) that gets stronger with actin concentration (sub-diffusive at all lags) and with longer projected filament length `L_F` (sub-diffusive only at long lags, from closed non-escapable meshes). In FF this must **emerge** from LJ excluded-volume between a diffusing membrane species and the *dynamic native cortex mesh* — never be hard-coded as a rejection rule (that would violate the fine-grained/mechanistic rule). Use their MSD-slope curves as the acceptance target.

- **[REJECT for FF — DCM only] Cadherin trans/cis binding kinetics, cluster-size laws, weak-cis→large-cluster result, cad/actin tethering.** These belong to the DCM cadherin-junction contract (see the project's active DCM cadherin-cluster+maturation redesign), not FF. No filament mechanics.

- **[REJECT] The projected-2D rigid-actin representation itself.** `L_F = h_actin·tanφ` collapses a 3D filament to a 2D immobile segment with no bending/stretch/polymerization. FF already models the full 3D dynamic filament — this is a downgrade, useful only as an intuition for how filament *tilt* controls apparent mesh size.

## 2. FORCE LAWS / KINETIC SCHEMES to port

There are **no force laws** in this paper (rule-based Brownian dynamics, explicitly no potentials). Two kinetic/geometric schemes are transcribable, but only as reference — FF already has richer versions.

- **Stochastic per-step event firing (already FF-equivalent).**
  `p_event = 1 − exp(−k·Δt)`  (Eq 3), applied to association and dissociation with intrinsic rates `k_ass`, `k_dis`. FF's Bell-Evans binding updater already uses this Poisson form; the paper adds nothing (its `k_dis` is force-independent, i.e. **weaker** than FF's `k_off = k_off0·exp(F/F_b)`). Do **not** replace FF's force-dependent off-rate with this constant-rate scheme.

- **Brownian displacement magnitude (reference for any FF membrane diffuser).**
  step per Δt = `√(4·D·Δt)`, random 2D direction. Maps to FF as: a membrane-bound particle of diffusion coefficient `D` (µm²/s) under the BAOAB integrator should exhibit this MSD in the free limit — a sanity check, not a new integrator.

- **Projected filament length (geometry only, for the corralling scenario).**
  `L_F = h_actin · tan(φ)`  (Eq 4), with `h_actin` = effective sub-membrane region thickness, `φ` = filament tilt from the membrane normal. FF doesn't need this (it has true 3D filaments) but it defines the **scenario knob**: cortex filaments oriented near-normal (φ→0, "vertical") give a fine punctate mesh; near-tangential (φ→90°, "parallel") give a long open mesh. Symbol map: `φ` ↔ FF cortex filament polar-angle distribution; `h_actin` ↔ FF sub-membrane shell thickness.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (as an FF scenario)

Two FF-runnable scenarios, both at native scale on the real cortex (never coarse):

- **S-A: Corralling → sub-diffusion of a membrane tracer.** Seed a dilute set of membrane-bound tracer particles (LJ-coupled to the native 38000-filament cortex, MCF7 R=7.5 µm) at the physiological cortex density; run BAOAB; measure tracer MSD(τ). Sweep effective cortex mesh size by the physiological actin concentration band (non-muscle **46–70 µM**) and by cortex filament length distribution. Target: MSD slope drops below 1 (sub-diffusive) as mesh tightens, diffusive (slope≈1) at short lag / open mesh. This tests FF excluded-volume + cortex connectivity, emergently.

- **S-B: Cortex architecture vs filament orientation.** Build the native cortex with filament polar-angle distributions biased "vertical" (φ~75°, near-normal) vs "parallel" (φ~15°, near-tangential) at matched actin concentration. Measure the emergent effective mesh size / apparent pore-size distribution. Qualitative target: near-tangential → longer effective pores / more open mesh; near-normal → finer, more uniform mesh (their punctate-vs-linear result, translated to a *mesh geometry* observable rather than a clustering one).

Both are secondary to FF's core cortical-tension / contraction problems — run only if membrane-protein confinement or cortex pore-size becomes a live FF question.

## 5. VALIDATION TARGETS for FF observables

- **Sub-diffusion exponent:** membrane-tracer MSD slope **< 1** under corralling; **≈ 1** (free diffusion) at short lag or open mesh (Fig 3C,3D). Direction and lag-dependence are the acceptance criteria.
- **Cortex mesh / cluster nearest-neighbor spacing:** **31 – 45 nm** (Fig 5H) — a length scale for cortex pore/feature spacing; smaller and more uniform for near-normal filament orientation. Usable as an order-of-magnitude sanity band for FF cortex pore size.
- **F-actin turnover bimodality:** fast tip pool ~**20 s**, slow stalk pool half-life ~**2 min** (Fig 5 context / [7]) — FF's filament-age histogram should show two timescales, not one.
- **Actin concentration → mesh tightening monotonicity:** increasing actin concentration (60→240 µM) monotonically reduces effective mesh size and increases sub-diffusion (Fig 3B,3C) — a monotonic-trend check for FF, not an absolute number.
- (DCM-only targets — K_D^cis ~500 µm⁻², cluster lifetime ∝[cad]², %trans/%cis — excluded from FF acceptance.)

## 6. RISKS / caveats

- **Rigid, immobile, projected-2D actin.** The paper's actin has no bending, stretch, polymerization, or force — it is a static wall network. Anything imported as *mechanism* would violate FF's fine-grained/mechanistic hard rule. Use only as parameter bands + emergent-reproduction targets; let FF's dynamic cortex generate corralling itself.
- **In-vitro/reconstitution-flavored concentrations.** The muscle actin band (230–960 µM) is not MCF7 cortex — use only the **non-muscle 46–70 µM** band, and even that is a cell-type-general reference, not an MCF7 datum. Reconcile against the project's own ratified cortex density (KB-3.18 ~100/µm², Nc≈266k) before use; do not let 60–240 µM override the ratified cortical density.
- **Adherens-junction context, not free cortex.** These turnover/length numbers are measured *at cell–cell junctions*, where actin is bundled and junction-stabilized. FF's isolated single-cell cortex may legitimately differ; treat the tip/stalk 20 s / 2 min split as an upper-fidelity target for junctional cortex, not a global cortex mandate.
- **Constant (force-independent) off-rates.** The paper uses `k_dis` with no force dependence. Never let this regress FF's Bell-Evans `k_off = k_off0·exp(F/F_b)` crosslinker/clutch off-rates — FF is strictly more mechanistic here.
- **2D → 3D.** All geometry is a 2D projection with periodic 1 µm² planes. Length scales (mesh 31–45 nm, L_F, h_actin 50–100 nm) transfer as *magnitudes* but the 3D cortex has out-of-plane connectivity the paper cannot see; validate at native 3D scale with the full compartment stack, never a stripped/coarse cortex.
- **Physiological baseline:** any FF corralling/turnover scenario must start from the `--from-resting` native cortex at real turgor/viscosity, not a fresh un-relaxed build — the corralling/sub-diffusion signal is meaningless on an unphysical baseline.
