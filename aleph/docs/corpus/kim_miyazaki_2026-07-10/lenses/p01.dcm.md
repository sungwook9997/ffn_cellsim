# DCM lens — p01

**Paper:** Miyazaki & Harada 2011, *Bayesian estimation of the internal structure of proteins from single-molecule measurements*, J. Chem. Phys. **134**, 085108 (DOI 10.1063/1.3516587).

**Verdict up front (relevance to DCM ≈ 0.5 / 5).** This is a statistical-inference / stochastic-dynamics method paper built on a 2-bead ("Brownian double pendulum") single-molecule toy. It contains **no cortex, membrane, turgor, cadherin-junction, division, confinement, or aggregate mechanism** — nothing at the deformable-surface-mesh continuum scale DCM operates on. It cannot supply a DCM force law, a physiological parameter, a geometry/protocol, or a quantitative validation target: every number in it is nondimensional (units fixed `k*=γ*=k_BT=1`) toy output, not an in-vitro biophysical measurement. The only genuinely transferable content is **methodological**, and even that is a better fit for the FF (fine-grained Langevin) engine than for DCM. I record the thin, honest levers below and flag the rest as non-applicable rather than manufacture relevance.

---

## 1. Mechanisms to adopt

Nothing in the paper is a cell-mechanics mechanism DCM lacks. Two methodological ideas are *adjacent* to DCM but are opt-in tooling, not physics changes — neither beats a current DCM mechanism because DCM has no counterpart:

- **(Tooling, not a force) Differentiable Bayesian calibration of DCM's unmeasured mechanical parameters.** The paper's core move — infer hidden mechanical parameters `Π*={k,h,γ,Γ}` (stiffnesses + frictions) from a *partially observed* trajectory by minimizing a negative-log-marginal-likelihood objective `Hτ(Π)=−τ⁻¹ ln P([y]|Π)` (Eq. 3) — maps onto a real DCM problem: several DCM parameters are not directly measured for MCF7 (nucleus modulus `E_nuc` 1–10 kPa, cytoplasm `η≈65 Pa·s`, cortex `γ`, bending `κ_m`). DCM is already **GPU-resident + differentiable in Warp**, so the exact-gradient version of this inference (fit a small set of unknown constitutive constants so that simulated *observable* nodes reproduce a measured trajectory/shape series) is implementable *without* the WKB machinery — autodiff replaces the saddle-point marginalization. **Why it does not beat anything now:** it is not a mechanism; it is a calibration workflow, and it is explicitly forbidden to fit constitutive constants to PI experimental data (`No fitting to PI experimental data` hard rule). It could only be used against *literature* trajectories as a cross-check oracle, never to tune a gate.
- **(Cautionary result, not a mechanism) Loss-of-precision / identifiability transition.** The paper proves (Fig. 2b, Fig. 4, App. A) that when the observed DOF is weakly coupled to and much slower than the hidden DOF (`h*` small, `Γ*` large, probe relaxation `τr~Γ*/h*` long), the objective landscape *flattens* and the hidden parameters become **non-identifiable even as τ→∞** (sample variance jumps >4 decades). The DCM-relevant lesson: if we ever try to back out a hidden compartment parameter (e.g. `E_nuc`) from only the *outer membrane* node motion, and the nucleus is stiff/weakly-coupled to the surface (the DCM analogue of small `h*`), the fit is structurally unidentifiable — flag it, do not report a spuriously precise value. This is a "don't do X" guardrail, not an adopt-able force.

**Net:** no DCM module (`membrane`, `cortex γ`, `cytoplasm/turgor`, `nucleus`, `contact/cadherin junction`, `remesh`, `T1`) gains a mechanism from this paper.

## 2. Equations to port to the surface-mesh / continuum level

**None port to the DCM surface-mesh/continuum level.** The governing dynamics (Eqs. 6–7) are *point-particle overdamped Langevin*, one hidden bead + one probe bead:

- Eq. (6): `γ ẋ = −k x − h(x−y) + ξ`, `⟨ξξ⟩ = 2γk_BT δ`
- Eq. (7): `Γ ẏ = −h(y−x) + η`, `⟨ηη⟩ = 2Γk_BT δ`

These have no field/mesh generalization here — there is no surface tension `γ_cortex`, no area elasticity `K_A`, no bending `κ_m`, no enclosed-volume/turgor `Π`, no advection or curvature operator. Symbol collisions are traps, not mappings: the paper's `γ` and `Γ` are **scalar bead frictions** (not DCM cortical tension `γ`), its `k`/`h` are **scalar spring stiffnesses** (not `K_A`/`κ_m`), its `Π` is the **parameter vector** (not osmotic pressure). Porting Eq. 17 (the closed-form Hamiltonian) or Eqs. 12–16 (Onsager–Machlup action + WKB) to DCM would require the model to be linear-Gaussian in the hidden DOF; DCM's mesh physics (volume constraint, contact penalty, catch-bond junctions) is strongly nonlinear, so the paper's *exact* saddle-point result does not even hold — the authors themselves note nonlinear potentials only admit an *approximate* WKB expansion (§V).

The one convention worth transcribing for the **FF engine** (not DCM): the **fluctuation–dissipation noise variance `2γk_BT`** and the **Stratonovich (midpoint) discretization** of the OM path integral (Eqs. 11–12) are the correct reference for any *thermal* Langevin term. DCM is run overdamped-deterministic at the continuum scale (no explicit node thermal noise), so this does not feed a DCM force field.

## 3. Parameters to set

**None.** Every parameter in the paper (Parameter Table, dossier lines 82–104) is a nondimensional toy value with units fixed to `k*=γ*=k_BT=1`:

| paper symbol | paper value | why it does NOT feed a DCM config field |
|---|---|---|
| `k*` (trap stiffness) | 1 (unit-fixing) | scalar bead-trap spring, not `K_A`, `κ_m`, or `E_nuc`; dimensionless |
| `h*` (linker stiffness) | swept 10⁻²–10² | inference-precision control variable, no cell counterpart |
| `γ*`, `Γ*` (bead frictions) | 1 / swept 10⁻²–10² | point-particle Stokes drag, not cytoplasm `η` (65 Pa·s) or per-node drag |
| `Δt`, `τ`, `N` | 10⁻⁴ / 10 / 10⁵ | sampling/observation-time of the *inference*, not a DCM integrator dt |
| `σ_noise` | ≤ ~10⁰ | measurement-noise SD of the toy, not a physical quantity |

Nothing supersedes a DCM default (`γ` interphase 0.15 / mitotic 1.5 mN/m, `η≈65 Pa·s`, `Π₀≈40 Pa`, `E_nuc` 1–10 kPa, `K_A`, `κ_m` all stand unchanged). Do **not** KB-register any of these as constants; per the "method/theory source, not a quantitative validation oracle" flag (dossier line 150).

## 4. Geometry / protocol to reproduce

**None applicable to DCM.** The paper's "geometry" is a 2-bead spring in a harmonic trap near a wall (Fig. 1) — a single-molecule F1-ATPase probe assay. It is not a confinement, aspiration, AFM-indentation, division, aggregate-compaction, or durotaxis scenario. The numerical protocol (Appendix B: generate trajectory at true `Π*`, keep only observable `[y]`, zero-temperature Metropolis minimization of `Hτ` in log-parameter space, 10⁵ iterations, replicas × samples, discard `‖log Π̂−log Π*‖>3`) is an *estimation* protocol, not a mechanical-scenario protocol DCM can stage. The only reusable pattern, and only if a differentiable-calibration task is ever sanctioned: the **replica-and-sample identifiability discipline** (multiple random inits + multiple data realizations to detect a flat/degenerate objective before trusting a fitted parameter).

## 5. Validation targets for DCM observables

**None.** DCM observables are tension (mN/m), shape index, division force, ring-closure rate, compaction fraction, contact angle, cytoplasmic flow speed. This paper reports *inference-quality* metrics only, all dimensionless:

- accuracy gain vs power-spectrum fitting: 1–2 orders of magnitude (Fig. 7) — a method benchmark, not a cell observable.
- sample-variance jump >4 decades at the critical curve (Fig. 2b) — identifiability, not physics.
- systematic error ∝ τ⁻¹ (Fig. 3c, Eq. A11) — estimator convergence, not physics.
- noise-robustness cutoffs σ_noise ≈ 0.18–0.56 (Fig. 5) — toy-model thresholds.

**None of these is a number a DCM run should reproduce.** Register p01 as a *method/theory* KB source (Bayesian hidden-parameter estimation; Onsager–Machlup/WKB; loss-of-precision transition; Miyazaki-lab provenance), not as a validation gate — matching the dossier's TAG-validation flag.

## 6. Risks / caveats

- **Category mismatch (the dominant caveat).** The regime is single-molecule (a purified motor probe), overdamped point particles, linear-Gaussian, nondimensional. DCM is a living-MCF7 deformable continuum: multi-compartment, nonlinear (volume constraint, contact, catch-bonds), physiological-unit. There is essentially no shared physics — resist any temptation to over-map (`γ`, `h`, `Π` symbol collisions are the trap).
- **The WKB/saddle-point exactness does not survive nonlinearity.** DCM's forces are nonlinear, so the paper's *closed-form* marginal likelihood (Eq. 17) is not available; only an autodiff/MCMC approximation would be, and only for a calibration workflow, not runtime physics.
- **Physiological-baseline rule is untouched but must be guarded.** If anyone were to build the differentiable-calibration tool, it must still initialize DCM at the physiological operating point (turgor Π₀ ON, cytoplasm η ON, cortex γ at its resting `ΔP·R/2` value) and may only fit against *literature* trajectories as a cross-check — never PI experimental data, never a derived parameter tuned to pass a gate (hard rules: no-fitting, no-magic-numbers, no-gate-loosening). The paper's own zero-temperature Metropolis "fit `Π*` to data" loop is exactly the pattern those rules forbid at production, so import the *identifiability discipline*, not the *fitting stance*.
- **Adaptation, if pursued at all:** keep it in FF/validation tooling, not in the DCM runtime; use Warp autodiff instead of WKB; and always run the replica×sample identifiability check before quoting any inferred DCM parameter, because DCM's stiff, weakly-coupled inner compartments (nucleus) sit precisely in the paper's "loss-of-precision" corner (`h*` small, `Γ*` large).

Salvage value is a single methodological guardrail (differentiable hidden-parameter calibration + its identifiability failure mode), which belongs in validation tooling, not in DCM physics. Score 0.5/5.
