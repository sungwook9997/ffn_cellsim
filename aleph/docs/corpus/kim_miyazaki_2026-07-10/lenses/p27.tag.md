## Paper kind

**simulation** (3D agent-based Brownian-dynamics model output) **with embedded experimental support** (VAEM live-cell imaging of *Arabidopsis* hypocotyl epidermal cells, Table 1 "experiment" column).

Consequence for how the numbers may be used:
- The **model outputs** (Table 1 "model" column, all sweeps Figs 4–11) are **comparison-only / simulation** — never a truth source. BUT because FF is the *same* Kim-lineage agent-based engine, they are usable as a **verification/regression target** (does FF, configured with the paper's Table 2 params, reproduce the paper's reference observables within their stated ~2×?).
- The **experimental VAEM values** (poly 1.6–1.8 µm/s, depoly ~0.2 µm/s, length 10–17 µm, severing 0.008–0.014 events/µm/s, nucleation 2×10⁻⁴ events/µm²/s) are real measurements → **overlay / cross-check targets only, never fit**.
- **Hard caveat that dominates everything below:** this is **PLANT (Arabidopsis) cortical actin at C_A = 1 µM** (a deliberate computational-efficiency choice; real plant is 40–50 µM). It is **NOT mammalian, NOT MCF7, NOT at physiological actin concentration.** No membrane/turgor/junction/nucleus physics → **zero DCM relevance.** Every candidate here is FF-engine, plant-context, and must be flagged as such — none can become an MCF7 single-cell biological contract.

These are proposed as **FF verification / regression gates** (does the same-lineage engine reproduce the published reference observables when run at the paper's Table 2 parameters?) — NOT as MCF7 biological contracts. They are legitimate because FF is the Kim agent-based lineage and the paper + its public code (github.com/ktyman2/plantactin) give a matched-parameter ground truth. Bands are taken *as reported*, not invented.

1. **`VG-FF-barbed-elongation` (candidate, PI review)** — Observable: emergent barbed-end elongation velocity of a free (uncapped, non-formin) filament at matched [G-actin]. Band: experiment **1.25 µm/s free / 2–2.25 µm/s formin-associated**, model reference **2.2 ± 0.4 µm/s**; accept FF within ~2× of the plant experimental range. Engine: FF. Source: Table 1 / Fig 1C,3E / text p.409. Caveat: velocity is [actin]-dependent (paper runs C_A=1 µM); band is plant, overlay-only.

2. **`VG-FF-severing-frequency` (candidate, PI review)** — Observable: emergent whole-network severing events per µm per s from the angle-dependent law. Band: experiment **0.008–0.014**, model **0.01 ± 0.002 events/µm/s**. Engine: FF. Source: Table 1 / Fig 1F,3F. Pairs with oracle row 22.

3. **`VG-FF-nucleation-frequency` (candidate, PI review)** — Observable: total (de novo + Arp2/3-branched) nucleation events per µm² per s at steady state. Band: experiment **2×10⁻⁴**, model **1.2×10⁻⁴ events/µm²/s** (branched 0.8×10⁻⁴, de novo 0.4×10⁻⁴). Engine: FF. Source: Table 1, text p.409–410.

4. **`VG-FF-formin-enhancement` (candidate, PI review, near-species-general)** — Observable: ratio of formin-bound to free barbed-end elongation velocity. Source: Table 1; α_form Table 2.

## Oracle candidates

Three closed-form laws are directly implementable as FF analytic cross-checks (consistent with "oracles = cross-checks, validate FF against analytic ground truth"):

1. **Angle-dependent severing oracle** — `k_sev(θ) = k0,sev · exp(λ_sev·θ)` (Eq 9). Given a filament held at a known bend angle θ, FF's emergent severing hazard must match this exponential. Mechanistically important: it is the *only* mechanochemically-coupled process in the model, and it is exactly how a bending crosslinker/myosin buckling would raise turnover in FF's cortex. **Caveat:** λ_sev is *not tabulated* in the paper ("quite high") — the oracle is implementable in *form* but the sensitivity constant must be sourced from the public code before it becomes a numeric contract.

2. **Cylindrical-segment drag oracle (Clift 1978)** — `ζ = 3πμ·r_c·(3 + 2·r0/r_c)/5` (Eq 2). Analytic per-segment drag for a short cylinder; FF's assigned segment drag can be regression-checked against this closed form given (µ, r0, r_c). Cleaner than a sphere-Stokes approximation for filament segments.

3. **Fluctuation–dissipation thermal-force oracle** — `⟨Fᵀ(t)Fᵀ(t)⟩ = 2 k_B T ζ δ_ij / Δt` (Eq 3, Underhill & Doyle 2004). Standard FDT amplitude for an overdamped Langevin step; a cross-check that FF's thermal-noise variance is correctly scaled to drag and timestep. Note: our production integrator is Leimkuhler-Matthews BAOAB (higher fidelity than this paper's explicit-Euler Eq 4) — this oracle checks the *noise amplitude*, not the integration scheme, and BAOAB is the mechanistic upgrade over Eq 4.

4. **(Derived) WLC persistence-length oracle** — `l_p = κ_b·r0 / (k_B T)`; with the paper's κ_b,A gives l_p ≈ 8.9 µm, inside the 9–17 µm actin range. Analytic tie between FF's bending stiffness and the measurable filament persistence length; analogous role to the Helfrich κ oracle but for 1D filaments.
