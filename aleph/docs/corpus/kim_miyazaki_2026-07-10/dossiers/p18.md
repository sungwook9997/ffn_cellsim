## Summary
The paper asks how cells structurally remodel a fibrous extracellular matrix (ECM) to promote their own durotaxis (directed migration up a stiffness gradient), and which cellular forces govern this. The authors build a 2D, overdamped, agent-based biomechanical model in which each polarized cell is a two-point unit (front + rear "cell-points") coupled by a spring, migrating over a discrete fibrous matrix modeled as a triangular lattice of nodes joined by extensional + bending "chains," with a random fraction p of chains removed to mimic ECM porosity/plasticity. Cell-points exert lamellipodium-partitioned contractile forces on nearby matrix nodes (front stronger than rear) via focal-adhesion-like viscous coupling; reaction forces drive migration, and stiffer matrix regions resist contraction more, producing emergent durotaxis. Two scenarios are studied: (1) on an externally strained rectangular matrix, anisotropic stiffening (E∥/E⊥) is induced by uniaxial strain ε (0–2.5) and connectivity p (0–0.5); cells migrate preferentially along the strain/stiff direction, and the durotactic index rises with ε and stiffness anisotropy and falls with p — with control tests (fixed matrix velocity vᵢ=0; single-node vs distributed contraction) confirming the bias is durotaxis, not contact guidance. (2) On an unstrained circular matrix, cells must self-generate the stiffness pattern: a single cell cannot; a cohesive cluster (with cell–cell adhesion κa,int = 10⁻⁵ N/m) collectively contracts the matrix, builds sustained radial tension (Fr/Fθ ≈ 2), and then a motile subset escapes and migrates radially outward along the stiffened tracks — mechanistically reminiscent of collective invasion/intravasation in cancer. Increased contractility (1.5×) independently boosts follower recruitment onto pre-stiffened paths; adhesion and contractility act through distinct but non-additive mechanisms.

## Model & Methods
- **Model type:** 2D agent-based / discrete mechanical model. Overdamped (inertia-free) quasi-static force balance — each governing equation sets the sum of velocity-dependent drag forces + position-dependent elastic forces to zero (Eq. 1). Two coupled species: cell-points (NCP) and matrix points (NM). Viscoelasticity via Kelvin–Voigt elements (linear spring ∥ dashpot).
- **Solver:** All 2(NCP + NM) governing equations are assembled into a linear system **Mu = f** (Eq. 2), where M holds drag coefficients, u is the unknown x/y velocity vector, and f holds velocity-independent (elastic + contractile) forces. Solved each timestep for velocities.
- **Integrator:** Positions updated from the solved velocities via the **Adams–Bashforth fourth-order** integration scheme (ref 39, Hayes 2011). Explicit timestep value is in Table S1 (supplement, not in this PDF).
- **Cell representation:** polarized 2-point unit — front + rear cell-point joined by a harmonic spring (κs,FR, rest length r0,FR). Polarity vector points rear→front. Each cell-point carries a semicircular (half-annular, 180°) adhesion zone set by outer Rout and inner Rin radii; front is larger than rear (Rout,F > Rout,R, Rin,F > Rin,R). Front adhesion zone partitioned into **6 sub-regions (lamellipodia)**; one randomly active at a time, active for **0.1 h** then switches; rear zone always fully active.
- **Matrix representation:** nodes initialized on a **triangular lattice**, connected by chains (springs). A fraction **p** of chains randomly removed (ECM porosity/plasticity; method from Broedersz & MacKintosh 2011, ref 38). Connectivity fixed for the run (permanent crosslinks — a stated limitation). Chains carry extensional (harmonic spring), bending (harmonic angle over triads), and viscous (dashpot) forces. Compression buckling captured by asymmetric spring stiffness (κs,M reduced ×1/10 when compressed).
- **Cell–matrix coupling:** viscous focal-adhesion friction (λ) + contractile force. Each matrix node assigned to exactly one (nearest) cell-point whose active lamellipodial region contains it; that cell-point pulls it with Ftot/NM per node (front Ftot,F ≫ rear Ftot,R). Reaction force pulls the cell toward the matrix (Newton's 3rd law).
- **Geometry / BCs — rectangular runs:** target final size ≈ 1000 µm × 1000 µm; uniaxial normal strain ε applied at left/right boundaries (0–2.5), top/bottom free; node count held ≈constant (~46,400) by adjusting rest length r0,M. Stiffness anisotropy probed by applying Fext = 0.01 nN to a central 100 µm × 100 µm patch for 1 h (cells absent) and measuring ⟨displacement⟩ parallel vs perpendicular.
- **Geometry / BCs — circular runs:** circular matrix radius 500 µm, boundary nodes fixed, r0,M = 5 µm. Cells within 4·Rout,F of the boundary removed to avoid edge effects. 100 cells seeded in a central circular region of radius 50 µm on a grid of spacing 17.7 µm, front placed at r0,FR with random orientation. Runs up to ~1000 h.
- **Algorithm outline (per step):** (i) determine active lamellipodia + node→cell-point assignments; (ii) compute all elastic/bending/contractile forces → f; (iii) assemble drag matrix M; (iv) solve Mu = f for velocities; (v) advance positions with Adams–Bashforth-4.

## Governing Equations
1. **Eq. 1** — `F_d(v) + F_e(r) = 0` : overdamped force balance per point (drag + elastic = 0, no inertia).
2. **Eq. 2** — `M u = f` : global linear system; M = drag-coefficient matrix, u = unknown x/y velocities, f = velocity-independent forces.
3. **Eq. 3** — `[F_{d,I} + F_{s,II'} + F_{d,II'}] + Σ_J (F_{d,IJ} + F_{int,IJ}) + Σ_i (F_{d,Ii} + F_{c,Ii}) = 0` : force balance for cell-point I (self terms; inter-cell drag+interaction; cell–matrix drag+contraction).
4. **Eq. 4** — `F_{d,I} = −η v_I` : medium drag on a cell-point (η = cell drag coefficient).
5. **Eq. 5** — `U_{s,II'} = ½ κ_{s,FR} (r_{II'} − r_{0,FR})²` : harmonic front–rear spring potential (maintains cell length).
6. **Eq. 6** — `F_{d,II'} = −α (v_I − v_{I'})` : intracellular (front–rear) relative-motion drag (α = front-rear drag coeff).
7. **Eq. 7** — `F_{d,IJ} = −β (v_I − v_J)` if r_{IJ} < r_{cr,int} (= Rout,I + Rout,J), else 0 : intercellular drag (β = cell-cell drag coeff), active only within contact.
8. **Eq. 8** — piecewise cell–cell interaction (repulsion/adhesion), from SimuCell3D (ref 40):
   - `F_{int,IJ} = κ_{r,int}(r_{IJ} − r_{0,int}) r̂_{IJ}` if r_{IJ} < r_{0,int} (volume-exclusion repulsion);
   - `= κ_{a,int}(r_{cr,int} − r_{max,int} − |r_{IJ} − r_{max,int}|) r̂_{IJ}` if r_{0,int} < r_{IJ} < r_{cr,int} (cell–cell adhesion tent function);
   - `= 0` otherwise. With r_{0,int} = Rin,I + Rin,J, r_{max,int} = (r_{0,int} + r_{cr,int})/2.
9. **Eq. 9** — `F_{d,Ii} = −λ (v_I − v_i)` : cell–matrix viscous focal-adhesion friction (λ = cell-matrix drag coeff); this is the term through which the cell senses matrix stiffness (see Fig. 3E control).
10. **Eq. 10** — `F_{d,i} + Σ_j (F_{s,ij} + F_{d,ij}) + Σ_{j,k} F_{b,ijk} + F_{d,iI} + F_{c,iI} = 0` : force balance for matrix point i.
11. **Eq. 11** — `F_{d,i} = −γ v_i` : medium drag on a matrix point (γ = matrix drag coeff).
12. **Eq. 12** — `U_{s,M} = ½ κ_{s,M} (r_{ij} − r_{0,M})²` : harmonic extensional (chain) potential between matrix nodes.
13. **Eq. 13** — buckling asymmetry: `κ_{s,M} = κ⁰_{s,M}` if r_{ij} ≥ r_{0,M} (tension); `= κ⁰_{s,M}/10` if r_{ij} < r_{0,M} (compression) — fibers 10× softer in compression.
14. **Eq. 14** — `F_{d,ij} = −ξ (v_i − v_j)` : matrix–matrix relative-motion drag (ξ = matrix-matrix drag coeff).
15. **Eq. 15** — `U_{b,ijk} = ½ κ_{b,M} (θ_{ijk} − θ_{0,M})²` : harmonic bending potential over matrix-node triads (κ_{b,M} = bending stiffness).
16. **Eq. 16** — `F_{c,iI} = (F_{tot,I} / N_M) r̂_{iI}` : contractile force cell-point I applies to each of its N_M interacting matrix nodes (F_tot,F front ≫ F_tot,R rear). Reaction on cell: `F_{c,Ii} = −F_{c,iI}`.
17. **Eq. 17** — `E∥/E⊥ = ⟨D_{ext,⊥}⟩ / ⟨D_{ext,∥}⟩` : stiffness-anisotropy ratio = inverse ratio of mean node displacements under fixed Fext (stiffness ∝ 1/displacement).
18. **Eq. 18** — `Durotactic index = ⟨ (D_{c,∥} − D_{c,⊥}) / (D_{c,∥} + D_{c,⊥}) ⟩` : directional bias of migration relative to strain direction; range −1 (worst) to +1 (best).
19. **Eq. 19** — `F_r = F cos θ` : radial component of a chain's tensile force (θ = angle to radial direction, 0–90°).
20. **Eq. 20** — `F_θ = F sin θ` : circumferential component of chain tensile force.
21. **Eq. 21** — `Radial migration bias = D_{c,r} / D_{c,s}` : radial displacement over shortest path between two cell positions (10-h delay); from Cortay 2020 (ref 45).

## Force Laws & Potentials
- **Harmonic springs** (front–rear cell link Eq. 5; matrix chain Eq. 12): linear restoring `F = −κ (r − r₀)`.
- **Harmonic bending** (matrix triads Eq. 15): `F ∝ −κ_b (θ − θ₀)` — semiflexible-fiber bending resistance.
- **Buckling nonlinearity** (Eq. 13): tension-stiff / compression-soft (×1/10) — the standard fibrous-ECM nonlinearity (Storm 2005, Notbohm 2015; refs 42, 30).
- **Viscous drags** (Eqs. 4, 6, 7, 9, 11, 14): all linear `F = −(coeff)·Δv`; distinct coefficients η (cell–medium), α (intracell front-rear), β (intercell), λ (cell–matrix / focal-adhesion friction), γ (matrix–medium), ξ (matrix–matrix). λ encodes focal adhesion as effective friction (Walcott & Sun 2010, ref 41).
- **Cell–cell interaction** (Eq. 8): linear repulsion inside r_{0,int}; piecewise-linear "tent" attraction (adhesion) between r_{0,int} and r_{cr,int}, peaking at r_{max,int}; zero beyond. Functional form adopted from SimuCell3D (ref 40).
- **Active contraction** (Eq. 16): constant total contractile force per cell-point distributed equally over engaged nodes, directed node→cell (centripetal pull), front > rear.
