Ten tracks were designed against the PI specification, four were adversarially attacked, and a completeness critic reviewed the whole. This document is the merged result. ## 0. The gate has changed

**Mechanical connectedness of every part is the gate. Physiological magnitude is not.** Every gate in this document is therefore a conservation identity, an exact zero/non-zero, a sign-sense, a symmetry, a scaling exponent, a grid-invariance, an analytic-oracle *ratio*, or an ablation ordering — never a comparison of an absolute value against a literature band. A gate that cannot be evaluated without an unsourced constant does not appear. Parameters must still be plausible enough not to blow up numerically, and are swept coordinates or fitted **outputs**, never inputs to a pass criterion.

**Labelling rule, mandatory on every artifact.** Each run emits one JSON with: config + config hash; population census (unique active IDs per component, dormant capacity, node/element counts, exact peak GPU bytes); a **t0 row measured before the first step**; per-step telemetry; residual **and** residual/signal; per-parameter provenance (`SOURCED` / `DERIVED` / `PI_GAP` / `UNRATIFIED_PROXY`); the **measured** evidence rung (never a literal — `scripts/ac_gate_b_cortex_motor_native.py:393` currently hard-codes `"evidence": "CONNECTED"` and that must be deleted); and `quantitative_claim_status: BLOCKED` on every magnitude. Verdicts are `MECHANISM PASS` / `MECHANISM FAIL` / **`VOID`** (emitted, never PASS or FAIL, when residual/signal exceeds a ceiling declared *before* the run). Every gate ships a named negative control that must be **observed to fail**; a control that was never run invalidates the claim.

**One rung is missing from the ladder.** The 8-state ladder has no state for "mechanically connected, quantitatively blocked" — which under the new priority is the *success* case. PI decision D1 (§6).

### T1 — Coupled N-owner implicit solve + connector Jacobians *(new; the critic's RANK 1)*
*A5000 for the native tier; CPU-exact tier on the Mac.*

**Today, and why this is the plan's single largest hole.**
- `aleph/engine/composed_native.py:347` `solve_candidate()` is, verbatim, *"One composed candidate-force **pass**"*: zero forces → `world.pipeline.run_candidate()` → `_load_compute()`. **No position update, no iteration, no residual, no convergence latch.**
- `aleph/engine/transaction.py:129` step 3 is `solve()`, a caller-supplied `Callable[[], None]`. `CellTransaction` owns no solver by design.
- `scripts/ac_gate_b_composed_native.py:232` passes `accepted_d = ones(1)` with no ledger/`tol_sq_d` — the composed cell unconditionally accepts a state in which nothing moved. (`transaction.py:139-146` already *supports* `ledger.balance_ok_d`; nothing uses it.)
- **The only coupled solver in the tree works only because of the aliasing every track wants removed.** `aleph/components/incumbent/implicit_mechanics.py:1770 add_linc_stiffness_kernel` (nucleus↔actin), `:1775 add_erm_stiffness_kernel` (membrane↔cortex), `:1764 add_segment_crossbridge_stiffness_kernel` (myosin↔actin) are genuine cross-component tangent blocks — over the single merged array built at `aleph/components/incumbent/assemble.py:754` (*"compose the global node array `[actin | myosin | nucleus | membrane]`"*). **De-aliasing destroys it.** No original track noticed.
- The one correct N-array pattern exists and is hard-coded 2-way: `aleph/engine/sf_implicit.py:481-491` — `gather_two_kernel` into contiguous scratch, coupled solve, `add_scatter_two_kernel` back into two never-merged owner arrays. It is **untracked in git** (`git ls-files` returns nothing).

**Why per-component solvers are not an option.** The original plan proposed `mt_implicit.py`, `if_implicit.py`, `NucleusImplicitCG`, plus `sf_implicit.py` — N separate SPD solves exchanging connector *forces*. That is component-level Gauss–Seidel; its convergence factor is set by connector-stiffness / component-stiffness, and the mechanically important connectors are the stiff ones (k_erm ≈ 4600 pN/µm; α-actinin 4.6e5 pN/µm dominating λ_max ≈ 3.7e6 per `sf_implicit.py:11-13`). It will not converge for exactly the couplings that matter, and a non-converged split is indistinguishable from a dead connector — which makes T3's transmission matrix, T5-N8 and T8's matrix all unfalsifiable.

### (a) Ion channels — NOT NOW for mechanics, with five named triggers

**Position: no.** Aquaporin water permeability is *legitimately* lumpable into L_p, and this is categorically different from the lumpings the project forbids. What *is* missing is one rung **down** in the dependency order: the conserved pools N_i with per-solute σ_i and the live device enclosed volume (T6a-V2/V3). Pools are **state**; channels are the **rate law** that changes that state. And in the ratified baseline (adherent, in medium, r = 1, quasi-static) ion fluxes are at homeostatic steady state, so their net contribution to ΔΠ_eff is a **constant** — which is exactly the constant Π₀ already ratified as a sweep axis. Adding channels now introduces conductances, densities and pump stoichiometries that are all PI-GAPs, lowering the sourced fraction of the model while changing no mechanical prediction.

### (c) Stokes vs Darcy — a staged verdict, and the drag term that must die in the same commit

**The physics.** The Brinkman screening length is ℓ_B = sqrt(k). At the project's k = 5e-18 m² (`ac/fluid/params_i0b1.yaml`), ℓ_B = 2.24 nm; re-derived from the project's own cortex population (70,686 × 3 µm over a 706.9 µm² × 0.2 µm shell ⇒ ρ_L = 1500 µm/µm³ ⇒ ξ = 25.8 nm, k = ξ²/C for C = 16–72), ℓ_B = 3.0–6.5 nm. The viscous term beats the Darcy term only below ℓ_B: the ratio is exactly (ℓ_B/L)², i.e. 2.0e-5 at L = 0.5 µm and 8.9e-8 at L = 7.5 µm. **At the whole-cell scale Darcy is not a convenience approximation of Stokes — it is the leading-order asymptotic limit of Stokes in this medium.** Re is 1.5e-10 (bulk η) to 1e-5 (pore η), so Stokes is exactly the right physics and the whole question is discretisation and cost.

**The cost.** A resolved whole-cell DNS needs ~4.2e11 cells at dx = 2 nm ≈ 25 TB for 15 fp32 fields — ~1580× a 16 GB A5000 and ~300× a full 8×H100 node. **Infeasible by construction, not merely expensive.** Whole-cell Stokes–**Brinkman** at 100–250 nm is affordable (0.2 GB, 8–130 ms/outer step) but, per the attack, **ℓ_B is unresolved there** ((dx/ℓ_B)² ≈ 2000 at dx = 100 nm), so its advertised gains — real shear, vorticity, no-slip — are grid artifacts at that resolution. Pore-scale DNS in a 0.5–1 µm REV **is** affordable (0.9–3.0 GB) and is where the one genuinely lumped number gets de-lumped.

**Verdict and staged path.** (1) **REV DNS to measure k_ij and φ from the project's own explicit filament geometry**, turning both from PI-GAP *inputs* into measured *outputs* — this directly serves PI purpose #5 and is the fine-grained move. (2) **Stokes–Brinkman only where free fluid actually exists**: the extracellular **media** the baseline specifies (today there is none at all), the cell–substrate lubrication film, bleb interiors, the perinuclear gap — regions where k→∞, ℓ_B→∞, and Darcy is not an approximation but simply wrong, and where the oracles are exact (6πμav, Brenner wall correction). (3) **Do not** attempt full-cell resolved DNS. (4) Any whole-cell Brinkman operator must carry the **storage + α div(v_s)** continuity, not div v = 0.

**Darcy on the PI's three wants, honestly.** Visible interior flow: **partially delivered** — Darcy gives a genuine cell-centred velocity v_f = v_s + q/φ and it is fully visualisable; but for uniform k, curl(q) = −(1/μ)∇k × ∇p = 0 identically, so **today's field is a potential flow and can never show a vortex, recirculation, or a shear layer.** That is the specific structural deficit. Volume exchange: **fully delivered**, not a Darcy deficit. Drag on filaments: **not delivered** — the only fluid→solid force is −α∇p, so a filament moving through quiescent uniform-pressure fluid feels exactly zero fluid force. Getting fluid-borne drag does **not** require resolved Stokes: the Darcy-consistent form is the Brinkman body force (μ/k)(v_f − v_s) at Darcy cost, and its coefficient is exactly what the REV can **measure**.

**The double count — exactly what must be removed in the same commit.** Nothing double-counts today only because the `ac` mechanics is a quasi-static descent with **no physical drag at all**, and `sf_implicit.py`'s `mobility_step = dt/γ` is a CFL-derived numerical mobility. ## 7. Honest risks

**Load paths that sum to zero — the enumerated list.** This is the failure class most likely to make a passing gate meaningless, and it has a *specific* form in almost every track:

1. **Bipolar minifilament** (T7) — net force is zero **by construction**, so any net-force metric is guaranteed zero and proves nothing. Mitigation: the cancellation ledger (anchor reaction ÷ Σ\|f_head\| per filament), reported per step.
2. **Isotropic osmotic traction** (T6a-V8) — a radial traction's vector sum is **exactly** zero by symmetry, so a net-force-only gate passes on a completely disconnected build. Mitigation: the anti-vacuity control that *demonstrates* the degenerate variant passing.
3. **MT aster and IF cage** (T8) — both radially symmetric, so a radial load transmits per-edge and cancels globally, exactly as the crawl traction did. Mitigation: \|Σf\| **and** Σ\|f\| reported separately; symmetric-load control on every drag gate.
4. **Closed ventral SF dipole** (T10-A4) — **verified structurally zero**: 10 FA sites in 5 exact mirror-±x pairs (`sf_population.py:481-494`), so the traction resultant vanishes independent of whether the clutch is wired, adjoint, or converged. Mitigation: gate on Σ\|f\|, the per-clutch load distribution, and a **polar (odd)** moment.
5. **Unanchored MT** (T5-N7, T8-6) — MT-pushes-nucleus with a free far end is an internal couple: Σ\|f\| large, net zero, the pair simply drifts. Mitigation: `mt_cortex_capture` or a Dirichlet MTOC is a **requirement**, not an option.
6. **Pressure force on a closed symmetric cell** (T4.7) — −α∇p is a gradient field with uniform quadrature, so its resultant over a closed shell is zero by construction. Mitigation: the per-channel positive control (each channel > 100× the measured noise floor).
7. **Global force-balance ledger** (`ledger.py:329`) — **vacuously satisfied by 0 = 0**. Mitigation: never report the residual without Σ\|traction\| and n_contributing, and the T1.4 control that shows an isotropic grip passing it.
8. **`membrane_ecm_contact` + `integrin_collagen_clutch`** on the same basal pair — repulsive and adhesive can cancel. Mitigation: at zero clutch extension the total normal force must equal the contact-only force **bitwise**.
9. **Brinkman drag under affine volume-preserving motion** (§2c) — identically zero for rigid translation, rigid rotation and uniform shear. Mitigation: a volume-preserving-shear dissipation gate, before deleting the 65.9 Pa·s channel.
10. **Protrusion push/reaction pair** (T11-P2) — net zero by construction (correctly), so polymerization alone can never move the cell and arm (ii) must show *deformation* with centroid inside the noise band.

**Tracks whose headline observable might be structurally zero.** Beyond #4 and #2 above: T6b's "wall per decade of residual reduction" has a **zero denominator** on the very configuration it was written for (both MG arms are recorded residual-**flat**: OFF flat it5→39, ON flat it10→39); T12's "committed physical seconds per wall hour" is identically **0** for every arm; T7's original v/v0→1 limit reads **0.417** at the driver's dt because the derived stall cap — a linear-stall law — governs; and T6a's obvious dt-plateau anchor is **empirically flat** (a +76% change in bound myosin moved `residual_start` by exactly zero digits and `residual_candidate` by 7e-10 relative). Each is handled above by replacing the observable, not the tolerance.

**Other ways this plan could be wrong.**

- **T1 might not converge either.** An N-owner coupled solve is the right structure, but the SF slice already fails its own 1% residual criterion at 15.5%, and adding MT (κ ~300× actin) and plectin worsens conditioning. If T1.3's (b) also stalls, the honest response is a Schwarz-block preconditioner or accepting that some transmission ratios are BLOCKED — **not** falling back to (c) and calling the result CONNECTED.
- **Bit-identity, the plan's main safety net, is precluded by 192 atomic sites.** T0.2 is placed first for exactly this reason, but if the ULP-budget fallback proves too loose to discriminate, several refactor gates lose their teeth and will need deterministic two-pass reductions (with their own cost).
- **Every number in the plan is from a suspended, non-physiological config, not the PI's baseline.** The headline probe records `N_fa_sites: 0`, `N_linc_sites: 0`, `per_region: {cortex}`, and self-labels `resting_bound_myosin_source: "TEST-native-probe NOT physiological"`, `erm_kinetics_mode: DIAGNOSTIC_HARD_THRESHOLD_NOT_PRODUCTION`, `overlap_free_cortex: false` against a default of True. The 65 GPU-years and every effort estimate will move once the adherent baseline lands.
- **T3's coarse-configuration status is inherent.** The cortex-only isolation build **is** a stripped configuration by design, and this project has been contradicted natively six times after reasoning from one. Every isolation result must be labelled isolation-scope and re-earned on the composed build.
- **The gate a broken build cannot fail.** The precedent is real. Every step here ships a named control that must be **observed** to fail, and several of those controls are **literally today's code** (T4.10 on the aliased lane; T5-N7's LINC-off bit-identity; T8-6's capture-disabled arm; T9-S3's comparative connectivity form; T10-A3's scratch-array discard) — so the teeth are demonstrated on the current build *before* it is fixed. If a control cannot be constructed for a step, treat that step as an **unwritable gate**, not a passing one.
- **Breadth accumulating faster than convergence.** Four components already sit at KERNEL_BOUND with kernels never codegen'd; `linc_connector.py` is 1,581 lines with zero callers and is not even exported. The discipline in M4–M9 is: **no new component or connector is written until its predecessor has a committed artifact.**
- **Unratified proxies silently driving a run, then reading as evidence.** `DynamicInstabilityRateCard(ratified=False)`, keratin EA = None, `FASCIN_K_CROSSLINK_PN_PER_UM = None`, `linc_per_node = 1`, `eps_rupture = 0.50` (which its own parameter gate says not to keep). Compounding: `assemble.py:1033-1036` stamps `SOURCE_GROUNDED` whenever a value is not None **without inspecting the source string**, so a run honestly supplying `MECHANISM_DEMO_DIAGNOSTIC` is recorded as source-grounded — the guard works and the ledger lies, and the ledger is what a KB harvest ingests. Mitigation: explicit `--unratified-proxy` flags, provenance required in `_require_param`, and a BLOCKED list in every artifact.
- **Stale Warp kernel cache producing byte-identical false positives** after a kernel edit — a measured project failure (an old 3-D cache once "proved" 645 invariance). Every parity, bit-identity and A/B protocol clears `~/.cache/warp/<ver>` and records the compile.
- **Scope creep into magnitude.** `RESERVOIR_STRAIN`, L_p, Π₀, σ_refl, k_erm, ρ₀, φ, k, D_c, the nucleus moduli, k_on, ρ_L, patch radius a, VIN_KDISS, the FA areal count — all unsourced or PI-GAP. The failure mode is a plausible-looking curve being read as a quantitative result. No pass criterion in this document references an absolute magnitude; parameters are swept coordinates or fitted outputs (reservoir capacity, q* = sqrt(σ/κ), the Boyle–van 't Hoff intercept b, k_ij, φ, the recovered exponents); every artifact carries `quantitative_claim_status: BLOCKED`.
- **The engine as a passenger.** Every native "engine-owned" result to date reaches the physics only because `_accumulate_all` calls into a monkeypatched adapter, and every native surface owner is a `NoOpSurfaceMechanics`. Mitigation: T0.3's manifest records the launching object and array `.ptr` per channel and **fails** when a channel was launched by the incumbent driver. Truncate this plan anywhere and the project's stated purpose is the first casualty.
