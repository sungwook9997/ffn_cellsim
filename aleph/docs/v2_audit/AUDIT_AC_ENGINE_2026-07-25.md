## 3. WHAT IS NOT WHAT IT LOOKS LIKE

Ranked by how much downstream work would be built on a false premise.

**1. The composed native cell's "accepted physical step" has no solver — and its next increment collides with the incumbent.** `solve_candidate` zeroes force arrays, runs one accumulate pass, computes head loads, returns. No integrator, so the sf_arc reject-gated position restore is trivially satisfied and `CellTransaction`'s "inner mechanical solve to convergence" is one force pass. Worse for the *next* step: it zeroes `cortex_port.force_d`, which **is** `cell.f_d`, while `_accumulate_all` also zeroes it (verified: `driver.py:144`) — so the first real relax passed as `solve` collides. **Honest label:** *device-resident force-assembly + transaction wiring demo, never stepped on CUDA.* Every other native slice does pass a real converging relax, so this defect is confined to the flagship script.

**2. A `CONNECTED` rung stamped into a committed artifact.** `ac_gate_b_cortex_motor_native.py:393` hard-codes `"evidence": "CONNECTED"` (verified), baked into the npz metadata and the rendered HTML — for a 2-participant slice where cortex is not a bound component and 1 of 32 connectors is registered. `ROLLING_ROADMAP.md` never claims CONNECTED for anything and explicitly refuses one for the interior column. **Honest label:** *CUDA_UNIT (2-participant, aliased arrays, force-accepted).* This is the only place in the tree that self-promotes a rung, and it does it in machine-readable output.

**3. Every "engine-owned" native result is delivered by monkeypatching the frozen incumbent.** `cell.myosin = _SliceMyosinAdapter(...)` and `cell.membrane = _SliceMembraneAdapter(...)` (verified). The engine's forces reach the physics only because `_accumulate_all` calls `cell.myosin.accumulate(pos, f)`. The incumbent still owns the array, the zeroing, and the inner solve. **Honest label:** *engine component as a passenger injected into the incumbent's accumulator.* **No native result yet demonstrates the engine driving a step.**

**4. The completeness and coverage gates gate nothing.** `require_complete=True` has **zero non-test call sites** (verified: every real builder passes `False`). `assert_fully_bound` checks only method-name callability. `_facade_candidate_tasks` looks up `facade_dispatch[claim.owner_type]` and checks `callable(...)` with **no `isinstance` check** (verified). Consequence: the eight canonical facade classes' own architecture validation — including `SurfaceBody`'s membrane/cortex anti-aliasing guard — has **never executed in any composed world, test or native.** **Honest label:** *a name-based manifest, not a type or capability gate.*

**5. γ = 3.7 pN/µm as "real power-stroke tension."** Crossbridge term is 0.0191; the other 3.7043 is turgor-loaded passive actin + crosslink, partitioned into "network" by construction. No t0 baseline is measured. The committed **figure banner discloses the split** — only the prose drops it. **Honest label:** *γ_total 3.72 = 0.019 crossbridge + 3.70 passive network, at an unconverged force-accepted step.*

**6. "GATE A CLOSED."** No artifact anywhere (one PNG; the three ensemble numbers exist only in prose). Produced by a bespoke fixed-iteration descent harness with geometric backtracking and no convergence test — not the driver's accepted-step path, which the *same document* records as never committing a descending candidate (0.0% position change over 3,000 iterations). The number is dominated by the **un-refined 642-vertex nucleus block** (clean actin max is 0.0356; 0.1606 is the nucleus) — the membrane was grid-refined for exactly this reason and the nucleus never was. Its own source doc says the closure is "**SURFACED to PI for ratification**"; no ratification exists. The physiological-mesh rung is 0.28 > 0.21. **Honest label:** *a static residual descent to 0.1398 at the CLAUDE.md baseline discretization — PI-surfaced, unratified, unarchived, nucleus-dominated, and not reproduced in the runtime.*

**7. membrane and cortex as two disjoint components over one array pair.** Both owners and both connector endpoints are `cell.pos_d`/`cell.f_d`. The engine **already contains the guard that rejects this** (`surface_body.py:349-353`) and the native lane bypasses it by never constructing the facade. One module contradicts itself 12 lines apart: `ERMCortexSlice.accumulate` claims "two never-merged arrays" while `build_native_surface_owner` in the same file admits "both surfaces alias one global array."

**8. The ERM load path's physical density is a mesh knob.** `erm_density_per_um2` defaults to `None`, selecting one-tether-per-vertex topology labelled `..._DIAGNOSTIC`; **no GATE-A or GATE-B script ever sets a density.** So ρ₀ = f(`membrane_subdivisions`): ~58/µm² at subdiv 6, ~927/µm² at subdiv 8, against a sourced ~100/µm². ## 6. HONEST QUALITY ASSESSMENT

**Verdict: strong physics and unusually strong epistemics, carrying a documentation layer that is roughly one rung optimistic across the board and an artifact layer that went missing precisely at the flagship results. That is a process defect, not a competence defect, and items 0 and 7 fix most of it in under a day.**

### Where the engineering is genuinely strong

- **Adversarial self-refutation is a live habit, not a slogan.** `GATE_A §9` discovered that its own §§2–8 had measured raw `max|F|` instead of the constrained `max|PF|`, quantified the split (5.7892 = |Jᵀλ| 4.4820 + |PF| 1.7399, constraint error 1.1e-16), FD-verified the corrected rank-one tangent to 1e-10, and **demoted its own prior sections to "raw-|F| history" rather than quietly editing numbers.** The fine-mesh grid-dependent-steric hypothesis was killed by the team's own `--no-steric` production test and written up in a CORRECTION section. `outputs/ac/gate_b_sf_motor/REPORT.md` **withdraws** a previously reported "T → 1.92 pN PASS" as an unconverged transient and refuses to quote magnitudes at 15.5% residual. `RESTING_SETPOINT_SOURCING` retracts three of its own conclusions in a CORRECTIONS block. `AC_ENGINE_COMPLETION_ROADMAP` retracts the "one PI-GAP closes the gate" framing one line after stating it. Two thousand lines of coarse/multigrid solver were built, run at **full native**, refuted, and kept flagged-off with the refutation recorded. This is rarer than good code and it is what made this audit tractable.
- **Honest scaffold labelling at the code layer, consistently.** In nearly every case the audit found an overclaim, the *executable* layer had already stated its tier correctly and the drift was introduced by a summary. `ac_gate_b_cortex_motor_native.py`'s docstring pre-discloses the force-accept, the γ_source/γ_network split, and "NOT the physiological ~100s pN/µm magnitude." `_excluded_facade_noop`: "It launches nothing." `sf_population.py`: "NOT the native SF inventory." `test_ecm_forces.py`: "CPU-safe; native forbidden ... two independent proofs, both CUDA-free." `NATIVE_COMPOSITION_SCOPE_2026-07-25.md` was committed **27 minutes before** the composed-native commit specifically to state that the components do not run together and that the builder's only caller feeds CPU census doubles. That localisation is a gift: the fix is docs discipline in one or two files, not a code-integrity project.
- **Required-no-default parameter guards are implemented, and three independent verifiers tried to break them and failed.** `_require_param` + `_GAP_PARAMS` with the catch-slip four becoming mandatory exactly when `CATCH_SLIP` is selected; ERM rejecting all five magnitudes at construction; `NonlinearCableCard` validating EA and crossover with no defaults; `DynamicInstabilityRateCard` shipping `ratified=False` so an unratified proxy cannot silently drive a run; `FASCIN_K_CROSSLINK_PN_PER_UM = None` explicitly forbidding inheritance of the filamin value; `SourceGatedLincKinetics.propose_candidate` **raising rather than inventing a hazard law**; `CellState` structurally rejecting any rate whose target is force/tension/count/topology; `aleph/components/weave/presets.py` — "a pure assembler — it CHOOSES nothing." This is the anti-magic-number rule as executable code, and it is the single best-engineered layer in the tree.
- **Measurement over inference, where it counts.** The `.ptr` print proving split ownership. The exact-zero tension control at zero bound heads (5.55e-14). The bit-exact reject-restore record (`binding_soa_restored`, both `position_bit_restored`, `clock_did_not_advance`). A **non-vacuous** profiler gate requiring hot D2H == 0 **and** positive control > 0. `COURANT_TARGET = 0.5` derived from the explicit-Euler limit with a Gershgorin λ_max bound and explicitly labelled "NOT a fitted constant."
- **Provenance disclosure at the constant, not in a doc.** `k_erm` states the primary paper's 2.2 pN/nm, the dissertation N≈1 re-analysis that yields 4.6, and that KB registration is PENDING. The "Salbreux band" comment declares itself a misnomer and names the real HeLa anchor. The capture-radius reconciliation distinguishes the physiological 0.210 reach from the 0.6 diagnostic knob with a geometric invariance argument. Two dimensions initially filed these as violations; both verifiers reclassified them as exemplary.
- **PI-gated things were genuinely not done autonomously.** No `omit_mask` in `driver.py`. The composed-native commit touched only engine/scripts/tests and says "`aleph/components/incumbent/driver.py` UNTOUCHED." `--balance-gate` **refuses with a `SystemExit`** rather than faking a predicate. Restraint at exactly the right boundary.
- **Real build-time invariants** rather than comments: exact-once dispatch rejecting duplicate claims and duplicate (runtime, phase); composite-joint dedup in two independent places so the FA series joint cannot become two springs; `ConnectorContract` rejecting one-way loads and kinetic-without-commit-on-accept.

### Where it is weak or risky — systemic, not nits

- **Documentation outruns evidence, in one direction, systematically.** Six of the audit's severest surviving findings are summary-layer: "GATE A CLOSED" (unratified, unarchived, nucleus-dominated); "composed native cell ... gbook gate PASS ... full native population" against its own commit's "NOT yet native-run"; "22 CUDA tests" for 6+16; "native-runs 40 steps" with no artifact; "seam CUDA_UNIT" for a test file with **zero** CUDA-gated tests; "real power-stroke tension" for a 0.5%-crossbridge number. The consistent shape is: **the script is more careful than the paraphrase of the script.** Because `SUCCESSOR_HANDOFF` is what a fresh session boots from, the rounding is load-bearing, and one of its inversions is 180° from the commit body.
- **Evidence hygiene collapsed exactly at the flagship.** Three of five GATE-B drivers persist nothing; GATE A has one PNG and no data; the two npz carrying the dynamic numbers are gitignored by a policy whose stated substitute (JSON) was never produced. Meanwhile `outputs/ac/implicit/` holds ~20 committed native artifacts for far less consequential solver probes. **The discipline exists in the project's own habits; it lapsed on the results that matter most.** A successor cannot even reconstruct the GATE-A closure config from disk — the only committed resting artifacts are the *opposite* configuration.
- **Thresholds and scopes set after the measurement.** `0.21 pN` has no derivation and no definition site (~12 hand-copied literals). GATE A closed by *redefining the baseline* (dropping the myosin seed) — defensible under CLAUDE.md's own physiological-baseline prescription, self-surfaced for ratification, and then headlined as closed without it. The closure number is the un-refined 642-vertex nucleus block, when the membrane had been grid-refined for precisely that reason. The fine-mesh "grid refinement" series (0.14 / 0.21 / 3.42) changes crosslink density 20→40 *simultaneously* with seg 0.5→0.075, so it cannot support a grid-invariance argument as written.
- **Breadth accumulated faster than convergence.** 13 components / 32 connectors / ~55k LOC, with: 4 components at KERNEL_BOUND whose kernels have never been codegen'd; 19 of 32 connectors declared-only; a 1,581-line 7-kernel LINC module with zero callers, not even exported; a `CHEMICAL_FLUX` family no connector uses; 518 lines of unwired mean-field ERM biology with no design memo. Simultaneously, **not one native run yet has (a) an integrator inside the engine's own step, (b) a physical acceptance predicate, or (c) a converged residual.** The composed cell was committed as a "FIRST" before its `solve` had a solver.
- **Aliased ownership was deferred and is now load-bearing.** Both connectors with native-population evidence run on one array pair; the engine already contains the guard that rejects it, bypassed by never constructing the facade; the ERM SoA is borrowed from the incumbent and "transferred" by setting `membrane.n_erm = 0`. Every subsequent "component owner" built on this pattern inherits it, and the composed lane already reproduces it.
- **Every guard that would have caught all of this is scoped one notch too narrow.** `require_complete=True`: zero non-test callers. `assert_fully_bound`: name-callability only. `_facade_candidate_tasks`: no type check — which is *why* five no-ops and eight spies satisfy "all eight facades present." D2H guard: four named functions. CPU-launch guard: `tests/` only. CUDA-ordinal ban: `ac/` only. `PopulationLedger`: constant blocks, and not invoked in 3 of 5 slices. Ladder: no machine representation. Freeze: nothing at all. **The narrowness of the guards is the mechanism, not a coincidence.**
- **A parameter split-brain the queue does not mention.** `ac/engine` refuses to default what `ac/cell` defaults, for the same physical names — and every banked number came through `ac/cell`. The PI-GAP queue over-declares two already-sourced gaps (S1, cortical minifilament density), omits ~10 declared yaml GAPs, omits the cortex mesh triple its own companion audit ranked worst, omits the ERM/LINC density-vs-grid defect, and lists four values as "awaiting PI" that PI decided on 2026-07-21 and that are blocked only on autonomous SE registration.

### The two habits

**Keep, above everything else: withdrawing your own result the moment its metric or convergence is wrong — in writing, with the number that refutes it.** `GATE_A §9`; the fine-mesh CORRECTION; the sf_motor withdrawal and its 15.5%-residual refusal to quote a magnitude; the natively-refuted coarse operators kept flagged-off with the refutation recorded; `RESTING_SETPOINT_SOURCING`'s self-retractions. This habit is worth more than any of the code, and it is why this audit could be precise rather than speculative.

**Stop: promoting a rung in a summary or in an artifact's own metadata on the strength of a mechanism demo.** Concretely — stop writing an evidence state into a driver's output (`"evidence": "CONNECTED"` at `ac_gate_b_cortex_motor_native.py:393`, baked into a committed npz and a rendered HTML), and stop letting `ROLLING_ROADMAP` / `SUCCESSOR_HANDOFF` paraphrase a script whose own docstring is more careful than the paraphrase. Make it mechanical: **no rung claim anywhere without a committed artifact whose fields prove it.** That single rule is why item 0 comes first, and it is the only thing standing between this engine and a genuinely trustworthy CONNECTED.
