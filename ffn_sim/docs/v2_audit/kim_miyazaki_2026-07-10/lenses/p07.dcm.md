# DCM lens — p07

**Paper:** Wisdom, Indana, Chou, Desai, Kim, Chaudhuri (2020) *Matrix Biology* 85–86:94–111 —
"Covalent cross-linking of basement membrane-like matrices physically restricts invasive protrusions
in breast cancer cells." DOI 10.1016/j.matbio.2019.05.006.

**One-line framing for DCM.** This is fundamentally an FF/ECM-network paper (Taeyoon-Kim Brownian-dynamics
cross-linked fiber matrix with Bell slip-bond cross-linkers). Its DCM value is *conceptual and observable-level*,
not a physics drop-in: (1) it demonstrates that **permanent (plastic) deformation retention is a bond-turnover
phenomenon governed by an off-rate + rebind**, distinct from stiffness — the exact conceptual template DCM's
open *loose→compact aggregate-compaction RATE* problem needs (currently drag-limited; real 24–48 h needs
cadherin T1 rearrangement, not aggregate-σ); (2) it gives a clean **confinement / protrusion-into-environment
scenario** with a crude serial-wall membrane whose edge-length-window + localized radial protrusive force map
onto DCM's surface mesh; (3) it hands over ready **shape observables** (circularity, strain metric). Do **not**
import the fiber/cross-linker matrix into DCM — that is FF's lens. Below is only what advances the *cell-surface*
DCM engine at single-cell / N≈400 scale.

---

## 1. MECHANISMS to adopt

### M1 — Cadherin junction PLASTICITY = Bell off-rate + rebind → permanent aggregate deformation (highest value)
- **DCM module:** cell-cell contact / cadherin catch-bond junction (Rakshit KU-4.2), the `T1 rearrangement (open)`
  compaction-rate problem.
- **Change:** The paper's central mechanistic result (Fig. 6, Eq. 1) is that a matrix retains **permanent**
  deformation *only if* its cross-links can **unbind under load AND rebind in the new configuration** — i.e.
  plasticity is a molecular-rearrangement (turnover) property, governed by the zero-force off-rate `k0,u` and
  force sensitivity `λu`, and is **decoupled from stiffness** (initial modulus flat across the whole `k0,u`/`λu`
  sweep, Fig. 6d,f). Low turnover → deformation elastically recovers; high turnover → deformation is retained.
- **Why it beats DCM-now:** DCM's aggregate compaction currently gets its "permanence" from an *aggregate surface
  tension σ pulling against elastic drag* — the memory note records this reproduces only the mechanical **end-state**,
  and RATE/timescale citations are *forbidden* because ~100 s = drag-limited σ-pull, whereas real compaction is
  24–48 h and cadherin-turnover-driven (freezing the junction leaves σ-compaction unchanged → σ is junction-independent).
  This paper says exactly what the missing driver is: **a load-dependent bond off-rate with rebind makes deformation
  PLASTIC (permanently retained) rather than elastic.** Porting a Bell off-rate + rebind onto the cadherin cluster —
  so that a stretched junction unbinds and re-forms shorter as neighbors approach — gives DCM T1 rearrangement from a
  *mechanistic bond process*, not a lumped σ. This is the fine-grained option the hard rule demands.
- **Concretely:** junction cluster bonds already have Rakshit catch-bond kinetics; add the **rebind** leg so that after
  a load-driven detachment the junction re-anneals at the current (compacted) separation. The plastic-strain fraction
  then *emerges* from off-rate·rebind balance exactly as Fig. 6d/f shows permanent-strain rising with `k0,u`, without
  any σ tuned to a target.

### M2 — Confinement / protrusion-into-environment scenario as a DCM shape driver
- **DCM module:** node-face penalty contact (Ericson) + membrane; the listed-open `confinement response`.
- **Change:** Reproduce the paper's cell-in-matrix confinement: a DCM cell surrounded by an environment whose
  *ability to permanently yield* (not its stiffness) sets whether a protrusion extends. Long-thin protrusion emerges
  in a **high-turnover (plastic)** surround; blunt-round cell in a **low-turnover (elastic)** surround (Fig. 7a,b).
- **Why it beats DCM-now:** DCM has node-face contact but no scenario that tests confinement-driven shape as a function
  of *environment yield* vs stiffness. This gives a physiologically-anchored confinement BC and a decisive test that
  DCM's contact + membrane elasticity respond to environment **plasticity** the right way.

### M3 — Membrane edge length-window constraint (extensional cap/floor)
- **DCM module:** membrane area-elasticity K_A / edge springs + remesh.
- **Change:** The model constrains every membrane element to a hard length window **[4 nm, 800 nm]** (initial 400 nm)
  via extensional forces — a fine-grained protrusion-enabling rule: pushed nodes shorten local elements, letting force
  *concentrate* (40 weak nodes → effective ~1 nN tip). DCM's remesh already splits/merges faces; adopting an explicit
  **edge-length window as an elastic penalty** (not just a remesh trigger) lets a protrusion locally refine the mesh and
  concentrate cortical/protrusive force at a tip without a magic remesh threshold.
- **Why:** grid-invariant (window is physical lengths), mechanistic (extensional spring), and directly supports the
  bleb/protrusion open items.

### M4 — Localized radial protrusive-force patch (dynamic, self-concentrating)
- **DCM module:** protrusion / membrane-cortex coupling force injection.
- **Change:** Apply a **constant outward force on a localized patch of surface nodes** (paper: 25 pN × 40 nodes on the
  right hemisphere, patch free to change size/shape as the surface deforms) rather than a global pressure. The patch
  self-concentrates as elements shorten. This is a clean template for a DCM invadopodium/bleb driver and for asymmetric
  (durotaxis-precursor) protrusion.

## 2. EQUATIONS to port to the surface-mesh / continuum level

### Eq. 1 — Bell slip-bond off-rate (→ cadherin junction plasticity, M1)
```
        ⎧ k0,u · exp( λu · |F_s| / (kB·T) )   if the junction bond is in TENSION (r ≥ r0)
  k_u = ⎨
        ⎩ k0,u                                 if in COMPRESSION (r < r0)
```
Symbol → DCM state map:
- `k_u` → per-junction-bond **detachment rate** in the cadherin cluster updater (already Rakshit; this is the slip leg —
  keep the catch leg from Rakshit, add this as the high-force slip branch or as the ECM-facing junction if modeled).
- `k0,u` → zero-load off-rate config field of the junction bond (see §3).
- `λu` → junction force-sensitivity length (§3).
- `F_s` → the current spring/tension force on the junction bond = penalty/edge force DCM already computes between the
  two contacting cell faces (node-face contact force magnitude).
- `r0` → junction equilibrium separation (the bond rest length).
- **Plasticity emerges from Eq. 1 + a rebind event** at the deformed separation; no closed-form plastic-strain law is
  fit — it is measured (see §5).

### Eq. 2 — Cell-boundary strain metric (→ DCM shape/deformation observable)
```
  ε = ( d − r0,m ) / ( 2 · r0,m )
```
- `d` → for DCM: max radial distance from cell centroid to the **environment/contact boundary** sampled over solid-angle
  bins (the paper uses 120 fiber nodes at 3° in 2D; in 3D use the farthest contacting environment node per angular bin).
- `r0,m` → initial cell radius (7.5 µm for MCF7; paper used 10 µm).
- Use as the DCM "how far did the cell push/retain into its surround" observable for confinement runs.

### Eq. 3 — Incompressible modulus conversion (validation bookkeeping)
```
  E = 2(1+ν)·G* = 3·G*   (ν = 0.5),   G* = sqrt(G'² + G''²)
```
- Only for comparing DCM effective stiffness / environment stiffness to the paper's reported `E` values; ν=0.5 matches
  DCM's enclosed-volume (near-incompressible cytoplasm) assumption.

### Eq. 4 — Circularity (→ 3D DCM shape index)
```
  circularity = 4π · area / perimeter²     (2D; 1 = circle)
```
- Port to 3D as the **shape index / sphericity** `Ψ = π^{1/3}(6V)^{2/3} / A` (=1 for a sphere) computed from the DCM
  surface mesh (V = enclosed volume, A = mesh surface area). Low Ψ = protrusive/elongated. This is the natural 3D
  analog of the paper's headline morphology readout.

## 4. GEOMETRY / PROTOCOL to reproduce as DCM scenarios

### P1 — Creep–recovery of the *cell environment* (plasticity calibration, no cell)
- Domain 40×40×1 µm, PBC in x,y (paper 2D). For DCM: a slab/box of the contact-environment.
- Apply constant shear stress **100 Pa for 1 h** (top boundary +x displacement, feedback-adjusted to hold stress),
  then **0 Pa for ~2 h** recovery.
- **Observable:** permanent (plastic) strain vs. off-rate/λ (see §5). This calibrates the M1 turnover before wiring
  the junction into an aggregate.

### P2 — Single-cell protrusion into a tunable-plasticity surround (headline scenario)
- Domain 100×60×1 µm (paper 2D); DCM: single MCF7 cell R=7.5 µm centered in a deformable environment.
- Apply **1 nN total** as a localized radial patch (25 pN × 40 nodes, M4) for **1 h**, then unload, recover **0.3 h**.
- Run at **two surround conditions**: high-turnover/plastic vs low-turnover/elastic (M1 off-rate high vs low).
- **Expected DCM outcome (qualitative match target):** long-thin protrusion + retained deformation in the plastic
  surround; blunt-round cell + recovered deformation in the elastic surround.

### P3 — Aggregate compaction with plastic junctions (the real payoff, N≈400)
- Take the DCM N≈400 aggregate; give the cadherin junctions the M1 Bell off-rate + rebind.
- **Test:** does loose→compact now proceed as a *turnover-limited plastic* densification (deformation retained as
  neighbors approach), and is the RATE governed by junction off-rate (not by an aggregate-σ pull against elastic drag)?
- This is the decisive experiment that would let DCM legitimately talk about a compaction *timescale* (currently
  forbidden) — because the memory-flagged missing ingredient (bond-turnover-driven plasticity) would now be present.

### P4 — Native + full-compartment mandate (HARD rule compliance)
- P2/P3 conclusions are only valid on the **native, full-compartment** DCM cell (all compartments physiological-baseline
  ON, from-resting). Any coarse/stripped run is a non-authoritative smoke test and must be reconfirmed on the native cell.

**Key decoupling to reproduce:** stiffness ⟂ plasticity — DCM must show that changing junction/environment
**turnover** moves permanent-strain a lot while leaving **initial modulus** essentially unchanged. If a DCM change
moves both together, the mechanism is wrong.

## 6. RISKS / caveats

1. **Cell type & regime mismatch.** MDA-MB-231 (mesenchymal, protease-independent invadopodia) in a purified in-vitro
   BM-mimic, not living MCF7 (epithelial). The *physics lesson* (plasticity = bond turnover, decoupled from stiffness)
   transfers; the specific cell phenotype does not. Keep DCM at MCF7 R=7.5 µm and physiological baseline — do not adopt
   the invadopodium as a default MCF7 behavior.

2. **2D / quasi-2D model.** The Kim model is a 40×40×1 or 100×60×1 µm slab with a **serial-wall (1D chain) membrane** —
   crude vs DCM's closed 3D triangulated surface. Circularity (2D) → must be reimplemented as 3D shape index/sphericity
   (Eq. 4 note). The strain metric (Eq. 2) must be re-binned over solid angle in 3D. Do not import the 2D geometry;
   import only the force laws and observables.

3. **The `k*0,u`, `λu` values are ECM cross-linker constants, not cadherin.** Using them verbatim in a cadherin junction
   would be a magic-number substitution. They are order-of-magnitude / functional-form anchors only; the physiological
   cadherin off-rate stays Rakshit KU-4.2. Surface to PI before any KB registration (this is FF's parameter to own, not
   DCM's — the FF lens should carry the ECM cross-linker `k_off0`/λ).

4. **Environment stiffness (100 Pa rBM / 2 kPa IPN) is in-vitro biomaterial, not in-vivo tissue.** The paper itself
   notes rBM is an order of magnitude softer than real tumor tissue. Use the 2 kPa IPN (tumor-like) as the
   physiologically-defensible surround; treat 100 Pa rBM as a soft-limit control, not the physiological baseline.

5. **"Plasticity" here is an *environment* property; DCM's payoff (M1/P3) reuses the same math for *cell-cell junctions*.**
   That reuse is a hypothesis-level transfer (both are load-dependent bond turnover with rebind), not something the paper
   directly validates for cadherin. Present P3 as a mechanistic proposal to be validated on the native aggregate, and do
   **not** cite this paper as evidence for a cadherin compaction *rate* — it evidences the *form* (turnover → plastic
   retention, decoupled from stiffness), which is what the open problem was missing.

6. **No timestep / spring-constant values in the main text** (Supplementary Table 2, not in file). The extensional/bending
   spring constants for the membrane wall are unavailable here; if M3 needs them, derive from DCM's own K_A/κ_m at
   physiological values rather than borrowing — the paper gives geometry (length window) but not stiffness.
