# FF lens — p39

**Paper:** Slater, Li, Indana, Xie, Chaudhuri & Kim, "Transient mechanical interactions between cells and viscoelastic extracellular matrix," *Soft Matter* 2021, 17, 10274–10285 (DOI 10.1039/d0sm01911a). Taeyoon-Kim agent-based Langevin fiber-network + Chaudhuri 3T3/collagen verification.

**One-line relevance to FF:** This is a Cytosim-class fine-grained *ECM* fiber network — every collagen fiber = serially-connected bending+stretching cylindrical elements, every inter-fiber cross-link is an *explicit transient* bond with a **Bell's-law force-dependent off-rate**. It is the FF cross-linker / Bell-Evans mechanism, but on the **collagen/ECM side** (the FF `collagen-Mikado` / traction-recruitment substrate the project already builds), and it supplies (a) the ECM cross-link turnover kinetics that make matrix viscoelasticity/viscoplasticity **emergent** (not a lumped modulus), and (b) a clean analytic validation ladder (σ∝r⁻¹, relaxation-vs-connectivity). The *cell* side of this paper is a LUMPED zero-rest-length cortex — **do not adopt it**; FF's native 38000-filament cortex is strictly finer-grained and supersedes it.

---

## 1. Mechanisms to adopt

Ranked by FF payoff. Everything here targets the FF **ECM/collagen substrate** module (`ff_crawl_on_substrate`, collagen-Mikado network) and its **cross-linker** submodule — NOT the cortex.

**(A) ECM collagen cross-links become EXPLICIT TRANSIENT slip-bonds with Bell off-rate — [strong, primary lever].**
FF's current collagen-Mikado / ECM substrate treats inter-fiber junctions as (largely) permanent geometric links; the FF Bell-Evans machinery lives on the *cortex* cross-linkers (α-actinin/filamin). This paper says the physiologically correct ECM is a network whose junctions **turn over** under load: `k_ub = k_ub,0·exp(x_ub·|F|/k_BT)` for tensioned links. Adopt this SAME Bell-Evans updater FF already has for cortex, instantiated on the collagen inter-fiber cross-links. Why it beats current FF: matrix **stress relaxation, creep and plastic (irreversible) remodeling all EMERGE mechanistically** from bond turnover instead of being absent (permanent links) or lumped into a viscoelastic modulus. Directly unblocks "network contraction & stress relaxation" and "confinement-driven self-organization" open items on the ECM side.

**(B) Emergent viscoplasticity / irreversibility from load-biased unbinding — [strong].**
The paper's headline mechanism: because tensioned cross-links unbind preferentially (slip bond) and rebind in the *deformed* configuration, matrix deformation is **mostly irreversible** — remove the cell and fibers barely retract (Fig S7). This is a free, physically-correct plasticity channel for FF's ECM: no plastic constitutive law needed; register it as an emergent observable. Beats any lumped viscoplastic dashpot because it is grain-resolved (each bond is a particle/bond in FF already).

**(C) Load-sharing sets the effective turnover rate — connectivity-gated relaxation — [medium, conceptual].**
Key finding: higher fiber concentration `C_f` or cross-link density `R_xl` → more links share a load → each bears less force → slower Bell unbinding → higher, more sustained, longer-range stress. FF should expose `R_xl` (cross-links per fiber-length) and `C_f` as first-class ECM knobs and verify the monotone connectivity→relaxation-rate coupling. This is the ECM analogue of the DCM cadherin **load-sharing cluster** the project already built (memory: project-dcm-cadherin-cluster-redesign) — same physics, transplanted to collagen.

**(D) Poroelastic-like elastic/viscous split even at zero unbinding — [medium, guardrail].**
Even with `k_ub,0 = 0` (no turnover), stress still relaxed >50% (Fig 5A) — a poroelastic/network-rearrangement channel independent of bond kinetics. Adopt as a **sanity guardrail**: when FF benchmarks ECM relaxation, do NOT attribute all relaxation to Bell turnover; a large fraction is elastic network re-equilibration. Prevents over-tuning `k_ub,0` to a target (would violate the no-fitting rule).

**(E) Buckling-orientation readout: tensed fibers radial, buckled fibers circumferential — [low/medium, validation-oriented].**
Under a central contractile load, fibers with end-to-end ratio >1 orient radially (~0°) and bear tension; ratio <1 buckle circumferentially (~90°). FF already has bending κ per fiber, so buckling emerges — this gives the FF ECM a concrete symmetry-breaking observable ("buckling/condensation" open item) and an orientation-field validation target.

**NOT adopted (explicitly):** the cell/cortex model. The paper's cortex is a lumped ring of **zero-rest-length contractile springs** (`U = ½k_s,c·r²`, always contractile) with **permanent FA-like harmonic links** to fibers. Both are proxy/lumped mechanisms that FF's native actomyosin cortex (Stam–Hocky minifilaments + Hill f-v) and motor-clutch catch-bond adhesions already beat. Using them would violate the fine-grained-over-lumped hard rule. Keep only the ECM network + its cross-link kinetics.

## 2. Force laws / kinetic schemes to port

**(2.1) Bell slip-bond off-rate for ECM cross-links (Eq. 2 of paper) — PORT to FF ECM cross-linker updater:**
```
k_ub = k_ub,0 · exp( x_ub · |F_s,xl| / (k_B T) )     if  r ≥ r_0,xl   (tensioned → slip)
k_ub = k_ub,0                                          if  r <  r_0,xl   (compressed → baseline)
```
Symbol → FF state map:
- `k_ub,0`  → `ecm_xl.k_off0` (zero-force off-rate of a collagen inter-fiber cross-link)
- `x_ub`    → `ecm_xl.x_beta` (Bell force-sensitivity length, meters)
- `|F_s,xl|`→ magnitude of the harmonic spring force on the cross-link bond = `k_s,xl·(r − r_0,xl)`, computed from current FF bond extension (only the TENSILE branch accelerates; compression stays at baseline — note this is a **one-sided** slip bond, unlike a symmetric Bell)
- `k_B T`   → thermal energy, `4.1e-21 J` at 300 K (already in FF)
- `r_0,xl`  → cross-link equilibrium/rest length

Implementation note: FF's existing cortex Bell-Evans updater is `k_off = k_off0·exp(F/F_b)`; identical form with `F_b ≡ k_BT/x_ub`. So `F_b = 4.1e-21 / 1.0e-10 = 4.1e-11 N = 41 pN` for the paper's ECM cross-link — reuse the same kernel, just a distinct parameter set for the ECM bond population. **Add the compression clamp** (`r<r_0` → baseline rate) if not already present; that one-sidedness is what makes buckled regions retain connectivity.

**(2.2) Cross-link binding scheme — PORT as ECM re-binding rule:**
Cross-linkers bind to sites spaced **every 100 nm** along fiber elements, **with no contact-angle preference** (isotropic binding). Map: FF ECM re-binding samples candidate partner-fiber sites on a 100-nm lattice within a capture radius `r_0,xl`, no angular gating. Combined with (2.1) this closes the bind↔unbind turnover loop that generates viscoelasticity.

**(2.3) FA / fiber–cortex link (Eq. 1) — DO NOT port as-is (lumped); note only for interface:**
```
U_s,fc = ½ · k_s,fc · (r_fc − r_0,fc)²    (permanent harmonic)
```
FF's cell→ECM traction interface should stay motor-clutch / integrin catch-bond (finer-grained). Keep Eq. 1 only as a fallback/oracle for a *passive* tether stiffness cross-check, not as the runtime adhesion.

**(2.4) Fiber assembly kinetics — PORT as ECM build protocol (see §4):**
nucleation (appearance of one element) + polymerization (element addition at BOTH ends) over the first 200 s to reach mean fiber length ≈10 µm. FF already has barbed-end growth for cortex; reuse a two-ended growth variant for collagen fiber assembly.

**(2.5) Stress diagnostic (implied Eq.) — PORT as FF ECM observable:**
`σ_radial(r) = [Σ radial component of chain spring forces crossing cylinder radius r] / (lateral area ∝ r)`. In a 2-D/quasi-2-D slab, full transmission ⇒ **σ ∝ r⁻¹**; in 3-D ⇒ **σ ∝ r⁻²** (Ronceray 2016, ref 39). Use the exponent as the transmission diagnostic.

## 4. Network architecture / protocol to reproduce (FF scenario)

**Scenario "ECM-VE-remodel" — single contractile cell in a transient-cross-linked collagen disc.**
1. **Domain:** cylindrical slab, radius 100 µm, thickness 1 µm (quasi-2-D) for the r⁻¹ diagnostic; OR use FF's native 3-D collagen block and switch the diagnostic to r⁻². Cell centered.
2. **Cell:** at the FF end this is the **native full cell** (`--cortex-fil 38000 --from-resting --microtubules`, MCF7 R=7.5 µm) — its actomyosin cortex supplies contraction endogenously via Stam–Hocky minifilaments + Hill f-v. (The paper's zero-rest-length ring is only a stand-in; FF does it mechanistically.)
3. **ECM build (0–200 s):** nucleate collagen fiber elements, polymerize at both ends to mean length ≈10 µm; form transient inter-fiber cross-links on the 100-nm site lattice with Bell off-rate (§2.1); form cell→ECM traction couplings (FF motor-clutch/integrin catch-bonds, not the paper's permanent FA harmonic).
4. **Contraction phase (t>200 s, ~1 h sim):** let native myosin contract the cortex; measure σ(r,t), fiber displacement, net local deformation, non-uniformity, tensed/bent orientation.
5. **Sweeps:** `C_f` (×0.5,1,2), `R_xl` (×0.125…4), `k_ub,0` (×0,1,10,100), and — replacing the paper's `k_s,c` sweep — a **native myosin activity** sweep (duty ratio / minifilament density), which is the fine-grained way to vary contraction.
6. **Irreversibility test:** at final frame, delete the cell, reload the tensed ECM, measure outward fiber retraction vs the inward contraction displacement → quantify plastic fraction.

This scenario extends the project's existing FF crawl-on-substrate / collagen-recruitment work (memory: project-ff-crawl-mechanism, project-ff-active-movement-pieces) from a static/geometric ECM to a **turning-over viscoelastic ECM**.

## 5. Validation targets for FF observables

Reproduce these (qualitative trends + the numeric anchors) on the FF ECM scenario:

- **Stress spatial decay exponent:** σ ∝ **r⁻¹** in quasi-2-D slab (σ ∝ **r⁻²** in 3-D) once stress reaches the boundary; only high-connectivity / strong-contraction cases match — use as the transmission diagnostic. (Figs 2C, 3C, 4A, 5B/C insets.)
- **Peak stress ∝ contraction strength**, up to **≈55–60 Pa** at r≈20 µm for strongest contraction; ≈5–10 Pa for weakest (×0.1). Peak is **independent of `k_ub,0`** (stress peaks before links unbind). (Figs 2A, 5A.)
- **Relaxation vs fiber conc.:** 2-fold-low `C_f` → **≈80% stress drop in 10 min**; 2-fold-high `C_f` → **only ≈20% drop in 1 h**. (Fig 3A.)
- **Relaxation vs cross-link density:** relaxation rate ∝ `R_xl⁻¹`; at `R_xl/R* = 0.5` → **>90% drop at 1 h**; peak stress ∝ `R_xl`. (Fig 4A–C.)
- **Poroelastic floor:** even at `k_ub,0 = 0` (no turnover) → **>50% relaxation** persists (elastic/viscous network split). (Fig 5A.) — guardrail, not a fit target.
- **Deformation optimum:** net local deformation near membrane peaks at **intermediate connectivity** `R_xl/R* = 0.25` (too low = can't pull; too high = resists). Max fiber displacement **≈5 µm** near membrane; net deformation **≈1–2.5 µm**. (Figs 4F, 2F.)
- **Non-uniformity (SD/mean of displacement):** ranges **≈0.1–1.0**; rises with r, with low `C_f`, low `R_xl`, high `k_ub,0`. (Figs 2G–5G.)
- **Fiber orientation:** tensed (end-to-end ratio >1) ≈ **0° radial**; buckled (<1) ≈ **90° circumferential**. (Fig S1G/H.)
- **Irreversibility:** matrix deformation mostly plastic — retraction ≪ inward displacement on cell removal; reversible fraction rises with `C_f`, `R_xl`, and slower unbinding. (Fig S7.)
- **In-vitro cross-checks (3T3/collagen, qualitative):** remodeling decreases 1→5 mg mL⁻¹ collagen; tTG covalent cross-linking (500 µg mL⁻¹) reduces remodeling; myosin inhibition (ML-7 25 µM, blebbistatin 10 µM) drastically reduces it; low-density gels remodel non-uniformly; timescale grows over 24 h. (Fig 6.)

## 6. Risks / caveats

- **In-vitro purified collagen ≠ living cortex.** These constants (`k_ub,0=1e-5 s⁻¹`, `x_ub=1e-10 m`, `F_b≈41 pN`, 100-nm spacing, ~10-µm fibers) belong to the **ECM/collagen side ONLY**. Do NOT overwrite FF's cortical cross-linker constants (α-actinin `k_off0=0.066 s⁻¹` Ferrer 2008, filamin) with them — they are ~6600× slower and describe fibril–fibril bonds, a different protein population. Register as a separate `ecm_xl` parameter set.
- **One-sided slip bond, not catch bond.** Eq. 2 accelerates only under tension and clamps to baseline under compression — it is a pure slip bond. This is fine for weak collagen cross-links but do NOT let it leak into the cell adhesion / cadherin path, where the project mandate is **catch bonds** (Rakshit KU-4.2; memory: feedback-junction-switch-fine-grained). Keep ECM-slip and adhesion-catch distinct.
- **Lumped cortex must be discarded, not imported.** The paper's zero-rest-length contractile ring + permanent FA harmonic links are lumped proxies. Importing them would violate the fine-grained-over-lumped hard rule and regress FF below its native cortex. Use only the ECM network + cross-link kinetics; drive contraction from FF native myosin.
- **2.5-D geometry vs FF native 3-D.** The σ∝r⁻¹ result is a **geometry artifact** of the 1-µm slab (lateral area ∝ r). At FF native 3-D scale the correct exponent is **r⁻²** (Ronceray 2016). Do not "validate" against r⁻¹ in a 3-D FF run — switch the diagnostic. Per the native-scale HARD rule, any conclusion must come from the full 3-D native cell, not a thin coarse slab.
- **ESI-gated absolutes.** Absolute `k_s,c*, C_f*, R_xl*, k_s,fc, r_0,xl, κ_b, ζ, Δt` are in ESI Table S1 (absent here). Sweeps are *relative*; do not KB-register absolute ECM stiffness/density from this PDF — retrieve ESI or cross-anchor to Nam 2021 (ref 45) first.
- **No fitting to relaxation curves.** The >50% zero-turnover relaxation floor (poroelastic) means matrix relaxation is NOT solely a `k_ub,0` knob. Reproduce the *emergent* relaxation from independently-sourced constants; never tune `k_ub,0`/`x_ub` to hit the 80%/20%/90% numbers (that would violate no-fitting + no-gate-loosening).
- **Species/cell-type:** validation is mouse 3T3 fibroblast (strongly contractile) in collagen-I; FF target is MCF7. Trends transfer; absolute stresses/remodeling extents do not — treat Fig 6 numbers as directional overlay only.
