# DCM lens — p31

**Paper:** Slater, Sciortino, Bausch, Kim — "Cluster formation and phase separation driven by mobile myosin motors in the motility assay." *Phys. Rev. Research* **7**, 013312 (2025). DOI 10.1103/PhysRevResearch.7.013312.

**One-line verdict for DCM:** LOW relevance. This is a flat quasi-2D (50×50×0.1 µm) myosin-motility-assay of *gliding F-actin on a surface* with explicit mobile motors — an active-matter / collective-behavior study. It has **no membrane, no enclosed volume, no turgor, no cell shape, no cortex-as-surface-tension, no cell–cell junction** — i.e. none of the DCM engine's continuum surface-mesh objects. Its primitives (semiflexible filaments, PCM motors, overdamped Langevin, excluded-volume) are **FF-engine** objects, not DCM objects. Nothing here ports directly to the DCM surface-mesh/γ/Π/K_A/κ_m level. Below I record the two *indirect* levers an architect could legitimately draw, and I flag the rest as out-of-DCM-scope (belongs in the p31 FF lens).

---

## 1. MECHANISMS to adopt

Honest assessment: **no first-class DCM mechanism transfers.** DCM represents the actomyosin cortex as a lumped surface tension γ (pressure-borne, γ=ΔP·R/2); this paper never coarse-grains motor activity into a surface stress, so there is no equation or protocol to lift to the mesh. Two *indirect/advisory* items only:

- **(Advisory, not a module) Motor mobility → bound-fraction decay → effective contractility is transient.** Fig. 1(j): the bound-motor fraction *spikes then decays to a low steady level, and the steady level is LOWER at higher motor mobility*, because mobile motors walk to barbed ends, self-organize, and phase-separate out of the actin. **Why this is a caution for DCM's open γ-generation problem:** DCM currently treats cortical γ as a static setpoint (interphase 0.15 / mitotic 1.5 mN/m). This paper is a concrete reminder that the *number of force-generating engaged motors is an emergent, self-limiting, mobility-dependent quantity*, not a constant. If a future DCM ever tries to *generate* γ mechanistically (rather than impose it via γ=ΔP·R/2), the engaged-motor fraction must be a dynamical variable with a decay, not a fixed density. This corroborates the existing project finding that the γ-floor is a force-*magnitude*/engaged-density limit (see MEMORY `project-gamma-floor-likely-deficit`), not a stiffness gap. **It does not give a value to set** — it is a modeling-philosophy datum.

- **(Advisory, speculative) Active-nematic organization of the cortex is a real but out-of-scope direction.** The cluster core is stabilized by +1/2 "wedge" nematic defects that trap pointed-ends-inward filaments (Fig. 1g–i). An active-nematic cortex on a *curved deformable surface* is a legitimate research program (Salbreux/Jülicher/Prost lineage — the paper cites Naganathan/Grill "cortical flow aligns actin to form a furrow" [ref 2] and Salbreux–Charras–Paluch "actin cortex mechanics" [ref 3], which ARE cortex-relevant and worth pulling separately). But *this* paper studies the defect physics on a **flat** substrate with **no** coupling to surface curvature or shape change, so it supplies no BC, no equation, and no parameter for a curved DCM cortex. Log as a pointer to the cited cortex papers, not as an adoptable mechanism.

**Bottom line for §1:** do not open a DCM module from p31. The FF engine is the correct home for everything mechanistic here.

## 2. EQUATIONS to port to the surface-mesh/continuum level

**None port to the DCM surface-mesh/continuum level.** All governing equations (A1–A8) are per-segment filament/motor dynamics, i.e. FF-engine equations, and DCM does not represent individual cortical filaments. For completeness, mapping each to DCM shows *why* it does not fit:

| Paper Eq. | What it is | DCM analog? |
|---|---|---|
| A1 `F_i − ζ_i ṙ_i + F_i^T = 0` | per-endpoint overdamped Langevin | DCM already uses overdamped node dynamics `ζ_node ṙ = F`; DCM derives ζ_node from cytoplasm η=65 Pa·s per node, so no change. The *form* matches; nothing new. |
| A2 FDT noise `⟨F^T F^T⟩ = 2k_BTζ/Δt` | thermal force | DCM is largely deterministic at cell scale (thermal negligible for a 7.5 µm shell); not adopted. |
| A3 `ζ_i = 3πμ r_c (3+2 r_0/r_c)/5` | cylindrical-segment drag | This is a *filament-segment* drag closed form — an FF-engine formula, NOT a node-on-mesh drag. DCM per-node drag comes from η and node spacing, not segment geometry. Do not port to DCM. |
| A4 | explicit Euler update | DCM uses IPC large-dt / implicit; this is inferior for DCM's stiff contact. Do not adopt. |
| A5–A8 | actin stretch/bend, motor spring, excluded-volume | filament-level potentials → FF only. DCM membrane uses K_A (area), κ_m (bending of the *surface*), not per-filament κ_s/κ_b. |
| Eq. 1–3 | nematic S, polar P, velocity correlation | analysis metrics over filament pairs; DCM has no filament field to measure them on. |

**No equation is transcribed for DCM adoption.**

## 3. PARAMETERS to set

**No DCM config field is fed by this paper, and nothing supersedes a current DCM default.** Every quantity is filament/motor-assay scoped (FF domain). For the record, the reusable numeric anchors — all FF/TAG, not DCM — are:

- Motor reference diffusion `D*_M = 5.11×10⁻¹⁴ m²/s` (mobile-motor drag reference) — FF motor mobility, if FF ever models bilayer-anchored motors. **Not a DCM field.**
- Motor binding rate `k_{+,M} = 40·N_H = 160 s⁻¹`, binding-site spacing 7 nm, `N_H = 4` heads/segment — FF myosin kinetics. **Not a DCM field.**
- Collective-onset actin areal density `≈903 monomers/µm²` (below this, negligible collective behavior; strong clusters at 6020–12040) — FF/assay density threshold. **Not a DCM field** (DCM uses cortex γ, not monomer areal density).
- Filament-length crossover: clusters at ⟨L_f⟩ ≤ 2.58 µm, closed **rings** at ⟨L_f⟩ = 7.43 µm — FF filament-length physics. **Not a DCM field.**
- `Δt = 1.15×10⁻⁵ s` (their explicit-Euler step) — FF/assay-specific; DCM uses large-dt IPC. **Do not adopt.**
- κ_{s,A}, κ_{s,M}, κ_{b,A}, κ_r, μ, r_0, r_c live in the SI [ref 32], not this PDF — flag for SI retrieval **only if the FF lens needs them.**

## 4. GEOMETRY / PROTOCOL to reproduce

**No DCM scenario is reproducible from this paper.** The geometry is a periodic flat slab (50×50×0.1 µm, PBC in x,y, filaments pinned to z=13.5 nm) — a substrate motility assay, the opposite of DCM's closed enclosing surface with turgor. None of DCM's scenarios (confinement, micropipette aspiration, AFM indentation, cytokinetic division, aggregate compaction, durotaxis) appears. The two-phase *initiation → production* protocol (nucleate/polymerize to set a length distribution, then freeze length and switch motors on) is an **FF-engine** cortex-build recipe (it echoes FF's existing distributed-length + barbed-end-growth build, MEMORY `project-ff-filament-length-growth`), not a DCM protocol.

- **Only transferable protocol idea (weak, FF-side):** "build a frozen semiflexible-filament length distribution via a nucleation-rate-controlled initiation phase, then activate motors" — this is already essentially what FF does; p31 is corroboration, not new geometry, for DCM.

## 5. VALIDATION TARGETS for DCM observables

**None.** The paper's measured/simulated numbers are all assay observables with **no DCM counterpart**:

- F-actin glide speed v_A (↓ with mobility, plateau ~1–2 µm/s), motor speed v_M (↑ to ~5–6 µm/s at D̄_M=4) — gliding speeds, no DCM analog (DCM has no gliding cortex on a substrate).
- Polar order P ~0.5–0.6 (high mobility) vs ~0.2–0.3 (low); nematic S ~1 throughout — order parameters over a flat filament field; DCM measures cortical γ, shape index, contact angle, compaction — none of which appear here.
- Phase-separation metric M/M₀ ~3 (D̄_M=1); bound-motor fraction decay curve — assay metrics.
- +1/2 / −1/2 nematic defect classification — flat-field defects, not a DCM observable.

There is **no** tension, shape index, division force/rate, ring-closure, compaction, contact-angle, or cortical-flow-speed number that a DCM run should reproduce from this paper. Do NOT register any p31 value as a DCM validation gate. (Register as FF/TAG anchors instead — see FF lens.)

## 6. RISKS / caveats

- **Regime mismatch is total for DCM.** In-vitro purified rabbit-skeletal actin + HMM on a DOPC supported lipid bilayer, flat quasi-2D, periodic, purified reconstitution — vs. a living MCF7-like 3D deformable cell with membrane, turgor, nucleus, and cadherin junctions. There is no path to "adapt" the flat-assay collective physics into a DCM surface object without inventing a curved-surface active-nematic-cortex module wholesale, which this paper does not provision (no BC, no curvature coupling, no value).
- **Do not manufacture a DCM lever from this to look productive.** The physiological-baseline HARD rule cuts the other way here: importing an assay-scale motor-mobility number or a flat-field order parameter into DCM would be initializing a cortex module from a *non-physiological, wrong-geometry* baseline (purified assay ≠ cortex). That is exactly the invalid-baseline failure mode the rule forbids. The correct action is to route p31 to the **FF engine** (its filament/PCM-motor/Langevin/drag primitives are FF-native) and to the **TAG/KB** as FF motor-kinetics anchors, and to keep it OUT of DCM config.
- **The one genuine DCM-adjacent takeaway is a caution, not a build:** if DCM ever moves from imposed γ (γ=ΔP·R/2) to *generated* γ, the engaged-motor fraction must be a self-limiting dynamical variable (Fig. 1j), consistent with the existing engaged-density γ-floor diagnosis — but this paper supplies no MCF7 datum, so it cannot set a value and must not be used to tune the γ-floor.
- **Better cortex sources are cited *inside* p31:** refs [2] Naganathan/Grill (cortical flow → furrow) and [3] Salbreux–Charras–Paluch (actin cortex mechanics) are the actually-cortex-relevant references and are worth pulling on their own for the DCM cortex/cytokinesis work; p31 itself is not.
