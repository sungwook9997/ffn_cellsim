## Paper kind

**simulation** (agent-based Brownian-dynamics, forward-Euler Langevin; Taeyoon Kim lab model, a sibling of Cytosim which is FF's physics reference). There is **no new wet-lab measurement** in this paper — every σy, γy, E0, turnover rate, and motor stress is a *model output*. The one experimental anchor it cites is the predecessor **Mulla 2022, Nat. Mater. [ref 18]** ("Weak catch bonds make strong networks"), which is NOT this paper.

**Consequence for use (hard rule):** all quantitative results here are **comparison-only, never a truth source and never a fit target**. They may seed FF cross-check *comparisons* (sibling model → FF parity-style agreement) but cannot become an acceptance-band contract on their own. The one thing that CAN become a first-class artifact is the **closed-form catch-slip lifetime law (Eq. 1)** — an analytic oracle candidate — and the reparameterized {τ0, τmax, Fmax} descriptors as *draft parameters* (with provenance flagged as simulation-chosen, area-matched to slip).

> Caveat: the actual force-law constants (k^{s0}, k^{c0}, λ^s, λ^c), drag ζ, stretch/bend stiffnesses, on-rate, timestep, per-head stall force all live in **Supporting Information Table S1**, which is NOT in the 13-page main PDF. Any oracle/parameter registration must fetch S1 first.

## Coverage vs existing gates

- **VG-U2-catch-slip-bond** (KB-2.5; `type=Verification`, band = "Lifetime peak near ~30 pN for integrin-FN"). This is the ONLY catch-slip gate in the KB, and it is about the **integrin–fibronectin** bond (FA clutch), peak ~30 pN. This paper's catch-slip is an **actin cross-linker (α-actinin-4 / filamin)** with lifetime peak at **Fmax≈14.7 pN** — a *different molecule, different location, different peak force*. → **NOT covered; does not tighten or challenge VG-U2**, which stays integrin-specific. The two must remain separate gates (a crosslinker catch-slip gate would be new).
- **MC-U2-fa-motor-clutch** already commits to "Bell-Evans / catch-slip integrin bonds" — again FA-side, not the cortex/cytoskeleton crosslinker. No overlap of the actual bond.
- **F_stall_motor** parameter (PARAM-F_stall_motor, default 2 pN, KU-2.4/2.18) is *per-head/per-motor* stall; this paper's 512-head construction lumps 64 arms × 8 heads and cites a stall in S1 (not in main PDF). Consistent in spirit (~2 pN/head myosin-II) but no numeric conflict extractable here.
- **No existing gate** covers: network yield stress σy, yield strain γy, tangent modulus Ey, cross-linker turnover rate, or single-motor contractile stress. All of items #4–#10 are **uncovered**, but as simulation outputs they are candidates for *comparison-only* cross-checks, not new band contracts.
- Analytic oracles present (Bell-Evans off-rate, Hill f-v, Young-Laplace, Helfrich, Kelvin-Voigt) do **not** include a catch-slip (Bell + inverse-Bell) lifetime form → Eq. 1 is a genuine gap.

1. **proposed_vg_id: VG-FF-crosslink-catchslip-lifetime** — *(the defensible one, oracle-backed)*

   - Band/value: τ(F) = 1/[k^{s0}e^{λ^s F/kT} + k^{c0}e^{−λ^c F/kT}] rising from τ0 to a single maximum τmax at Fmax, then slip-decaying. Reference descriptors τ0≈9.5 s, τmax≈53 s, **Fmax≈14.7 pN** (tolerance TBD from S1 constants; peak-force band e.g. 10–20 pN).

2. **proposed_vg_id: VG-FF-catchslip-network-strengthening** — *(comparison-only, sibling-model)*
   - Observable: in FF bulk shear of a cross-linked actin network, catch-slip cross-linkers raise **both** yield stress σy AND yield strain γy vs a slip-only control at matched connectivity (breaking the stiffness–extensibility trade-off), and this advantage appears **only at high connectivity** (high CF·RCL), flipping <1 at low RCL.

   - Source: Figs.1C, 2A–B, S3, p.3/p.6.

## Oracle candidates

**Eq. 1 — catch-slip cross-linker lifetime law (closed form).** This is the strongest first-class contribution and a genuine gap in the current oracle set (which has Bell-Evans slip but no catch-slip):

```
k_u(F) = k^{s0}·exp(+λ^s |F| / kT)  +  k^{c0}·exp(−λ^c |F| / kT)      (r ≥ r0)
       = k^{s0} + k^{c0}                                              (r < r0, no tensile load)
τ(F)  = 1 / k_u(F)     →  rises from τ0=1/(k^{s0}+k^{c0}) to a single max τmax at Fmax, slip-decay beyond
```

- Implement as an analytic cross-check `validation/oracles/.../catch_slip_lifetime.py`, sibling to the existing Bell-Evans oracle. Ground-truth curve for FF cross-linker off-rate; also validates the reparameterization {τ0, τmax, Fmax} ↔ {k^{s0}, k^{c0}, λ^s, λ^c}.
- **Blocked on SI Table S1** for the four constants. The main-PDF gives only the descriptor triple.
- Note this is the *same functional family* as the integrin catch-slip already implied by VG-U2 / cadherin catch-bond (Rakshit KU-4.2), so a single generic catch-slip oracle could serve crosslinker, integrin, and cadherin with different constants.
