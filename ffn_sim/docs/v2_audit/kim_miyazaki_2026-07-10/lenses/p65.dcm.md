# DCM lens — p65

**Paper:** T. Kim, W. Hwang, R.D. Kamm, "Computational Analysis of a Cross-linked Actin-like Network," *Exp. Mech.* 49:91–104 (2009). DOI 10.1007/s11340-007-9091-3.

**Honest verdict up front.** This is a *fine-grained filament-scale* Brownian-dynamics model (bead-spring F-actin + idealized cross-linkers in a 560 nm periodic box, ms timescale, purified/water regime). It is the ancestral blueprint of **FF**, not of DCM. DCM is a closed-surface continuum cell where the entire actin network is coarse-grained away into a surface tension γ, a bending κ_m, and an enclosed-volume constraint — exactly the layer this paper resolves explicitly. So there is **no direct surface-mesh force, no γ value, no division/confinement/aspiration protocol** here to port. What *does* transfer is a small set of **mechanistic FORMS** — (i) a load-dependent bond-rupture + slow-reformation kinetics that reframes DCM's open aggregate-compaction-RATE problem, and (ii) a connectivity/percolation → stiffness picture that is the sub-grid justification for DCM's cortex-tension continuum. Everything numeric here is at the wrong scale/regime for DCM and must NOT be registered as a DCM parameter. Net DCM impact: **low (~1.5/5)**.

---

## 1. MECHANISMS to adopt

### M1 — Junction / cadherin-cluster off-rate: Bell slip-bond form + thermal amplification (→ DCM cell-cell junction module)
The paper's cross-linker unbinding is **Bell's law**, `k_off = k_off0 · exp(γ F_b / k_BT)` (Eq. 16). DCM's cell-cell interface already uses a Rakshit **catch**-bond (KU-4.2) — Bell is the reference **slip** limit of that same one-junction interface, so this is confirmatory rather than new. The genuinely useful finding is downstream (§ Annealing, p102): the *athermal* off-rate `k_off0 = 0.4967 s⁻¹` under-predicts the *effective* off-rate measured in the simulation by ~60–200× — **≈100 s⁻¹ (bundler) and ≈30 s⁻¹ (orthogonal)** — because the bond force `F_b` fluctuates thermally and Bell's exponential rectifies those fluctuations. 
- **WHY it beats what DCM does now:** DCM evaluates junction lifetime on the *mean* load. If DCM (also overdamped Langevin) computes cadherin-cluster lifetime from `k_off0·exp(γ⟨F⟩/kT)` using the time-averaged junction force, it will over-estimate lifetime by ~2 orders. The mechanistic fix is to evaluate the off-rate on the **instantaneous fluctuating node/junction force each step** (which DCM already has, since it's stochastic), OR carry the Jensen-gap correction `⟨exp(γF/kT)⟩ > exp(γ⟨F⟩/kT)` explicitly. No magic number: the amplification is *emergent* from the thermal force already in the integrator.

### M2 — Compaction RATE = rupture-limited, power-law (t⁻⁰·⁰⁵) reformation, NOT first-order on-rate (→ aggregate σ / T1-rearrangement, the OPEN problem)
The paper's most DCM-relevant physics is in *Filament Bundling / Annealing / Rheology* (pp. 101–102). Under mechanical strain: (a) bonds rupture more readily via Bell (Eq. 16); (b) **after rupture the network locally reorganizes → filaments realign along the stress direction** (their ref [39], stress-fiber annealing); (c) ruptured cross-links **reform on a slow power law `(N_sat − N_ACP) ~ t⁻⁰·⁰⁵`, NOT as a first-order reaction** (Fig. 11); (d) the reformation timescale is set by this power-law healing (minutes), **not** by the fast free-crosslinker on-rate. They explicitly tie this to cytoskeletal **fluidization and "healing"** on a minutes timescale.
- **WHY it beats what DCM does now:** DCM's current loose→compact aggregate compaction is **drag-limited aggregate-σ pull that hits an end-state in ~100 s** (see memory `project-dcm-ipc-large-dt` / `project-dcm-compaction-turgor-blocked`), whereas real MCF7-aggregate compaction is 24–48 h and the PI has scoped the fix as *cadherin T1-rearrangement escalation, not aggregate-σ*. This paper supplies the missing **mechanistic law** for that escalation: junction compaction should proceed by **cluster rupture under aggregate stress + slow, sub-first-order (power-law) re-encounter/reformation under crowding**. Modeled that way, the long 24–48 h timescale becomes **emergent** (rupture rate × diffusion-limited re-encounter in a crowded interface), with **no fitted rate constant** — which is exactly what the "no magic number / no gate-loosening" rule demands. The rearrangement is not a tuned relaxation time; it is Bell-rupture-gated reformation.

### M3 — Cortex tension γ as the continuum shadow of a percolating orthogonal (filamin/ACP^C) network (→ cortex γ-generation, the γ-floor open problem)
The paper establishes (Intro p92; Results) that the **cortical actin layer near the plasma membrane is the orthogonal ACP^C (filamin-type) network**, and that **network connectivity/percolation is the determinant of mechanical stiffness** (adjacency-matrix `Σ Qᵏ`, refs [31–33]), with connectivity rising when filaments are longer / softer (Fig. 7, Fig. 9). 
- **WHY it's useful (weakly):** DCM's cortex γ is a lumped continuum; the long-standing **γ-floor deficit** (memory `project-gamma-floor-likely-deficit`: active γ floored ~500× under band, a *generation/density* limit) is precisely a statement about the sub-grid network. This paper says the lever is **percolation of the orthogonal network → elastic stiffness**, and that connectivity is set by filament length and bending compliance — a *mechanistic* target for any future sub-grid γ estimator. It gives **no γ number** (purified, no myosin), so it cannot close the floor; it only names the correct sub-grid variable (percolation, not areal density alone).

## 2. EQUATIONS to port to the surface-mesh / continuum level

Only two forms survive the scale jump; both are FORMS, not values.

**Eq. 16 (Bell) — junction off-rate**, transcribed:
```
k_off = k_off0 · exp( γ · F_b / k_BT )
```
Symbol map to DCM: `F_b` → per-junction (cadherin-cluster) tensile load carried by the node-face / catch-bond interface, N; `γ` → reactive length (bond compliance), m — in DCM this is the catch-bond's KU-4.2 parameter, keep DCM's Rakshit form and use Bell only as the slip-limit sanity check; `k_off0` → zero-force off-rate (DCM already carries the α-actinin/cadherin `k_off0`, re-anchored elsewhere to 0.066 s⁻¹ Ferrer 2008 — do NOT overwrite with this paper's 0.4967). `k_BT` = 4.142×10⁻²¹ J at 300 K (matches DCM). **Port the Jensen-gap lesson, not the number:** evaluate on the fluctuating `F_b(t)`, i.e. `⟨k_off⟩ = k_off0·⟨exp(γF_b/kT)⟩`.

**Eq. 8 (persistence ↔ bending) — calibration protocol form only:**
```
L_p = k_b · σ_A / (k_BT)
```
Symbol map: at the DCM surface level the analogue is the membrane/cortex bending modulus κ_m setting a bending persistence of the *surface*. This is **not a numeric port** (DCM has no explicit filaments) — it is a reminder of the *calibration protocol*: measure the tangent–tangent correlation `⟨cos(θ(s)−θ(0))⟩ = e^{−s/L_p}` (Eq. 7) to back out a bending constant. Useful only if DCM ever grows an explicit sub-grid cortex; then κ_m ↔ L_p via this relation.

**Not ported (filament-scale, no DCM surface analogue):** truncated-LJ excluded volume Eq. 4 (DCM uses Ericson node-face penalty instead), harmonic stretch Eq. 5, harmonic bend Eq. 6, torsion Eq. 9, Damköhler Eq. 17, polymerization/length scaling Eqs. 18–21, bundle diameter `σ_b=√N_f,b·σ_A`. These are FF-native.

## 4. GEOMETRY / PROTOCOL to reproduce

No DCM-usable scenario. The paper's only geometry is a **periodic cubic box (40–80 σ_A ≈ 280–560 nm)** of self-assembling monomers — sub-cellular, no free surface, no membrane, no confinement/aspiration/AFM/division. It is a reconstitution-in-silico, not a whole-cell mechanics protocol.

One indirect protocol idea (FF-side, listed for completeness): the **connectivity-via-adjacency-matrix-powers** metric (`Σ Qᵏ` counts (k+1)-filament connected sets → percolation) is a clean way to score whether a sub-grid cortex network percolates; if DCM ever instruments a resolved cortex patch, this is the percolation observable to report. ## 5. VALIDATION TARGETS for DCM observables

**None direct.** Every quantitative result (L_p≈20 µm; cross-angle −2.39±3.98° bundler / 87.5±10.5° orthogonal; L_c bimodal 5σ_A/10σ_A; pore ∝ C_A^{−1/3}; bundle diameter 1.5–2.3 σ_A; t̃_p ~ Φ^{−5/6}Da_n^{1/2}; ⟨L_f⟩ ~ (Da_n Φ^{1/3})^{1/2}) is a **filament-network morphology target for FF**, at 560 nm / 1–10 ms — none is a DCM surface observable (no tension, shape index, division force, ring closure, compaction, contact angle, or cortical-flow number is measured here).

The single number a DCM *sub-grid* model could someday check against: the **effective vs athermal off-rate amplification (~30–100 s⁻¹ vs 0.4967 s⁻¹)** as an emergent consistency test of any load-dependent junction-lifetime implementation — but this is a soft, cross-regime check, not a validation gate.

## 6. RISKS / caveats

- **Wrong engine layer.** This resolves the exact microstructure DCM deliberately coarse-grains into γ/κ_m/Π. Importing its forces as DCM surface forces would double-count or mis-scale. It belongs in FF; DCM takes only the *reframed laws* (M1, M2).
- **Wrong regime — purified, water, athermal-baseline.** Water η (0.86 mPa·s), no myosin, no membrane, no turgor, no cytoplasm crowding, 300 K reconstitution. DCM's physiological-baseline HARD rule forbids adopting any of these; adapt by taking only dimensionless *forms* (Bell exponential, power-law reformation, percolation→stiffness) and evaluating them at DCM's physiological operating point (η=65 Pa·s, ΔP-borne γ, real cadherin k_off0).
- **Wrong scale — ms/560 nm vs hours/µm.** The paper never reaches steady state (99%-polymerization cutoff; Fig. 11 still evolving; t^{−0.05}); it explicitly cannot resolve stress fibers (500 nm) or aggregate compaction. So M2's power-law-healing law is a *mechanistic seed* for the 24–48 h compaction timescale, not a calibrated timescale — DCM must let the long time **emerge** from Bell-rupture × crowded re-encounter, never fit t⁻⁰·⁰⁵ or a relaxation constant to hit 24–48 h (that would be gate-fitting).
- **Computationally accelerated rates.** k_A,n and k_A,e are inflated for cost; t̃_p is non-physical by the authors' own statement. Any rate borrowed from this paper is doubly non-physiological.
- **Cross-linker ≠ cadherin.** ACP^B/ACP^C are α-actinin/fascin/filamin (intracellular F-actin cross-linkers), not cell-cell cadherin. M1/M2 use them only as *analogues* for the load-dependent bond; the actual DCM junction stays Rakshit KU-4.2.
- **Bottom line for the PI:** worth one paragraph in the compaction-rate design note (M2 reframe: rupture-limited power-law reformation ⇒ emergent long timescale, no magic number) and a one-line check on junction off-rate evaluation (M1: use fluctuating force). Not worth a DCM code change on its own, and **no KB SourceEvidence row should anchor a DCM parameter to it.**
