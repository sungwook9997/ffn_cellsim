# FF lens — p51

**Paper:** Hassan, Biel & Kim (2019), "Mechanical Model for Durotactic Cell Migration," *ACS Biomater. Sci. Eng.* 5(8) 3954–3963. DOI 10.1021/acsbiomaterials.8b01365. Taeyoon Kim lab, Purdue.

**One-line verdict for FF.** The *cell* side of this paper is a lumped 2-point machine — the antithesis of FF's fine-grained mandate — and carries **nothing** portable as an FF cell mechanism. The *substrate* side (a stretch+bend+viscous triangulated spring network with spatially-graded stiffness) and the *emergent, no-decision durotaxis result* ARE portable: they give FF (a) a physically-grounded viscoelastic ECM upgrade and (b) a marquee emergent-behavior validation target — durotaxis with NO stiffness-sensing rule, exactly the kind of thing FF's motor-clutch traction should produce for free. Kim is the same lab FF already benchmarks its DCM⊗ECM 1/r work against ([[project-dcm-ecm-kim-1r-gap]]), so this slots into an existing validation line.

## 1. MECHANISMS to adopt

### 1a. ECM substrate as an explicit stretch **+ bending** viscoelastic spring network — HIGH value
FF's current ECM is a collagen-Mikado network (crawl substrate, [[project-ff-crawl-mechanism]], [[project-ff-active-movement-pieces]]). This paper's substrate model adds two mechanistic ingredients FF should confirm it has, and one it likely lacks:
- **Bending springs on the fiber network** (eq 10): each connected triplet i–j–k carries an angular harmonic `U_b = ½ κ_b,M (θ_ijk − θ_ijk,0)²`. This is what gives the network *strain-stiffening* (linear-elastic at low strain, stiffening at high strain) with κ_b,M=1 nN·µm and connectivity fraction p=0.4. FF's Mikado ECM should carry an explicit **angular bond** per fiber junction, not just stretch springs — otherwise the ECM cannot strain-stiffen and durotaxis cues will be mis-scaled. Map to FF module: **crosslinker/ECM junction** angular term (FF already has Arp2/3 angle-harmonic machinery — reuse that kernel on collagen junctions).
- **Dilute-connectivity via random bond removal** (fraction p of the 6 possible chains per node removed → node coordination 0–6). This is the Broedersz–MacKintosh (2011, ref 34) sub-isostatic construction. FF's Mikado build should expose a **connectivity/coordination knob** so the ECM sits below the isostatic point (z<4 in 2D, or the 3D analog) where bending dominates and the network is soft-then-stiffening — the physiological regime for collagen. Right now FF has no explicit coordination-number control.
- **Substrate viscoelasticity as inter-node viscous drag ξ** (eq 11): `F_d,ij = −ξ(v_i − v_j)`, a Kelvin–Voigt element in parallel with the stretch spring. FF's ECM is (per the notes) elastic + globally drag-coupled; adding a **relative-velocity dashpot on each ECM bond** makes the network a genuine Kelvin–Voigt material with a tunable relaxation time τ ~ ξ/κ. This is the single most important upgrade because the whole durotaxis result hinges on the elasticity-vs-viscosity competition — a purely elastic ECM cannot reproduce it.

**Why this beats current FF:** FF already prefers mechanistic over lumped, so it should NOT copy the paper's lumped *cell*; but on the *substrate* FF is currently *less* mechanistic than needed (no per-bond bending, no per-bond dashpot, no coordination control). This is a case where the paper is more fine-grained than FF on the ECM axis.

### 1b. Durotaxis as an EMERGENT test of FF's existing clutch traction — HIGH value (as scenario, not new mechanism)
The paper's headline claim: directed migration up a stiffness gradient emerges from *pure mechanics* with **no decision rule, no stiffness-dependent property change**. FF already has the fine-grained machinery this should emerge from — motor-clutch adhesion + integrin catch-bonds + actin retrograde flow ([[project-ff-crawl-mechanism]] traction-driven crawl, physiological 28–45 nm/s). **Do NOT adopt any of the paper's cell mechanics.** Instead adopt the *claim as a validation target*: put an FF cell on a stiffness-graded ECM and check that emergent durotaxis appears from clutch reinforcement alone (Chan–Odde motor-clutch, ref 47 in this paper — already an FF acceptance oracle). This is the mechanistically-honest version of their coarse result.

### 1c. Non-centripetal traction direction — MEDIUM value (already emergent in FF, use as a cross-check)
The paper imposes traction *tangentially* (non-centripetal, along the tangent to a circle about the cell-point, motivated by non-centripetal actin retrograde flow, Burnette 2011 ref 35). In FF this direction is **not imposed** — it emerges from the actual retrograde-flow field of the explicit filaments. Use the paper's observation ("retrograde flow / traction is not centripetal") only as a **sanity cross-check** on FF's emergent traction field, never as an imposed direction. This is the correct fine-grained inversion of their assumption.

### What to explicitly REJECT (violates FF hard rules)
- 2-point cell, partial-donut adhesion regions, 6 lamellipodial sectors, constant-torque propulsion τ_F≫τ_R, the kinematic-constraint `Mu=f` solve — all lumped proxies for cytoskeleton FF represents explicitly. **Do not port.**
- The lumped drag coefficients η, α, β, λ, γ fit to reproduce experimental MSD/velocity (ref 39) — this is *fitting to outcome*, forbidden by FF's no-fitting rule. Do not import their numeric values.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF durotaxis scenario)

A directly usable FF scenario — the mechanistically-honest version of the paper's setup:

**Build.**
- ECM: FF collagen-Mikado network, ADD per-bond bending (κ_b) + per-bond dashpot (ξ), coordination set sub-isostatic (analog of p=0.4). Patch large vs cell (paper: 500×500 µm; FF single-cell can use a smaller patch scaled to R=7.5 µm cell with generous margin). PBC transverse to the gradient; fixed boundaries along the gradient axis.
- Two stiffness protocols (Fig 2): **(a) sharp step** — stiff half : soft half at 100:1 ratio; **(b) linear gradient** — κ decreasing along +x, center pinned at a reference stiffness, gradient magnitude 0–200 pN/µm².
- Cell: a **native full-compartment FF cell** (cortex 38000 filaments, `--from-resting`, microtubules, membrane, nucleus, turgor — per the HARD native-scale rule) placed at the interface / gradient center, adhering via motor-clutch + integrin catch-bonds. **No stiffness-sensing rule anywhere** — that is the whole point.

**Run.** Let the cell crawl (traction-driven, [[project-ff-crawl-mechanism]]) for the physiological equivalent of the paper's 12 h (step) / 36 h (gradient). Seed-ensemble (≥ the 7/11/17/23-seed convention FF already uses) because durotaxis is a statistical bias, not a single-trajectory fact.

**Caveat on native cost.** The paper runs 30 cells × 12 h on a supercomputer with a *lumped* cell. FF's native cell is ~5 s/real-second on the A5000; a 12 h biological run is out of reach at native scale for an ensemble. Resolution: run the durotaxis *scenario* to demonstrate the emergent directional bias over a tractable window (hours, not 36 h) at native scale, and treat any longer coarse run strictly as a **non-authoritative dev smoke test** to be reconfirmed — do NOT report a coarse durotaxis DI as a result (the coarse-cell structural-instability trap, MEMORY native-full rule).

## 6. RISKS / caveats

1. **The cell model is lumped — importing any of it violates FF's core rule.** The 2-point/torque/kinematic-constraint machinery is a proxy for exactly the cytoskeleton FF represents explicitly. Adopt ONLY the substrate laws (§2) and the emergent-durotaxis *targets* (§5). This is the dominant risk: it is tempting to "just add a torque driver" — forbidden.
2. **2D, purely mechanical, no explicit FA dynamics.** The paper assumes every substrate point in an active region *instantly* becomes a FA (no force-dependent binding/unbinding). FF's whole advantage is force-dependent clutch/catch-bond kinetics (Bell–Evans, Rakshit). FF's durotaxis will therefore differ in mechanism (real clutch reinforcement vs instantaneous FA) — this is a *feature*, and FF should expect **stronger/cleaner** durotaxis than the paper (the authors themselves predict FA dynamics would enhance it, Discussion p8). Do not tune FF to match their DI magnitude; match the *qualitative signatures* (biphasic in κ, decreasing in ξ, orientation-independent speed).
3. **Fitted lumped drags (η,α,β,λ,γ) reproduce experimental MSD** — this is fitting-to-outcome, forbidden. Never import these numbers; FF's dynamics come from η=65.9 Pa·s cytoplasm + explicit drag, not from an MSD fit.
4. **Effective vs molecular stiffness.** κ_s,M (0.001–0.15 nN/µm) and κ_b,M (1 nN·µm) are *network-effective/calibration* constants, not single-fiber moduli. Using them directly as FF fiber link_k would double-count. Re-derive FF's per-fiber constants from collagen physics; use the paper's values only to set the *scenario stiffness contrast* and to cross-check the network-level stress–strain.
5. **ξ units are nN·hr/µm (per-bond dashpot), not a bulk Pa·s viscosity.** Convert to a relaxation time τ=ξ/κ (e.g. 180 s at ξ=0.05, κ=1) before comparing to FF's cytoplasm/ECM timescales; do not confuse with the 65.9 Pa·s cytoplasm viscosity.
6. **Native-scale + physiological-baseline compliance.** Run the FF durotaxis scenario on the native full-compartment cell from `--from-resting` (HARD rule, MEMORY [[feedback-native-full-compartment-always]]); the 12–36 h biological windows are infeasible for a native ensemble, so demonstrate the emergent bias over a tractable window and label any long coarse run non-authoritative. Do not report DI from a coarse cell.
7. **Species/type.** Paper calibrates geometry to polarized fibroblasts (Omelchenko 2002). FF's target is MCF7 (R=7.5 µm). Durotaxis signatures (biphasic DI, orientation-independent speed) are expected to be type-robust per the authors ("results do not change as long as RF>RR"); use the *shape* of the curves, not fibroblast-specific magnitudes.
