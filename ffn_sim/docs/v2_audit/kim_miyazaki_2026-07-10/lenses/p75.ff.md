## 1. Mechanisms to adopt  (strong — same discrete-segment BD family as FF)
- **Discrete fibril + crosslinker + bundler Brownian-dynamics network** is the SAME modeling family FF implements (filaments as bending beams + Bell-Evans crosslinkers). Near drop-in analogue: fibrils↔actin filaments, cross-linkers↔α-actinin, **bundlers↔fascin/filopodial bundling**. FF's filopodium already needs bundling — this paper gives the mechanistic bundler: a two-arm element enforcing a length + TWO angles (κ_b,bu,1, κ_b,bu,2), binding fibril end (site b₁) to a partner point (b₂), tuning bundle length L_B. That is exactly how FF should build filopodial/stress-fiber bundles mechanistically instead of a lumped bundle stiffness.
- **Stress relaxation from force-dependent crosslinker unbinding + filament rearrangement.** Directly relevant to the FF cortex stress-relaxation / γ-turnover story ([[project-ff-afm-overshoot-was-artifact]]): the network relaxes because crosslinkers unbind under load (Bell) and fibrils rearrange. Connectivity/heterogeneity sets the relaxation rate.

## 2. Force laws / kinetic schemes to port
- Over-damped Langevin + Euler (Eq.1).
- Harmonic stretch/bend for fibril/crosslinker; bundler = stretch + 2 bend angles (Eqs.2–5) → mechanistic bundle.
- **Bell's law** `k_off = k_off0·exp(F·x_b/k_BT)` (Eq.6) — crosslinker off-rate (FF already uses this; corroborating anchor).
- Relaxation observable σ(t)|γ=20% → τ½.

## 5. Validation targets for FF observables
- Bundled network relaxes faster than unbundled; smaller L_B → faster/greater relaxation; smaller θ → faster.
- Stiffness (storage modulus) invariant while relaxation rate changes — separates elastic from viscous response (a clean FF cross-check).
