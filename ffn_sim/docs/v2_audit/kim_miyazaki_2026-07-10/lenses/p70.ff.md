# FF lens — p70

**Paper:** Sakamoto et al. 2020, *Tug-of-war between actomyosin-driven antagonistic forces determines the positioning symmetry in cell-sized confinement*, Nat Commun 11:3063. DOI 10.1038/s41467-020-16677-9.

**One-line for FF:** A fine-grained *in-vitro* actomyosin reconstitution (Xenopus egg extract, microtubule-free) in cell-sized confinement that gives FF (a) directly-usable α-actinin crosslinker on/off rate constants and a turnover-time law, (b) F-actin contour-length control levers via gelsolin/mDia2, (c) an *emergent force-percolation* validation target (crosslinker density + filament length → contractile bridge forms → outward pull), and (d) a periodic centripetal actomyosin-wave phenomenon that FF's cortex+bulk network should self-organize into. This is the "network contraction & stress relaxation / motor-driven flows / confinement self-organization" regime of FF, not the single-molecule regime — but it hands us clean rate constants for the crosslinker module and a percolation observable to reproduce at native scale.

---

## 1. MECHANISMS to adopt

### 1.1 Crosslinker turnover as the rate-limiter for force transmission (crosslinker module)
The paper's central mechanistic claim is that **long-range contractile force transmits through the network only when a contiguous chain of crosslinking sites is *simultaneously* occupied** — a *force-percolation* transition (their refs 32–34: Alvarado, Sheinman, Ronceray). Each site along a boundary→center path is "on" with probability 1/2 per turnover time τ; the network transmits contraction only when all N≃R/L sites in series are occupied at once.

- **Why it beats current FF:** FF already has explicit Bell-Evans α-actinin bonds (k_off = k_off0·exp(F/F_b)), so the *machinery* exists. What this paper adds is the **emergent, testable consequence**: whether a globally-contractile stress percolates is set by the *ratio* of two microscopic quantities FF already carries — crosslinker turnover time τ and filament contour length L. FF can measure this as an *emergent* network observable (does a spanning stressed cluster form?) rather than assuming force transmission. This is exactly the "network contraction & stress relaxation … confinement-driven self-organization" open problem — the paper gives the analytic prediction to check against.
- **FF change:** add a diagnostic that detects a *force-percolating cluster* (a connected set of filaments+occupied-crosslinkers spanning cortex→interior carrying tension above a floor) and log its formation time τp vs system size. No new mechanism needed in the runtime — it is a *readout* over the existing bond graph, plus using the paper's τ, L to set/validate the crosslinker kinetics.

### 1.2 F-actin contour-length as a first-class contractility lever (filament + severing + formin modules)
The paper shows Dc (the percolation transition size) is set by L, and moves L three ways:
- **gelsolin (300 nM) → severing → shorter L** (top-5% L: 5.7→3.2 µm) → percolation harder → Dc 85→60 µm.
- **mDia2/formin FH1FH2 (30 nM) → longer L** (top-5% L 5.7→6.0 µm measured; fit L=10 µm) → Dc 85→138 µm.
- control L: fit 6.1 µm, measured top-5% 5.7 µm.

- **Why it beats current FF:** FF has exponential length distribution (1–10 µm) + barbed-end growth + formin ratchet, but (per the memory index) **no severing channel**. Gelsolin severing is the *missing turnover/fragmentation channel* — and this paper shows severing is not cosmetic: it directly controls whether the network can generate long-range contractile stress. Adding a **gelsolin/cofilin-style severing kernel** (Poisson severing rate per unit length, shifts the length distribution downward) closes an FF gap and lets FF reproduce the L-dependence of percolation. This is the "filament turnover/fragmentation" open problem, named as a concrete mechanism.
- **FF change:** add a `sever` channel to the filament module — per-segment stochastic scission with rate k_sev·(local bound-severer). Tie the resulting steady-state length distribution to the measured control top-5% L=5.7 µm and the gelsolin-shortened 3.2 µm as validation anchors. Existing formin/barbed-growth already covers the long-L direction (validate against 6.0 µm measured under mDia2).

### 1.3 Boundary Arp2/3 activation couples bulk network to the membrane (Arp2/3 + membrane/clutch module)
Anchoring WASP-VCA to the boundary (Ni-NTA lipids) activates Arp2/3 *at the membrane*, which increases bulk-network↔boundary coupling and pulls the cluster to the edge — and even drives whole-droplet migration. PEG passivation removes the coupling → cluster centers.

- **Why it relevant to FF:** FF already has membrane containment + Arp2/3 angle-harmonic branching + integrin clutches. This paper is a clean demonstration that **surface-localized Arp2/3 nucleation converts bulk contraction into a net boundary traction** — the same physics FF needs for lamellipodial protrusion and crawl. The VCA-on vs PEG-off contrast is a binary switch FF can reproduce: nucleation density at the membrane as the control parameter for whether interior contraction transmits to the boundary as traction.
- **FF change:** expose membrane-localized Arp2/3 nucleation density as a config knob; validate that "on" produces boundary-directed net force (edge cluster) and "off" does not. No new mechanism — parameter exposure + validation scenario.

### 1.4 Periodic centripetal contractile waves as an emergent cortex observable
Beyond the initial one-shot network contraction, the extract produces **periodic centripetal actomyosin rings/waves** propagating boundary→center with period T≈46 s, driven by turnover-regenerated F-actin (active-gel: grow F-actin → bind myosin+crosslinker → contract → dissolve → regrow). This is Hiraiwa & Salbreux PRL 2016 active-stress-from-turnover physics.

- **Why relevant to FF:** FF's cortex + myosin + turnover has all the ingredients for spontaneous oscillatory contraction (pulsatile cortex). If FF reproduces a wave period in the right ballpark from first principles, that is strong validation of the coupled turnover+myosin+crosslinker loop. This is the "motor-driven flows / buckling-condensation symmetry-breaking" open problem.
- **FF change:** none to the mechanism — this is a *validation target* (§5). Requires FF to run with turnover ON at physiological rates so waves can regenerate.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### 2.1 Crosslinker turnover time (α-actinin) — direct FF crosslinker kinetics
```
τ = 1 / (k_off + C0·k_on)                         (paper Eq. for τ; refs 35,36)
```
Symbol map to FF crosslinker (α-actinin) module:
- `k_off`  → FF `k_off0` (the *zero-force* off-rate in Bell-Evans k_off = k_off0·exp(F/F_b)); paper value **0.66 s⁻¹**.
- `k_on`   → FF crosslinker on-rate (second-order) **1.2×10⁶ M⁻¹ s⁻¹**.
- `C0`     → local crosslinker concentration, extract value **~1 µM** ([α-actinin], Wühr 2014).
- `τ`      → emergent turnover time; literature **0.54 s** (0.66 + 1×1.2 = 1.86 s⁻¹ → 0.54 s), fit-to-data **0.46 s**.

FF keeps the *force-dependent* form (mechanistic, this paper only used the zero-force rates); the paper supplies the **k_off0 = 0.66 s⁻¹** anchor and the k_on. Note: at zero force this reproduces the paper's τ, so FF is a strict superset.

### 2.2 Force-percolation / bridge-maturation law (network diagnostic, not a runtime force)
```
p(N)  = 1 − [ 1 − (1/2)^N ]^{T/τ}                  (Eq. 1)   probability a spanning bridge forms within time T
N     ≃ R/L = D/(2L)                               sites in series along boundary→center
τp    = 2^N · τ                                    (mean maturation time, ∝ e^R)
p(D)  = 1 − [ 1 − (1/2)^{D/(2L)} ]^{T(D)/τ}         (Eq. 2)   edge-positioning probability
Rc/L  = log2( T / τ )                              (Eq. 3)   critical radius where τp = T
```
FF symbol map:
- `N`  → number of crosslinking sites along a spanning path = (path length)/(mean filament contour length L). In FF, count occupied crosslinker sites along the actual bond-graph geodesic from cortex to interior body.
- `1/2` → per-site occupancy probability at steady state (k_on·C0 ≈ k_off so ~half occupied). FF can *measure* the true fraction from the bond graph instead of assuming 1/2 — a fidelity improvement.
- `T`  → the competing "push" timescale = actomyosin wave period (§2.3). 
- `τp` → FF-measurable: time until a tensed spanning cluster first appears.

Use this as the **acceptance oracle** (validation), never as runtime physics — consistent with the FF rule that closed-forms are oracles.

### 2.3 Wave period = active-gel turnover time (validation relation)
```
T = t0 = (time to grow contacting F-actin) + (bind myosin+crosslinkers) + (onset of ring contraction)
```
Weak size dependence measured: `T = 2.5×10⁻²·D + 39` s (control). In FF, T is emergent from turnover+myosin binding rates; the relation is a target, not a law to hardcode.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario name (proposed): "confined extract contraction + force-percolation".** A pure-actomyosin, microtubule-free FF network in cell-sized confinement — an ideal *clean* FF test because there is no membrane cortex-anchoring, no turgor, no nucleus mechanics to confound; it isolates the crosslinker+myosin+filament-length physics.

Geometry & composition:
- Circular quasi-2D confinement, diameter swept **D = 16–330 µm**, aspect ratio h/D = 0.3–0.6 (thin slab). For native FF, run the physiologically-relevant subrange straddling Dc≈85 µm (e.g. 60, 85, 120, 150 µm) at full filament density.
- Bulk (isotropic) F-actin network: [actin]~20 µM, exponential length dist with top-5% L≈5.7 µm; α-actinin crosslinkers C0~1 µM with k_on=1.2×10⁶ M⁻¹s⁻¹, k_off0=0.66 s⁻¹; myosin-II minifilaments (Stam–Hocky) with Hill f–v; turnover ON (barbed growth + severing) so the network can regenerate.
- Boundary: passive (PEG-like, no nucleation) vs Arp2/3-active (VCA-like membrane nucleation) as a two-level surface condition.
- Optional interior "cluster" (a passive rigid inclusion standing in for the nucleus-like aggregate) to read out positioning.

Protocol (matches paper's time course):
1. t=0 initialize at physiological operating point (density, [crosslinker], viscosity) — network relaxed but polymerization-competent.
2. Trigger polymerization → **initial global contraction ~10 s** sweeps material into a single central cluster (Dcluster ≈ 0.25·D).
3. Observe **periodic centripetal waves** (period T≈46 s) and, in parallel, stochastic **bridge maturation** (percolated tensed path cortex→cluster).
4. Sweep D; log positioning state (center vs edge) and the two timescales T and τp.

Perturbation matrix (each a one-line FF config change, all with measured targets):
- +α-actinin 250 nM (τ→0.09 s) → Dc↑ to 115 µm.
- +gelsolin 300 nM (L→3.2 µm) → Dc↓ to 60 µm  [needs severing channel].
- +mDia2 30 nM (L→6–10 µm) → Dc↑ to 138 µm  [formin already in FF].
- boundary PEG vs VCA → center vs edge.

## 6. RISKS / caveats

1. **k_off0 = 0.66 s⁻¹ vs FF's current 0.066 s⁻¹ (10× faster).** FF re-anchored α-actinin k_off0 to **0.066 s⁻¹ (Ferrer 2008)** after the 2026-06-02 hallucination audit. This paper (via Wachsstock 1994) uses **0.66 s⁻¹** — a full order of magnitude faster turnover. These are different measurement contexts (bulk rheology fit vs single-molecule AFM). **Do NOT silently supersede.** Register Wachsstock 0.66 s⁻¹ as a *reconstitution-context alternative* KnowledgeClaim, keep Ferrer 0.066 s⁻¹ as the FF runtime default, and surface the discrepancy to PI. The percolation prediction is sensitive to τ, so which k_off0 FF uses will shift emergent Dc — good reason to run both and see which reproduces the geometry-sensing transition.

2. **Xenopus egg extract ≠ MCF7 cortex.** All numbers are meiotic-extract, in-vitro, microtubule-free, 20 °C, no membrane cortex-anchoring, no turgor, no plasma-membrane. Per the KB flag, register these as **reconstitution reference values, not MCF7 cell-type-specific**. They are excellent for validating the *crosslinker/myosin/length mechanism in isolation*, not for setting MCF7 cortical tension γ. Do not let extract L or τ overwrite MCF7 config.

3. **Coarse-grained theory, no particle force laws.** The paper itself uses active-gel + percolation math, *not* Bell/Hill/bending. FF's value-add is precisely to *replace* their p(N)=1−[1−(1/2)^N]^{T/τ} lumped percolation with explicit filament+crosslinker dynamics and *recover* their p(D) as an emergent output. Use their equations only as acceptance oracles (§2.2), never in the FF runtime — this honors the mechanistic-over-lumped hard rule.

4. **Quasi-2D (h/D=0.3–0.6) vs FF's 3D native cell.** The assay is a thin slab; FF's native cortex is a 3D shell. Reproduce the percolation/length physics in a matched thin-slab FF scenario first (clean comparison), then check that conclusions carry to 3D — do not force the 3D native cell into a pancake to match. The scenario in §4 is a *dev/validation* geometry; any cortical-tension conclusion must still be reconfirmed on the native 38000-filament full-compartment cell (HARD rule).

5. **Native-scale + physiological-baseline compliance.** Run the FF percolation/wave scenario at full filament density with turnover, myosin, and crosslinkers ON at physiological values from t=0 — not a stripped coarse network. A coarse network would percolate/collapse as an artifact and masquerade as the mechanism (exactly the 2026-07-09 failure mode). Sweep D at native density.

6. **Severing channel is new code.** Reproducing the gelsolin arm requires adding a filament-severing kernel FF does not yet have. Scope it as a proper stochastic per-length scission process (mechanistic), validated against the measured 3.2 µm shortened length — not a length-clamp hack.
