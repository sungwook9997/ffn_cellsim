# FF lens — p18

**Paper:** Yim, Slater & Kim (2026), *Durotactic Migration Driven by Anisotropic Matrix Stiffening and Mechanical Feedback*, bioRxiv 10.64898/2026.05.19.726229 (Taeyoon-Kim lab, Purdue). 2D overdamped agent-based cell + fibrous-ECM model.

**One-line FF verdict:** This is *not* a filament-cytoskeleton paper — the cell is a coarse 2-point agent, so nothing in it upgrades FF's actin/myosin/crosslinker/formin/Arp2/3 kernels. Its FF value is entirely on the **ECM SUBSTRATE side**: it is a clean, fully-specified, tension/compression-asymmetric semiflexible *fiber-network substrate* (triangular lattice + extensional + bending + buckling + random dilution) with published *anisotropic-stiffening / plastic-recovery / radial-tension* validation numbers. It directly parallels our existing FF⊗ECM Taeyoon-Kim collagen-Mikado work (`project-ff-crawl-mechanism`, `project-dcm-ecm-kim-1r-gap`) and gives us a substrate-model to reproduce cell-driven matrix remodeling at native scale. Treat it as an ECM-substrate reference + validation battery, NOT a cytoskeleton-mechanism source.

## 1. MECHANISMS to adopt

All adoptable mechanisms are in the **ECM substrate / cell-matrix-coupling layer**, i.e. the collagen network FF crawls/pulls on. None touch the intracellular filament engine.

- **ECM substrate module — buckling asymmetry (tension-stiff / compression-soft ÷10).** The matrix chain spring uses a *piecewise* stiffness: full `κ⁰_{s,M}` in tension, `κ⁰_{s,M}/10` in compression (Eq. 13). Our FF collagen-Mikado network currently uses symmetric harmonic springs (link_k Ferrer). Adding this asymmetry is the single most important ECM upgrade here: it is the canonical fibrous-ECM nonlinearity (Storm 2005, Notbohm 2015) and is what lets a *contractile cell locally stiffen and align* the matrix (radial fiber recruitment, strain-stiffening) instead of just elastically deforming it. WHY it beats current FF: symmetric springs cannot reproduce buckle-under-compression → the emergent tensile radial tracks + F_r/F_θ≈2 remodeling signature simply do not appear. Fine-grained (per-bond, per-step sign test on `r_ij vs r_0`), not lumped.

- **ECM plasticity via random chain dilution `p`.** A fixed fraction `p` of lattice chains is removed at build time to mimic ECM porosity/permanent-crosslink plasticity (method Broedersz–MacKintosh 2011). This is exactly our Mikado connectivity-dilution knob. WHY relevant: `p` governs both stiffness anisotropy (↓ with p) and irreversible remodeling / recovery (↓ recovery with p). It gives FF a principled, single-parameter way to sit the collagen substrate at a realistic sub-isostatic connectivity rather than a fully-connected (over-elastic) lattice. Fine-grained: per-bond Bernoulli deletion, not a continuum porosity field.

- **Cell–matrix coupling as explicit viscous focal-adhesion friction `λ` (motor-clutch adjacent).** Coupling is `F_{d,Ii} = −λ(v_I − v_i)` (Eq. 9), i.e. the cell reads matrix stiffness through a *velocity-difference friction* at the adhesion, NOT a stiffness lookup (their Fig. 3E `v_i=0` control proves durotaxis is transmitted through this term). WHY relevant to FF: our clutch already resolves individual integrin bonds; this paper is the coarse-grained justification that the *stiffness signal is emergent from relative sliding at the adhesion*, which is precisely what our fine-grained motor-clutch produces natively. Use it as a cross-check that FF's clutch, run on a compliant vs stiff FF-substrate, yields the same durotactic sign — not as a mechanism to import (ours is already finer-grained).

- **Contractile remodeling → emergent anisotropic stiffening (validation scenario, not a new force).** The cell distributes a fixed total contractile force over engaged nodes `F_{c,iI}=(F_tot/N_M)·r̂` (Eq. 16), front≫rear. In FF this maps onto the cortex/adhesion pulling collagen inward via the clutch; the *emergent* outcome (radial alignment, sustained F_r/F_θ≈2 under a cohesive cluster, decay when cells escape) is a target behavior for the FF collagen network under a contractile cell.

**NOT adoptable (explicitly reject):** the 2-point polarized cell, the 6-lamellipodium random-switch (0.1 h) partition, the front/rear spring, the `α/β/η` cell drags, and the SimuCell3D tent cell-cell adhesion (Eq. 8) — these are DCM/agent-level, coarser than FF, and violate our fine-grained rule if imported into the filament engine. (Eq. 8 is a DCM-lens item.)

## 2. FORCE LAWS / KINETIC SCHEMES to port (ECM substrate only)

Map symbol → FF substrate state. FF works in µm/nN; the paper is already in µm/nN, so units drop in directly (no meter↔µm slip — cf. `reference-dcm-meters-ff-microns`).

**(a) Extensional chain (collagen segment) — Eq. 12:**
```
U_{s,M} = ½ κ_{s,M} (r_ij − r_{0,M})²      →  F = −κ_{s,M}(r_ij − r_{0,M}) r̂_ij
```
FF map: `r_ij` = current bond length between two collagen nodes; `r_{0,M}` = rest length (5 µm here); `κ_{s,M}` = FF collagen link stiffness (currently Ferrer link_k). Already present in FF — this is our existing bond, confirm sign/rest-length convention matches.

**(b) Buckling asymmetry — Eq. 13 (PORT THIS):**
```
κ_{s,M} = κ⁰_{s,M}          if  r_ij ≥ r_{0,M}   (tension)
κ_{s,M} = κ⁰_{s,M} / 10     if  r_ij <  r_{0,M}   (compression)
```
FF map: per-bond branch on `sign(r_ij − r_{0,M})` inside the Warp collagen force kernel; multiply the stretch stiffness by `1.0` or `0.1`. Differentiable-safe via a smooth `where`/tanh gate if gradients are needed. This is a 2-line kernel change to the FF ECM bond.

**(c) Semiflexible bending over node triads — Eq. 15:**
```
U_{b,ijk} = ½ κ_{b,M} (θ_ijk − θ_{0,M})²   →  angular harmonic on triad (i,j,k)
```
FF map: identical in form to FF's actin bending angle κ, but applied on the *collagen* network with its own `κ_{b,M}`. FF already has angular-harmonic bending machinery — instantiate it on ECM bonds with the value in §3.

**(d) Network viscous drags — Eqs. 11, 14 (overdamped substrate):**
```
F_{d,i}  = −γ v_i            (matrix node ↔ medium)
F_{d,ij} = −ξ (v_i − v_j)    (matrix node ↔ neighbor, dashpot)
```
FF map: FF's BAOAB already supplies per-particle medium drag (γ) via the friction/thermostat; the *relative-velocity* dashpot ξ between bonded collagen nodes is a Kelvin–Voigt element FF does not currently carry on ECM bonds. Optional add for stress-relaxation realism (see Risks — but note the paper itself is over-elastic because crosslinks are permanent).

**(e) Radial tension decomposition — Eqs. 19–20 (MEASUREMENT protocol, port as an FF observable):**
```
F_r = F cos θ ,   F_θ = F sin θ        (θ = chain angle to radial direction)
```
FF map: for a contractile cell/cluster at center, decompose every collagen bond tension into radial/circumferential and report `F_r/F_θ`. This is the key remodeling metric (target ≈2). Pure post-processing on FF bond tensions.

**(f) Stiffness-probe protocol — Eq. 17:**
```
E∥/E⊥ = ⟨D_ext,⊥⟩ / ⟨D_ext,∥⟩         (stiffness ∝ 1/displacement under fixed F_ext)
```
FF map: apply `F_ext = 0.01 nN` per node on a central 100×100 µm patch (cells absent) for 1 h, measure mean parallel vs perpendicular node displacement → anisotropy. Reusable FF substrate-characterization routine.

**Kinetic note:** there is **no bond off-rate / catch-bond / motor duty cycle / branching-angle scheme in this paper** to port — crosslinks are permanent (a stated limitation) and there is no explicit actomyosin. FF's own Bell-Evans / Hill / Stam-Hocky kernels remain the finer-grained truth; this paper does not supersede any of them.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenarios)

Two ready-made FF-substrate scenarios (build the ECM as an FF collagen network, run the FF cortex/adhesion cell on it):

**Scenario A — externally-strained rectangular substrate → anisotropic stiffening + durotaxis.**
1. Build triangular-lattice collagen, `r_{0,M}=5 µm`, dilute fraction `p=0.3`, add Eq. 13 buckling + Eq. 15 bending (`κ_{b,M}=0.001 nN·µm`).
2. Apply uniaxial normal strain `ε` (0→2.5) at left/right boundaries, top/bottom free; hold node count ≈const by shrinking `r_{0,M}` (5→2.67 µm at ε=2.5).
3. Probe stiffness: `F_ext=0.01 nN` on central 100×100 µm patch, 1 h, ∥ vs ⊥ → E∥/E⊥ (Eq. 17).
4. Seed FF cell(s), run 100 h, measure durotactic index (Eq. 18) vs ε, p.

**Scenario B — unstrained circular substrate → cell-driven radial remodeling + collective escape.**
1. Circular collagen, radius 500 µm, boundary nodes fixed, `r_{0,M}=5 µm`.
2. Seed contractile FF cell(s) in central r=50 µm region (grid 17.7 µm), remove cells within 4·R_out,F of boundary.
3. Run ~1000 h (long); trace a 200 µm analysis ring `R_a`; measure matrix contraction strain, `F_r/F_θ` (Eqs. 19–20), fraction escaped, radial-migration bias (Eq. 21, 10 h delay).
4. Toggle cohesion/contractility to reproduce the 4-condition escape battery (§5).

**Native-scale adaptation:** run the FF *cell* at native (cortex-fil 38000, full compartments, `--from-resting`) on this FF collagen substrate. The paper's cell is coarse; our contribution is that the *substrate* physics (Eqs. 12–16, 19–20) is what we import, driven by our native fine-grained cortex+clutch — not the coarse cell.

## 6. RISKS / caveats

- **Not a cytoskeleton paper.** Zero actin/myosin/crosslinker/formin/Arp2/3 kinetics. Do NOT let any 2-point-agent construct (front/rear spring, 6-lamellipodium switch, α/β cell drags, tent adhesion Eq. 8) leak into the FF filament engine — that would replace fine-grained mechanism with a coarse proxy (violates the hard rule). Confine adoption to the ECM substrate + measurement protocols.

- **Supplement gap.** The load-bearing numbers (`κ⁰_{s,M}, θ_{0,M}, F_tot, drags, Δt`) live in Table S1, absent from this PDF. Quantitative reproduction requires fetching the bioRxiv supplement first; do not back-fill with guesses (no-magic-number rule).

- **2D, not 3D.** Triangular lattice in a plane; FF collagen is 3D Mikado. The buckling/bending/dilution laws port dimension-agnostically, but the *anisotropy numbers* (E∥/E⊥, DI) are 2D-specific and should be treated as order-of-magnitude cross-checks, not exact 3D targets.

- **Permanent crosslinks → over-elastic (author-acknowledged limitation).** The model has NO bond turnover, so it under-represents stress relaxation/viscoplasticity. FF's own force-dependent Bell-Evans crosslinker off-rate is *finer-grained and better* here — keep FF's turnover; do not down-grade to permanent bonds. If reproducing their plasticity curves, reproduce via `p` (structural dilution) as they do, and note FF can additionally do it mechanistically via unbinding.

- **No force-dependent FA maturation.** Coupling `λ` is a constant viscous friction; the paper explicitly lacks catch-bond/maturation. FF's motor-clutch + integrin catch bonds are the mechanistic upgrade — use FF's clutch on this substrate rather than importing constant-λ.

- **Timescales are huge (100–1000 h).** These are substrate-remodeling times far beyond FF's native ~seconds-of-real-time budget on the A5000. Reproduce the *mechanism/sign/ratio* (buckling → anisotropy, F_r/F_θ≈2, durotactic sign) at native scale over feasible windows; do NOT quote absolute remodeling times as FF results (cf. the DCM aggregate-σ timescale-quoting prohibition, `project-dcm-compaction-turgor-blocked`).

- **Physiological-baseline compliance.** If used as an FF scenario, build the collagen substrate at its physiological stiffness/connectivity and run the cell `--from-resting` at native cortex — never a stripped or coarse cell (repeat-stated hard rule).
