# FF lens — p48

**Paper:** Kim JH & Kim T (2025), "The mechanism of dynamic steady states in lamellipodia," *PLOS Comput Biol* 21(10):e1013572. DOI 10.1371/journal.pcbi.1013572. Code: github.com/ktyman2/Lamellipodia.

**Why this paper matters for FF (one line):** This is the FF engine's *exact* paradigm — the Taeyoon-Kim Cytosim-class agent-based Brownian-dynamics framework that FF mirrors: F-actin = serially-connected cylindrical bending/stretching/torsion segments, Arp2/3 angle-harmonic 70° branch, permanent ACP cross-links, NMII via the parallel-cluster model (walk + catch-bond unbinding), Bell-model adhesion clutch, and **angle-dependent buckling-induced severing**. It supplies a near-drop-in reference implementation plus a self-consistent parameter set and a set of emergent validation targets (retrograde flow 20–30 nm/s, contractile-vs-frictional force competition, biphasic severing window). The single highest-value transfer is the **buckling-induced severing channel (Eq S9)** — it directly attacks three of FF's named open problems at once: network contraction & stress relaxation, filament turnover/fragmentation, and motor-driven flow continuity.

## 1. MECHANISMS to adopt

### 1.1 (TOP LEVER) Angle-dependent, buckling-induced F-actin severing — `turnover` module, NEW channel
- **What:** severing rate per filament segment rises exponentially with the *local bending angle* θ: `k_sev = k0_sev · exp(λ_sev · θ)`. Because k0_sev is tiny, severing is effectively silent for straight filaments and fires only where myosin contraction has buckled the network into a dense arc/bundle. One segment is removed at the mid of the filament; freed segments recycle.
- **Why it beats current FF:** FF currently has no fragmentation channel that *responds to mechanical state*. The paper shows severing is **indispensable** for a homogeneous, continuous flow: without it, myosin compacts the cortex into a bundle that traps the motors and *stalls* contraction (Fig 4A) — precisely the pathology FF sees when it tries to generate contraction/tension. Severing is what lets a highly cross-linked, highly branched network (short buckling units, high compressive resistance) actually contract instead of jamming. This is the mechanistic driver behind stress relaxation and pulsatile/reversible contraction (their refs 47, 61). Directly relevant to FF's open γ-generation / network-contraction / stress-relaxation problems: a network that can't disassemble its own compacted regions cannot sustain steady tension generation.
- **Biphasic, so it is self-limiting (a feature):** too little severing → bundle traps motors (stall); too much → filaments fragment before motors can load them (loss of connectivity). The window is a genuine emergent constraint, not a tuning knob — see §5.

### 1.2 Myosin unbinding as a *disassembly promoter*, not only a force generator — `myosin` module framing
- The paper (citing ref 27) treats NMII at the rear as doing double duty: it generates contractile force AND, via the buckling it induces, it *promotes* disassembly (through severing). FF should adopt this coupling: motor-driven buckling → elevated local θ → severing. This is emergent from §1.1 + Hill/PCM motors already in FF; no new force law, just the wiring that motor compaction feeds the severing angle field.

### 1.3 Nascent focal-adhesion clutch as a transient force-dependent elastic link with Bell slip-off — `clutch` module
- Nascent FA = transient linear-elastic spring from an actin endpoint to a substrate node, formed within a 200 nm capture radius at rate k+,C, broken by a **Bell slip-bond** that only accelerates under tension (Eq S10; §2.2). FF's motor-clutch already has integrin catch bonds; this paper's contribution is the *population-level* result: the clutch friction saturates because link force-dependent unbinding caps the total transmissible force (plateau in Fig 5G, 6G). This is the mechanistic origin of the "grid-drag caps crawl speed" behavior FF sees — friction is set by a competition, not a fixed drag. Use it to reframe FF's crawl-speed-vs-drag open problem as **contractile force vs. force-limited adhesion friction**, which has an escape route (§4.4 rescue modes).

### 1.4 Assembly/disassembly spatial balance for steady flow — `turnover`/scenario
- Steady retrograde flow = front assembly (barbed polymerization + Arp2/3 branching, capped at 0.98 µm) balanced against rear disassembly (pointed depolymerization + severing), with monomer recycled through a closed pool (≥10% free-monomer floor). FF has barbed-end growth already; the missing pieces are (a) spatially-localized pointed-end depolymerization and (b) the severing channel, plus (c) a monomer-conservation pool so growth is disassembly-limited. Together these convert FF's one-shot protrusion/crawl into a *sustained* dynamic steady state.

### 1.5 ACP cross-link density sets whether the network contracts *as a whole* — `crosslinker` module
- Below a threshold ACP density the motor forces don't percolate transverse to the flow, so the network stalls against FA friction instead of contracting uniformly (S4). Because Arp2/3 branches all point toward the leading edge, there is no natural transverse percolation — ACPs supply it. Lesson for FF cortex/lamellipodium: cross-linker density is a *connectivity percolation* control on whole-cell contraction, not just a stiffness knob. FF already has α-actinin/filamin explicit bonds; register the percolation threshold as a design constraint.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### 2.1 Angle-dependent severing (Eq S9) — PORT verbatim
```
k_sev = k0_sev · exp(λ_sev · θ)
```
- θ = instantaneous local bending angle at the segment junction (same θ FF already computes for its bending potential U_b = ½κ_b(θ−θ₀)²). Symbol map: `k0_sev` → FF `turnover.sever_k0` (s⁻¹), `λ_sev` → FF `turnover.sever_angle_sensitivity` (deg⁻¹ — NOTE θ enters in **degrees** here, keep units consistent), θ → the bend angle already in FF's angular-bond state. On fire: delete one segment at filament midpoint, sever the bond, return both fragments to the pool; any Arp2/3/ACP/motor bound to the removed segment loses that connection and is free to rebind. Provenance: adapted from Kim ref 61, validated against McCullough 2011 (ref 46) severing-angle distribution.

### 2.2 Bell slip-bond FA unbinding (Eq S10) — cross-check FF clutch
```
k_u,C = k0_u,C · exp( λ_u,C · F_s,C / k_B T )   if  r ≥ r0,C   (under tension)
k_u,C = k0_u,C                                   if  r < r0,C   (slack — no acceleration)
```
- F_s,C = spring force on the link; r, r0,C = instantaneous / equilibrium link length. Symbol map: `k0_u,C` → FF `clutch.koff0`, `λ_u,C` → FF `clutch.force_sensitivity` (units of length/energy so that λ·F/kT is dimensionless — i.e. λ_u,C = x_β / (something) — confirm against FF's Bell x_β convention), F_s,C → link tension. Key nuance FF should replicate: **slip only under tension** (compressed/slack links keep the zero-force rate). This is a slip-bond (contrast FF's integrin *catch* bond — see §6 caveat).

### 2.3 Parallel-cluster-model (PCM) motor kinetics — cross-check FF myosin
- NMII motor = backbone + 8 arms, each arm = 4 heads (N_h=4); arm binding rate = **40·N_h** = 160 s⁻¹. Walking rate k_w,M and unbinding rate k_u,M come from the Erdmann–Schwarz PCM (their refs 48,49; FF-lineage benchmarking in ref 78): 3 head states, 5 transition rates; **k20** = ATP-dependent post-power-stroke→unbound transition. Catch-bond assumption: both k_w,M and k_u,M *decrease* with smaller k20 or larger load. Calibration anchor: at reference k20 = 17 s⁻¹ → unloaded v = **120 nm/s**, stall F = **5.33 pN** per arm. FF uses Hill (1938) + Stam–Hocky minifilament — this is a *different* motor mechanochemistry (PCM vs Hill). Do NOT swap FF's Hill law; instead use the {120 nm/s, 5.33 pN} operating point as a **cross-check target** for FF's force-velocity curve (§5), and treat the "walk-and-unbind both scale with k20/load (catch)" behavior as a qualitative consistency check.

### 2.4 Cylinder drag (Eq S2) — cross-check FF's per-segment drag
```
ζ_i = 3π μ r_c,i · (3 + 2 r0,i / r_c,i) / 5
```
- μ = medium viscosity, r0,i = segment length, r_c,i = segment diameter. Use to sanity-check FF's per-bead drag against a Cytosim-class cylinder approximation. NOTE FF must set μ to the **physiological ~65 Pa·s MCF7 cytoplasm** (project HARD rule), NOT the low water-like value this in-vitro-flavored 2D model may use — see §6.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

### 4.1 "Lamellipodial retrograde-flow steady state" scenario
- **Geometry:** thin slab **5 µm (x) × 2.5 µm (y) × 0.1 µm (z)**. PBC in x; +y repulsive (leading edge), −y sticky (lamella interface); z walls repulsive. Substrate = fixed-z triangulated mesh (50 nm edges) at z=0.
- **Spatial zoning (Fig 1C):** assembly/barbed-polymerization zone y=2.125–2.5 µm; disassembly/pointed-depoly zone y=0–0.375 µm; motor zone y=0–0.1875 µm (motor drag ×1000 to pin motors, prevent +y drift); FA-formation zone y=0.325–0.675 µm (scaled by A_FA); flow measured near +y.
- **Build:** self-assemble branched net from −y-nucleated seeds, barbed ends biased +y, elongate ≤0.98 µm, Arp2/3 branch (70°), ACP cross-link. ~90% actin into network, ≥10% free-monomer pool. Then turn on motor walking → rear contraction → retrograde flow.
- **FF fit:** this maps cleanly onto FF's lamellipodium architecture (Arp2/3 70°±35°). It gives FF a *self-contained, well-posed* scenario to demonstrate emergent sustained retrograde flow + traction, distinct from FF's whole-cortex cell. Use as a mechanism-isolation testbed for the severing channel BEFORE porting severing into the native 38000-filament cortex.

### 4.2 Measurement protocol
- Flow speed = y-component of front F-actin velocity, sampled every 2 s in a +y rectangle. F-actin density = 40 y-bins normalized to N_A/40. Heterogeneity = coefficient of variation (CoV) of density along y. Total substrate force = Σ FA-link spring forces.

### 4.3 One-parameter sweeps (each has a threshold/window — reproduce as FF sanity sweeps)
k−,A (0/4–6/≥8), k0_sev (0 / 10^−5.5–10^−4.5 / 10^−2.5), λ_sev (0.5/1.0/2.5), R_M (0.001–0.04), A_FA (0–0.5), k20 (2/6/17/30), k+,A (0.4/>1/24), R_Arp2/3 (0.006/0.01/0.016), R_ACP (0.005/0.02/0.08).

### 4.4 Rescue / multi-mode protocol (mechanistic coupling test)
- A network that fails from **too few motors** (R_M=0.0015) is rescued by *lowering* FA friction (A_FA→0) OR *raising* R_M→0.004 — both give ~35 nm/s.
- A network that fails from **too-fast depoly** (k−,A=10) is rescued by *raising* flow speed (R_M→0.01 or A_FA→0.05) — gives ~35–45 nm/s (faster than reference).
- **FF use:** this is a direct test that FF's contractile-force-vs-adhesion-friction competition and assembly/disassembly balance are *coupled* the same way — a strong falsifiable cross-check of FF's emergent motor-clutch physics.

**Key mechanistic validation claims to reproduce in FF (not just numbers):**
1. Without severing, myosin compacts the net into a bundle that *traps motors and stalls contraction* (a jamming pathology).
2. With intermediate severing, contraction proceeds and the network stays homogeneous (CoV minimized).
3. Total transmissible traction *plateaus* because FA slip-bond unbinding caps force — traction is force-limited, not drag-limited.
4. Flow onset is *abrupt* (frictional-slippage transition) once contractile force exceeds FA friction.

## 6. RISKS / caveats

- **This is a 2D lamellipodium assay, not the 3D MCF7 cortex.** The geometry, fixed spatial zones (assembly-front / disassembly-rear / motor-rear / FA-mid), and −y-sticky boundary are 2D-crawl-specific. Adopt the *severing channel and rate law* (which are geometry-agnostic and fire on bending angle wherever buckling occurs), but do NOT import the fixed zones into the native cortex — in the 3D cortex, buckling/severing should be spatially emergent, not zoned. **Per the project HARD rule, validate the ported severing at NATIVE scale (38000-filament cortex, --from-resting, full compartments), not on this thin coarse slab.** Use the 5×2.5×0.1 µm scenario only as a mechanism-isolation smoke test, labelled non-authoritative.

- **Coarse-graining choices are NOT physiological setpoints.** C_A=250 µM (real lamellipodium 500–1000 µM), r0,A=140 nm segments, and longer/fewer filaments + extra ACPs are deliberate compute-efficiency compromises the authors flag themselves. FF's rule is native scale + physiological operating point from t=0: keep FF's own segment length, filament count, and its measured actin density (KB-3.18 ~100/µm²). Adopt the *mechanism*, not the coarse numbers.

- **Permanent (non-unbinding) ACPs violate FF's mechanistic rule.** The paper freezes cross-links (k_off=0) for simplicity. FF must keep **Bell-Evans force-dependent crosslinker off-rate** (α-actinin k_off0=0.066 s⁻¹ Ferrer 2008, per project KB) — do NOT regress to permanent links. The paper's *percolation-threshold* insight (§1.5) still transfers; the permanence does not.

- **FA link is a slip-bond; FF integrins are catch-bonds.** Eq S10 is pure Bell slip (rate rises with force). FF's integrin clutch uses catch-bond kinetics (Rakshit KU-4.2). Use Eq S10 only to cross-check the *nascent* FA slip regime / the force-limited traction plateau — do NOT replace FF's catch-bond with a slip-bond.

- **PCM vs Hill motor mechanochemistry.** The motor kinetics (parallel cluster model, k20) are a *different* formalism from FF's Hill(1938)+Stam–Hocky. Keep FF's Hill law (mechanistic rule already ratified); use {120 nm/s, 5.33 pN, catch-like load dependence} purely as force-velocity cross-check anchors.

- **Viscosity / baseline.** The BD drag (Eq S2) likely uses a low, in-vitro-like μ. FF must run at the physiological ~65 Pa·s MCF7 cytoplasm from t=0 (HARD rule) — do not inherit a water-like μ or the implied fast timescales. The severing *rate* k0_sev=3.2×10⁻⁵ s⁻¹ and the flow speeds are calibrated to the paper's conditions; re-anchor the severing window in FF by matching the *emergent* McCullough severing-angle distribution rather than transplanting the absolute rate.

- **No deformable membrane / no Brownian ratchet in this paper.** Flow is driven *solely* by rear motors (repulsive +y wall contributes ~nothing). FF *does* have membrane + polymerization ratchet — so FF should NOT strip those; expect the parameter thresholds to shift once front-pushing is present (the authors say so explicitly). Treat all thresholds/windows as regime-specific, to be re-mapped in the full FF stack.

- **Exact stiffnesses (κ_s,A, κ_b,A, κ_t,Arp2/3, κ_s,C, k0_u,C, λ_u,C) are in the S1 Table PDF**, not in the retrieved main text. Fetch the S1 Table (or the open-source repo `github.com/ktyman2/Lamellipodia`) before quoting any bending stiffness numerically; do not KB-register the oracle κ values (oracle = cross-check, not truth — per project rule).
