# DCM lens — p51

**Paper:** Hassan, Biel & Kim (2019), "Mechanical Model for Durotactic Cell Migration," *ACS Biomater. Sci. Eng.* 5(8):3954–3963. DOI 10.1021/acsbiomaterials.8b01365. Taeyoon Kim lab (Purdue).

**One-line honest verdict for DCM:** This is a *substrate-mechanics + emergent-durotaxis* paper whose **cell** is far coarser than DCM (two lumped points, no surface mesh, no volume, no cortex). It contributes **nothing to DCM's cell-body compartments** (γ generation, division, bleb, confinement). Its genuine, portable value for DCM is (1) a **viscoelastic (Kelvin–Voigt) triangulated ECM/substrate** the DCM cell can be seated on — a stretch+bend+per-edge-viscous-drag network — and (2) a set of **emergent-durotaxis validation targets** for any adhesive DCM-cell-on-substrate scenario. Treat as a **substrate/scenario reference**, not a cell-mechanism source. (Same Kim-lab fiber-network family already referenced in `[[project-dcm-ecm-kim-1r-gap]]`.)

## 1. MECHANISMS to adopt

Ranked by real applicability to DCM at our single-cell fine-grained scale.

### M1 — ECM/substrate as a **viscoelastic triangulated spring network** (stretch + bend + per-edge viscous drag) — *DCM contact/ECM layer*
**What:** Model the substrate/ECM the DCM cell adheres to as points on an equilateral-triangular lattice, connected by chains carrying a **stretch spring** (Eq. 9), a **bending spring** on triplets (Eq. 10), and a **per-edge viscous drag** between adjacent nodes (Eq. 11). Randomly delete a fraction `p` of chains (each node keeps 0–6) to mimic ECM polymer connectivity/disorder.
**Why it beats what DCM does now:** DCM's current cell-substrate/ECM coupling is a node-face penalty contact against effectively rigid/elastic geometry; there is no *dissipative* substrate with a tunable elasticity-vs-viscosity balance. This paper's key physical finding is that the **Kelvin–Voigt short-vs-long-timescale split** (spring transmits force at all times; drag only resists at short timescales, relaxes at long) is *the* control knob for whether a substrate can *sustain* cell traction. That dissipative-substrate physics is exactly the missing ingredient for DCM durotaxis/traction-on-viscoelastic-ECM and is a strictly-more-mechanistic substrate than a rigid plane. It is also fine-grained (explicit nodes/edges), consistent with our hard rule.
**Caveat:** the *disorder* is frozen (connectivity fixed in time) — acceptable for a substrate, but do NOT reuse this as a model for the living cortex (which remodels).

### M2 — **Non-centripetal, torque-derived traction** on adhesions (constant-strain-energy driver) — *DCM adhesion/traction*
**What:** Instead of prescribing traction magnitude, generate it from a **constant torque** τ per motile unit (Eq. 7), balanced by **tangential (non-centripetal) contractile forces** on adhesion points, with the magnitude *solved*, not set, via a kinematic constraint (Eq. 12). Physical motivation: measured substrate strain energy is ~constant regardless of stiffness (ref 48 Gardel).
**Why it beats what DCM does now:** DCM aggregate-σ and cadherin junctions are contraction models for cell–cell, but DCM has **no cell–substrate traction law** that is stiffness-adaptive without a sensing rule. The torque/constant-strain-energy formulation gives an *emergent* stiffer→bigger-traction response for free (stiffer substrate resists more → larger solved force at the same torque), which is the mechanistically-honest way to get durotaxis without a decision rule — aligned with our "no lumped stiffness-sensing switch" preference.
**Caveat:** the paper's *centripetal-vs-tangential* geometry is tied to its 2-point cell; for DCM the natural home is FF (fine-grained clutch/retrograde-flow traction, `[[project-ff-crawl-mechanism]]`). For DCM adopt only the **constant-strain-energy / traction-emerges-from-substrate-resistance principle**, not the 2-point torque machinery.

### M3 — **Emergent durotaxis, no decision rule** — *DCM scenario/validation philosophy*
**What:** Directed migration toward stiffer regions arises purely from cell↔substrate mechanics; the cell changes *no* property in response to stiffness.
**Why it matters for DCM:** This is the same "mechanism must EMERGE, no binary latch" principle the PI enforced for the cadherin junction (`[[feedback-junction-switch-fine-grained]]`). It gives DCM a clean acceptance criterion: any future DCM-on-graded-ECM run must produce durotaxis *without* a stiffness-conditional parameter. Adopt as a **design constraint + validation target**, not a code module.

### M4 — **Overdamped quasi-static linear solve `Mu = f` per step** — *DCM solver architecture (informational)*
**What:** Eqs 1,7,8,12 assemble into `Mu=f` (Eq. 13): M from instantaneous geometry, u = unknown node velocities + adhesion force magnitudes, f = torques + spring/bending forces; solved each step.
**Why note it:** DCM is overdamped/quasi-static too. The paper's structure — *solve for forces AND velocities simultaneously under a kinematic (inextensible-string) constraint* — is a constraint-based alternative to DCM's explicit IPC/penalty stepping. Low priority (DCM's differentiable-Warp explicit path is deliberate), but worth logging as an architectural comparison for the T1/adhesion-constraint work.

## 2. EQUATIONS to port (to the DCM surface-mesh / ECM-node level)

Port targets are the **substrate/ECM node & edge** laws (DCM-adjacent), not the 2-point cell laws.

**(Eq. 9) Chain stretch** — port to DCM ECM edge:
```
U_s,ij = ½ κ_s,M (r_ij − r_0,M)²   →   F_s,ij = −κ_s,M (r_ij − r_0,M) r̂_ij
```
Map: `i,j` = ECM/substrate mesh nodes; `κ_s,M` → ECM edge extensional stiffness (nN/µm); `r_0,M` = edge rest length (= lattice spacing set by density `n`). This is the elasticity knob varied spatially for durotaxis.

**(Eq. 10) Triplet bending** — port to DCM ECM angular springs:
```
U_b,ijk = ½ κ_b,M (θ_ijk − θ_ijk,0)²
```
Map: angle at node `j` in triplet `i-j-k`; `κ_b,M` = bending stiffness (nN·µm); `θ_ijk,0` = rest angle, **allowed to vary with the number of removed chains at a node** (disorder-dependent reference angle — important detail: don't set all rest angles equal). Gives linear-elastic-at-low-strain + strain-stiffening — the physiologically-correct ECM response.

**(Eq. 11) Per-edge viscous drag** — the KEY new law for DCM's ECM (**this is the transferable physics**):
```
F_d,ij = −ξ (v_i − v_j)
```
Map: relative-velocity drag between *connected* ECM nodes; `ξ` = substrate viscosity (nN·hr/µm). Combined with Eq. 9 this makes each edge a **Kelvin–Voigt element** (spring ∥ dashpot). DCM currently has cytoplasm viscosity and per-node medium drag but **no Kelvin–Voigt relative-velocity drag on the ECM/contact network**; adding this is the single most portable mechanistic upgrade from this paper.

**(Eq. 2) Medium drag** — already the form DCM uses (`F = −η v`); confirms overdamped consistency, no change needed.

**(Eq. 7) Torque balance / (Eq. 12) kinematic constraint** — port ONLY conceptually to DCM traction:
```
τ_I − γ ω_I + Σ_i Δ_I,i × F_C,Ii = 0      (constant-torque driver)
L·v_I − L·v_i + (Δ×L)·ω_I = 0             (adhesion reeled along inextensible tangent)
```
Do **not** transcribe the matrix into DCM (2-point-cell-specific). Carry across the **invariant** it encodes: traction magnitude is *whatever the substrate resistance requires to dissipate a fixed active energy budget* — i.e. constant strain energy per adhesion, stiffer substrate ⇒ larger solved traction.

**Reaction law** `F_C,Ii = −F_C,iI` (Newton's 3rd) — trivially already respected by DCM node-face penalty.

## 4. GEOMETRY / PROTOCOL to reproduce (as DCM scenarios)

**Scenario A — sharp stiffness step (durotaxis test-bed):** 500×500 µm viscoelastic ECM (M1), PBC in y, fixed x-boundaries. Left half `κ^H_s,M`, right half `κ^L_s,M`, ratio 100:1; uniform ξ. Seat one adhesive DCM cell (`--from-resting`, full compartments) at the interface, oriented +y. Run 12 h. Expect emergent bias toward stiff (left). Sweep κ^L ∈ {0.001, 0.01, 0.1} nN/µm × ξ ∈ {0.025, 0.05, 0.1, 0.25}.

**Scenario B — stiffness gradient (reorientation test):** same domain; κ_s,M steps down left→right, center-line fixed at 1 nN/µm; gradient ∈ {0, 20, 80, 200} pN/µm². Seat cell at center, orient ±x. Run 36 h. Expect: above a critical gradient, +x-initialized cells reorient toward −x (stiff).

**Scenario C — substrate calibration (no cell):** stretch the ECM ±x by 5% with center-line fixed; verify elasticity-dominated region sustains larger, longer-lived forces than viscosity-dominated region (paper Fig S8c). This is the **acceptance test for the M1 Kelvin–Voigt ECM** before any cell is added — a clean, cell-free sanity gate.

**Scenario D — traction/force-map readout:** under the 200 pN/µm² gradient, record per-edge ECM chain forces over 0→36 h; expect an **asymmetric front-larger/rear-smaller dipole** and force accumulation biased into the stiff region.

All of these plug into DCM's existing "adherent cell from resting checkpoint" path; the only new engine piece is the M1 viscoelastic ECM.

## 5. VALIDATION TARGETS (DCM observables)

Numbers a DCM-on-viscoelastic-ECM run should reproduce:

| observable | target | condition |
|---|---|---|
| Durotactic index DI (strong bias) | ≈ 1.0 | low ξ, elastic stiff region |
| DI (unbiased PRW baseline) | 0.5 | high ξ (durotaxis screened) |
| DI vs soft-region stiffness κ^L | **biphasic** (peak at intermediate κ^L) | sharp step, low ξ |
| DI vs viscosity ξ | **monotonic decrease → 0.5** | sharp step |
| **DI high-level transition** | at κ^H ≈ **0.15 nN/µm** | independent of κ^L |
| Average migration speed | **10–35 µm/hr** (sharp-step); 5–25 (ratio sweep) | Fig 3c/4c |
| Speed dependence | ↑ with **both** κ and ξ (short-timescale resistance) | — |
| Speed vs orientation | depends **only** on local stiffness, NOT orientation | high gradient |
| Distance before reorientation | **∝ 1/gradient** (~200 µm @ low → ~50 µm @ 200 pN/µm²) | +x-init |
| Fraction reaching soft boundary | → 0 at high gradient (all reorient to stiff) | 36 h |
| Peak per-edge ECM force | up to ~**0.5 nN** | migrating cell, 200 pN/µm² |
| Force pattern | asymmetric dipole (front > rear), accumulates in stiff region | gradient |
| Substrate response | linear-elastic at low strain, strain-stiffening at high | κ_b,M=1, p=0.4 |

**Discriminating check (the paper's own logic):** speed rises with stiffness but is orientation-independent ⇒ speed is *not* the durotaxis mechanism. A DCM run that produces durotaxis via a speed-only asymmetry would be reproducing an artifact, not the mechanism.

## 6. RISKS / caveats (and how to adapt without breaking physiological-baseline)

1. **The cell is not a DCM cell.** Two lumped points, no membrane/cortex/nucleus/volume, no cortical tension. **Nothing** about γ generation, division, bleb, confinement, or compaction-rate transfers. Do not mine this for cell-body mechanism. → Use the FF engine for the *cell* side of durotaxis (fine-grained clutch traction, already built, `[[project-ff-crawl-mechanism]]`); use DCM only if/when the DCM cell is seated adhesively on the M1 ECM.

2. **2D, in-vitro, fibroblast/MSM-shaped.** Our target is 3D MCF7-like (R≈7.5 µm). The substrate lattice is 2D-planar; DCM is 3D. Adapt by using M1 as a **2D basal substrate** the 3D DCM cell adheres to (physiologically correct: cell on a dish/ECM), NOT by forcing the cell into 2D. Cell stays at its 3D physiological baseline.

3. **Frozen substrate disorder + no FA dynamics.** Connectivity fixed; all in-region points become FAs instantly (no force-dependent bond kinetics — the paper flags this as its own limitation). This VIOLATES our fine-grained rule if used for the *adhesion* layer. → Keep DCM adhesions on the **Rakshit catch-bond / clutch** mechanism (KU-4.2), NOT this instant-FA rule. Borrow only the *substrate elasticity/viscosity field*, which is legitimately structural.

4. **Constant-torque driver is a lumped active law.** τ per point is an assumed constant (dimension of energy), motivated by constant-strain-energy (ref 48) — defensible as a *principle* but it is a proxy, not fine-grained motor mechanics. → For DCM/FF keep the driver as **explicit myosin/retrograde-flow traction**; use the constant-strain-energy observation only as a *cross-check target* (does emergent DCM traction hold strain energy roughly constant across stiffness?), never as the runtime law.

5. **ξ units are nN·hr/µm** (hour-scale), reflecting the 12–36 h migration timescale — 10⁶-scale different from DCM's second-scale mechanical relaxation. This is exactly the timescale trap flagged in `[[project-dcm-compaction-turgor-blocked]]` (don't quote drag-limited rates as physiological). Convert carefully and treat migration-timescale numbers as *behavioral* targets, not mechanical-relaxation rates.

6. **Physiological-baseline compliance:** initialize the M1 ECM at a *real* MCF7-relevant substrate modulus, not the paper's abstract 0.001–10 nN/µm sweep values, when doing a *production* DCM run — the sweep is for mechanism discovery. Anchor κ_s,M to a physical ECM/gel Young's modulus (surface to PI for the MCF7 substrate value; do not default to a convenient number). ξ likewise must be a real viscoelastic-gel value, not tuned to hit a DI target (no-gate-fitting rule).

---

**Bottom line for the DCM engine:** one genuinely portable mechanism (M1: viscoelastic Kelvin–Voigt triangulated ECM, Eqs 9–11, with the per-edge drag ξ being the novel ingredient DCM lacks), one portable *principle* (M2/M3: constant-strain-energy emergent traction ⇒ decision-free durotaxis), and a full durotaxis scenario+validation suite (§4–5). The cell model itself is below DCM fidelity and is not adopted.
