# TAG-validation lens — p24

**Paper**: Jung, Tabatabai, Thomas, Tabei, Murrell & Kim (2019), "Dynamic motions of molecular motors in the actin cytoskeleton," *Cytoskeleton* 76(11–12):517–531, DOI 10.1002/cm.21582.
**Lab**: Taeyoon Kim (Purdue) agent-based Brownian-dynamics actomyosin model + Murrell (Yale) in-vitro reconstitution.

## Paper kind

**simulation** (primary) — agent-based coarse-grained Brownian-dynamics (over-damped Langevin) of F-actin + ACP cross-linkers + myosin motors as cylindrical segments, **with a supporting in-vitro reconstitution experiment** (2-D phalloidin-stabilized F-actin + α-actinin + skeletal-muscle myosin on a supported lipid bilayer).

Consequence for use: the paper's headline **curves and observables (Figs 2–6: TE-MSD magnitudes, avg force/head, fraction-of-stalling, g_max/g_init, time-to-stall) are MODEL OUTPUTS → comparison-only, never a truth source.** The reconstitution numbers (Fig 4e,f) are **experimental → overlay/cross-check only, never fit.** The registrable, defensible material is the set of **literature-sourced input parameters** the model imports from primary papers (Ferrer 2008, Cuda 1997, Erdmann/Schwarz PCM, Harris & Warshaw 1993) — those are the citable anchors, not this paper's own outputs. Bell's-law slip-bond (Eq 1) is a re-use of an existing oracle form, not a new closed form.

This is squarely an **FF-engine** paper (fine-grained segmented filaments + Bell slip-bond cross-linkers + force-dependent motor walk/unbind + F-actin treadmilling). DCM relevance is weak/indirect (only the "cortical turnover relaxes stress" qualitative insight).

## Coverage vs existing gates

- **Myosin stall force** — directly touches **PARAM-F_stall_motor** (default **2 pN**, KU-2.4/2.18). This paper's **3.8 pN/head** (Erdmann/Schwarz PCM single myosin-II head) is the canonical value and **CHALLENGES the 2 pN default** (nearly 2×). It also sits against the CLAUDE.md "F*=7pN kept AS-RECORDED, do not retune, flag for later debug" note. Net: this paper is a clean **literature anchor** for the debated FF motor stall — flag for the PI-owned F* debug, do **not** auto-change.
- **Unloaded motor velocity** — touches **PARAM-v_unloaded** (default **100 nm/s**, range 10–100, KU-2.4/3.12). Paper's NMII **<140 nm/s (Cuda 1997)** is CONSISTENT and slightly widens the upper bound; the 100 default is within the paper's bound. **CONFIRMS** (mild), no change needed.
- **Bell / catch-slip bond** — the existing **Bell-Evans oracle** + **VG-U2-catch-slip-bond** (integrin, peak ~30 pN) and **MC-U2-fa-motor-clutch** (Bell-Evans off-rate). Paper's Eq 1 is the same slip-bond form applied to the ACP cross-linker; it **CONFIRMS the oracle form** and supplies a filamin-A anchor (k⁰=0.115 s⁻¹) for a cross-linker off-rate — but note the KB already re-anchored the **α-actinin** k_off0 to 0.066 s⁻¹ (Ferrer 2008); **0.115 s⁻¹ is the filamin-A value**, a different cross-linker — register separately, do not overwrite the α-actinin row.
- **Cross-linker kinetics generally** — no existing gate holds an FF cortex cross-linker off-rate as a contract (VG-U3-cortex-multifilament is a Phase-2 topology gate, band = "Bell-Evans crosslink dynamics active", no numeric off-rate). So the filamin-A k⁰ is **new territory** at the FF cortex level.
- **MSD anomalous transport / motor mobility** — **no existing gate** covers intracellular motor MSD or its anomalous exponent. Uncovered.
- **F-actin turnover / treadmilling rescue** — **no existing gate**; the FF cortex has a barbed-end growth kernel (KB-3.6) but no validated turnover-rate contract. Uncovered (and mostly simulation-derived, so weak candidate).

## Oracle candidates

- **Bell slip-bond off-rate (Eq 1)** k_u = k⁰·exp(λ·|F|/k_BT) for r≥r₀ (else k⁰). This is the **existing Bell-Evans oracle form** applied to a cross-linker — **CONFIRMS the oracle**; supplies filamin-A parameters (k⁰=0.115 s⁻¹, λ from Ferrer 2008) for a cross-linker instantiation. Not a new oracle.
- **Parallel Cluster Model (PCM, Erdmann & Schwarz 2012)** for force-dependent myosin walking/unbinding rates (both monotonically decreasing with arm load, stall at 3.8 pN/head). This is a **more-mechanistic candidate oracle than the current Hill force-velocity oracle** for a multi-head myosin cluster — worth noting as a future cross-check oracle for the FF motor kernel (cooperative several-head mechanochemistry), but the closed forms live in the Erdmann/Schwarz papers, not here. **Candidate — PI review.**
- **MSD estimators (Eqs 2–4: TE-MSD, E-MSD, τ-MSD) + α power-law classification** — a standard measurement-protocol / analysis convention, not a physics oracle; useful as the FF motor-tracking analysis recipe (τ=10 s lag, ergodicity check E-MSD≈TE-MSD). Register as method, not oracle.
- **Radial distribution g(r) (Eq 5)** aggregation metric (Δr=20 nm, 0.1–1 µm window, g_max/g_init) — analysis convention for FF network heterogeneity; method, not oracle.
