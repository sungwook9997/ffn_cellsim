## 1. Mechanisms to adopt  (HIGH relevance — squarely FF/Cytosim regime)
- **Myosin-minifilament steric penetration vs mesh size.** FF represents myosin as Stam–Hocky bipolar minifilaments and actin as a network with an emergent mesh. This paper gives the *quantitative steric gate*: a ~1.32 µm minifilament is excluded from a network when inter-filament spacing ≲110 nm and penetrates when ≳160 nm — an all-or-none transition over only ~2.5× density. FF should reproduce this excluded-volume/mesh interaction directly (LJ excluded-volume between minifilament body and filaments), giving a mechanistic myosin-engagement gate instead of assuming motors always bind.
- **Motor-assisted (active) insertion.** Penetration is blebbistatin-sensitive → ATPase activity helps insert the motor into sparse networks. FF's Hill-motor + excluded-volume should show this emergently.
- **Cofilin severing vs network density (turnover channel).** Small severers (~3.5 nm) penetrate regardless of density, yet disassembly is sharply suppressed above ~20–30 µM actin (non-steric: impaired fragment escape + impaired twisting in branched/entangled networks). A candidate FF turnover refinement: severing rate that depends on local entanglement/branch density, not just a constant k_sever.
- **Branched (Arp2/3) network with capping + profilin** at controlled density — a clean FF architecture target (the FF lamellipodium uses Arp2/3 70°±35°).

## 2. Force laws / kinetic schemes to port
- Disassembly scaling `Ḋ ∝ ρ_actin^(-2) · ρ_cofilin,bound` → FF severing-rate density dependence.
- Steric exclusion = hard-body: engagement when local mesh spacing ξ ≳ L_myofilament (~1.3 µm). Encodable as the existing excluded-volume LJ between the minifilament and surrounding filaments.

## 4. Network architecture / protocol to reproduce
- Density-controlled branched network (VCA→Arp2/3, capped, profilin) at 2–50 µM actin; inject myosin minifilaments → measure penetration vs ξ. A direct FF steric-gate benchmark.
- Density-gradient network + myosin → directed actin flow toward dense region (FF emergent-flow test needing only gradient + connectivity).

## 5. Validation targets for FF observables
- All-or-none myosin exclusion at ξ ≈ 110 nm (excluded) / 160 nm (penetrates).
- Directed flow toward densest region; sparse region disconnects and floats.
- Cofilin-driven disassembly rate vs actin density (power-law with exponent ≈ −2).
- Actin+myosin condensate forms in sparse but not dense networks.

## 6. Risks / caveats
- Purified rabbit-actin + smooth-muscle myosin on an SLB, 2D-ish membrane-templated geometry — not the 3D MCF7 cortex; use the steric/mesh thresholds and severing-density law as mechanism + cross-check, validate at NATIVE 38000-filament scale. SMM ≠ NMIIA (isoform); treat the 1.32 µm as a myosin-minifilament length cross-check, not a substitution for the NMII datum. Score ≈ 2.5/5 (high mechanism value, in-vitro regime).
