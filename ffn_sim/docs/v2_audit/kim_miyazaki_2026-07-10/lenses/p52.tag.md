# TAG-validation lens — p52

**Paper:** Kubota et al. 2021, *Microscopic Temperature Control Reveals Cooperative Regulation of Actin–Myosin Interaction by Drebrin E*, Nano Lett. 21, 9526–9533. DOI 10.1021/acs.nanolett.1c02955.

## Paper kind

**experimental** (in-vitro reconstitution: HMM/actin gliding-motility assay + single-molecule Qdot tracking + cosedimentation affinity). No computational model, no continuum mechanics, no closed-form dynamical law. All equations are empirical/geometric fits (temperature-gradient calibration, per-event velocity/temperature estimators) or a phenomenological Hill dose–response fit — none is a mechanistic force/kinetics law. Consequence for use: every number here is an **overlay / on-demand cross-check target**, never a fit target and never a runtime mechanism. The engine (MCF7 single-cell DCM cortex + FF filaments) does not model drebrin E, neuronal actin side-binders, or temperature-dependent motor kinetics, so nothing here is a current-contract input.

## Coverage vs existing gates

No existing gate covers any observable in this paper. Nearest neighbours, and why none is a match:

- **Hill force-velocity oracle** (validation philosophy list) — this is the closest analytic relative, but the paper's "Hill equation" is an **inhibitory dose–response in [drebrin]** (Eq 4: `v = 1 − Cⁿ(1−b)/(kⁿ+Cⁿ)`), NOT the Hill 1938 force-velocity law the oracle implements. They share only the name. No confirm/tighten/challenge relation.
- **PARAM-v_unloaded = 100 nm/s** (Actin retrograde flow, KU-2.4/3.12) — this is *retrograde flow speed*, a different observable from HMM *gliding-assay sliding velocity* (~7–15 µm/s, ~100× faster). The paper does NOT challenge v_unloaded; it is a distinct in-vitro reconstitution speed and should not be conflated.
- **PARAM-F_stall_motor = 2 pN** (KU-2.4/2.18) — the paper reports no per-head force, so no relation.
- **VG-H7-gate-a/b, VG-H3-KU35** (active cortical tension γ) — these concern MCF7 cortex tension magnitude; drebrin E is a neuronal regulator absent from the MCF7 cortex model. The paper's temperature-dependence of actomyosin activity is mechanistically adjacent but supplies no MCF7 datum and no band.

Net: this paper adds **no coverage overlap** and **challenges no current band**.

## Param candidates

All experimental, all staged as literature/parameter rows only — none supersedes a current Parameter row, none is a runtime input today.

- **PARAM-v_HMM_sliding (candidate)** — HMM–actin gliding-assay sliding velocity, ~7–15 µm/s over 28–37 °C, in-vitro reconstitution. Use: FF motor speed sanity reference. Flag: distinct from PARAM-v_unloaded (retrograde flow, 100 nm/s) — do not merge.
- **PARAM-actin_half_pitch (candidate)** — actin filament helical half-pitch = **36 nm** (bare F-actin, AFM; ref 22 within paper). Genuinely reusable actin structural constant; 36 nm is the canonical half-helical-repeat. Elongates to 40 nm on drebrin-A decoration (allosteric, drebrin-specific — register the +drebrin value as conditional only).
- **PARAM-drebrin_actin_stoichiometry (candidate)** — 1 drebrin : 5 actin subunits (ref 5). Drebrin-specific; register only if a neuronal side-binder is ever modelled.
- **PARAM-Kd_drebrinE_actin (candidate)** — 6 nM (25 °C) / 32 nM (37 °C), luminescence densitometry (this work). Supersedes the older literature 120 nM (ref 5, Coomassie) *within a drebrin-E context* — but there is no current drebrin Parameter row, so nothing in our KB to supersede. Register as literature datum with the temperature condition attached.

Note: paper also gives an apparatus calibration `T(x) = −3.1·ln(x/x0) + 42.9` (x0=1 µm). This is a **rig-specific optical-microheater gradient fit, not physics** — do NOT register as a parameter or oracle.

## Oracle candidates

**None.** No closed-form mechanistic law is offered. The Hill dose–response (Eq 4) is a phenomenological curve fit (its parameters n, IC50, b are the *fit outputs* the paper reports, not a predictive law derivable from first principles), and the occupancy relation `p = [drebrin]/(Kd+[drebrin])` is the standard single-site Langmuir isotherm already trivially available — not worth a new oracle. The velocity/temperature estimators (Eqs 2–3) are measurement geometry, not laws. The existing Hill 1938 force-velocity oracle is unaffected.

If FF ever models tropomyosin/regulator gating of the cortex, this is the mechanistic precedent — but it is not a validation contract today.
