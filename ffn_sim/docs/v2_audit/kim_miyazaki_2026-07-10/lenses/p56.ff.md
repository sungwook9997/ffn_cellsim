# FF lens — p56

**Paper:** Chiba, Miyazaki & Ishiwata (2014), "Quantitative Analysis of the Lamellarity of Giant Liposomes Prepared by the Inverted Emulsion Method," *Biophys. J.* 107(2):346–354, DOI 10.1016/j.bpj.2014.05.039.

**Bottom line for FF:** This is an imaging/geometry + membrane-fabrication methods paper from the Miyazaki (Ishiwata-lab) in-vitro-reconstitution lineage. It measures ZERO filament mechanics — no persistence length, no crosslinker/motor kinetics, no force law, no rheology, no contraction rate. Its only quantitative model is a fluorescence-vs-radius geometric-optics fit (σ=0.913 µm focal leakage, δ=0.143 µm pixel). Its FF value is confined to (a) validating that inverted-emulsion GUVs are single-bilayer (justifies FF's single-membrane containment assumption), and (b) supplying a well-specified **encapsulated-actin-in-confinement reconstitution protocol** FF can mirror as a scenario. There is no new mechanism, force law, or rate constant to port into the actin/crosslinker/myosin/formin/Arp2/3/clutch core. Relevance is peripheral.

---

## 1. MECHANISMS to adopt
Honest verdict: **none for the filament/motor/crosslinker core.** No mechanism in this paper beats or supplements a current FF mechanism. Every FF module (bending beam, Bell–Evans crosslinker, Stam–Hocky myosin, formin ratchet, Arp2/3 branch, motor-clutch) is untouched by this work.

Two *tool-level* (not core-mechanism) items are worth cataloguing:

- **Membrane compartment — single-bilayer assumption is empirically licensed.** FF's membrane containment treats the boundary as ONE bilayer. This paper is the canonical proof that inverted-emulsion GUVs are ~97% unilamellar (98.0% default vs 49.8% for hydration). So FF's single-membrane model is not a simplification of the relevant experimental substrate — it *is* the substrate. No change to FF; this removes a would-be caveat.
- **Depletion (Asakura–Oosawa) bundling as an in-vitro comparator, NOT as an FF runtime mechanism.** The assay bundles F-actin with 10% w/v PEG-20k via entropic depletion attraction (ref. Asakura & Oosawa 1954). FF should keep bundling **mechanistic** (explicit α-actinin/filamin crosslink bonds), per the hard rule — depletion is a lumped entropic proxy and must NOT replace explicit crosslinkers. It is only relevant if FF ever wants to reproduce *this specific assay's* passive bundles; even then, prefer an explicit short-range attractive potential over an AO closed form.

## 2. FORCE LAWS / KINETIC SCHEMES to port
**None mechanistically portable.** The paper's one equation is an optics model, not a force law. Recorded for completeness (do NOT put in the FF runtime — it belongs to any FF *visualization/validation* tooling that quantifies membrane fluorescence, if ever):

**Eq. 1 — apparent equatorial membrane fluorescence of a unilamellar vesicle, radius r:**

    I(r) = I₀ ∫_{−arccos((r−δ)/r)}^{+arccos((r−δ)/r)} exp( − r² sin²θ / (2σ²) ) · r dθ

- z ≈ r·sinθ = distance from focal plane; kernel exp(−z²/2σ²) = out-of-focus leakage (focal-depth proxy).
- Symbols → NOT FF state. r = vesicle radius; I₀ = per-unit-area membrane intensity; δ = pixel size (0.143 µm); σ = focal leakage depth (0.913 µm); θ = radial-ray angle.
- Lamellarity is n if F.I. ∈ [(n−0.5)·I(r), (n+0.5)·I(r)] — each added bilayer adds one I₀.

This has zero mapping to bond off-rates, duty cycles, force-velocity, or branch-angle distributions. No kinetic scheme exists in the paper.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce
This is the paper's one real FF contribution: a **fully specified cell-sized-confinement encapsulation geometry** FF can run as a scenario (an in-vitro analog of the cortex-in-a-bag).

- **Geometry:** giant unilamellar vesicle, spherical, diameter ≳2 µm up to tens of µm (comparable to MCF7 R=7.5 µm), single egg-PC bilayer (~5.2 nm). Osmotically balanced across membrane (inner 150 mM sucrose + 350 mM glucose; outer 500 mM glucose) → net-zero osmotic pressure baseline unless deliberately imposed. Note: FF's physiological-baseline rule wants resting turgor ON; this assay is *iso-osmotic by design*, so it is a **turgor-free** confinement control, useful precisely for isolating filament self-organization from turgor.
- **Cargo:** 50 µM F-actin (or 10 µM G-actin polymerized in-situ by α-hemolysin-triggered salt influx), optionally + 10% PEG-20k depletion bundling. Xenopus egg extract variant = a crowded cytoplasm-like cargo (a coarse "full cytoplasm" analog).
- **Dynamics observed:** actin polymerization + PEG-depletion bundling inside the vesicle over ~30–60 min (onset ~30 min, terminates ~60 min).
- **FF scenario spec:** native-scale actin (or bundled filopodium/cortex architecture) enclosed in a single-bilayer membrane containment sphere, iso-osmotic (turgor≈0), let self-organize. This is a clean control for confinement-driven organization WITHOUT turgor or motors — a baseline against which FF's turgor-ON and myosin-ON cortex runs can be differenced. Keep it native scale + full membrane compartment per the hard rule; the vesicle IS the full membrane compartment here.

## 6. RISKS / caveats
- **Regime mismatch (dominant):** purified reconstitution, iso-osmotic, motor-free, crosslinker-free (bundling is entropic PEG depletion). This is NOT living cortex — no myosin prestress, no turnover, no adhesion. Do not import any timescale here as a living-cortex target.
- **Depletion ≠ mechanistic crosslinking:** AO depletion attraction is a lumped entropic proxy. Adopting it into the FF runtime would VIOLATE the fine-grained-over-lumped hard rule. Keep bundling via explicit α-actinin/filamin bonds; use depletion only to interpret *this assay's* passive bundles if ever reproduced.
- **Concentration vs density:** 50 µM bulk F-actin is a reconstitution concentration, not the KB-3.18 cortical areal density (100/µm²). Reconcile before using as an FF setpoint; do not treat 50 µM as a cortex density.
- **Iso-osmotic vs physiological turgor:** the assay is turgor-free by osmotic matching. FF's physiological-baseline rule wants resting turgor (~40 Pa) ON in production. Use this scenario only as a *labelled turgor-free control*, not as the physiological baseline — perturbations/measurements still belong on the turgor-ON native cell.
- **Optics fit is instrument-specific:** σ=0.913 µm is a property of their microscope, sample-independent. It has no transfer value to FF and must never be treated as a physical length in the model.
- **Native-scale rule:** any confinement scenario built from this must be run at native cortex scale (38000 filaments) with the full membrane compartment before any conclusion — a coarse vesicle would collapse structurally and mimic a mechanism artifact.
