# DCM lens — p16

**Paper:** Yim, Patterson, Suter, Miller, Kim (2025) "Computational Modeling of Motor-Driven Extension of Microtubule Bundles in Axons" — bioRxiv 10.1101/2025.09.25.678704 (preprint, not peer-reviewed). Taeyoon Kim agent-based cylindrical-element Brownian dynamics.

**Bottom line for DCM: LOW relevance (score ~1/5).** This is a *fine-grained filament* model (explicit MTs + Tau-like cross-linkers + dynein motors as bending-beam cylinders in a confining tube). It has **no cell surface, no closed triangulated mesh, no membrane area-elasticity/bending shell, no cortex-tension γ, no turgor/enclosed-volume, no node-face contact, no cadherin junction, no aggregate σ** — i.e. none of the SimuCell3D-style continuum machinery DCM *is*. It belongs to the FF (Cytosim/filament-FEM) engine class, and the sibling FF lens is where its substance lands. For DCM the only usable transfers are (a) two engine-agnostic numerical forms (cylinder drag, Bell off-rate) DCM already largely has, and (b) a confining-tube geometry + buckling concept that could seed a *confinement* DCM scenario. Everything below is deliberately scoped to those; I am not inflating filament physics into surface-mesh mechanisms.

---

## 1. MECHANISMS to adopt

Honest triage — only two items clear the "genuinely applicable to DCM at our scale" bar, both weak:

1. **Confinement scenario (DCM `contact`/BC module) — reproduce cell-sized cylindrical confinement as a boundary condition.** The paper confines its content in a rigid cylinder (r = 2 µm, L = 20 µm) with one **fixed** end-cap and one **moving** end-cap that advances only when the internal pushing force exceeds a resisting force F_R. DCM's open confinement/bleb problem could reuse exactly this *force-gated moving-boundary* idea: a DCM cell pushed into a channel/under a coverslip advances a rigid wall only when cortical + turgor push-out force exceeds an externally imposed F_R. **Why it beats DCM now:** DCM currently has no confinement BC at all; this gives a clean, mechanistic (not lumped) way to impose channel/wall confinement and read out an emergent advance rate. It is a *geometry/protocol* transfer, not a new force law.
   - *Caveat:* the paper's cylinder confines filaments; for DCM the wall would confine the **surface mesh nodes** via the existing node-face/Ericson penalty against wall triangles — so it reuses DCM machinery, only the wall geometry + the F_R-gated advance are new.

2. **Cylindrical-element drag form (engine-agnostic, `common`/dcm drag) — cross-check only.** Eq. (3) gives the translational drag of a short cylinder. DCM currently derives per-node drag from cytoplasm η≈65 Pa·s. This paper's cylinder-drag closed form is a *dimensional cross-check* on any DCM sub-element (e.g. microtubule stubs if ever added, or the drag scaling of edges) — **not** a replacement for the node drag DCM uses. **Why note it:** it is the same Clift/Grace/Weber form used across the Kim lineage; keep it as a validation oracle, not a runtime change.

**Explicitly NOT adopted (would violate scope / physiological-baseline rule):**
- MT buckling / Euler critical load (Eq. 10): belongs to explicit filaments (FF), not a surface-mesh continuum. DCM's nucleus/cortex are not slender beams.
- Dynein force-velocity (Monzon curves): a motor-on-filament law; DCM has no explicit motors. (DCM's γ is *pressure-borne*, not motor-resolved by design.)
- Biphasic cross-linker density optimum: a filament-network property; DCM's cortex is a tension shell, not an explicit cross-linked mesh.

## 2. EQUATIONS to port to the surface-mesh/continuum level

Only forms DCM can actually host. Both are already present in spirit; transcribed for completeness.

**Eq. (3) — cylinder drag (cross-check oracle, not a port):**
```
ξ_i = (3π μ r_{c,i} / 5) · (3 + 2 r_{0,i}/r_{c,i})
```
Map: μ → DCM cytoplasm viscosity (η≈65 Pa·s); r_{c,i}, r_{0,i} → element diameter/length. DCM state has **per-node drag**, not per-cylinder, so this does not map onto a node force directly — use it only to sanity-check any future edge/beam sub-element drag. Do **not** overwrite DCM's η-derived node drag with it.

**Eq. (8) — Bell force-dependent unbinding (already the DCM cadherin/contact off-rate family):**
```
k_u = k⁰_u · exp( F_s · x_u / (k_B T) )
```
Map to DCM: F_s → tension carried by a cadherin catch-bond cluster bond (Rakshit KU-4.2 junction interface); x_u → bond compliance length; k⁰_u → zero-force off-rate. **This is a slip-bond form; DCM's cadherin is a catch-bond (KU-4.2), which is richer.** So this equation *confirms* the DCM off-rate structure but must **not** replace the catch-bond with a slip-bond — that would be a fine→lumped regression forbidden by the hard rule. Value of the transfer: a cross-check that the slip limb of the catch-bond reduces to this Bell form at high force.

**Eq. (11) — persistence length ↔ bending stiffness:** `l_p = κ_b / (k_B T)`. Purely a units bridge; usable if DCM ever assigns a bending stiffness to a slender inclusion, but MT l_p (1–10 mm) is **MT-specific and irrelevant** to DCM's membrane bending κ_m or nucleus modulus.

No Eq. maps onto DCM's γ, Π, K_A, or κ_m as a *new* mechanism.

## 3. PARAMETERS to set

**None supersede any DCM config default.** Every quantitative parameter in this paper is MT/dynein/Tau-specific (r₀,MT=280 nm, l_p=1–10 mm, dynein F_M≈5–7 pN, R_X=0.25 µm⁻¹, C_MT≈23 µM). None feeds a DCM field (γ, Π₀, η, K_A, κ_m, E_nuc, cadherin k_off). The only DCM-adjacent numbers:

| symbol | value | units | DCM use | supersedes? |
|---|---|---|---|---|
| confinement cylinder radius | 2 | µm | *scenario* geometry for a confinement BC (adapt to R≈7.5 µm MCF7 → channel ~5–15 µm) | no (new scenario, not a config default) |
| curvature threshold | 0.2 | rad/µm | Memet-2018 "curved" criterion — only if DCM ever reports mesh-edge curvature; not a physical param | no |
| Δt | 1.8×10⁻⁵ | s | filament BD timestep — DCM uses IPC large-dt; **not** transferable | no |
| μ (medium viscosity) | unspecified in paper | Pa·s | would be DCM η if given — but paper leaves it blank | no |

Do **not** register any of this paper's numbers as a sourced DCM constant: it is a preprint and its core stiffnesses (κ_s, κ_b magnitudes, k⁰_u,X, x_u,X, F_R) are all unspecified.

## 4. GEOMETRY / PROTOCOL to reproduce

**One usable DCM scenario:** *force-gated moving-wall confinement.*
- Rigid cylinder / channel of radius R_ch with one fixed end-cap and one movable end-cap.
- The movable cap advances (channel lengthens) at a step only when the DCM cell's internal push force on the cap (from cortex tension γ + turgor Π₀ transmitted through the surface mesh) exceeds an externally set resisting force F_R.
- Read-out: emergent advance distance vs time; internal pressure build-up; cortex tension redistribution against the walls.
- **Adaptation to our scale (physiological-baseline preserved):** channel radius scaled to confine a single MCF7 R≈7.5 µm cell (mild confinement 6–7 µm to strong 4–5 µm); walls act on mesh nodes via DCM's existing Ericson node-face penalty; **turgor Π₀≈40 Pa and interphase γ≈0.15 mN/m stay ON from t=0** (do not relax the shell to fit into the tube — press the *already-pressurised* cell in).

The paper's other protocols (tubulin-concentration sweep, MT-length sweep, cross-linker-density sweep, dynein-density sweep) are **filament-model sweeps with no DCM analogue** and are not reproducible in DCM.

## 5. VALIDATION TARGETS for DCM observables

**None.** This paper reports MT-bundle observables — bundle strain ε_max≈0.08, time-to-peak ~100 s, curved-MT fraction ~0.2, dynein speed 0.2–1.1 µm/s, F_M 5–7 pN, Euler F_cr∝κ_b/L_uns², biphasic-optimum R_X=0.25 µm⁻¹. **None of these is a DCM surface/continuum observable** (cortical tension, shape index, contact angle, division force, ring closure, compaction, cortical flow speed). There is nothing here a DCM run should be asked to reproduce. (These numbers *are* validation targets for the FF engine — see the FF lens.)

The single soft "target" DCM could adopt from the confinement scenario is *qualitative*: a confined pressurised cell should advance a force-gated boundary only above a threshold push force — but the paper gives no value at our scale to anchor it.

---

## 6. RISKS / caveats

1. **Category mismatch (dominant risk).** This is a filament-bundle model; DCM is a surface-mesh continuum. Any attempt to "port a mechanism" risks importing a lumped filament proxy into a place DCM deliberately keeps continuum (γ pressure-borne, no explicit motors) — a *backwards* move under the fine-grained-over-lumped hard rule. Guard: restrict transfer to the confinement geometry + the two forms DCM already owns.
2. **Preprint, not peer-reviewed; core parameters unspecified.** κ_s, κ_b magnitudes, k⁰_u,X, x_u,X, F_R, μ are all left blank in the text. Cannot anchor any sourced DCM numeric to it. KB registration (if any) must flag preprint/qualitative.
3. **Wrong cell type & cytoskeleton.** Neuronal axon MT bundle, not MCF7 epithelial cortex. MT persistence length 1–10 mm and dynein extensile pushing have no counterpart in DCM's actomyosin-cortex tension shell. Do not let MT stiffness/motor numbers leak into DCM's κ_m/E_nuc/γ.
4. **2D-ish confinement to a tube vs our 3D cell.** The paper's "thickness" w_dom side-support is a bundle-packing effect; for a DCM confinement scenario, confinement must be a true 3D wall acting on the whole closed mesh, with turgor and cortex ON — not a thin-slab approximation.
5. **Bell slip-bond vs DCM catch-bond.** Eq. (8) is slip-only; replacing DCM's Rakshit catch-bond with it would loosen fidelity. Use only as a high-force-limb cross-check.

**Net:** treat p16 as an FF-engine paper. For DCM it yields *one* optional confinement scenario (force-gated moving wall, adapted to a pressurised MCF7 cell) and two cross-check equations (cylinder drag, Bell slip limb) — no new surface-mesh mechanism, no parameter supersession, no reproducible DCM validation number.
