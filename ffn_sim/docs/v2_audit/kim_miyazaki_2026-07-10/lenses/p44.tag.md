# TAG-validation lens — p44

**Paper:** Bidone, Jung, Maruri, Borau, Kamm, Kim (2017) — *Morphological Transformation and Force Generation of Active Cytoskeletal Networks*, PLoS Comput Biol 13(1):e1005277. DOI 10.1371/journal.pcbi.1005277.

## Paper kind

**simulation** (agent-based / coarse-grained Brownian-dynamics model output — the Kim-lab canonical actomyosin model, Mak 2016 / Kim 2015 lineage). Governing consequence for the KB: **the paper's own emergent numbers (bundle tension ~4 nN, compaction ~10–20 s, σ_x^c, buckling frequencies) are COMPARISON targets for the FF engine, never a truth source** — the FF filament engine is a near-exact methodological twin (explicit actin beams + Bell slip-bond crosslinkers + catch-bond myosin minifilaments + overdamped Langevin), so this is a *reproducible FF scenario*, not an experimental measurement.

The **valuable, registrable content is the paper's sourced input parameters**, which are drawn from experimental literature (Ferrer 2008 filamin-A rupture; Isambert 1995 actin persistence length; Erdmann–Schwarz PCM), NOT from the simulation. Those carry clean provenance and are the real KB additions. The single experimental *anchor* the paper cites for validation is transverse-arc condensation ~20 s (Heath 1983) — an overlay datum, not the sim's output.

## Coverage vs existing gates

- **Bundle/cortex tension** — the ~4 nN emergent bundle tension is sub-grid to DCM (a filament bundle inside the cortex), and there is **no FF gate** for network→bundle tension. Weak/indirect relation to `VG-H3-KU35-cortex-tension` and `VG-H7-gate-a/b` (whole-cell γ ~0.35–0.65 mN/m): those are macroscopic areal tensions, not a single-bundle line tension, so this does NOT confirm/challenge those bands. Cannot be used to loosen the failing γ-floor gate.
- **Motor stall / velocity** — `PARAM-F_stall_motor` (default 2 pN) and `PARAM-v_unloaded` (10–100 nm/s) exist but there is **no gate** on them. Paper's 5.7 pN / 140 nm/s are model reference values that **conflict** with those defaults (see Param candidates). No band contract to confirm/challenge.
- **Crosslinker off-rate** — no existing Parameter row for an ACP/filamin slip-bond off-rate; `MC-U2-fa-motor-clutch` uses Bell-Evans for integrin, and the Bell-Evans **oracle exists**. The paper supplies a filamin-A datum for that same oracle law but for a *cortex crosslinker*, not covered by any current gate.
- **Buckling / persistence length** — no existing gate on actin buckling or actin L_p. `PARAM-ell_p` (17 µm) is **collagen**, a different polymer; actin L_p=9 µm is a distinct constant, not a conflict.

**Net: no existing gate is confirmed, tightened, or challenged by this paper's bands** (its bands are simulation output). The overlap is at the *parameter* level.

## New gate candidates

All below are **FF-engine reproduction scenarios**, staged as *candidate, PI-gate review*. Because the source numbers are simulation output, they should be registered as **FF cross-check / trend gates (comparison-only)**, NOT as hard experimental-band contracts — except the compaction timescale, which has an independent experimental anchor.

1. **[candidate, PI-gate review] VG-FF-network-to-bundle-time** — condensation time of a homogeneous crosslinked actomyosin slab into a single bundle. Band: **~10–20 s** for high motor / moderate-to-high crosslinker density. Engine: FF. Basis: Fig 1B/Fig 2 (sim) **plus independent experimental anchor** transverse-arc condensation ~20 s (Heath 1983 [29], p13) — this dual anchor makes it the most defensible gate here. Measurable at our scale (single-cell sub-domain).
2. **[candidate, PI-gate review] VG-FF-buckling-required-for-contraction** — sanity/mechanism gate: suppressing filament buckling (100×κ_b,A) in an *isotropic* network abolishes bundle tension; buckling events peak *before* max tension. Engine: FF. Observable: fraction buckled (end-to-end/contour < 0.6) vs generated tension. Qualitative mechanism cross-check (no numeric band) — Fig 3D,F. Ties to FF's mechanistic-buckling principle (cf. H.7 Gate-B lever).
3. **[candidate, PI-gate review] VG-FF-tension-sustainability-law** — trend gate: bundle max-tension ↑ with both motor and crosslinker density; *sustainability* ↑ crosslinker, ↓ motor (load-sharing → slower slip-bond rupture). Engine: FF. Comparison-only monotonic-trend contract, not a magnitude band — Fig 2E,F. Guards the emergent load-sharing physics.

Do **not** propose a hard-band gate on the ~4 nN bundle tension: it is pure simulation output with model-relative densities, so a fixed band would be a convenience number, violating the no-magic-number rule.

## Oracle candidates

- **No new closed-form oracle.** The paper's ACP off-rate law (Eq 8, `k_u = k⁰_u·exp(λ|F|/k_BT)`) **is exactly the existing Bell-Evans oracle** — the paper contributes filamin-A *parameters* to that oracle, not a new law.
- The **parallel cluster model (PCM, Erdmann & Schwarz [20,21])** motor catch-bond kinetics is a candidate mechanistic motor model but is **not a clean closed form** (it is a stochastic multi-head cluster model), so it is not a drop-in analytic oracle; the existing **Hill force-velocity oracle** remains the analytic cross-check for the motor, with f_stall≈5.7 pN / v≈140 nm/s as PCM-consistent reference endpoints.
