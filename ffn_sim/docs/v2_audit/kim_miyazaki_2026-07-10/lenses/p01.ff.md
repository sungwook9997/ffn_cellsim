# FF lens — p01

**Paper:** Miyazaki & Harada, "Bayesian estimation of the internal structure of proteins from single-molecule measurements," *J. Chem. Phys.* **134**, 085108 (2011). DOI 10.1063/1.3516587.

**Bottom line for FF:** This is a *statistical-inference / method* paper, not a mechanism paper. It contains **no cytoskeletal force law, no motor kinetics, no crosslinker off-rate, no in-vitro biophysical measurement** to port into FF. Every number is nondimensional (units fixed k*=γ*=k_BT=1) from a 2-bead Brownian-double-pendulum toy standing in for F1-ATPase. There is **nothing to adopt into the FF cortex/motor/crosslinker mechanism stack.** Its only value to FF is (a) a correctness reference for how we write overdamped Langevin bead-spring dynamics with proper FDT noise, and (b) an optional, out-of-band *calibration/inference* tool for recovering hidden coarse-grained parameters from observable trajectories. Both are peripheral. Relevance score ≈ 1/5.

---

## 1. MECHANISMS to adopt

**None as an FF runtime mechanism.** The paper's "model" (harmonic trap + one linear coupling spring + viscous drag + thermal noise) is strictly *below* what FF already implements — FF's filament segments already use harmonic stretch/bend bonds, Bell–Evans force-dependent crosslinker off-rates, Hill force–velocity motors, and constrained BAOAB Langevin with FDT noise. Adopting anything from p01's mechanics would be a **downgrade** (linear/harmonic, no catch bonds, no active motors), which the HARD "fine-grained mechanistic over lumped" rule forbids.

Two *methodological* items are worth logging, neither is a mechanism change:

- **(peripheral) Overdamped-Langevin + Onsager–Machlup correctness reference.** Eqs (6)–(7) with noise variances 2γk_BT / 2Γk_BT (FDT) and the Stratonovich (midpoint) OM action Eq. (12) are a clean, published reference for validating that FF's bead-spring Langevin steps carry the right FDT noise amplitude and midpoint discretization. Use only as a *unit test / cross-check oracle* for the integrator, not a runtime change. FF already targets BAOAB (Leimkuhler–Matthews), which is a strictly better splitting than the Euler–Maruyama-style OM discretization here.
- **(peripheral, opt-in) Hidden-parameter Bayesian calibration tool.** The core idea — observe a subset of DOF **y**, integrate out hidden DOF **x** by WKB/saddle-point, and estimate model parameters Π by minimizing Hτ(Π) = −τ⁻¹ ln P([y]|Π) — could be repurposed to *calibrate* an FF coarse-grained bead's effective stiffness/drag from a native-scale reference trajectory (e.g. infer an effective segment drag γ_eff or bond stiffness that reproduces a filament's observable tip fluctuation). This is an **out-of-band analysis utility**, never in the hot loop, and does NOT touch physiological-baseline or native-scale rules because it only post-processes trajectories. Low priority.

**Why it does NOT beat current FF mechanisms:** current FF is already fine-grained and mechanistic; p01 offers only a lumped 2-bead proxy and an estimator. No net upgrade to γ generation, contraction, turnover, motor flows, or crawl speed — the listed open problems — is available here.

## 2. FORCE LAWS / KINETIC SCHEMES to port

Only the generic overdamped Langevin bead-spring equations, which FF already has. Transcribed for the record, with symbol → FF-state map:

- **Hidden bead (trap + coupling spring + drag + noise), Eq. (6):**
  `γ ẋ = −k·x − h·(x−y) + ξ(t)`, ⟨ξξ⟩ = 2γk_BT δ.
- **Probe bead (coupling spring + drag + noise), Eq. (7):**
  `Γ ẏ = −h·(y−x) + η(t)`, ⟨ηη⟩ = 2Γk_BT δ.
- **Initial canonical energy, Eq. (10):** `H = (k/2)x² + (h/2)(y−x)²`.
- **Onsager–Machlup action (midpoint/Stratonovich), Eq. (12):** quadratic in the discretized path; sums `[γ(Δx/Δt) + k·x̄ + h(x̄−ȳ)]²/4γ` etc. over N steps.
- **Objective (inference, NOT a force):** `Hτ(Π)[y] = −τ⁻¹ ln P([y]|Π)` (Eq. 3); closed form Eq. (17) with `φ² = (k+h)²/γ²`, `χ² = h²/(γΓ)`.
- **MAP hidden-path error, Eq. (20):** `⟨(x̂−x)²⟩ = (1/βh*)[2/κ* − 1/√(κ*²+g*)]`, `κ*=1+k*/h*`, `g*=γ*/Γ*`.

**Symbol → FF mapping (for the integrator cross-check only):** k → harmonic-trap/anchor stiffness; h → inter-bead bond stiffness (FF filament segment spring); γ, Γ → per-particle friction (FF's η-derived per-node drag); ξ,η → FF's FDT thermal-noise term. **No catch-bond, no motor, no branching, no turnover term exists in this paper to map.**

**None.** No G'(ω)/G''(ω), no stress-relaxation time, no contraction rate, no network tension, no motor velocity-vs-load, no buckling threshold, no mesh size, no exponent that maps to an FF cell-mechanics observable. The paper's quantitative results (accuracy gain 1–2 decades vs spectrum fitting; variance jump >4 decades at the loss-of-precision line; error ∝ τ⁻¹; noise thresholds σ_noise ~ 0.18–0.56) are *estimator-performance* metrics, not physical validation numbers. Register the paper as a **method/theory** KB source only — explicitly NOT a quantitative validation oracle (matches dossier's TAG-validation flag).

## 6. RISKS / caveats

- **Regime mismatch (dominant):** purified single-protein rotary motor in a bead assay, ATP-*absent* (no active stepping), linear/harmonic potential only. FF is a living-cortex, active, nonlinear, catch-bond, many-filament system. Importing p01's mechanics would strip active and nonlinear physics — a direct violation of the fine-grained-mechanistic HARD rule. **Do not.**
- **Nondimensional trap:** all values are unit-fixed toy numbers. Registering any as a physical constant would inject a magic number with no lit provenance. Keep them out of `configs/`.
- **If we build the calibration tool:** the paper's own **loss-of-precision transition** is the caveat — when the observed proxy is weakly coupled (h* small) and heavily damped (Γ* large), the estimate becomes unreliable even for infinite data. For an FF coarse-grained-parameter fit this means: only trust inferred effective parameters when the observable is *tightly coupled* to the hidden DOF (k*≪h*, Δt < τr ≈ Γ*/h*), and always report the sample-averaged variance to confirm we are in the "precise phase." This keeps any inferred parameter honest, but such inferred values must still be cross-checked at NATIVE scale before use — never let an inference substitute for a physiological datum.
- **Net recommendation:** log p01 in the KB as Miyazaki-lab provenance + a method/theory reference for Bayesian hidden-DOF inference and OM/Langevin correctness; take **no** FF runtime action.
