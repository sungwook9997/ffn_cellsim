# FF lens — p61

**Paper**: Linsmeier, Banerjee, Oakes, Jung, Kim & Murrell (2016) "Disordered actomyosin networks are sufficient to produce cooperative and telescopic contractility." *Nat. Commun.* 7:12615. DOI 10.1038/ncomms12615.

**Why this paper is high-value for FF**: The agent-based simulation half is a **Taeyoon-Kim-lab Brownian-dynamics actomyosin model** (authors W. Jung + T. Kim), i.e. *exactly FF's physics domain and lineage*: F-actin as serially-connected cylindrical segments with fixed barbed/pointed polarity, myosin as a **bipolar thick-filament with multiple load-dependent motor arms**, disordered cortex-like network, **no crosslinker → myosin-is-the-only-connectivity** limit, and a persistence-length sweep. It is built on refs 56 (Jung–Murrell–Kim 2015, Comput. Part. Mech. 2:317) and 57 (Mak–Zaman–Kamm–Kim 2016, Nat. Commun. 7:10323) — the FF agent-based ancestry. The experimental half supplies a rare, clean **quantitative validation battery for FF's cortex-contraction observables** (cooperativity threshold, telescopic law, strain phases, crosslinker stiffening, bending-invariance). Crucially it is a *disordered* (non-sarcomeric, non-stress-fibre) network — the SAME architecture as FF's MCF7 cortex — so its conclusions transfer without an ordering assumption.

Note: the paper's *main-text* mechanisms are largely geometric + qualitative ("load-dependent kinetics, Supplementary Fig 8 / Note 4"); the closed-form motor force law and the numeric rate constants live in the SI + refs 56/57 (not in this file). I flag every place a value must be pulled from the SI before it becomes a runtime datum.

## 1. MECHANISMS to adopt

### 1.1 Myosin — bipolar thick-filament geometry as an explicit multi-arm minifilament (CONFIRMS + refines FF's Stam–Hocky myosin)
The Kim myosin agent is: a **rigid backbone of 3 cylindrical segments, each 42 nm long, symmetric polarity, connected by elastic hinges**; at **each of the 2 backbone endpoints, 2 motor arms** (→ 4 arms total per minifilament); arms bind actin at sites spaced **every 7 nm** and step with load-dependent kinetics. This is the Craig–Megerman (1977, ref 58) side-polar smooth-muscle-myosin geometry.
- **Why it beats current FF**: FF's myosin is a Stam–Hocky multi-head bipolar minifilament — this paper is an *independent, same-family* parameterization that pins the discrete geometry (segment length 42 nm, hinge elasticity, arm count/placement, 7 nm site spacing). Adopt the **elastic-hinge backbone** (3 rigid segments + 2 hinges) if FF currently uses a single rigid rod: the hinge lets the minifilament bend/re-orient under load, which is what lets a *disordered* network condense (the paper's whole point). Confirms our arm count is right and gives a concrete site-spacing lattice.

### 1.2 Myosin — spatially-gated processivity (activation-region mechanism) → a native FF "myosin patch" scenario
Inside the activation ROI, motors have a **low off-rate / strong load-dependence (processive)**; outside, motors are **non-processive**. Stress is generated locally in the ROI and *propagates outward* through the passive network.
- **Why useful for FF**: This is a mechanistically clean way to drive **local contraction and cortical-flow** in the native cortex without globally cranking myosin — set a spatial field on the myosin off-rate `k_off_myo(x)`. It directly probes FF's open problems of **motor-driven flows** and **cortical-tension generation localized in a patch**, and gives a validation-matched protocol (see §4). Mechanistic (per-motor off-rate field), not a lumped active-stress term.

### 1.3 Crosslinker — filamin-A **stiffens → suppresses** contraction (non-monotonic connectivity lesson)
Adding filamin-A at R_C=[filamin]/[actin]=0.035 (45 nM) **bundles F-actin, raises network stiffness E, and REDUCES both strain (ε≈2.4→0.3) and strain rate (~0.015→0.002 s⁻¹)**. Meanwhile at high myosin density, **myosin itself acts as the crosslinker** that percolates the network (no separate crosslinker needed for contraction).
- **Why useful for FF**: FF treats crosslinkers (α-actinin, filamin) as pure connectivity-adders. This paper shows crosslinker has a **two-sided effect** — it raises connectivity (needed for force percolation) but if it over-stiffens it *kills* contraction because a stiff network resists condensation. This is the mechanistic content behind the FF-open "network contraction & stress relaxation" problem: contraction rate ∝ (active stress)/(elastic modulus) ~ σ_a/E. FF should reproduce that **increasing α-actinin/filamin density is non-monotonic for contraction** and validate against the ε(R_C) drop. Also validates the "myosin-only connectivity" limit as a legitimate FF baseline network.

### 1.4 F-actin bending/buckling is NOT required for cortex contraction (negative-control mechanism)
Raising persistence length from ℓ_p=20 µm → 320 µm → 2.6 mm (bending progressively suppressed) **slows and lowers** strain/strain-rate/boundary-velocity but **preserves the telescopic law and cooperative contraction**. So buckling (Murrell–Gardel 2012, refs 18/28) is a *rate modulator*, not the *mechanism* of disordered-network contraction — the mechanism is total active-motor content + filament sliding/sorting.
- **Why useful for FF**: This is a **guardrail** for FF interpretation. When FF's native cortex contracts, do NOT attribute it to buckling by default. FF can run the same ℓ_p sweep (its actin bending κ is an explicit parameter) as a **falsification test**: if FF's contraction *vanishes* at high ℓ_p, FF has a bug (over-reliant on buckling); if it merely slows, FF matches the paper. Directly relevant to FF's "buckling/condensation symmetry-breaking" open problem.

## 2. FORCE LAWS / KINETIC SCHEMES to port

### 2.1 Active-stress accumulation timescale (continuum, but sets a FF-observable target)
σ_a(r,t) = σ₀(r)·(1 − e^(−t/τ_a)), with σ₀(r)=σ₀ const for r≤ξ, 0 outside; τ_a = active-stress accumulation time.
- **Map to FF**: This is *emergent* in FF, not an input — FF should **measure** its own network tension build-up curve from the virial/boundary stress and fit τ_a, then check the exponential-saturation form and that ε(t) shows the P1/P2/P3 phases (§5). Do NOT inject σ_a as a lumped term (violates the mechanistic rule); use it only as the expected shape of FF's emergent stress(t).

### 2.2 Strain / strain-rate as field divergences (measurement protocol to port verbatim)
ε = ∇·**u** (u = time-integrated displacement field), dε/dt = ∇·**v** (v = velocity field). Boundary velocity averaged in a 2.65 µm window about the ROI circumference; strain rate taken as the slope of ε(t) in phase P2 (100–300 s); ε_max taken as the P3 plateau (>300 s).
- **Map to FF**: This is the **FF cortex-contraction analysis pipeline**. Bin FF filament-node velocities onto a grid (or coarse-grained flow field), take divergence → strain rate; time-integrate → strain. Adopt the identical P2-slope / P3-plateau definitions so FF numbers are apples-to-apples with the paper. Negative ∇·v = contraction; its minimum marks max contractility.

### 2.3 Cooperativity (Hill) law for ε_max vs myosin density
ε_max(ρ) = ε_sat · ρ^{n_H} / (ρ_c^{n_H} + ρ^{n_H}), with **n_H = 11**, **ρ_c = 0.56 µm⁻²** (thick-filament areal density). Strain RATE, by contrast, is **linear** in ρ (dε/dt ∝ ρ).
- **Map to FF**: This is a **percolation-like connectivity transition** — force can only span the network once myosin (acting as crosslinker) density exceeds ρ_c. FF should *emerge* this: sweep FF myosin minifilament areal density and reproduce (i) a sharp sigmoidal ε_max(ρ) with a large Hill coefficient and (ii) a linear dε/dt(ρ). The dual behaviour (sharp ε_max but linear rate) is a strong, non-trivial FF acceptance oracle. Do NOT fit n_H into FF — it must arise from the connectivity physics.

### 2.4 Myosin load-dependent off-rate (Bell-type family; SCHEME named, form in SI)
Main text: "motor arms … exert force with load-dependent kinetics" (Supplementary Fig 8, Supplementary Note 4); "strong load dependence" processive inside the ROI, non-processive outside. This is the Bell/catch–slip family FF already uses (Bell-Evans k_off = k_off0·exp(F/F_b)).
- **Map to FF**: Consistent with FF's existing Bell-Evans motor detachment + Hill force–velocity. **Action**: pull the exact k_off0, F_b (detachment force), stall force, step size, duty ratio, and force–velocity parameters from **refs 56/57 SI** (Jung–Murrell–Kim 2015; Mak et al. 2016) — those are the Kim-lab numeric motor kinetics behind this paper. The spatial gating (§1.2) is just k_off0 → k_off0(x): low inside ROI, high outside.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario spec)

**Scenario "disordered-cortex telescopic-contraction" (2D quasi-cortex patch):**
- **Network**: disordered planar F-actin, mean length ⟨l⟩≈7.1 µm (exponential dist.), ℓ_p=20 µm, **no crosslinker** (myosin-only connectivity) — matches FF's native disordered cortex minus ordering. Optionally add filamin at R_C=0.035 for the stiffening arm.
- **Myosin**: bipolar minifilaments (42 nm×3 backbone, 4 arms, 7 nm lattice) at areal density ρ swept across ρ_c=0.56 µm⁻² (points 0.37/0.48/1.01).
- **Activation geometry (the key control)**: define a **circular ROI of radius ξ**; inside ξ set myosin off-rate LOW (processive), outside HIGH (non-processive). Sweep ξ across **small 9 µm / medium 23 µm / large 37 µm** (paper's S/M/L; sim used ξ=6 µm in a 40 µm box). This is directly buildable in FF as a spatial field on `k_off_myo`.
- **Physiological-baseline compliance**: run on the **native full cortex** (`--cortex-fil 38000 --from-resting --microtubules`, Nc≈266k) with membrane/turgor/gravity ON — do NOT strip to a bare 2D sheet for a *conclusion* (a 2D reconstitution patch is a dev smoke test only; reconfirm any finding on the native full cell per the HARD rule). The 2D assay maps to FF's cortex shell; use it to set/validate the myosin+actin sub-model, then run the telescopic protocol as a localized myosin patch on the 3D cortex.
- **Measurement**: PIV-equivalent flow field → ∇·v (strain rate), ∇·u (strain), boundary velocity in a 2.65 µm ring; P2-slope and P3-plateau definitions (§2.2).

**Two FF-native experiments this unlocks:**
1. **Cooperativity sweep** — ρ across ρ_c → reproduce sharp ε_max(ρ) (n_H≈11) + linear dε/dt(ρ).
2. **Telescopic sweep** — ξ = 9/23/37 µm at fixed ρ>ρ_c → boundary velocity ↑ with ξ while ε_max, dε/dt ≈ const.

## 6. RISKS / caveats

1. **Purified in-vitro 2D vs living 3D cortex.** The assay is a phalloidin-stabilized (no turnover/severing), crosslinker-free, methylcellulose-crowded 2D sheet on a lipid bilayer with substrate friction ζ. FF's native cortex is 3D, turgor-pressurized, membrane-bounded, with turnover and ATP-driven dynamics. **Adapt**: use the paper for the myosin+actin *sub-model* and the *shape* of laws (Hill form, telescopic scaling, ε(t) phases), not for absolute magnitudes on the living cell. Keep FF's physiological baseline (65 Pa·s cytoplasm, 40 Pa turgor, full compartments); the 2D bilayer + friction ζ do not transfer.

2. **No filament turnover in the assay.** Phalloidin stabilization removes severing/depolymerization, so this paper cannot inform FF's turnover/fragmentation channel — treat ρ_c/n_H as a *fixed-network* percolation datum. In the living cortex turnover will renormalize the effective connectivity; do not over-read ρ_c=0.56 µm⁻² as the in-vivo threshold.

3. **ρ is a 2D areal density (µm⁻²).** ρ_c=0.56 µm⁻² is thick-filament number per unit *area*. FF's 3D cortex needs this converted to an areal density on the cortex shell (thin-shell), not a volumetric density — map to filaments/motors per µm² of cortex surface, consistent with the KB-3.18 areal-density convention (~100/µm² actin). Unit-slip risk (cf. the DCM-meters/FF-µm lesson) — audit dimensions before gating.

4. **Continuum E, η, σ₀, ζ are fits, not physics.** They live in SI Table 1 as coarse-grained parameters. NEVER register them as FF runtime inputs or KB parameters (they are model-fit oracles at best). Only ρ_c, n_H, the telescopic scaling, ε(t) phases, and the filamin/bending trends are legitimate cross-check oracles.

5. **ℓ_p reconciliation.** Kim uses ℓ_p=20 µm; FF/CLAUDE cites 17 µm. Both are literature-defensible for actin (17–18 µm is the common cited value; 20 µm is a rounded Kim-lab convention). Keep FF at its sourced 17 µm for production; use 20 µm only when replicating this paper's numbers exactly, and note the choice. The 320 µm / 2.6 mm values are **artificial bending-suppression probes**, never physiological.

6. **Motor kinetics not in main text.** The actual k_off0/F_b/stall/step/duty are in refs 56/57 SI, not here. Do not invent them — pull from Jung–Murrell–Kim 2015 (Comput. Part. Mech. 2:317) and Mak–Zaman–Kamm–Kim 2016 (Nat. Commun. 7:10323), or fall back to FF's existing Bell-Evans + Hill values. This lens supplies geometry + validation targets, not the motor rate constants.

7. **Filamin concentration ambiguity.** Text gives R_C=0.035 ⇔ 45 nM in the Fig 5g caption but the bar plot (Fig 5h,i) is labelled 0 vs 300 nM. Reconcile against the SI before using the ε(2.4→0.3) drop as a *quantitative* gate; the *qualitative* "crosslinker over-stiffening suppresses contraction" is safe to use now.
