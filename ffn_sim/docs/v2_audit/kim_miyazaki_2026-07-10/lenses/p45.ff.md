# FF lens — p45

**Paper:** Li et al. 2025, *Characterization, Enrichment, and Computational Modeling of Cross-Linked Actin Networks in Transformed Trabecular Meshwork Cells*, IOVS 66(2):65. DOI 10.1167/iovs.66.2.65.

**Why this paper matters to FF (one line):** the computational half is **Taeyoon Kim's agent-based F-actin + ACP Brownian/Langevin engine** (refs 33–36) — FF's direct sibling (explicit filaments as bending beams + explicit cross-linkers + excluded volume + self-assembled network + boundary-clamped bulk rheology). It hands FF a **portable bulk-rheology validation harness**, a **cross-linker density connectivity setpoint (R_ACP=0.1)**, and a concrete **tensile-vs-shear-vs-compression stiffness-anisotropy target**. It does **not** introduce a new fine-grained mechanism FF lacks — FF is already *more* mechanistic (Bell–Evans ACP off-rate, Stam–Hocky myosin, Hill f-v), and these sims are **passive (no motors), no depolymerization**. Net value = a validation scenario + a parameter anchor + a pointer to the fragmentation-contraction channel (ref 33), not a physics replacement.

## 1. MECHANISMS to adopt

**Caveat up front:** the in-text model is *coarser* than FF in three ways — (a) harmonic bending only (FF already has this), (b) **no ACP force-dependent unbinding is invoked in these runs** (network is assembled then frozen and strained; ACPs act as fixed harmonic cross-links), (c) **no myosin** (purely passive network rheology). So there is little "adopt this over FF's mechanism" here; FF's mechanisms dominate. What FF *should* take:

- **Cross-linker (α-actinin/filamin) module — connectivity setpoint, not a new law.** The model sets ACP molar ratio **R_ACP = C_ACP/C_A = 0.1** as "the ratio needed to maintain connectivity between F-actins." This is a directly usable *percolation/connectivity floor* for FF's cross-linker seeding: at C_A≈100 µM native actin, seed cross-linkers at ~0.1× molar to guarantee a spanning, mechanically-coupled cortex before running any rheology. FF's current cross-link count is seeded per-filament-contact; adding an explicit *molar-ratio connectivity check* (R_ACP≥~0.1) as a build-time gate prevents under-linked, mechanically-floppy networks masquerading as physics (relevant to the coarse-cell "collapse" artifact already documented). **This is a build-gate, not a mechanism change.**

- **Filament (actin beam) — CLAN "hub-and-spoke" / triangular-lattice architecture as an FF scenario.** CLANs are interconnected F-actin with ≥3 hubs and radial spokes (triangulated). This is a distinct *emergent architecture class* alongside FF's cortex / lamellipodium (Arp2/3) / filopodium (bundle). FF should be able to self-assemble a CLAN-like triangular lattice from nucleation-with-orientation + ACP cross-linking and reproduce its anisotropic rheology (§5). Good stress-test of whether FF's cross-linker + excluded-volume physics gives the right *network-level* elastic anisotropy, not just single-filament mechanics.

- **[Pointer, from ref 33 — the genuinely novel FF lever this paper cites but does not itself run]:** Li, Biel, Lomada, Yu, Kim, *Soft Matter* 2017 (ref 33): **"Buckling-induced F-actin fragmentation modulates the contraction of active cytoskeletal networks."** This is exactly the *F-actin fragmentation channel that facilitates contraction* that FF's known open problem "network contraction & stress relaxation / filament turnover/fragmentation / buckling-condensation symmetry-breaking" needs. **Recommendation: pull ref 33 as its own paper.** In FF terms: when a filament segment's compressive load exceeds the Euler buckling threshold, allow a stochastic **sever event at the buckled site** (bead-rod bond scission), which relieves the compressive stall and lets the motor-driven network keep contracting instead of jamming. This is the mechanistic route to stress relaxation + contraction that a purely elastic cross-linked network cannot produce. p45 itself is passive and does not exercise it, but it is the model lineage's key contraction mechanism.

- **[Pointer, ref 36 — Mak/Kamm/Kim, *Nat Commun* 2016]:** motor-driven cytoskeletal networks, tension buildup + phase transition in self-renewing networks. Relevant to FF's γ-generation / motor-driven-flow open problems; pull separately if not already in KB.

## 2. FORCE LAWS / KINETIC SCHEMES to port

The main text prints only functional *families* (numeric κ live in Supplementary Materials + refs 33–36, **not in this PDF** — do not KB-register κ from p45). Symbols mapped to FF state:

1. **Overdamped Langevin, forward-Euler update** (their integrator):
   `ζ_i · dr_i/dt = F_i^det + F_i^thermal`  →  `r_i(t+Δt) = r_i(t) + (Δt/ζ_i)(F_i^det + F_i^thermal)`,
   with `⟨F^thermal(t)·F^thermal(t')⟩ = 2 k_B T ζ δ(t−t')`.
   **FF map:** FF's constrained Leimkuhler–Matthews BAOAB is *strictly better* (they use bare forward Euler). **Do NOT adopt their integrator** — this is a case where FF's mechanistic choice wins. Use only for cross-check of the deterministic force sum.

2. **Extensional (stretch):** `F_s = −κ_s (r − r_0)` — FF's bead-spring stretch modulus. Same form.

3. **Bending:** `U_b = ½ κ_b (θ − θ_0)²`, `F = −∂U_b/∂r` — FF's angular bending κ setting ℓ_p. Same form. (θ_0 = 0 straight for actin; branch angle 70° for Arp2/3 lives in FF, not here.)

4. **Excluded volume (repulsive):** `F_r = −κ_r δ` for overlap δ>0 else 0 — FF's LJ-repulsive. Same intent (they use harmonic/Hertzian; FF uses LJ repulsive — keep FF's).

5. **Nucleus volume conservation:** `U_V = ½ κ_V (V−V_0)²/V_0` — **DCM idiom, not FF** (nucleus is a triangulated mesh with V/A conservation). Flag for the DCM lens.

6. **Nucleus surface-area conservation:** `U_A = ½ κ_A (A−A_0)²/A_0` — DCM idiom.

7. **LINC-mimicking nucleus↔F-actin attractive tether:** harmonic attractive force on 20% of F-actin ends toward the nucleus surface. **FF map:** if/when FF couples cortex/perinuclear filaments to a nucleus compartment, this is the coupling law — a harmonic tether on a specified filament-end fraction. Fraction = **0.20**. Mostly DCM-side, but the *filament-end selection + tether stiffness* is FF state.

8. **Boundary (virial) stress observable** — this is the portable piece:
   `σ = (Σ F_component on all F-actin ends clamped to the +y boundary) / A_boundary`.
   Shear → x-component; tensile/compressive → y-component. **FF map:** FF already computes virial σ_vm; this gives the *clamped-end reaction-force* protocol for a boundary-driven rheology test (see §4). Directly implementable as an FF observable.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenarios)

**Scenario FF-CLAN-A — boundary-clamped bulk rheology (the portable harness):**
1. Assemble a cross-linked actin network in a thin periodic slab **10 × 8.66 × 0.1 µm** (PBC x,y), C_A=100 µM, R_ACP=0.1, via nucleation-with-orientation + polymerization + ACP cross-linking; **no depolymerization** (or FF-native turnover off for the elastic test).
2. Disable PBC in y; **sever filaments crossing the two y-normal faces and clamp their cut ends** to those faces.
3. Displace the **+y face at constant rate** in +x (shear), +y (tensile), or −y (compressive); −y face fixed. Strain rate 0.001 s⁻¹ to |ε|=0.05.
4. Measure `σ = Σ(force-component on +y-clamped ends)/A_face`; **network stiffness = σ/ε** (or dσ/dε) per mode.
This is a clean, self-contained FF integration test that exercises cross-linker + excluded-volume + bending physics at network scale, *decoupled from turgor/membrane/motors* — useful as a **unit-level sanity harness**, but per the native-scale rule, any *conclusion* must be reconfirmed on the full native cortex, not this reduced slab.

**Scenario FF-CLAN-B — perinuclear shell compression (mostly DCM, FF supplies the shell):**
Sphere nucleus d=5 µm frozen during assembly; assemble CLAN shell in r_N→1.1·r_N at C_A=60 µM, R_ACP=0.1; tether 20% of F-actin ends to the nucleus (LINC); compress +y face to ε=−0.2 (fig −0.5) at −0.01 s⁻¹; σ = total resist force / nucleus-boundary contact area. FF owns the shell filaments; DCM owns the meshed nucleus.

**Primary FF target = the network-stiffness anisotropy (tension ~2.4e4 > shear ~1.0e4 > compression ~0.5e4 Pa).** A correctly-built FF cross-linked network under the §4-A protocol should reproduce (i) the *ordering* tension≫shear>compression and (ii) roughly the ~2× tension/shear ratio. Physical basis stated in the paper: "deformation was hindered by the **limited extensibility of actin fibers**" — a taut cross-linked filament network is stiff in tension (pulls on inextensible fibers) and soft in shear/compression (fibers buckle, carry ~0 load; the paper explicitly counts compressive fiber force as zero in its stress coloring). This is a strong nonaffine-network signature and a good discriminator of whether FF's excluded-volume + cross-linker + bending stack is behaving.

## 6. RISKS / caveats

- **Regime: passive, motor-free, in-vitro-like.** These sims have **no myosin, no ATP, no depolymerization** — a frozen self-assembled elastic network strained quasi-statically. FF's living cortex is motor-driven, turnover-active, turgor-pressurised. Use scenario FF-CLAN-A as a **decoupled elastic unit-test only**; do NOT read its σ values as cortical tension γ, and do NOT relax FF's physiological-baseline rule to match it. Any native-cell conclusion re-runs on the full compartment stack.
- **Cell type mismatch: GTM3 (transformed glaucomatous trabecular meshwork), not MCF7.** CLANs are a TM-specific pathological structure; the whole-cell moduli (~4 kPa CLAN+) are TM cells on glass, not MCF7. Treat AFM numbers as *cross-check magnitude* only, not FF calibration targets. The network-rheology numbers are geometry/parameter-driven (C_A, R_ACP) and are more transferable than the cell-type-specific AFM values.
- **Force constants absent from this PDF.** κ_s, κ_b, κ_r, κ_V, κ_A, Δt, ζ are in Supplementary Materials + refs 33–36. **Never register a κ citing p45.** If FF needs Kim-lab κ values, pull refs 33 (Soft Matter 2017), 34 (Comput Part Mech 2015), 35 (PLoS Comput Biol 2009), 36 (Nat Commun 2016) directly.
- **Coarser than FF — don't downgrade.** Their integrator is forward-Euler; their ACP is a fixed harmonic link (no Bell–Evans in these runs); their bending is plain harmonic. FF's BAOAB + Bell–Evans off-rate + Hill/Stam–Hocky motors are strictly more mechanistic. Adopt only the *scenario/protocol/parameter* content, not the reduced physics.
- **2D-favoring lattice box.** Domain y = 8.66 µm = 5√3 makes the box commensurate with a **triangular lattice** — their CLAN geometry is partly imposed by box choice. FF should let the lattice **emerge** from nucleation-orientation + cross-linking rather than hard-coding a triangular mesh; if FF cannot self-assemble the triangulated hub-spoke motif, that is itself a finding.
- **Nucleus is a sphere (paper's own caveat).** V/A-conserving meshed sphere, d=5 µm — a DCM object; real nuclei are ellipsoidal. The 6200/3200/2300 Pa ladder is a DCM validation target, not FF.
- **Best genuine mechanism (fragmentation-driven contraction) is in ref 33, not here.** If the goal is FF's contraction/stress-relaxation open problem, p45 alone is thin — chase ref 33.
