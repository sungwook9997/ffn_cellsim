# FF lens — p13

**Paper:** Saraswathibhatla, Rabbi, … Taeyoon Kim, Chaudhuri (2025) — *Swirling motion of breast cancer cells radially aligns collagen fibers to enable collective invasion.* bioRxiv 10.1101/2025.01.31.635980. **NOT peer-reviewed (preprint) — flag verdict before KB-citing.**

**One-line for FF:** The computational core is a **Taeyoon-Kim-lab agent-based Brownian-dynamics semiflexible-fiber network with Bell's-law slip-bond crosslinkers** — i.e. an independent, fully-specified Cytosim-class engine that is a *direct structural twin of FF's collagen/Mikado + cross-linker side*. It gives us (a) a ready-made cross-check oracle with a complete published parameter table, and (b) one strong new **emergent mechanism + validation scenario**: **negative normal stress** (shear → contractile radial stress) reproduced in an **annular dipole-shear geometry** that maps cleanly onto the FF cortex/ECM confinement problem.

## 1. MECHANISMS to adopt

### M1 — Negative normal stress as an EMERGENT network observable (highest-value lever)
- **FF module:** filament network mechanics (cortex + collagen-Mikado ECM), no new code — it *emerges* from the existing semiflexible-beam + crosslinker potentials FF already has.
- **What it is:** in a fibrous (col1/fibrin/actin-semiflexible) network, applied **shear** generates a **contractile (negative) normal stress of magnitude comparable to the shear stress** (Janmey 2007, this paper's ref 24). Physically: under shear, ~50% of fibers go into tension and pull inward; because semiflexible fibers are far softer in compression (buckle) than in tension, the tension-carrying subset dominates and the network contracts along the gradient direction. HP col1 acIPNs and IBC tissue show |normal| ≈ |shear|; healthy tissue shows *positive* normal stress.
- **Why it beats current FF handling:** FF currently has no validated *shear→normal-stress coupling* test. This is a first-principles emergent signature that FF's bending-beam + Bell-Evans network SHOULD reproduce with zero new mechanism — a powerful falsification test of the FF network's nonlinear-elastic fidelity. If FF's cortex does NOT show negative normal stress under shear, its buckling/tension-asymmetry is wrong. It directly probes the "buckling/condensation symmetry-breaking" and "network contraction & stress relaxation" open problems.
- **Concrete adoption:** run FF's existing cortex/ECM patch under parallel-plate simple shear at 20% strain amplitude and measure the first normal-stress difference σ_normal vs σ_shear. Target: |σ_normal| ≈ σ_shear (sign negative) for a col1-like semiflexible network; the ~50/50 stretch/compress fiber split (Fig. 4g) is the microstructural check.

### M2 — Bell's-law slip-bond crosslinker with a compression cutoff (kinetic refinement)
- **FF module:** cross-linkers (α-actinin, filamin) — Bell-Evans off-rate.
- **Change:** adopt the paper's *piecewise* off-rate that is **only force-accelerated under tension**, held at the base rate under compression (Eq. 9 below). FF's current Bell-Evans applies `k_off = k_off0·exp(F/F_b)` on |F|; this paper is explicit that for a crosslinker arm, unbinding accelerates **only when the arm is stretched (r ≥ r0)**; compressed arms sit at the zero-force base rate. This is the mechanistically-correct slip bond (compression does not load the bond off its ligand) and is cheap to add.
- **Why it beats current:** removes a spurious compression-driven unbinding channel; matters for cortex under confinement where many links are transiently compressed.

### M3 — Cylinder (rod-element) drag, length-dependent (integrator fidelity)
- **FF module:** integrator / per-particle drag ζ.
- **Change:** use the Clift cylinder-drag form (Eq. 5) `ζ = 3πμ·r_c·(3 + 2·r0/r_c)/5` so drag scales with **element length r0 and diameter r_c**, rather than a per-bead constant. Matters because FF's grid-drag / crawl-speed problem (Σγ ∝ Nc) is a drag-model artifact; a physically-grounded per-element cylinder drag is the mechanistic anchor to compare against.
- **Caveat:** this is a *dev cross-check*, not necessarily a supersede — FF's drag must stay tied to the physiological cytoplasm viscosity (65 Pa·s MCF7), NOT the paper's elevated μ=8.6 Pa·s (see Risks).

### M4 — Annular dipole-shear loading protocol as an FF self-organization scenario
- **FF module:** ECM collagen scenario driver + cortex boundary loading.
- **Change:** reproduce the paper's **annular geometry + dipole-mode boundary shear** (see §4) as an FF scenario: tangential (swirling) forcing on an inner boundary produces *radial* contractile deformation that *propagates farther* than the tangential (dipole-localized) deformation, driving **radial fiber alignment (TACS-3)**. This is a clean emergent symmetry-breaking / self-organization test at OUR single-cell-adjacent scale (inner radius 50 µm ≈ spheroid; but the mechanism is scale-free and applies to a single-cell cortex-ECM interface).

## 2. FORCE LAWS / KINETIC SCHEMES to port

**Overdamped Langevin / Brownian dynamics (Eq. 3):**
```
F_i − ζ_i·(dr_i/dt) + F_i^T = 0
```
map: `F_i` = deterministic force on element-endpoint i (stretch+bend+crosslink+repulsion), `ζ_i` = drag, `F_i^T` = thermal force. Inertia neglected (overdamped) — same regime as FF's BAOAB high-friction limit.

**Fluctuation–dissipation (Eq. 4):**
```
⟨F_i^T(t)·F_j^T(t)⟩ = (2·k_B·T·ζ_i/Δt)·δ_ij·δ
```
white-noise variance ∝ drag·temperature/Δt. Direct analogue of the FF BAOAB noise term; use to cross-check FF's noise amplitude normalization.

**Cylinder drag (Eq. 5):**
```
ζ_i = (3π·μ·r_c,i / 5)·(3 + 2·r0,i / r_c,i)
```
`μ` medium viscosity, `r_c,i` element diameter, `r0,i` element length. → FF per-segment drag.

**Explicit Euler update (Eq. 6):**
```
r_i(t+Δt) = r_i(t) + (1/ζ_i)·(F_i + F_i^T)·Δt
```
(FF uses constrained BAOAB — higher-order; Euler here is only the oracle's integrator.)

**Extensional (stretch) harmonic (Eq. 7):**
```
U_s = ½·κ_s·(r − r0)²   →   F = −κ_s·(r − r0)
```
map: fiber segments (`κ_s,f`), crosslinker arms (`κ_s,xl`), boundary springs (`κ_s,bnd`). Same Hookean stretch FF uses.

**Bending harmonic (Eq. 8):**
```
U_b = ½·κ_b·(θ − θ0)²
```
`θ0,f = 0` (intrinsically straight fiber). map: FF actin bending κ. Note this is an **angular** stiffness (units N·m), directly usable as the FF bending-modulus datum for a collagen fiber.

**Bell's-law crosslinker unbinding (Eq. 9) — the kinetic scheme to port (M2):**
```
k_−,xl = k0_−,xl · exp( λ_−,xl · |F_s,xl| / (k_B·T) )   if  r ≥ r0,xl   (arm in TENSION)
k_−,xl = k0_−,xl                                        if  r <  r0,xl   (arm in compression → base rate)
```
map to FF: `k0_−,xl` = zero-force off-rate, `λ_−,xl` = Bell length (bond force-sensitivity), `F_s,xl = −κ_s,xl·(r − r0,xl)` = crosslinker spring force. **Key structural detail vs current FF: the exp acceleration gates on TENSION only.**

**Boundary loading (dipole mode) — the shear protocol:**
- Inner-boundary endpoint rotates CW if `((initial CCW angle from +x) mod 60°) < 30°`, else CCW. → dipole shear pattern.
- Rotate binding point **0.001°/timestep** until any attached fiber tension exceeds **100 pN**, then hold.
- Only the **dipole** mode reproduces experiment; stochastic (CW/CCW 50/50) and uniform (all-CCW) modes fail. → the dipole (alternating-sign, cell-pair) forcing is the mechanistically-required boundary condition.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce (FF scenario)

**Scenario: "annular swirl-shear → radial fiber alignment (TACS-3)"**
- **Geometry:** 3D slab confined between two concentric cylinders — outer R=200 µm, inner R=50 µm, height 1 µm (quasi-2D). Two z-boundaries confine. (For a single-cell FF variant, shrink the inner radius to a cortex/cell radius ~7.5 µm; the mechanism is scale-free.)
- **Assembly:** nucleate + polymerize fibers to ⟨L⟩≈1 µm (grow, no depoly), density C_f≈2.85/µm³; bind crosslinkers (site pitch 100 nm, ratio ~5.72 xl/fiber) via k₊,xl. Fiber endpoints within 1 µm of either cylinder bind irreversibly (k₊,bnd) with tether κ_s,bnd; cylinder + z boundaries repel crossing elements (κ_r,bnd).
- **Loading:** outer-boundary endpoints fixed; inner-boundary endpoints **rotate in dipole mode** (see §2) at 0.001°/step until tension >100 pN. This is *shear* applied tangentially at the inner boundary.
- **Observable evolution:** radial contractile deformation propagates outward (small decay exponent), tangential deformation stays dipole-localized (large exponent), fibers reorient radially → radial alignment index rises.
- **Also a plain shear-rheology harness:** parallel-plate simple shear at 20% strain amplitude → measure normal stress (M1).

**Necessity controls to replicate (mechanism dissection):** (i) no-crosslink / low-connectivity → radial deformation decays as fast as tangential (loses distal propagation); (ii) only dipole BC works — stochastic/uniform shear does not produce net radial alignment.

## 6. RISKS / caveats

- **Preprint, not peer-reviewed.** Set KB verdict to CHECK; do not register as an OK-verdict empirical constant. The fiber-model parameters are *model* values (Kim-lab BD), so they belong as a **model-contract cross-check reference**, never as physiological anchors.
- **Collagen ECM, not actin cortex.** κ_s,f, κ_b,f, xlinker rates are tuned for a **col1 network**, not the actomyosin cortex. Do NOT overwrite FF's lit-anchored actin values (α-actinin k_off0=0.066 s⁻¹ Ferrer 2008; ℓ_p=17 µm; Ferrer link_k 4.6e5/8.2e5). Use these numbers ONLY for the FF **collagen/Mikado ECM side** and as parity oracles.
- **Elevated μ=8.6 Pa·s.** The oracle's viscosity is a numerical convenience (elevated to damp the explicit-Euler network), NOT physiological. FF must keep the **65 Pa·s MCF7 cytoplasm** physiological baseline; the drag *form* (Eq. 5) is portable, the *number* is not.
- **Explicit Euler, Δt=4×10⁻⁴ s.** Lower-order than FF's constrained BAOAB. Parity checks must compare *converged* states/observables, not step-by-step trajectories; do not import Δt.
- **Quasi-2D 1-µm slab + coarse ⟨L⟩=1 µm fibers.** The oracle is deliberately coarse. Per the NATIVE-scale HARD rule, any FF *conclusion* (e.g. "FF reproduces negative normal stress") must be reconfirmed at native cortex scale (38000 fil, Nc≈266k, `--from-resting`, full compartments), not at the oracle's coarse slab. The oracle is a cross-check target, not a scale to run FF at.
- **Scale of the annular scenario.** Inner R=50 µm is a *spheroid* surrogate (multi-cell), above FF's single-cell scale. Keep FF's port at single-cell fine-grained scale — apply the *mechanism* (shear→negative-normal-stress→radial alignment) to a single-cell cortex–ECM interface (inner R ~ cell radius), not by simulating a 100-µm spheroid. The physics (negative normal stress) is scale-free; only run what FF is scaled for.
- **Dipole-BC specificity.** The result that *only* dipole (alternating-sign cell-pair) shear works, not stochastic/uniform, is a boundary-condition finding tied to E-cadherin-coordinated swirling — it is a *forcing pattern* to impose in a scenario, not an intrinsic FF mechanism. Don't over-read it as a network property.
- **No magic-number leakage.** The 100 pN tension cap and 0.001°/step rotation are *protocol* knobs of the oracle, not physics; if reproducing the scenario in FF, derive the loading from a physiological cell traction/velocity, not by copying these convenience values to make an alignment gate pass.
