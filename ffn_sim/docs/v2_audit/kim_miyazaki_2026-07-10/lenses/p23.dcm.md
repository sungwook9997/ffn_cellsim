# DCM lens — p23

**Paper:** Yamamoto & Miyazaki (2026), "Optical Control of Actin Network Assembly on the Supported Lipid Bilayer." Bio-protocol 16(8): e5656. DOI 10.21769/BioProtoc.5656.
**Type:** wet-lab in-vitro reconstitution + optogenetics **protocol** (companion method of Nat Commun 2025, DOI 10.1038/s41467-025-62653-6).

## Verdict up front (relevance to DCM ≈ 1/5)

This is a **purified-protein, flat supported-lipid-bilayer (SLB), 2D branched-actin assembly protocol**. It contains **no governing equations, no force laws, no rate constants, no constitutive model, and no continuum/surface-mesh content**. DCM is a closed triangulated surface-mesh continuum cell (SimuCell3D physics on Warp). There is **no mechanism here that can be ported to a DCM force/module as written** — the system is molecular (single-filament Arp2/3 nucleation) and geometrically flat (an infinite planar bilayer, not a cell-sized closed shell). Everything DCM-adjacent is **conceptual scenario/validation framing**, not an importable mechanism or parameter. What FF (the fine-grained Cytosim engine) would model, DCM abstracts into a lumped cortex `γ` — so this paper is squarely in FF's lane, not DCM's. I record below only what is honestly adaptable, and flag the rest as non-portable.

---

## 1. MECHANISMS to adopt

Nothing directly. The paper's core mechanism (light-gated iLID–SspB recruitment of an NPF → local VCA surface density → Arp2/3-branched polymerization; profilin suppresses bulk nucleation; capping protein bounds filament length) lives entirely below DCM's coarse-graining. DCM does not resolve individual filaments, branches, or NPF molecules; it carries a **lumped surface tension `γ`** on the cortex layer. Two weak conceptual hooks only:

- **(Conceptual, cortex-γ generation lever — do NOT implement from this paper.)** The paper establishes empirically that **actin network density scales monotonically with NPF (VCA) surface density**, and NPF surface density is the tunable input (via light intensity 0.04–0.18 nW/µm² or DGS-NTA(Ni) mol fraction). DCM's open `γ`-generation problem currently uses the pressure-borne closure `γ = ΔP·R/2`. This paper *reinforces* the intuition that cortex mechanical output is set by an areal density of an upstream regulator — but it gives **no density→tension conversion**, so it cannot supply the missing `γ(ρ_actin)` law. The actual density→tension datum, if it exists, is in the Nat Commun companion [30], not here. **Do not register a `γ` law from this paper.**
- **(Conceptual, reversible actuation scenario.)** The system's headline feature — polymerization halts instantly when light is turned off, and is spatially patternable — is a clean analog of a **time-varying, spatially patterned cortical-tension boundary condition**. If DCM ever wants a "myosin/cortex modulated in a patch of the surface then released" scenario (relevant to bleb, cytokinetic-ring, confinement studies), this paper is a real-world existence proof that such patterned on/off cortex actuation is physical. That is a *scenario idea*, not a mechanism to code.

**Why it does not beat what DCM does now:** DCM's `γ = ΔP·R/2` is a physiological-baseline closure with a real number (interphase ≈0.15 mN/m). This paper offers no competing closed form and no MCF7-relevant tension number, so there is nothing to substitute.

## 4. GEOMETRY / PROTOCOL to reproduce

**Not usable as a DCM scenario.** The protocol geometry is a **flat, effectively infinite planar bilayer** in a 10–15 µL flow cell — the opposite of DCM's closed cell-sized spherical shell (R≈7.5 µm). DCM's needed scenarios (spherical confinement BC, micropipette aspiration, AFM indentation, cytokinetic division, N≈400 aggregate compaction, durotaxis) have **no counterpart** in this assay. The Miyazaki lab's *cell-sized spherical confinement* and *cortical-tension-during-cytokinesis* work (their ref [17], Yamamoto 2021 Nat Commun) is the DCM-relevant line — but **that is a different paper**; this protocol is deliberately planar and molecular. Do not build a DCM scenario from p23.

## 5. VALIDATION TARGETS for DCM observables

**None.** The measured observables — SspB fluorescence vs light intensity, Alexa647-actin fluorescence vs intensity (transient overshoot from a reagent-**depletion** effect), network thickness vs illumination duration — are **fluorescence intensities and pillar thicknesses on a flat bilayer in a purified-protein bulk**. They are not tension, shape index, division force, ring-closure rate, compaction ratio, contact angle, or cortical flow speed. Nothing here is a number a DCM run should reproduce. (The cup-shaped apical depression at ≥0.08 nW/µm² is a **monomer-depletion artifact of a finite bulk reservoir**, not a mechanical shape instability — explicitly not a DCM morphology target.)

## 6. RISKS / caveats

- **Regime mismatch is total, not partial.** Purified in-vitro reconstitution (no membrane tension, no turgor, no myosin, no cytoplasm viscosity, no living regulation) vs DCM's physiological-baseline MCF7-like cell. Adopting any number here would **violate the physiological-baseline HARD rule** — these are assay-buffer values (A50, pH 6.5 vesicle prep, 5 µM actin), not in-vivo setpoints.
- **2D flat vs 3D closed-shell.** Thickness/density measured normal to an infinite plane cannot be mapped onto a cortex on a curved closed surface; the "~30–40 µm pillar" is not a cortex thickness.
- **Molecular vs continuum scale.** The mechanism is single-filament Arp2/3 stochastic nucleation — below DCM's ratified coarse-graining. This is FF territory; forcing it into DCM would be exactly the lumped/fine-grained category error the project forbids in reverse (here, over-resolving into a continuum module has no state to attach to).
- **Depletion artifact trap.** The transient actin overshoot/decline is finite-reservoir depletion, not a real relaxation dynamic — do not mistake it for a mechanical timescale.
- **The real value is a KB SourceEvidence pointer**, not a DCM contribution: log the Miyazaki optogenetic-actin-reconstitution method as context for the density→function line, sourced from the Nat Commun companion [30], carrying **no citable DCM constant**.

**Bottom line:** No DCM mechanism, equation, parameter, scenario, or validation target is portable from p23. Relevance is limited to a conceptual reminder that cortex mechanical output tracks an upstream areal regulator density (a `γ`-generation intuition, unquantified here) and that patterned reversible cortex actuation is physically realizable. Route this paper to the FF lens, not DCM.
