# FF lens — p23

**Paper:** Yamamoto & Miyazaki (2026), "Optical Control of Actin Network Assembly on the Supported Lipid Bilayer," Bio-protocol 16(8): e5656. DOI 10.21769/BioProtoc.5656.
**Type:** wet-lab in-vitro reconstitution PROTOCOL (companion to Yamamoto & Miyazaki 2025, Nat Commun 16:7583, DOI 10.1038/s41467-025-62653-6 — the actual data paper).

**Bottom line for FF:** This paper contains **no governing equations, no force laws, no rate constants, and no mechanistic parameters**. It is a purified-protein recipe + microscope protocol. Its value to FF is entirely as a **reconstitution SCENARIO and a set of VALIDATION-TARGET concepts** for the Arp2/3 branched-network module (lamellipodium builder), plus **stoichiometric concentration ratios** that anchor an in-vitro FF test case. Everything numeric it reports is an *experimental setup knob* (light intensity, lipid mol%), not a physics parameter. Treat as a low-impact context/scenario source, not a parameter source. The quantitative curves live in the Nat Commun companion [30] and would be sourced from there.

## 1. MECHANISMS to adopt

Honest verdict: **nothing new to graft into an FF force/kinetic module.** The paper's biology is *exactly* what FF already models — Arp2/3-branched network, profilin-suppressed spontaneous nucleation, capping-protein-limited elongation, membrane-anchored NPF (VCA) triggering nucleation. FF's `lamellipodium` architecture (Arp2/3 70°±35° angle-harmonic branch) already covers it. So the "mechanism" contribution is architectural/scenario, not a new physical law:

- **NPF surface-density → nucleation-rate coupling (membrane-bound VCA).** FF module: **Arp2/3 branch nucleation** + **membrane containment**. Currently FF triggers Arp2/3 branching as a filament-side event. This paper's central mechanistic claim is that **branch nucleation rate is set by the *2D surface density* of NPF (VCA) on the membrane** — "the increased density of VCA on the membrane… positioned in close proximity to each other… triggering actin polymerization" (lines 94–106), and "network density depends on the density of VCA domains on the lipid bilayer" (General note 1). FF value-add: make Arp2/3 nucleation-site generation a **function of a membrane-resident NPF field σ_NPF(x)** rather than a spatially uniform bulk rate. This is more mechanistic than a homogeneous branch probability and is the physically correct way to seed a lamellipodium/cortex against the membrane. WHY it beats current FF: today FF has no explicit membrane-NPF surface reservoir gating where branches appear; adding one lets cortex/lamellipodium nucleation be **spatially patterned and density-graded**, which is what actually happens at the leading edge.

- **Monomer-depletion-limited overshoot (finite G-actin pool).** FF module: **filament turnover / monomer reservoir** (ties directly to the existing biphasic-cytoplasm + reservoir + turnover work, memory `project-ff-afm-overshoot-was-artifact`). The paper reports (General note 2, Fig 5C) that at intensities ≥0.08 nW/µm² actin fluorescence **rises transiently then declines** — a *depletion effect*: local polymerization consumes the finite G-actin pool faster than it is replenished, producing a "cup-shaped apical depression" / apical-high basal-low z-gradient. WHY relevant: this is a clean qualitative check that FF's **finite monomer reservoir + diffusive replenishment** produces the correct **transient-overshoot-then-plateau/decline** signature under strong localized nucleation, rather than unbounded growth. If FF's lamellipodium grows monotonically forever under sustained NPF, the reservoir coupling is wrong. This is a behavior to *reproduce*, not a parameter to import.

- **Capping + profilin as the density/mesh regulators (already in FF — confirms roles).** Profilin suppresses *spontaneous/bulk* nucleation (biases nucleation to Arp2/3-templated, barbed-end); capping protein limits elongation and thereby sets branch density / mesh size (lines 106–108). Confirms FF's existing capping + profilin channels are the right knobs for **network density**; no new law, but validates that mesh size should be tuned via **capping rate**, not filament length caps.

## 2. FORCE LAWS / KINETIC SCHEMES to port

**None.** The paper states no rate constant, no off-rate, no force–velocity, no branch-angle distribution, no unbinding spectrum. The only quantitative "law" is the empirical monotonic (and saturating) relation between blue-light intensity and NPF recruitment / network density:

- Recruitment/density knob (empirical, NOT a physics law): network density increases monotonically with light intensity over **0.04–0.18 nW/µm²** and **saturates at ~0.18 nW/µm²** (above which control is lost — Problem 4). This maps only to an *experimental actuator*, not to any FF force term. Do **not** encode light intensity in FF; the FF-relevant abstraction is: **NPF membrane surface density σ_NPF is the control variable, and branch-nucleation rate is a monotonic-saturating function of σ_NPF.** Functional form is unspecified here (would come from companion [30]).

Nothing to transcribe symbol-by-symbol.

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce

This is the paper's real deliverable for FF — a well-specified **in-vitro branched-network geometry** that FF can run as a validation scenario (fine-grained, single-patch scale, compatible with our engine):

- **Geometry:** quasi-2D branched actin sheet nucleated on a flat membrane (supported lipid bilayer, POPC + 6% DGS-NTA(Ni)). NPF (VCA) confined to the membrane plane; network grows **outward/upward (z)** from the 2D nucleation surface. Illuminated ROIs: 25×25 µm and 37×37 µm patches.
- **Connectivity:** Arp2/3 daughter filaments branch off mothers at the membrane, barbed ends toward the growth front, capped by CP → dendritic (lamellipodium-like) mesh. Profilin channels monomers to barbed-end/Arp2/3-templated growth.
- **Control axes** (each maps to an FF sweep variable):
  1. **NPF surface density** (paper: DGS-NTA(Ni) mol% + light intensity) → FF: σ_NPF on the membrane → sets **network areal density**.
  2. **Growth duration** (paper: 10/20/30 min illumination) → FF: integration time → sets **network thickness** (grows then plateaus at ~30–40 µm in-vitro).
  3. **Illumination area/pattern** → FF: spatial NPF patterning → arbitrary network footprint.
- **FF scenario to build:** a flat membrane patch with a spatially patterned NPF field; nucleate an Arp2/3 dendritic network from it at fixed monomer pool + capping + profilin; measure areal density vs σ_NPF and thickness vs time. This is a **clean, geometry-simple test of FF's Arp2/3 branch module + finite monomer reservoir** decoupled from turgor/whole-cell confounds — a useful unit test before trusting the same module inside the native cortex.

Caveat on scale rule: this is a *supplementary in-vitro unit test*, explicitly NON-authoritative for whole-cell conclusions. Any finding must still be reconfirmed on the native 38000-filament full cell before it is reported.

## 5. VALIDATION TARGETS for FF observables

Mostly qualitative trends (the hard numbers are in companion Nat Commun [30]); usable as **shape/sign checks** for the Arp2/3 + reservoir modules:

- **Density vs NPF surface density: monotonic, saturating.** Network areal density increases monotonically with NPF recruitment and **saturates** (in-vitro saturation of SspB accumulation at ~0.18 nW/µm²). FF check: branch density should rise then plateau as σ_NPF increases — not linear-forever. (Fig 5B,C, n=6.)
- **Thickness vs growth time: increases then plateaus at ~30–40 µm.** FF check: network thickness grows with integration time and saturates (monomer/capping-limited), not unbounded. (Fig 5E,F, n=12; 10/20/30 min.)
- **Transient overshoot then decline under strong sustained nucleation** (depletion signature, ≥0.08 nW/µm², Fig 5C). FF check: with a finite monomer reservoir, local F-actin should overshoot then relax — the reservoir/turnover coupling must reproduce this, and reproduce the **apical-high / basal-low z-gradient** ("cup-shaped apical depression").
- **Reversibility:** polymerization halts promptly when nucleation trigger is removed. FF check: turning off NPF/branch nucleation should stop net growth (existing capping+depolymerization should then shrink or hold).
- **Spatial confinement with membrane-fluidity leak:** network is sharp at the ROI core but lower-density at the periphery because membrane-bound NPF diffuses beyond the illuminated edge (General note 4). FF check: if NPF is a diffusive membrane field, expect a density gradient at the pattern boundary, not a step.

No G'(ω)/G''(ω), no stress-relaxation times, no contraction rate, no motor velocity-vs-load, no buckling threshold, no explicit mesh size or exponents are reported in *this* paper.

## 6. RISKS / caveats

- **Purified in-vitro ≠ living cortex.** This is 5 µM actin + a handful of purified ABPs on a flat SLB — no myosin, no crosslinker catch-bonds, no turgor, no membrane tension, no full cytoplasm. It informs the **Arp2/3 branch + monomer-reservoir** modules ONLY; it says nothing about cortical tension γ, contraction, or motor mechanics. Do not let its concentrations override FF's physiological cortex densities (native 38000, KB-3.18 ~100/µm²) — HARD physiological-baseline rule stands.
- **2D-on-membrane vs 3D cortex.** The assay grows a network *up from* a flat bilayer; the MCF7 cortex is a thin shell wrapping a 3D cell. The density/thickness laws transfer as *module unit tests*, but conclusions must be reconfirmed in the full 3D native cortex per the native-scale rule.
- **Optogenetic actuator is not physical.** Light intensity → iLID/SspB dimerization is an experimental trick with no cellular analog. Only the **abstracted control variable (NPF membrane surface density)** is portable; never encode light or iLID kinetics into FF.
- **No parameters = no KB registration risk, but also no citable constant.** Because the paper gives no rate/force constant, there is nothing to KB-register as a KB-x.y validation constant from *this* DOI. If any number is later cited (density-vs-NPF, thickness-vs-time), it must be sourced from the Nat Commun companion [30], not this protocol, and pass the citation-integrity gate.
- **Magic-number trap.** The in-vitro concentrations are convenient assay values, not derived physiological setpoints; if used, they define an explicitly-labelled in-vitro scenario, and must not leak into a production physiological run as tuning constants.

### One-paragraph synthesis
p23 is a wet-lab protocol with zero importable physics. Its genuine FF value is (a) one architectural idea — make Arp2/3 branch nucleation a monotonic-saturating function of a **membrane-resident NPF surface density field σ_NPF**, so cortex/lamellipodium seeding is spatially patterned and density-graded; (b) a clean **in-vitro branched-network unit-test scenario** (flat membrane, patterned NPF, actin:Arp2/3:profilin:CP ≈ 200:4:600:1) that exercises FF's Arp2/3 + finite-monomer-reservoir modules in isolation; and (c) three qualitative validation shapes — density saturates with NPF, thickness grows-then-plateaus, and strong sustained nucleation gives a depletion-driven transient overshoot with an apical-high z-gradient. No new force law, no rate constant, no supersession of any existing FF value.
