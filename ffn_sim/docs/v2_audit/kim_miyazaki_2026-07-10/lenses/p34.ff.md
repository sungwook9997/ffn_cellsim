# FF lens — p34

**Paper:** Mak, Kim, Zaman, Kamm — "Multiscale mechanobiology: computational models for integrating molecules to multicellular systems," *Integr. Biol.* 2015, 7, 1093–1108. DOI 10.1039/c5ib00043b.

**Type: narrative REVIEW.** No original governing equations, no parameter table, no new simulated observables. Its value to FF is (a) as a *roadmap / citation-graph pointer* to the primary papers that DO carry FF-usable physics — several of which are exactly FF's validation-oracle sources (Taeyoon Kim, a co-author here, is the author of the Brownian-dynamics crosslinked-actin engine FF is modeled after) — and (b) as a conceptual framing of the stiffening/percolation/transient-crosslink regimes FF already lives in. Everything numeric below is second-hand and must be traced to its primary source before KB registration. I flag provenance explicitly.

---

## 1. MECHANISMS to adopt

Nothing in this paper is a *new* mechanism FF lacks — but it names, and points to the primary sources for, several mechanisms FF should either already have or wire in. Ranked by FF applicability:

1. **Crosslinker (ACP) transient-bond softening / creep / stress-relaxation — Kim/Hwang/Lee/Kamm (refs 4, 47).** The review's central actin-rheology claim: transient crosslinkers with force-dependent off-rates govern network *softening, creep, and stress-relaxation*, and a **stress-supporting sub-network emerges** — after prestrain, removing a large fraction of ACPs/actin still sustains most of the stress (Fig. 1b). FF already has Bell-Evans crosslinkers, but the emergent *load-bearing-backbone* behavior and the transient-crosslink stress-relaxation spectrum are exactly the FF observables (network contraction & stress relaxation, an open problem). **Beats current FF only in that it names the correct oracle** — the co-author's BD engine — to validate FF's crosslinker turnover against. Go read ref 4 (Kim et al., the actin+ACP BD network) for the actual rate scheme.

2. **Bending→stretching (strain-stiffening) transition of semiflexible networks (refs 4, 29 Storm, 32 Onck, 43 Huisman).** At moderate strain a crosslinked semiflexible actin network transitions from bending-dominated to stretching-dominated response → nonlinear strain-stiffening (Fig. 3, regime 2). FF represents actin as explicit bending beams (κ, ℓ_p≈17 µm) + stretch modulus, so this is a *native emergent FF prediction* — the review tells us it is the load-bearing regime for long-range force transmission and mechanotransduction, i.e. the regime FF's cortex should sit in. **Use as a validation target, not a new mechanism.**

3. **Motor-driven (non-thermal) active stiffening + motor:crosslinker percolation phase transition (ref 6-area, p.6).** Myosin II + ATP actively stiffen the network; the **motor:ACP ratio drives a percolated → disconnected phase transition**. This is a fine-grained, mechanistic lever directly relevant to FF's γ-generation and motor-driven-flow open problems: FF's Stam–Hocky minifilaments + Bell-Evans crosslinkers should reproduce a connectivity phase boundary as a function of (motor density : crosslinker density). **New FF scenario, not new mechanism.**

4. **Cation/nucleotide tuning of actin bending rigidity → network stiffening (Bidone et al., ref 30).** Bound cation/nucleotide state tunes single-filament κ, which propagates to network strain-stiffening. FF currently uses a fixed ℓ_p≈17 µm. This is a *possible* fine-grained refinement (state-dependent κ per segment) but is out of scope for the single-cell cortex baseline unless nucleotide-state actin is being modeled; **flag as optional, trace to ref 30.**

5. **Filamin A / talin force-gated cryptic-site exposure (SMD, refs 2,3,19,23).** Force unfolds talin/filamin domains → exposes vinculin-binding sites → reinforcement. This is a *clutch/adhesion* mechanism (mechanosensitive reinforcement), relevant to FF's integrin/motor-clutch layer, but the physics lives at atomistic SMD scale and enters FF only as a coarse force-gated reinforcement rule. **Not adoptable directly at FF filament scale; note the unfolding-force thresholds (§3) as clutch parameters if a mechanosensitive-reinforcement clutch is later built.**

## 2. FORCE LAWS / KINETIC SCHEMES to port

The review writes out **only** the Kim single-cell force-balance schematic (Fig. 1c, adapted from ref 110) — a *cell-scale agent* model, coarser than FF. Transcribed for completeness; **do NOT adopt as FF runtime** (it is the lumped node-agent layer FF's architectural principle rejects):

- **Linear viscous drag on an integrin node i:** `F_D,i = −C_c · v_i` (Stokes drag; C_c = node drag coefficient, v_i = node velocity in cell frame). FF already uses per-node drag derived from cytoplasm η=65.9 Pa·s — this is the same functional form, so no change; the review adds no constant.
- **Quasi-static nodal force balance:** `F_SF + F_E + F_FA + F_L + F_D = 0` per integrin node (stress-fiber + elastic + focal-adhesion + ligand + drag = 0). This is a *lumped-agent* balance; FF resolves each of F_SF/F_E/F_FA into explicit filament/motor/clutch bonds. **Explicitly out of scope** — porting it would violate the fine-grained-over-lumped hard rule. Keep only as a sanity cross-check that FF's emergent per-node force sums to ~0 in quasi-static cortex.

**No Bell/catch-bond rate law, Hill force-velocity, branching-angle distribution, or bending/stretching potential with constants is written in this paper.** All are invoked qualitatively ("slip bonds, catch bonds," "bending→extension transition," "force-dependent binding/unbinding"). Nothing to transcribe as a kinetic scheme — go to the primary refs (27 Kong, 28 Thomas/Vogel/Sokurenko for catch/slip; ref 4/47 Kim for ACP off-rate).

## 4. NETWORK ARCHITECTURE / PROTOCOL to reproduce

One FF-usable scenario, described qualitatively (protocol details live in ref 4/47 Kim BD):

- **Prestrained crosslinked actin+ACP network under oscillatory strain, with stress-bearing-subnetwork ablation (Fig. 1b).** Protocol: build a crosslinked semiflexible actin network (actin beams + discrete ACP crosslinks), apply prestrain in one axis, then oscillatory shear; measure stress vs. time. **Then ablate** — remove 25/50/75% of ACPs (or actin) and re-measure — the finding to reproduce is that a *supportive sub-network* keeps sustaining most of the stress. This is a clean FF scenario for the network-contraction / load-path question: does FF's cortex develop an emergent stress-bearing backbone that is robust to crosslinker turnover? Reconstitution geometry/density/connectivity are in ref 4, not here — **run at native filament scale, not a stripped mini-network** (per the HARD native-scale rule), or label any coarse mini-network smoke test non-authoritative.
- **Motor:ACP ratio percolation sweep (p.6).** Sweep myosin-minifilament density against crosslinker density and locate the percolated→disconnected connectivity transition. FF-native scenario for γ-generation/percolation; parameters from the primary active-gel refs, not this review.

## 5. VALIDATION TARGETS for FF observables

All are second-hand; use as order-of-magnitude context / target *forms*, not as certified oracles (trace to primaries first):

- **Strain-stiffening regime structure (Fig. 3):** stiffness vs. stress has three regimes — (1) unstressed viscoelastic, (2) intermediate-strain elastic *stiffening* (bending→stretching), (3) large-strain *softening*/fluidization. FF cortex under increasing strain (or increasing internal motor stress) should reproduce this non-monotonic K(σ) shape. **Target = the qualitative curve form + the existence of an intermediate stiffening window**, driven by crosslinker/filament kinetics.
- **Emergent stress-bearing subnetwork robustness (Fig. 1b):** after 25–75% ACP/actin ablation, most network stress is retained under oscillatory strain. FF target: load-path robustness of the cortex to crosslinker unbinding.
- **Network stress order-of-magnitude:** ~10–40 Pa at 1–6 ms oscillatory strain (Fig. 1b, ref 4) — sanity band only.
- **Motor:crosslinker percolation boundary:** existence of a phase transition (connected active-stiffening ↔ disconnected) as motor:ACP ratio varies (p.6) — target = the transition exists and is sharp.
- **Active-fluctuation correlation time ~10 s** (ref 132) — target correlation time for FF's non-thermal motor-driven cytoplasmic fluctuations, if/when validating active-noise spectra.

## 6. RISKS / caveats

- **This is a review with no primary data.** Its biggest risk is treating it as a datum source. **Do not KB-register any number from it** (300 pN, >4 pN, ~10 s, 10–40 Pa) — every one is a citation; trace to ref 2/19/132/4 and register from there, matching the citation-integrity hard rule (confirm OK verdict on the *primary* source, not this review).
- **Regime mismatch — purified in-vitro BD networks vs. living MCF7 cortex.** The rheology findings (Fig. 1b, refs 4/29/32) are reconstituted/simulated purified actin+ACP networks; FF's target is a turgor-pressurized, membrane-contained, myosin-active living cortex at its physiological operating point. The stiffening/percolation *phenomenology* transfers; the numeric bands (10–40 Pa, 1–6 ms) are for a purified system at that paper's density/frequency and must not be imposed as FF acceptance without re-deriving at FF's physiological density (~100/µm², R=7.5 µm) and cytoplasm η.
- **Scale mismatch — Fig. 1c is a lumped cell-agent model.** Porting its `ΣF=0` node balance or `F_D=−C_c v` as an FF *runtime* would violate the fine-grained-over-lumped architectural principle. Use it only as a post-hoc quasi-static cross-check, never as mechanism.
- **Atomistic clutch numbers (talin/filamin) are SMD, non-equilibrium.** The unfolding forces (300 pN applied, >4 pN filamin threshold) come from steered-MD at non-physiological pulling rates; they cannot be used as equilibrium clutch off-rate constants without rate-extrapolation. Adopt only as coarse mechanosensitive-reinforcement thresholds if that clutch is ever built, flagged as SMD-derived.
- **Native-scale rule.** Any FF replication of the Fig. 1b ablation or the percolation sweep must run at the native 38000-filament cortex (or be explicitly labelled a non-authoritative coarse smoke test and reconfirmed native) — a stripped mini-network would be structurally unstable and its "subnetwork robustness" result would be an artifact.

---

**Bottom line:** p34 introduces no new FF force law, rate constant, or mechanism. Its FF worth is (1) confirming FF sits in the right physics regime (bending→stretching stiffening, transient-crosslink stress-relaxation, motor:ACP percolation), (2) supplying two clean native-scale FF *scenarios* (Fig. 1b subnetwork-ablation; motor:ACP percolation sweep) whose quantitative protocols live in co-author Kim's primary BD papers (ref 4/47) — the correct FF validation oracles — and (3) an order-of-magnitude active-fluctuation timescale (~10 s). Treat as a roadmap to primaries, not a datum source.
