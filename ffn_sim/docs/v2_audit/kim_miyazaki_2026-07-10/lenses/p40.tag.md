# TAG-validation lens — p40

**Paper:** Zhou, Jung, Farhana, Fujimoto, Kim, Yokokawa (2022) — *Durability of Aligned Microtubules Dependent on Persistence Length Determines Phase Transition and Pattern Formation in Collective Motion.* ACS Nano 16, 14765−14778. DOI 10.1021/acsnano.2c05593.

## Paper kind

**Mixed: experimental (in-vitro reconstitution) + simulation (agent-based Brownian dynamics), with method-grade analytic protocols.**

- **Experimental core** — in-vitro microtubule–kinesin-1 gliding motility assay (Yokokawa lab, Kyoto): measured persistence lengths, gliding velocity, bundle geometry, collision-outcome statistics, nematic-order/skewness trajectories. These are **overlay / cross-check targets**, never fit targets.
- **Simulation core** — agent-based Langevin/Brownian-dynamics model (Kim lab, Purdue): serially-connected cylindrical segments with extensional + bending + excluded-volume + kinesin propelling forces. Model *output* (bundle N_B, formation/disintegration times) is **comparison-only, never a truth source** — and is exactly the FF paradigm (Cytosim-style beams + motors), so it is a design/architecture reference for an FF microtubule compartment.
- **Analytic content** — Eqs 1–3 (Euler–Bernoulli clamped-free cantilever mode decomposition → persistence length via equipartition) is a genuine closed-form **measurement oracle**. Eqs 4–6 (nematic order S, skewness Sk) are analysis definitions, not physical laws. The core BD force laws (propelling force, extensional/bending/excluded-volume potentials, Table S7) live only in the SI and are **not in the provided text**.

Net: register as **parameter provenance + one candidate FF bending oracle**, not as a single-cell validation gate. The biology (MT–kinesin gliding on a coverslip, 2D collective active matter) is **not** the MCF7 single-cell mechanobiology target.

## Coverage vs existing gates

**No existing gate covers any of this.** Our validation state is single-MCF7-cell + ECM + spheroid mechanobiology (cortex tension γ, membrane/nucleus/cytoplasm moduli, FA motor-clutch, cadherin junction, Mikado ECM, necrosis zones). This paper is 2D microtubule–kinesin collective active matter on a coverslip — a different observable class entirely.

Nearest neighbors and why they do **not** match:
- **PARAM-ell_p (ell_p = 17 µm, KU-1.1)** = **type-I collagen** persistence length. The paper's Lp = 0.65–3.54 **mm** is **microtubule** persistence length — a different polymer, ~40–200× stiffer. Does **not** supersede or conflict; it is a distinct compartment (MT, not ECM fiber). Register separately if/when an FF MT compartment is built.
- **PARAM-kappa_fiber (7e-26 N·m², derived from ell_p·kBT)** — same story: this is the collagen-fiber bending modulus. MT κ = Lp·kBT ≈ (0.65–3.54e-3 m)(4.1e-21 J) ≈ 2.7e-24 – 1.5e-23 N·m² is ~40–200× larger and belongs to a separate MT parameter.
- **PARAM-F_stall_motor (2 pN, KU-2.4/2.18)** = **myosin-II** per-motor stall. The paper's 5–7 pN is **single kinesin-1** stall — a different motor. Does **not** supersede; stage as a separate kinesin parameter only if an FF MT-motor compartment is built.
- **PARAM-v_unloaded (100 nm/s, actin retrograde flow)** — unrelated to MT gliding v=601 nm/s.
- **VG-U1-mikado-topology / VG-U1-force-propagation** — ECM network alignment/nematic order, not motor-driven MT collective gliding. The nematic-order parameter S (Eq 4) is a shared *metric* but the systems differ.

## New gate candidates

**None proposed at OUR single-cell scale.** Per philosophy, a gate must be a real measurable observable with a defensible band **at our scale**. Every observable here is either (a) a 2D collective active-matter emergent statistic (nematic order, bundle geometry, phase-transition timing) with no counterpart in the single-MCF7-cell or spheroid engines, or (b) a molecular parameter better registered as a Parameter row than a gate. Fabricating a "MT collective nematic order" gate would be a contract with no engine to run it and no MCF7 relevance — declined.

## Oracle candidates

**One genuine candidate — the persistence-length-from-mode-variance oracle (Eqs 1–3).**

Euler–Bernoulli clamped-free (cantilever) beam: expand a fluctuating clamped filament's transverse shape y(s) in beam normal modes W_n (Eq 2), then by equipartition each mode amplitude variance gives

  **Lp = (1/var(a_n)) · (L/q_n)^4**,  with q_n = 1.875, 4.695, 7.855, (n−0.5)π for n=1,2,3,≥4 (Eq 3).

This is a standard, well-founded thermal-fluctuation → bending-rigidity closed form. It is a valuable **FF-engine cross-check** (an analytic oracle in the spirit of our existing Helfrich κL/2R² and κq⁴ bending oracles): clamp a simulated FF beam at one end, record tip/mode fluctuations under the BAOAB thermostat, extract Lp via mode-amplitude variance, and confirm it recovers the input κ/kBT. This directly extends the existing FF bending-rigidity validation (κq⁴ spectrum oracle) to the **cantilever geometry** and is worth implementing as a self-consistency verification. **Flag: candidate, PI-gate review** (it would be a verification oracle config, not an experimental gate).

Not oracle-worthy: Eq 4 (nematic order S) and Eqs 5–6 (skewness Sk) are image-analysis metric definitions, not physical laws — useful as measurement protocols if we ever quantify FF filament alignment, but they are not ground-truth cross-checks. The BD force laws (propelling force, potentials, Table S7) are SI-only and absent from the provided text, so no oracle can be extracted from them here.
