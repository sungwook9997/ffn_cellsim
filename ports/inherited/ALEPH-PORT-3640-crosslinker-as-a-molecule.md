## 0. What is wrong, in one line

**Aleph's cortical crosslink is not a molecule.** It has a stiffness and nothing else: its *reach*
is `CROSSLINK_CAPTURE_SPACINGS (= 2.2) × mean nearest-neighbour spacing`
(`cortex_surface_coupling.py:363`) — a **geometric consequence of the placement rule** — and its
rest length is whatever distance happened to exist when the builder ran.

Measured at ρ = 8: links **462 nm** long on average, 726 nm at the tail, against α-actinin's 35 nm
and filamin's 158 nm. **The links are 1.5× longer than the filaments they join.** Partners per
filament: 20.19, against a physiological 3–6.

This is the same class of error as the filament *count* being the mesh's, which
`filament_areal_density_per_um2` was introduced to fix. Nobody looked at the crosslink side.

## 1. The reach is not an axis, and that is the deeper problem

`docs/design/AXIS_REGISTRY.md` declares **125 axes** and states its own purpose:

> *"the join between a literature study and a sweep: both read the same list, so evidence gathered
> from papers and evidence generated by simulation land on the same coordinates and can be combined
> later."*

`Crosslink.stiffness_pn_per_um` is row 26, class `axis`, scale `log`. **The reach has no row**,
because it is not a field anyone sets — it is computed. A derived value cannot be swept, cannot
carry a prior, and cannot receive evidence from a paper.

**And it is the axis that matters most.** Measured on the 4090 (job 30), at fixed density, sweeping
the reach moves the relaxed areal modulus by **10⁵** while the affine modulus moves by **1.02**.
Nothing else measured in this project has that leverage.

So the first half of this port is not physics, it is bookkeeping: **make the reach a declared
material parameter so it can be an axis.** `docs/decisions/PROPOSAL-the-engine-must-work-before-a-sweep-means-anything.md`
calls this condition W-1.

## 2. What is imported, exactly

From `ffn_sim.ff.hand_kmc`, whose own docstring says *"Hand kinetic layer — KMC binding / stepping /
unbinding (NF2007 §10.1, grounded)"* and *"A **Hand** (Cytosim's term) is the binding element of a
motor or crosslinker"*:

| symbol | what it is |
|---|---|
| `HandParams` | the declaration: `name, k_on, capture_radius_um, p0, f0, v_max_um_s, f_stall, catch_slip, cs_*, link_k` |
| `ALPHA_ACTININ` | ε = **60 nm**, `link_k` = **4.6e5 pN/µm** — Ferrer 2008 PNAS AFM, 455 pN/nm |
| `FILAMIN` | ε = **60 nm**, `link_k` = **8.2e5 pN/µm** — Ferrer 2008 PNAS, companion; Pereverzev catch–slip |
| `NMIIA_MYOSIN` | ε = 210 nm, `v_max` = 0.2 µm/s — Kovács 2003, Veigel 2002, Stam-Hocky 2015 |
| `bell_off_rate`, `pereverzev_off_rate`, `bell_f0_from_x_beta` | the two grounded off-rate laws, for the kinetic stage that follows |

Verified importable from **this project's own interpreter** with only `sys.path` extended
(`/Users/sw1/miniconda3/envs/aleph/bin/python`, never the `ffn_sim` env). Transitive imports are
exactly `ffn_sim.ff.units` and nothing else.

**The presets are the point.** The module states *"Parameter presets are LITERATURE-ANCHORED (none
invented)"*, and this lane had already reported the single-molecule stiffness as **unsourced for all
three molecules** and raised it as needing a PI decision. **That report was wrong** — the numbers
exist, with a paper and a prior approval date attached, and the correction is recorded here rather
than quietly absorbed.

## 3. What is NOT imported

- **The KMC time integration.** `HandPopulation`, `attach_probability`, `detach_probability` and the
  stepping loop stay behind. Binding and unbinding are a *kinetic* layer that runs on top of a
  mechanical solve, and Aleph's cortex has no time integration of its own to run them on. Importing
  them now would put a rate law next to a solver that cannot advance it.
- **`link_k` as a fixed value.** See §4.
- **Any Cytosim source.** No Cytosim binary was built or read by this lane. The lineage is
  Cytosim → NF2007 → the provider's Python → this seam, and only the last arrow is code.

## 4. The imported stiffness is a **prior**, not a value

The PI, 2026-08-06 17:41 KST: *"근데 이것들도 파라미터 스왑에 있는 것들 아님?"* — and yes.

`Crosslink.stiffness_pn_per_um` is already declared `axis / log` in the registry with its prior range
column **deliberately empty**, waiting for exactly this. So Ferrer 2008's 4.6e5 and 8.2e5 do not
*replace* the axis; they **populate its prior**, which is what the registry says the join is for.

Aleph's current default is **50 pN/µm**. The imported anchor is **9,200× stiffer**. That is not a
number to swap in silently — it is a prior whose consequences are measured, and the provider's own
comment warns about them: *"crosslink_turnover still over-stretch at this stiffness"*.

**Two axes, then, not two constants:**

| axis | today | after |
|---|---|---|
| `Crosslink.stiffness_pn_per_um` | `axis`, prior empty, default 50 | `axis`, prior anchored at 4.6e5–8.2e5 (Ferrer 2008) |
| crosslinker **reach** | **not an axis** — derived as `2.2 × spacing` | `axis`, prior anchored at 60 nm (both molecules) |

## 5. The rule that changes

```
today      a crosslink exists for every filament pair within 2.2 x the mean spacing,
           and its rest length is that pair's closest approach, whatever it is

after      a crosslink exists IF AND ONLY IF the closest approach is within the
           crosslinker's capture radius; beyond it, there is no crosslink
```

Rest length stays the formation distance, which is the provider's choice too
(`ff/weave.py:199`) and avoids injecting a pre-stress the construction has no basis for.

**The retained control is kept.** `crosslink_capture_from_spacing_um` and
`CROSSLINK_CAPTURE_SPACINGS` remain and stay the default, because every committed cortex number was
measured on them; supplying a crosslinker **refuses** the derived path rather than silently
overriding it, so a build cannot be half of each.

## 6. The gates — written before the code

| # | Gate | Threshold |
|---|---|---|
| **C-1** | **No link beyond the molecule.** Max crosslink rest length with `FILAMIN` supplied. | `≤ 60 nm` |
| **C-2** | **The reach is an axis.** A row exists in `AXIS_REGISTRY.md` with class `axis`, and the value is a field a caller sets. | present |
| **C-3** | **The retained control is untouched.** Default arguments reproduce `K_A = 1081.819088` at ρ = 0.5, level 2. | bitwise |
| **C-4** | **The import surface is exactly the allowlist.** Nothing else from `ffn_sim` is reachable through the seam. | audited by a test |
| **C-5** | **Does the relaxed modulus now CONVERGE?** Tighten the residual by 10× and 100× at ρ = 100 with `FILAMIN`; report how far `K_A` moves. | **measured, no threshold** |
| **C-6** | **Connectivity, against physiology.** Crosslinks per filament and connected components at ρ = 100 with `FILAMIN`. | measured, no threshold |

**C-5 is the gate this port exists to answer and the one that can fail hardest.**
`PROPOSAL-the-engine-must-work-before-a-sweep-means-anything` §3 condition W-3 is currently failing
by a factor of **87** — tightening the residual from 1e-3 pN to ~1e-4 moved the relaxed modulus from
465.35 to 5.36, and it was still descending at the iteration cap. The hypothesis is that a network
held by 462 nm mean-field tethers has near-floppy modes the descent slides along forever, and that a
60 nm molecular link removes them.

**If C-5 shows the modulus still does not converge, the hypothesis is wrong** and the softness is
structural rather than a consequence of the reach — which would be a more important result than the
port, and would say the cortex needs a different solver rather than a different crosslink.

**C-6 has no threshold on purpose.** This lane has now guessed which change moves which number and
been wrong twice, and the ledger for `ALEPH-PORT-3639` records the second one.

## 7. What is NOT claimed

- **Not that the kinetics are ported.** Binding and unbinding rates are imported and unused. A
  crosslink here is still permanent once formed; nothing turns over.
- **Not that 60 nm is right for a cortex.** It is `HandParams.capture_radius_um` for both molecules
  in the provider's presets, and its provenance is the provider's, not a paper this lane read. It
  populates a prior; the axis is what gets swept.
- **Not that the stiffness anchor is safe to run at.** 9,200× the current default against an
  explicit descent is expected to be unstable, and measuring where it stops being stable is part of
  C-5 rather than a thing to route around.
- **Not that this makes the cortex physiological.** Reach and stiffness are two axes of many, and
  the filament is still three nodes with no turnover, no branching and no thermal motion.

## Amendment, 2026-08-07 — the seam was a dependency wearing a port's ledger entry

### What the guard caught

`tests/firewall/test_scope_firewall.py::test_no_module_imports_the_reference_project` was **red on
`main`**, and `aleph/vertical/crosslinker.py` — landed by this entry in `828a449` — was one of the
two offenders. The guard's stated reason is gate R1:

> *"Project Aleph must install and run with the reference project absent from disk."*

**It was red from the moment this port landed and this lane did not run it.** `tests/vertical` was
run and was green; the firewall directory was not. That is the whole of how it got in.

### The design was wrong, not the guard

The seam imported `ffn_sim.ff.hand_kmc` inside a function, behind a seven-name allowlist, with a
typed refusal when the archive was missing, and §2 of this entry argued that made it admissible.
It does not, and the counter-argument is not subtle:

**A typed refusal means Aleph *runs* without the provider. It does not mean Aleph *has* the
numbers.** A preset that only resolves on one machine is a value this repository does not possess,
and the ledger entry claiming it as a port was claiming something untrue.

The failure mode was visible before the guard found it. **The archive is Mac-only**, so the seam
refused on the GPU host and the two numbers had to be carried across by hand to run anything there
— which is the same fact the firewall states, arriving from the other direction. *Values travel;
the archive does not.*

`CLAUDE.md` §3's porting rule is unchanged by any of this and was always the answer: a port is a
re-derivation or a transcription **with a citation**, never a live reach into the archive.

### What replaced it

A table, in the module, with the provider commit and the line numbers:

| molecule | `capture_radius_um` | `link_k` [pN/µm] | transcribed from |
|---|---:|---:|---|
| `ALPHA_ACTININ` | 0.060 | 4.6e5 | `ffn_sim/ff/hand_kmc.py:129-132` @ `be0e5876` |
| `FILAMIN` | 0.060 | 8.2e5 | `ffn_sim/ff/hand_kmc.py:144-148` @ `be0e5876` |

Both `link_k` values carry the provider's own sourcing to Ferrer 2008 PNAS AFM (455 and 820 pN/nm),
and both remain **PRIORS** for the axes they populate. **No measured value changes** — these are the
same numbers every `-3640` and `-3641` result was taken at, and
`tests/vertical/test_crosslinker_is_transcribed.py` now pins them so a silent edit is a red test.

The pin is what makes this a transcription rather than a copy: it is **refutable**. Anyone with the
archive can open that file at that commit and check every digit.
